## Java 注释

注释是写给人看的说明文字，不是写给计算机执行的程序代码。在 Java 中，**注释不会被编译器当作程序逻辑处理，也不会在程序运行时执行**。因此，注释的核心作用不是“参与运算”，而是**帮助人理解代码**。

### 注释有什么用

注释的主要作用可以概括为以下几个方面：

1. **解释和说明代码。** 注释可以说明一段代码是做什么的、为什么这样写、实现思路是什么，从而提高代码的可读性。
2. **辅助调试和排错。** 在分析程序问题时，注释可以帮助开发者快速回忆某段代码的用途，也可以临时注释掉部分代码来缩小问题范围。
3. **便于后期维护。** 程序往往不是“一次写完永远不改”，而是需要不断修改和扩展。合适的注释可以降低维护成本。
4. **生成开发文档。** Java 中的文档注释可以配合 `javadoc` 命令自动生成 API 文档，方便他人查阅和使用。

### 怎么写好注释

注释并不是越多越好，而是要写得**准确、必要、易懂**。写注释时通常应注意以下几点：

1. **注释要简洁。** 能用一句话说清楚的，就不要写成一大段空话。
2. **注释要准确。** 注释必须和代码真实含义一致，不能写错，更不能“代码改了，注释没改”。
3. **注释要有意义。** 优先解释“为什么这样写”“这样设计的目的是什么”，而不是只重复代码表面意思。
4. **注释要适量。** 不是每一行代码都必须加注释，过多注释反而会影响阅读。
5. **注释要及时更新。** 当代码逻辑发生变化时，注释也应同步修改。
6. **注释要规范。** 尤其是在团队开发中，注释格式最好保持统一，便于阅读和维护。

> **易错点**：不要写这种没有实际价值的注释，例如：`i++; // i 自增 1`。这种注释只是把代码翻译成中文，没有提供额外信息，意义不大。

### Java 中的三种注释

Java 中常见的注释有三种：**单行注释**、**多行注释**、**文档注释**。

#### 单行注释

单行注释以 `//` 开头，从 `//` 开始直到本行结束的内容都会被当作注释。

```java
// 输出欢迎信息
System.out.println("欢迎学习 Java");
```

单行注释适合写简短说明，通常用于解释某一行代码或某一个小步骤。

#### 多行注释

多行注释以 `/*` 开头，以 `*/` 结尾，中间可以写多行内容。

```java
/*
这里用于说明一段较完整的逻辑：
先读取用户输入，
再进行格式校验，
最后输出处理结果。
*/
```

多行注释适合写相对完整的说明，例如某段逻辑的处理过程、注意事项等。

#### 文档注释

文档注释以 `/**` 开头，以 `*/` 结尾。它和普通多行注释长得很像，但作用不同：**文档注释主要用于生成 API 文档**。

```java
/**
 * 表示一个简单的计算器类。
 * 用于演示文档注释的基本写法。
 *
 * @author 李四
 * @version 1.0
 */
public class Calculator {
    
    /**
     * 计算两个整数的和。
     *
     * @param a 第一个整数
     * @param b 第二个整数
     * @return 两个整数的和
     */
    public static int add(int a, int b) {
        return a + b;
    }
}
```

文档注释通常写在：

- 类上
- 方法上
- 构造方法上
- 成员变量上

它可以配合 `javadoc` 命令自动生成结构化文档。

#### 文档注释中的常见标签

文档注释中可以使用一些特殊标签，用来描述更明确的信息。常见的有：

- `@author`：作者
- `@version`：版本
- `@param`：方法参数说明
- `@return`：返回值说明
- `@throws`：可能抛出的异常说明

例如：

```java
/**
 * 判断一个整数是否为偶数。
 *
 * @param num 要判断的整数
 * @return 如果是偶数返回 true，否则返回 false
 */
public static boolean isEven(int num) {
    return num % 2 == 0;
}
```

#### `javadoc` 命令

Java 提供了 `javadoc` 命令，用来根据**文档注释**自动生成 API 文档。下面先看一段示例代码：

```java
/**
 * 表示一个学生信息类。
 *
 * @author 王五
 * @version 1.0
 */
public class Student {
    
    /**
     * 输出学生的自我介绍信息。
     *
     * @param name 学生姓名
     * @param age 学生年龄
     */
    public static void introduce(String name, int age) {
        System.out.println("大家好，我叫" + name + "，今年" + age + "岁。");
    }
}
```

如果要为这段代码生成文档，可以在命令行中进入 `Student.java` 所在目录，然后执行：

```cmd
javadoc -author -version -d doc Student.java
```

这条命令中各个参数的含义如下：

- `javadoc`：表示调用 Java 的文档生成工具
- `-author`：把文档注释中的作者信息也生成到文档中
- `-version`：把文档注释中的版本信息也生成到文档中
- `-d doc`：指定输出目录为 `doc`，生成的文档会放到这个文件夹中
- `Student.java`：表示要为哪个 Java 源文件生成文档

执行完成后，当前目录下通常会生成一个名为 `doc` 的文件夹。打开该文件夹中的 `index.html`，就可以在浏览器中查看生成后的 API 文档。

## 标识符

在 Java 中，**标识符**就是程序员自己起的名字，用来给程序中的各种元素命名。例如变量名、方法名、类名、包名等，本质上都属于标识符。

Java 中的标识符可以用来标识很多程序元素，常见的有：**变量、方法、类、接口、枚举、注解、包、常量、类型参数** 等。

### 标识符命名规则

Java 中合法的标识符必须满足以下规则。

1. **标识符只能由字母、数字、下划线 `_` 和美元符号 `$` 组成。** 不能出现空格、横线、井号、感叹号等其他特殊符号。
2. **标识符不能以数字开头。** 也就是说，数字可以出现在中间或后面，但不能放在最前面。
3. **标识符不能是 Java 关键字。** 例如 `public`、`class`、`void`、`static` 等都不能直接拿来命名。
4. **标识符区分大小写。** 例如 `name` 和 `Name` 是两个不同的标识符。
5. **标识符长度原则上没有限制。** 但实际开发中应尽量做到简洁且有意义。

Java 对“字母”的支持范围比较广，不只限于英文字母。也就是说，Java 在语法层面支持使用很多语言中的文字作为标识符，例如中文理论上也是可以的。

> **补充**：虽然语法上允许使用中文作为标识符，但在实际开发中，通常仍然建议优先使用 **英文** 命名，这样更统一，也更利于团队协作和代码维护。

> **易错点**：单独一个下划线 `_` 在现代 Java 中**不能作为标识符单独使用**，这一点和“可以包含下划线”不是一回事。

### 标识符命名规范

命名规则解决的是“**能不能这样写**”，命名规范解决的是“**这样写好不好**”。也就是说，一个名字即使语法上合法，也不一定符合实际开发中的书写习惯。Java 中常见的命名规范如下。

| 标识内容                     | 命名规范                                                     | 示例                         |
| ---------------------------- | ------------------------------------------------------------ | ---------------------------- |
| 类名、接口名、枚举名、注解名 | **大驼峰命名法**：每个单词首字母大写                         | `StudentService`、`UserInfo` |
| 变量名、方法名               | **小驼峰命名法**：第一个单词首字母小写，后面每个单词首字母大写 | `studentName`、`doLogin`     |
| 常量名                       | **全部大写**，多个单词用下划线连接                           | `MAX_SIZE`、`LOGIN_SUCCESS`  |
| 包名                         | **全部小写**                                                 | `com.test.demo`              |

此外，命名时还应遵循一个非常重要的原则：**见名知意**。也就是说，看到名字，最好就能大致猜出它表示什么。

例如：

- `a`、`b`、`c` 这种名字通常可读性较差
- `studentName`、`orderCount`、`printMessage` 这种名字可读性更好

## 关键字

在 Java 中，**关键字**是语言本身事先规定好的、具有**特殊含义**的单词。它们不是程序员随便起的名字，而是 Java 语法的一部分，用来表示特定的结构、功能或控制逻辑，例如定义类、声明类型、控制流程、处理异常、限定访问权限等。

也正因为关键字本身已经被 Java 赋予了固定含义，所以它们**不能再被当作标识符使用**。也就是说，不能拿关键字去给类、变量、方法、包等重新命名。

关键字的作用，本质上是帮助 Java 组织程序的语法和逻辑。不同类型的关键字负责不同的功能：

| 类别               | 关键字举例                                                   |
| ------------------ | ------------------------------------------------------------ |
| **基本数据类型**   | `byte`、`short`、`int`、`long`、`float`、`double`、`char`、`boolean` |
| **流程控制**       | `if`、`else`、`switch`、`case`、`default`、`for`、`while`、`do`、`break`、`continue`、`return` |
| **访问控制**       | `public`、`private`、`protected`                             |
| **类与面向对象**   | `class`、`interface`、`enum`、`extends`、`implements`、`new`、`this`、`super`、`instanceof` |
| **修饰与特性相关** | `abstract`、`final`、`static`、`native`、`strictfp`、`synchronized`、`transient`、`volatile` |
| **异常处理**       | `try`、`catch`、`finally`、`throw`、`throws`                 |
| **包与导入**       | `package`、`import`                                          |
| **其他**           | `assert`、`void`、`const`、`goto`                            |

> **注意**：`const` 和 `goto` 虽然出现在 Java 的保留字列表中，但在实际 Java 编程中**并没有真正对应的正常使用场景**。学习时先知道它们**不能拿来命名**即可。

## 字面量

在 Java 中，**字面量**就是在程序中**直接写出来的数据**。它不是变量，不需要先定义，也不需要经过额外计算，写出来就表示某个确定的值。

例如：`10`、`3.14`、`true`、`'a'`、`"Hello"`。这些都属于字面量。

Java 中常见的字面量主要有以下几类：

| 类型               | 示例                            |
| ------------------ | ------------------------------- |
| **整数型字面量**   | `10`、`-5`、`0`、`100`          |
| **浮点型字面量**   | `3.14`、`-0.5`、`1.0`           |
| **布尔型字面量**   | `true`、`false`                 |
| **字符型字面量**   | `'a'`、`'1'`、`'国'`            |
| **字符串型字面量** | `"Hello"`、`"Java"`、`"你好呀"` |

这里要特别区分 **字符型** 和 **字符串型**：

- **字符型字面量** 必须使用 **单引号** 括起来，并且单引号中**只能有一个字符**
- **字符串型字面量** 必须使用 **双引号** 括起来，双引号中可以有一个字符、多个字符，甚至可以是空字符串

例如：

- `'a'` 是字符型字面量
- `"a"` 是字符串型字面量
- `'ab'` 是错误写法
- `"ab"` 是正确的字符串型字面量

> **补充**：像 `'\t'` 这样的写法虽然看起来由两个符号组成，但它表示的是一个**转义后的单个字符**，因此它仍然是字符型字面量。

### 加号运算符 `+`

在 Java 中，**加号 `+`** 有两个作用：

1. **求和**
2. **字符串拼接**

判断规则并不复杂，核心只要记住一句话：**只要 `+` 两边有一边是字符串，`+` 就执行字符串拼接；其它情况下，`+` 执行求和。**

例如：

- `5 + 6` 是求和，结果是 `11`
- `"5" + "6"` 是字符串拼接，结果是 `"56"`
- `"5" + 6` 也是字符串拼接，结果是 `"56"`

Java 表达式在没有括号干预时，通常按照**从左到右**的顺序计算；如果有小括号，则**先算括号里面**。

例如：

- `"5" + 6 + 7` 会先得到 `"56"`，再得到 `"567"`
- `"5" + (6 + 7)` 会先算括号里的 `6 + 7`，得到 `13`，最后结果是 `"513"`

## 变量

在 Java 中，**变量**可以理解为一个“用来存放数据的盒子”。但更准确地说，变量本质上是**内存中的一块有名字的存储空间**，程序可以通过这个名字去访问其中保存的数据。

一个变量通常包含三个核心要素：

1. **数据类型**：决定这个变量可以存什么类型的数据，以及通常需要多大的存储空间。
2. **变量名**：也就是这块空间的名字，只要符合标识符命名规则即可。
3. **变量值**：这块空间当前实际存储的数据。

例如：

```java
int age = 20;
```

这行代码表示：

- `int` 是数据类型，表示这是一个**整数类型**的变量
- `age` 是变量名
- `20` 是变量当前保存的值

### 变量为什么叫“变量”

“变量”中的“变”，体现在：**变量中存放的值是可以改变的**。例如：

```
int age = 20;
age = 30;
```

第一行表示变量 `age` 的初始值是 `20`，第二行表示把它的值改成 `30`。这种操作叫做：**给变量重新赋值**。也就是说，变量名一般不变，但变量中保存的数据可以变化，这就是“变量”这个名称的由来。

需要注意的是，**给变量重新赋值时，右边的值必须和左边变量的类型保持一致**，否则就会报错。例如下面这段代码就是错误的：

```
int age = 20;
age = "30";
```

原因在于，`age` 是 `int` 类型变量，只能存放整数，而 `"30"` 是字符串，不是整数，二者类型不匹配，所以编译器会报错。

> **补充**：可以把变量理解成一个有固定类型的盒子，**什么类型的盒子，就只能装什么类型的数据**。

### 变量的作用

变量最重要的作用有两个：**提高程序的可维护性** 和 **提高程序的可读性**。

如果程序中某个数据会重复出现，直接把数字或字符串一遍遍写死在代码里，后期一旦需求变化，就要改很多地方，不仅麻烦，还容易漏改。使用变量后，只需要修改变量的值，程序中引用这个变量的地方就会自动跟着变化，因此更容易维护。

例如：

```
double price = 58.0;
System.out.println(price * 1);
System.out.println(price * 2);
System.out.println(price * 3);
```

如果后面商品单价从 `58.0` 改成了 `66.5`，只需要改一处：

```
double price = 66.5;
System.out.println(price * 1);
System.out.println(price * 2);
System.out.println(price * 3);
```

同时，像 `price` 这样的名字本身就带有含义，看到代码时，比直接看到一堆 `58.0` 更容易理解程序到底在算什么，这就是变量对可读性的提升。

### 变量的声明、赋值、访问

#### 变量的声明

变量在使用之前，必须先进行**声明**。所谓声明，就是告诉程序：要创建一个什么类型的变量，以及这个变量叫什么名字。

语法格式如下：`数据类型 变量名;`，其中：

- **数据类型**用于说明变量中可以存放什么类型的数据。
- **变量名**用于后续访问这个变量。

例如：

```java
int count;
String title;
double salary;
```

变量名只要符合 **标识符** 的命名规则即可。按照 Java 的常见命名规范，变量名通常采用 **小驼峰命名法**（camelCase），即**首字母小写，后面每个单词的首字母大写**，例如 `userName`、`studentAge`、`totalScore`。

#### 变量的赋值

变量声明之后，可以通过 **赋值运算符** `=` 给变量保存数据。

例如：

```java
count = 15;
title = "Java入门";
salary = 8500.5;
```

这里的 `=` 叫做**赋值运算符**，它的作用不是表示“左右相等”，而是表示：**将右边表达式计算出来的结果，赋给左边的变量**。

也就是说，赋值时的执行顺序是：

1. 先计算 `=` 右边的内容。
2. 再把结果保存到 `=` 左边的变量中。

例如：

```java
int result;
result = 8 + 4;
```

程序会先计算 `8 + 4` 的结果，得到 `12`，再把 `12` 赋值给变量 `result`。

> **注意**：变量的声明和赋值也可以写在同一行，这种写法非常常见。
>
> 例如：
>
> ```java
> int level = 3;
> ```

#### 变量的访问

变量的访问主要有两种方式：**读取**和**修改**。

**读取**就是把变量中保存的值取出来使用，例如输出变量的值：

```
System.out.println(变量名);
```

**修改**就是给已经存在的变量重新赋值，用新的值替换原来的值：

```
变量名 = 变量值;
```

### 变量的使用细节

#### 变量必须先赋值，才能访问

局部变量在**声明之后**，如果还没有完成赋值，就**不能直接访问**。也就是说，Java 不允许读取一个“还没有明确值”的局部变量。

例如：

```java
int score;
System.out.println(score); // 报错：变量 score 可能尚未初始化
```

这段代码中，`score` 虽然已经声明了，但还没有赋值，因此程序不知道它当前到底应该保存什么值，所以会直接报错。

#### 变量必须先声明，后访问

方法体中的代码遵循**自上而下、逐行执行**的顺序。程序执行到某一行时，只能使用前面已经声明过的变量，不能先访问、后声明。

例如：

```java
System.out.println(price);
int price = 50;
```

这段代码会报错，因为程序执行到 `System.out.println(price);` 这一行时，变量 `price` 还没有声明，程序根本不知道 `price` 是什么。

#### 一行可以声明多个同类型变量

在一行代码中，可以同时声明多个**相同数据类型**的变量。

例如：

```java
int x, y, z = 500;
```

这行代码表示同时声明了三个 `int` 类型变量：`x`、`y`、`z`，其中只有 `z` 被赋值为 `500`，而 `x` 和 `y` 只是声明了，并没有赋值。

#### 同一作用域中，变量名不能重复

在同一个作用域内，变量名**不能重名**。也就是说，一个名字一旦已经被某个变量使用，在同一作用域中就不能再次声明同名变量。

例如：

```java
public static void main(String[] args) {
    int count = 10;

    count = 20;
    count = 30;

    int count = 40; // 报错：变量 count 已定义
}
```

这段代码中：

- `count = 20;`
- `count = 30;`

都属于对同一个变量进行**重新赋值**，这是完全允许的。

### 变量的作用域

**作用域**，就是变量的**有效范围**。一个变量并不是在程序的任何位置都能使用，它只能在自己所属的范围内被访问。

对于初学阶段，可以先用一句话来理解：**变量出了它所属的大括号，通常就不能再访问了。**

例如：

```java
public class ScopeDemo {
    public static void main(String[] args) {
        int total = 5;

        if (total > 0) {
            int temp = 100;
            System.out.println(temp);
        }

        System.out.println(total);
        System.out.println(temp); // 报错：这里已经超出 temp 的作用域
    }
}
```

在这段代码中：

- `total` 定义在 `main` 方法中，因此它的作用域是整个 `main` 方法体。
- `temp` 定义在 `if` 语句块中，因此它只能在这个 `if` 的大括号内部使用。
- 离开 `if` 语句块后，`temp` 就失效了。

变量之所以有作用域差异，是因为它们声明的位置不同，而声明位置不同，就会导致它们的**生命周期**不同。所谓**生命周期**，就是变量从**创建**到**销毁**的整个过程，也可以理解为：从内存开辟到内存释放的过程。

#### Java 的就近原则

Java 在访问变量时，遵循**就近原则**。所谓就近原则，就是：**如果多个位置存在同名变量，优先访问离当前位置最近的那个变量**。

例如：

```java
public class NearRuleDemo {
    static int value = 10;

    public static void main(String[] args) {
        int value = 99;
        System.out.println(value);
    }
}
```

输出结果是：`99`。

原因是：

- 类中有一个成员变量 `value`
- `main` 方法中又定义了一个局部变量 `value`
- 在 `main` 方法内部访问 `value` 时，会优先访问距离更近的局部变量

这就是 Java 的**就近原则**。

### 变量的分类

Java 中的变量，按照**声明位置**的不同，可以分为两大类：

1. **局部变量**
2. **成员变量**

#### 局部变量

**局部变量**，是指声明在**方法体、语句块、形式参数**中的变量。

例如：

```java
public class VariableTypeDemo {
    public static void printSum(int a, int b) {
        int result = a + b;

        if (result > 0) {
            int flag = 1;
            System.out.println(flag);
        }

        System.out.println(result);
    }
}
```

这里的：

- `a`、`b` 是方法的**形式参数**
- `result` 是方法体中的局部变量
- `flag` 是 `if` 语句块中的局部变量

它们都属于**局部变量**。

#### 成员变量

**成员变量**，是指定义在**类中、方法外**的变量。

例如：

```java
public class Student {
    String name = "Tom";
    int age = 18;
    static String school = "JavaSchool";
}
```

这里的 `name`、`age`、`school` 都定义在类中、方法外，因此都属于**成员变量**。

## 进制

### 二进制

二进制是计算机底层最基本的表示方式，只使用 `0` 和 `1` 两个数字，遵循 **满二进一** 的规则。计算机内部之所以使用二进制，是因为电子元件更容易稳定表示两种状态，例如通电与断电、高电平与低电平。

在二进制中，每一位都有自己的权值。从右向左依次为：$2^0,\ 2^1,\ 2^2,\ 2^3,\ \cdots$

例如，二进制 `1011` 中，各位的权值分别是：$2^3,\ 2^2,\ 2^1,\ 2^0$

#### 二进制与十进制的转换

**十进制转二进制**：十进制转二进制采用 **除 2 取余，逆序排列** 的方法。

例如，将十进制整数 `27` 转为二进制：

1. $27 \div 2 = 13$，余 $1$
2. $13 \div 2 = 6$，余 $1$
3. $6 \div 2 = 3$，余 $0$
4. $3 \div 2 = 1$，余 $1$
5. $1 \div 2 = 0$，余 $1$

将余数从下往上写，得到：$27_{10} = 11011_2$

**二进制转十进制**：二进制转十进制采用 **按位乘权，再求和** 的方法。

例如，将二进制 `1101` 转为十进制：

$1 \times 2^3 + 1 \times 2^2 + 0 \times 2^1 + 1 \times 2^0$

$= 8 + 4 + 0 + 1 = 13$

因此：$1101_{2} = 13_{10}$

> **补充**：所谓 **权值**，就是某一位所在位置对应的大小。在二进制中，每一位的权值都是 $2$ 的幂。

### 八进制

八进制只使用 `0` 到 `7` 这八个数字，遵循 **满八进一** 的规则。

在八进制中，每一位的权值从右向左依次为：$8^0,\ 8^1,\ 8^2,\ 8^3,\ \cdots$

#### 八进制与十进制的转换

**十进制转八进制**：十进制转八进制采用 **除 8 取余，逆序排列** 的方法。

例如，将十进制整数 `27` 转为八进制：

1. $27 \div 8 = 3$，余 $3$
2. $3 \div 8 = 0$，余 $3$

将余数从下往上写，得到：$27_{10} = 33_8$

**八进制转十进制**：八进制转十进制采用 **按位乘权，再求和** 的方法。

例如，将八进制 `346` 转为十进制：

$3 \times 8^2 + 4 \times 8^1 + 6 \times 8^0$

$= 3 \times 64 + 4 \times 8 + 6 \times 1$

$= 192 + 32 + 6 = 230$

因此：$346_8 = 230_{10}$

### 十六进制

十六进制遵循 **满十六进一** 的规则。

它使用的数字有：

- `0` 到 `9` 表示 $0$ 到 $9$
- `A`、`B`、`C`、`D`、`E`、`F` 分别表示 $10$、$11$、$12$、$13$、$14$、$15$

在十六进制中，每一位的权值从右向左依次为：$16^0,\ 16^1,\ 16^2,\ 16^3,\ \cdots$

#### 十六进制与十进制的转换

**十进制转十六进制**：十进制转十六进制采用 **除 16 取余，逆序排列** 的方法。

例如，将十进制整数 `255` 转为十六进制：

1. $255 \div 16 = 15$，余 $15$
2. 余数 $15$ 对应十六进制中的 `F`
3. $15 \div 16 = 0$，余 $15$
4. 余数 $15$ 仍对应 `F`

因此：$255_{10} = FF_{16}$

**十六进制转十进制**：十六进制转十进制采用 **按位乘权，再求和** 的方法。

例如，将十六进制 `ABCD` 转为十进制：

$A \times 16^3 + B \times 16^2 + C \times 16^1 + D \times 16^0$

$= 10 \times 16^3 + 11 \times 16^2 + 12 \times 16^1 + 13 \times 16^0$

$= 10 \times 4096 + 11 \times 256 + 12 \times 16 + 13 \times 1$

$= 40960 + 2816 + 192 + 13 = 43981$

因此：$ABCD_{16} = 43981_{10}$

#### 二进制与十六进制的转换

二进制与十六进制之间转换非常方便，因为 **4 位二进制正好对应 1 位十六进制**。

**二进制转十六进制：**转换方法是：**从右向左每 4 位分为一组，不足 4 位时，在左边补 0**，然后将每组二进制转换成对应的十六进制。

例如，将二进制 `1101011010111011` 转为十六进制：

先分组：

```
1101 0110 1011 1011
```

然后分别转换：

- `1101` 对应 `D`
- `0110` 对应 `6`
- `1011` 对应 `B`
- `1011` 对应 `B`

因此：$1101011010111011_2 = D6BB_{16}$

**十六进制转二进制：**转换方法是：**将每一位十六进制直接写成 4 位二进制**。

例如，将十六进制 `AF` 转为二进制：

- `A` 对应 `1010`
- `F` 对应 `1111`

因此：$AF_{16} = 10101111_2$

## 原码、反码、补码

### byte 与 bit

- `bit`（比特）是计算机中最小的**数据单位**，每一位只能是 `0` 或 `1`。
- `byte`（字节）是计算机中常用的**基本存储单位**，**1 个字节由 8 个比特组成**，即：$1\ \text{byte} = 8\ \text{bit}$。

常见存储单位换算如下：

- $1\text{KB} = 1024\text{byte}$
- $1\text{MB} = 1024\text{KB}$
- $1\text{GB} = 1024\text{MB}$
- $1\text{TB} = 1024\text{GB}$

> **补充**：在 Java 中，`byte` 类型占 **1 个字节**，`int` 类型占 **4 个字节**。

原码、反码、补码，都是**有符号整数在二进制中的表示方式**。对于一个二进制整数，最高位通常作为**符号位**：

- `0` 表示正数
- `1` 表示负数

计算机底层存储整数时，采用的是 **补码**。

### 正数的原码、反码、补码

对于正数来说，**原码、反码、补码完全相同**。

例如，十进制的 `+6`：

| 表示方式 | 二进制     |
| -------- | ---------- |
| 原码     | `00000110` |
| 反码     | `00000110` |
| 补码     | `00000110` |

### 负数的原码、反码、补码

对于负数来说，三者不同。

以十进制 `-6` 为例：

1. 先写出 `6` 的二进制：`00000110`
2. 得到 `-6` 的原码：符号位改为 `1`，即 `10000110`
3. 得到反码：**符号位不变，其余位取反**，即 `11111001`
4. 得到补码：**符号位不变，反码加 1**，即 `11111010`

整理如下：

| 表示方式 | 二进制     |
| -------- | ---------- |
| 原码     | `10000110` |
| 反码     | `11111001` |
| 补码     | `11111010` |

以 `byte` 类型为例，它占 $1$ 个字节，也就是 $8$ 个二进制位，因此取值范围是：$-2^7 \sim 2^7 - 1$，也就是：$-128 \sim 127$。其中：

- 最大值是 `127`，二进制补码为：`01111111`
- 最小值是 `-128`，二进制补码为：`10000000`

`-128` 是一个特殊值。在 `byte` 范围内，它的补码是：`10000000`。

> **注意**：`byte` 的范围不是 $-127 \sim 127$，而是 **$-128 \sim 127$**。也就是说，负数比正数多一个值。

### 已知负数的补码，求原码

如果一个二进制数是**负数的补码**，要反推出它的原码，可以这样做：

1. 确认它是负数，即最高位为 `1`
2. **符号位不变，其余位取反**
3. 再 **符号位不变，加 1**
4. 得到的结果就是这个负数的原码

例如，已知某负数的补码为 `10000010`，求原码：

1. 符号位不变，其余位取反，得到：`11111101`
2. 再加 `1`，得到：`11111110`

所以它的原码是：`11111110`。对应的十进制数是：$-126$。

## 数据类型

数据类型用于规定变量能保存什么数据，也决定了数据在内存中的表示方式。学习数据类型的直接目的，是为了能够正确地定义变量。

### Java 数据类型概述

Java 的数据类型分为两大类：**基本数据类型**和**引用数据类型**。其中，基本数据类型包括 `byte`、`short`、`int`、`long`、`float`、`double`、`boolean`、`char` 这 8 种；除这 8 种之外，其他大多数类型都可以先归为**引用数据类型**，例如 `String`、数组、类、接口、枚举等。现阶段重点掌握的是基本数据类型。

基本数据类型可以分为四类：**整数类型**、**浮点类型**、**布尔类型**和**字符类型**。其中：

- 整数类型有 `byte`、`short`、`int`、`long`，用于表示整数；
- 浮点类型有 `float`、`double`，用于表示小数；
- 布尔类型是 `boolean`，只有 `true` 和 `false` 两个值；
- 字符类型是 `char`，用于表示单个字符，并且基于 Unicode 编码。

| 数据类型  | 说明                           | 占用字节数           | 取值范围                                    | 默认值     |
| --------- | ------------------------------ | -------------------- | ------------------------------------------- | ---------- |
| `byte`    | 整数，适合较小整数             | 1                    | $-2^7 \sim 2^7-1$，即 $-128 \sim 127$       | `0`        |
| `short`   | 整数，范围比 `byte` 大         | 2                    | $-2^{15} \sim 2^{15}-1$                     | `0`        |
| `int`     | 最常用的整数类型               | 4                    | $-2^{31} \sim 2^{31}-1$                     | `0`        |
| `long`    | 表示更大的整数                 | 8                    | $-2^{63} \sim 2^{63}-1$                     | `0L`       |
| `float`   | 单精度浮点数                   | 4                    | 约 $\pm 3.4028235 \times 10^{38}$           | `0.0f`     |
| `double`  | 双精度浮点数，最常用的小数类型 | 8                    | 约 $\pm 1.7976931348623157 \times 10^{308}$ | `0.0d`     |
| `boolean` | 表示真假                       | 不直接规定固定字节数 | `true / false`                              | `false`    |
| `char`    | 表示单个字符                   | 2                    | $0 \sim 65535$                              | `'\u0000'` |

**基本数据类型**保存的是具体的值本身，例如整数值、字符值、真假值；**引用数据类型**保存的不是对象本体，而是对象的引用。现阶段可以先简单记住：**8 种基本数据类型之外，其余大多数类型都可以先看成引用数据类型**，其中也包括 `String`。

> **补充**：Java 设计出 `byte`、`short`、`int`、`long` 这些整数类型，是为了让程序在不同场景下可以根据数据大小选择更合适的类型。理论上，类型选得更合适可以节省空间，但在一般学习和开发中不必过度计较，**大多数整数直接使用 `int` 即可**。如果整数大到连 `long` 都放不下，就需要使用 `BigInteger`，但它已经属于引用数据类型。

> **补充**：`float` 和 `double` 都用于表示小数，但 `double` 精度更高、使用更普遍，因此通常优先使用 `double`。如果数值计算对精度要求非常高，`float` 和 `double` 都可能不够准确，此时通常会使用 `BigDecimal`，它同样属于引用数据类型。

#### 默认值

Java 中，变量在使用前都必须先声明。对于**局部变量**来说，声明之后还必须手动赋值，否则不能直接访问；对于**成员变量**来说，如果没有手动赋值，系统会自动赋一个默认值。因此，**局部变量没有默认值，成员变量有默认值**。

基本数据类型的成员变量默认值如下：

- `byte`、`short`、`int` 的默认值都是 `0`
- `long` 的默认值是 `0L`
- `float` 的默认值是 `0.0f`
- `double` 的默认值是 `0.0d`
- `boolean` 的默认值是 `false`
- `char` 的默认值是 `'\u0000'`

其中，`'\u0000'` 表示一个空字符。

引用数据类型的成员变量默认值是 **`null`**。例如，`String` 属于引用数据类型，如果它是成员变量且没有手动赋值，那么默认值就是 `null`。

### 整数类型

#### 整数型字面量的四种表示形式

Java 中的整数型字面量有四种常见写法：**十进制**、**二进制**、**八进制**、**十六进制**。十进制直接写数字即可；二进制以 `0b` 或 `0B` 开头；八进制以 `0` 开头；十六进制以 `0x` 或 `0X` 开头。

```java
int a = 18;      // 十进制
int b = 0b10010; // 二进制
int c = 022;     // 八进制
int d = 0x12;    // 十六进制
```

> **注意**：以 `0` 开头的整数会被当成**八进制**处理，因此这类写法要特别小心，不要和普通十进制混淆。

#### 整数型字面量默认当作 `int` 处理

Java 中，**任何整数字面量默认都按 `int` 类型处理**。如果希望某个整数字面量按 `long` 类型处理，必须在后面加 `L` 或 `l`，但通常推荐写成大写 `L`，因为小写 `l` 很容易和数字 `1` 混淆。

```java
int x = 20;
long y = 20L;
```

这一点要特别注意：判断一个字面量是否合法，首先看的是**字面量本身能不能作为 `int` 成立**，而不是先看左边变量的类型。因此，下面代码会直接编译报错：

```java
long n = 2147483648;
```

原因不是左边的 `long` 不够大，而是右边的 `2147483648` 默认先按 `int` 处理，但它已经超出了 `int` 的取值范围。正确写法应该是：

```java
long n = 2147483648L;
```

#### 自动类型转换

在基本数据类型中，**小容量类型可以直接赋值给大容量类型**，这种转换叫作**自动类型转换**。对于常见数字类型，可以先记住下面这个大小规律：

```
byte < short < int < long < float < double
```

例如：

```java
int a = 50;
long b = a;
double c = a;
```

上面这些写法都可以直接通过编译，因为都是**小容量到大容量**的转换。自动类型转换的本质是：目标类型的表示范围更大，通常能够容纳原来的值。

#### 强制类型转换

**大容量类型不能直接赋值给小容量类型**，因为这种转换**可能**会造成数据变化，因此必须由程序员显式写出强制类型转换符。也就是说，这种操作不是 Java 不会做，而是 Java 不允许你“悄悄地做”。

例如，下面代码会报错：

```java
int m = 30L;
```

因为 `30L` 是 `long` 类型字面量，而左边变量是 `int`。如果确实要转，就必须显式写出强制类型转换：

```java
int m = (int)30L;
```

强制类型转换并不一定一定丢失精度，但**有可能**丢失；是否真的出问题，要看转换前的具体数值是否超出了目标类型的表示范围。

整数强制类型转换时，可以先粗略理解为：**保留右边低位，砍掉左边多余的高位**。

例如：

```java
byte b = (byte)130;
```

`130` 作为 `int` 的二进制补码是：

```
00000000 00000000 00000000 10000010
```

强制转成 `byte` 后，只保留最后 8 位：

```
10000010
```

这个结果在 `byte` 中是按**补码**解释的，对应的十进制值是 **`-126`**，因此最终结果为：

```java
byte b = (byte)130; // -126
```

这说明强制类型转换之后，结果不一定还是原来的数值，因为转换后的类型位数更少，可能已经发生了截断。

> **易错点**：强制类型转换后，计算机看到的不是“原来的十进制值”，而是**截断后的二进制补码**。因此结果可能和直觉不一致。

> **补充**：**整数字面量没有超出 `byte`、`short`、`char` 的取值范围，可以直接赋值**
>
> 虽然 Java 中**整数字面量默认按 `int` 处理**，但如果一个整数字面量本身没有超出目标类型的取值范围，编译器允许它直接赋值给 `byte`、`short` 或 `char` 变量。这可以看作一种**编译期的特殊处理**，目的是让代码书写更方便。
>
> ```java
> byte b = 100;
> short s = 30000;
> char c = 66;
> ```
>
> 上面三行代码都可以直接通过编译，其中 `66` 会被当作字符编码处理，因此 `c` 对应的字符是 `B`。
>
> 如果整数字面量超出了目标类型的取值范围，就不能直接赋值，必须使用强制类型转换。
>
> ```java
> byte b = (byte)130;
> ```
>
> 这行代码可以通过编译，但最终结果不是 `130`，而是 **`-126`**，因为强制类型转换后只保留低位二进制，数值已经发生变化。
>
> **注意**：这里的“可以直接赋值”只针对**整数字面量**成立，不代表所有 `int` 类型的值都能直接赋给 `byte`、`short` 或 `char`。例如下面的写法仍然会报错：
>
> ```java
> int n = 100;
> byte b = n;
> ```

> **补充**：当表达式里全部都是整数字面量时，编译器有时会在**编译阶段直接算出结果**。如果结果没有超出目标类型的范围，就允许直接赋值。这可以看作编译器做的一种常量优化。
>
> ```java
> byte m = 12 / 4;
> ```
>
> 上面这行代码可以通过编译，因为 `12 / 4` 在编译阶段就能算出结果是 `3`，而 `3` 没有超出 `byte` 的取值范围。
>
> 但如果参与运算的是变量，情况就不同了。因为变量的值在编译阶段通常不能直接确定，编译器只能根据类型判断表达式结果。例如两个 `int` 变量相除，结果类型一定还是 `int`，因此不能直接赋值给 `byte` 变量。
>
> ```java
> int p = 12;
> int q = 4;
> // byte n = p / q; // 编译报错
> ```
>
> 如果确实要赋值给 `byte`，要么把接收结果的变量改成 `int`，要么显式进行强制类型转换。
>
> ```java
> int p = 12;
> int q = 4;
> byte n = (byte)(p / q);
> ```
>
> 这里的小括号不能省略。因为强制类型转换如果只作用在某一个操作数上，并不会改变整个表达式最终的结果类型。例如：
>
> ```java
> int p = 12;
> int q = 4;
> // byte n = (byte)p / q; // 仍然报错
> ```
>
> 这段代码中，只是把 `p` 转成了 `byte`，但 `byte` 和 `int` 一起运算时，仍然会先提升为 `int`，所以整个表达式结果还是 `int`，仍然不能直接赋值给 `byte`。

#### 整数运算中的类型提升

在 Java 中，两个 `int` 类型的数据做运算时，结果仍然是 `int` 类型。因此，如果两个整数相除，结果只会保留整数部分，不会自动变成小数。

```java
int a = 14;
int b = 4;
int c = a / b;
System.out.println(c); // 3
```

如果多种数字类型混合运算，Java 会先把它们统一提升到**参与运算的最大类型**，再进行计算。例如 `byte`、`int`、`long` 一起运算时，会先提升到 `long`，因此最终结果也是 `long` 类型。

```java
byte x = 20;
int y = 50;
long z = 80L;
long result = x + y + z;
```

如果把接收结果的变量 `result` 写成 `int`，就无法接收一个已经提升为 `long` 的运算结果。

### 浮点数类型

浮点型用于表示**带小数点的数值**。Java 中的浮点型有两种：`float` 是**单精度**，占 `4` 个字节；`double` 是**双精度**，占 `8` 个字节。`double` 的表示范围和精度都更高，因此实际开发中通常更常用 `double`。

同一个小数分别用 `float` 和 `double` 保存时，`double` 往往能保留更多有效位。

```java
double d = 1.234567890123;
float f = 1.234567890123F;
System.out.println(d);
System.out.println(f);
```

运行时通常可以看到，`float` 输出的小数位会更少，这说明它的精度低于 `double`。

#### 浮点型字面量默认被当作 `double`

Java 中，浮点型字面量默认按 **`double`** 处理。如果希望一个浮点型字面量按 **`float`** 处理，必须在后面加 `F` 或 `f`，通常推荐写大写 `F`。

```java
float a = 2.5F;
double b = 2.5;
```

如果直接写：

```java
float a = 2.5;
```

就会编译报错，因为右边的 `2.5` 默认是 `double`，而 `double` 不能直接赋值给 `float`。

#### 浮点型数据的两种表示形式

浮点型字面量有两种常见写法：**十进制写法**和**科学计数法写法**。

- 十进制写法就是普通的小数形式，例如 `3.14`、`0.5`、`.5`；
- 科学计数法则使用 `E` 或 `e` 表示乘以 `10` 的多少次方，例如 `6.2E3` 表示 $6.2 \times 10^3$，`4.8E-2` 表示 $4.8 \times 10^{-2}$。

```java
double x = 4.75;
double y = .75;
double z = 6.2E3;
double k = 4.8E-2;
```

#### 浮点型数据的存储原理

浮点数在计算机底层不是按普通十进制小数的形式直接存储的，而是按一种类似“科学计数法”的方式存储。以 `float` 为例，它占 `4` 个字节，也就是 `32` 位，通常由 **符号位**、**指数位** 和 **尾数位** 三部分组成。

- **符号位**：用于表示正负，`0` 表示正数，`1` 表示负数。
- **指数位**：用于表示数量级，可以理解为科学计数法中的指数部分。例如 `0.123E30` 中的 `30`，就对应数量级的变化。也正因为有指数位，浮点数可以表示非常大或非常小的数。
- **尾数位**：用于表示有效数字，也就是数值本身的精度部分。

> **补充**：正是因为浮点数采用了“符号位 + 指数位 + 尾数位”这种存储方式，其中**指数位决定了数值可以按指数级放大或缩小**，所以 `float` 虽然只有 `4` 个字节，但它能表示的数值范围却可以超过 `long`。这说明：**类型占用的字节数更多，并不一定代表它的数值范围一定更大**。

浮点数在计算机底层通常采用**近似值**存储，而不是精确值存储。这是因为计算机的二进制位数是有限的，但现实中很多小数在二进制中可能是无限循环的，无法被有限位数完整表示，所以只能保存一个足够接近的近似值。一般来说，参与存储有效数字的位数越多，精度就越高，这也是为什么 `double` 的精度通常高于 `float`。

正因为浮点数常常是近似存储，所以**浮点数参与运算后的结果，通常也只是近似值**，不能想当然地认为它一定和我们看到的十进制结果完全一致。例如：

```java
double a = 0.3;
double b = 0.2;
double c = a - b;
System.out.println(c);
```

这段代码输出的通常不是精确的 `0.1`，而是一个非常接近 `0.1` 的值。

因此，只要是**浮点数运算得到的结果**，一般都**不建议直接使用 `==` 做相等比较**。例如下面这种写法就可能得不到预期结果：

```java
double a = 0.3;
double b = 0.2;
double c = a - b;

if (c == 0.1) {
    System.out.println("相等");
}
```

更合理的做法是比较两个浮点数的**差值是否足够小**。也就是说，不要求它们“绝对相等”，而是只要它们之间的误差小到可以接受，就认为它们相等。

```java
double a = 0.3;
double b = 0.2;
double c = a - b;

if (Math.abs(c - 0.1) < 0.000001) {
    System.out.println("相等");
}
```

### 字符型详解

`char` 表示**字符类型**，占 `2` 个字节，取值范围是 $0 \sim 65535$。它和 `short` 占用的字节数相同，但两者含义不同：`short` 用于表示整数，`char` 用于表示字符；同时，`char` 没有负数，因此可以表示更大的非负整数范围。

`char` 类型的字面量必须使用**单引号**括起来，并且其中只能写**一个字符**，例如 `'B'`、`'7'`、`'中'`、`'#'` 都是合法的字符型字面量。

```java
char c1 = 'B';
char c2 = '7';
char c3 = '中';
char c4 = '#';
```

`char` 中的内容必须是单个字符，因此不能写多个字符。例如 `'xy'` 这样的写法是错误的，因为它已经不是一个字符，而是两个字符。

```java
// char c = 'xy'; // 编译报错
```

Java 中的 `char` 可以存储一个汉字，这是因为 `char` 底层基于 **Unicode 编码**。也就是说，`char` 存储的本质上不是“字形”，而是这个字符对应的编码值。

空单引号也是不合法的，因为 `''` 里面没有任何字符，而 `char` 变量必须接收一个字符，所以这种写法会编译报错。

```java
// char c = ''; // 编译报错
```

如果确实需要表示一个**空字符**，可以使用 `'\u0000'`。这里的 `\u` 表示后面跟的是一个 Unicode 编码值，`0000` 对应的就是空字符。

```java
char c = '\u0000';
```

> **注意**：**空字符**和**空格字符**不是一回事。`'\u0000'` 表示空字符，而 `' '` 表示空格，它们是两个完全不同的字符。

#### 转义字符

转义字符是以反斜线 `\` 开头的一类特殊字符序列，用来表示那些**不能直接写出**、**写出来容易产生歧义**，或者**本身就有特殊作用**的字符。常见转义字符如下：

| 转义字符 | 含义                 |
| -------- | -------------------- |
| `\t`     | 制表符，相当于 `Tab` |
| `\n`     | 换行符               |
| `\r`     | 回车符               |
| `\"`     | 双引号               |
| `\'`     | 单引号               |
| `\\`     | 反斜线本身           |

这些转义字符既可以出现在字符串中，也可以出现在字符中。例如，要在字符串里输出双引号，就不能直接写 `"`，而要写成 `\"`；要表示一个换行，就可以使用 `\n`。

```java
System.out.println("Hello\tJava");
System.out.println("第一行\n第二行");
System.out.println("\"Java\"");
System.out.println('\\');
```

> **注意**：转义字符虽然由两个字符组成，例如 `\n`，但它在程序中表示的是**一个特殊字符**。

#### 字符编码

计算机底层只能存储二进制，因此字符在存入计算机之前，必须先按照某种规则转换成二进制；而二进制在显示给人看之前，也必须再按照对应规则还原成字符。这套“字符和二进制之间的对应规则”，就叫做**字符编码**。

其中，把字符转换成二进制的过程叫做**编码**，把二进制还原成字符的过程叫做**解码**。例如，字符 `'A'` 按某种编码规则转换成一段二进制，这叫编码；把这段二进制再按同一规则还原成 `'A'`，这叫解码。

如果编码和解码使用的不是同一套字符集或同一套规则，就可能出现**乱码**。因此，避免乱码的关键就是：**编码时用什么规则，解码时也要用同样的规则**。

##### 常见的字符编码

常见字符编码很多，初学阶段重点了解几个最常见的即可：

- **ASCII**：主要用于英文、数字和基础符号，表示范围较小。
- **ISO-8859-1（Latin-1）**：也是单字节编码，能表示更多西文字符，并且向上兼容 ASCII。
- **Unicode**：一种统一的字符编号标准，目标是表示世界上各种语言中的字符。
- **UTF-8**：基于 Unicode 的可变长编码方式，英文通常占 `1` 个字节，汉字通常占 `3` 个字节，是目前最常见的编码方式之一。
- **GBK**：常见的中文编码方式，主要用于简体中文环境。
- **Big5**：常见的繁体中文编码方式。

##### ASCII 码

ASCII 是早期非常常见的一种字符编码，主要用于表示英文字母、数字、常见符号和控制字符。学习阶段不必整张表都背下来，但下面几个值建议记住：

- `'A'` 对应 `65`，因此 `'B'` 对应 `66`
- `'a'` 对应 `97`，因此 `'b'` 对应 `98`
- `'0'` 对应 `48`，因此 `'1'` 对应 `49`

这也是为什么有些字符既能按字符看，也能按数值理解。比如 `'A'`、`'a'`、`'0'` 在底层本质上都对应一个编码值。

##### Unicode

在 Java 中，`char` 和字符串都和 **Unicode** 密切相关。学习阶段可以先记住：Java 程序里可以直接使用 Unicode 转义形式来表示一个字符，写法是 `\u` 后面跟 4 位十六进制数。

```java
char c = '\u0042';
System.out.println(c);
```

上面代码输出的是：`B`。

因为 `\u0042` 对应的就是字符 `B`。这也说明，字符在程序里不仅可以直接写成 `'B'`，也可以写成对应的 Unicode 形式。

#### `char` 运算

`char` 本质上对应一个整数编码值，因此它既可以保存字符，也可以在一定范围内接收整数字面量。**只要整数字面量没有超出 `char` 的取值范围 $0 \sim 65535$，就可以直接赋值给 `char` 变量**；但变量最终保存的是字符，因此输出时看到的是对应字符，而不是那个整数本身。

```java
char c = 97;
System.out.println(c); // a
```

如果赋的整数超出了 `char` 的取值范围，就会编译报错。

```java
char c = 65536; // 编译报错
```

**`char` 参与算术运算时，会先按对应的编码值参与计算**。如果和 `int` 一起运算，那么 `char` 会先提升为 `int`，运算结果也会是 `int`。

```java
System.out.println('a' + 1); // 98
```

这是因为 `'a'` 对应的编码值是 `97`，所以表达式实际计算的是 `97 + 1`，结果自然是 `98`。

**如果一个表达式的最终结果仍然在 `char` 的取值范围内，并且编译器能在编译阶段直接算出结果，那么这个结果也可以直接赋值给 `char` 变量。**

```java
char c = 'a' + 1;
System.out.println(c); // b
```

这里编译器会先算出 `'a' + 1` 的结果是 `98`，再把 `98` 当作字符编码赋值给 `c`，因此输出的是 `b`。

**当 `byte`、`short`、`char` 混合运算时，它们都会先提升为 `int`，再进行计算**，因此表达式结果是 `int`，不能直接赋值给 `short` 或 `char` 这类更小的类型变量。

```java
byte b = 1;
short s = 1;
char c = 1;
// short num = b + s + c; // 编译报错
```

这段代码报错的根本原因，不是结果数值太大，而是 `b + s + c` 的结果类型已经是 `int`，而 `int` 不能直接赋值给 `short`。
