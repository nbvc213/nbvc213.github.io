## 高频考点 1：宏观经济发展目标

### 四大目标及衡量指标

| 宏观目标         | 衡量指标               | 核心理解                                         |
| ---------------- | ---------------------- | ------------------------------------------------ |
| **经济增长**     | **GDP**                | 一定时期生产活动的最终成果                       |
| **充分就业**     | **失业率**             | 关注劳动者就业，不等于所有人都有工作             |
| **物价稳定**     | **通货膨胀率**         | 价格总水平相对稳定，不是每种商品价格不变         |
| **国际收支平衡** | **国际收支及其平衡表** | 相对合理，不出现巨额失衡，不等于每项收支绝对相等 |

### 经济增长与 GDP

#### GDP 的含义

国内生产总值（**GDP**），是一个国家或地区所有常住单位在一定时期内生产活动最终成果的价值。

记忆关键词：**常住居民、一定时期、最终成果**。

> 解释：
>
> - GDP 从国内经济活动的角度统计，不能只统计本国国籍人员；最终成果用相应市场价值衡量。
> - 还可以将 GDP 与 GNP 作比较，将前者联系地域、后者联系国民理解。
>
> *补充：GDP 核算中的“常住单位”不只是自然人，还包括企业、政府等机构单位；是否属于常住单位，不能仅凭人在境内、企业所有者国籍判断。GNI（原称 GNP）同样不是“持本国国籍的人无论在哪里取得的全部产出”这一简单国籍口径，而是所有常住单位收入初次分配的最终结果。GDP 侧重生产，GNI 侧重初次分配收入。*

#### 三种表现形态与核算方法

| 表现形态     | 对应核算方法 | 理解                                 |
| ------------ | ------------ | ------------------------------------ |
| **价值形态** | **生产法**   | 从生产活动创造价值的角度计算         |
| **收入形态** | **收入法**   | 从生产所形成收入及其分配的角度计算   |
| **产品形态** | **支出法**   | 从最终产品和服务被如何使用的角度计算 |

> 解释：重点是对应关系：**价值—生产，收入—收入，产品—支出**。

#### 支出法与“三驾马车”

经济增长的“三驾马车”是**消费、投资、净出口**，与支出法的构成相联系。

> *补充：按相应国民经济核算口径，可概括为 GDP＝最终消费支出＋资本形成总额＋货物和服务净出口。这里的净出口是出口减进口；不要把全部出口额直接当作净出口。*

### 充分就业与失业率

#### 充分就业不是完全就业

目标是**充分就业**，不是把所有社会人口都安排到工作岗位。

> 解释：可以用“年满 16 周岁、有劳动能力”帮助理解劳动年龄及劳动者范围。
>
> *补充：充分就业并不意味着失业率为零，仍可存在摩擦性、结构性失业等。也不能仅凭年龄和劳动能力，便把所有人都列为实际参与劳动力市场的人口。*

#### 失业率公式

$$
\text{失业率}=\frac{\text{失业人数}}{\text{劳动力人口}}\times100\%
$$

> 解释：
>
> - **分母是劳动力人口，不是全部人口，也不是全部 16 周岁以上人口。**
> - 可以用“年满 16 周岁、具有劳动能力”概括劳动力人口，辅助记忆年龄与能力条件。
>
> *补充：按调查失业率统计口径，劳动力人口＝就业人口＋失业人口。16 周岁及以上但既不属于就业也不属于失业的人，是非劳动力人口；例如无求职意愿且未就业者，不能只因具备劳动能力就计入分母。失业还须符合未就业、正在求职、能够开始工作等条件。*

#### 16 周岁与 18 周岁的年龄比较

> 解释：
>
> - 可以联系民事行为能力帮助记忆：一般成年年龄为 **18 周岁**；**16 周岁以上的未成年人，以自己的劳动收入为主要生活来源的，视为完全民事行为能力人**。
> - 这里用于记忆年龄，不能将民事行为能力的判断与劳动力统计口径直接等同。

#### 城镇登记失业率

**城镇登记失业率**可以联系有就业意愿、进行失业登记等条件理解，传统口径还使用“非农业户口”的表述。

> *补充：不能把“我国主要统计失业率就是登记失业率”作为当前完整表述。国家统计局已定期公布城镇调查失业率；调查失业率与登记失业率的数据来源、覆盖及用途不同。现行登记失业人员解释也不宜只按旧的“非农业户口”条件机械判断。*

### 物价稳定与三类价格指标

**物价稳定不等于物价不变**，而是价格总水平在一定时期内不出现剧烈波动。

通货膨胀率衡量价格总水平变动，常用价格指标有三类：

| 指标             | 解释                                                         |
| ---------------- | ------------------------------------------------------------ |
| **CPI**          | 消费者物价指数，联系居民日常生活所购买的一系列消费品和服务的价格变化 |
| **PPI**          | 生产者物价指数，联系工业产品出厂价格变化理解                 |
| **GDP 平减指数** | 又称 GDP 缩减指数，覆盖较广的综合价格指标                    |

$$
\text{GDP平减指数}=\frac{\text{现价GDP}}{\text{不变价GDP}}\times100
$$

> 解释：可以用当年价格计算的 GDP 与不变价格计算的 GDP 比较，说明价格变动的识别。
>
> *补充：分子、分母应是同一时期产出的现价和不变价估值，不能写成“本年名义 GDP÷去年 GDP”。不变价所用基期及指数表达还须保持一致。经济增长比较也应区分包含价格影响的名义增速与剔除价格影响的实际增速。*

### 国际收支平衡

#### 相对平衡，不是绝对相等

国际收支平衡的目标是保持相对合理状态，**避免巨额盈余或赤字**。

> 解释：可以用收入大于支出理解盈余、收入小于支出理解赤字；相对平衡不要求每一项收支完全相等。
>
> *补充：国际收支采用复式记账，完整平衡表在统计上具有平衡关系；宏观目标中的“基本平衡”与记账上借贷相等不是同一个概念。判断顺差、逆差时还应明确所指账户或差额口径。*

#### 平衡表的结构

| 项目               | 理解                                               |
| ------------------ | -------------------------------------------------- |
| **经常账户**       | 记载经常性对外交易，以贸易产品等往来为主要例子     |
| **资本与金融账户** | 联系资本转移、投资及金融资产负债交易理解           |
| **错误与遗漏账户** | 为解决多来源统计数据不一致等问题设置的统计平衡项目 |

> 解释：跨境交易范围广、规模大，统计时点与资料可能存在差异，需要有关平衡项目。
>
> *补充：现行平衡表通常使用“净误差与遗漏”称谓。经常账户不仅包括货物，也包括服务、初次收入、二次收入等；净误差与遗漏是统计残差项目，不是可以随意修改真实交易数据的账户。*

## 高频考点 2：通胀与通缩

### 先区分现象与成因

从货币供求看，通货膨胀与**货币相对过多**相联系，通货紧缩与**货币相对不足**相联系。物价上涨、下跌是需要观察的表现，不能用现象本身循环解释原因。

> *补充：通货膨胀通常指一般价格水平在一定时期持续上涨，通货紧缩指一般价格水平持续下降。不能把单个商品涨价或降价直接等同于通胀、通缩，也不能把复杂成因都化约为现金数量的单一增减；需求、供给、成本和预期等均可能影响价格。*

### 通货膨胀的四种原因类型

| 类型               | 含义                       | 说明                                     |
| ------------------ | -------------------------- | ---------------------------------------- |
| **需求拉上型**     | **过多货币追逐过少商品**   | 总需求扩张超过供给承受能力，形成涨价压力 |
| **成本推动型**     | 工资推进、利润推进         | 从成本或加价等供给侧因素传导             |
| **供求混合推动型** | 既有需求因素，又有供给因素 | 多种力量共同作用                         |
| **结构型**         | 经济结构因素变化引起       | 不同部门、地区等变化相互传导             |

#### 工资推进的通货膨胀

**员工、工会要求涨工资→企业劳动成本上升→企业为维持利润提高售价→产品作为其他企业投入品，再向其他领域传导。**

> 解释：不只是工资上涨本身，还要关注其通过成本、定价传导至价格总水平的过程。

#### 利润推进的通货膨胀

> 解释：
>
> - 例如，垄断性较强的行业中，企业具有一定价格控制能力，为追求较高利润提高价格，价格再向其他领域传导。
> - **工资推进侧重成本，利润推进侧重企业加价和利润追求。**

#### 结构型的理解

> 解释：例如，某地区或部门的价格上涨，再向其他地区或部门传导。判断结构型通胀时，应抓住经济结构变化，不能只看货币总量。

### 通货膨胀的五项治理对策

1. **紧缩的货币政策**：主要由中央银行依法实施，减少货币供应量、提高利率。
2. **紧缩的财政政策**：增收节支、减少赤字，包括增加税收，减少政府公共投资、公共建设及其他支出。
3. **紧缩的收入政策**：限制收入增长，减轻购买需求。
4. **积极的供给政策**：增加商品和服务的有效供给，缓解短缺。
5. **货币改革**：在严重、恶性通货膨胀背景下，通过发行新货币或制度性改革等安排处理。

> 解释：
>
> - **紧缩的货币政策**：提高利率可能增强储蓄意愿，同时提高借款成本、抑制借款与支出，从而减轻需求压力。
> - **紧缩的财政政策**：可以用“增收节支、减少赤字”记忆。增收可以联系增加税赋；节支可以联系减少公共工程等政府支出；减少赤字有助于减轻财政扩张对总需求的推动。货币政策和财政政策是宏观调控的两类主要手段。
> - **积极的供给政策**：这里的“供给”是商品和服务供给，**不是增加货币供给**。既然部分涨价压力来自商品供给不足，就通过增加有效供给缓解短缺。
> - 可以用“**通胀降温、采取紧缩**”作方向性记忆。
>
> *补充：财政政策主要通过政府支出、税收等影响需求，不能把“减少赤字”直接等同于统计意义上货币供应量按相同金额下降。*
>
> *补充：收入政策通常涉及工资、价格等增长约束及协调，不能仅理解为直接削减所有人的工资或收入。*
>
> *补充：货币改革并非所有通胀的常规必选政策，单纯更换货币名称或面额也不自动消除通胀。具体政策仍须结合需求过热、成本冲击、供给约束等成因，不能推断所有通胀都只需同样幅度的总量紧缩。*

### 通货紧缩的四类原因

#### 货币供给减少

货币供给减少可以联系**政策时滞**理解。

> 解释：调控政策并非即时、精准生效；此前治理通胀的紧缩政策可能延后发挥作用，或调控过度，造成反方向影响。

#### 有效需求不足

1. **实际利率较高**。
2. 金融机构**贷款意愿下降、提高利率**。
3. **制度变迁、转型等体制因素**。

$$
\text{实际利率}\approx\text{名义利率}-\text{通货膨胀率}
$$

当名义利率不变、通货膨胀率下降甚至转负时，**实际利率可能上升**，实际借款负担加重。

> 解释：
>
> - 居民不愿或不敢消费、企业不愿投资，可能导致产品难以出售、价格承压。
> - 挂牌等利率属于名义利率；实际利率还考虑物价变化。名义利率和实际利率都可能影响借款需求。
>
> *补充：以上为近似关系，精确关系及预期、实际通胀口径要相互匹配。“实际利率提高”也不表示所有人都会储蓄增加，效果仍受收入、预期等因素影响。*

#### 供需结构不合理

供需结构不合理表现为经济中存在**不合理扩张和投资**。

> 解释：例如，高速扩张时生产大量产品，后续出现积压、销售困难，价格被迫下调。

#### 国际市场冲击

境外价格、需求等变化可以向国内传导，对经济和物价形成冲击。

### 通货紧缩的四项治理对策

| 对策               | 主要内容                                             |
| ------------------ | ---------------------------------------------------- |
| **扩大有效需求**   | 扩大**投资需求、消费需求**                           |
| **扩张的财政政策** | 增加财政开支、公共工程，扩大赤字，减轻税收等负担     |
| **扩张的货币政策** | 降低准备金率、再贴现率、基准利率等，运用公开市场操作 |
| **引导公众预期**   | 恢复信心，减轻“不敢消费、不愿投资”的状态             |

> 解释：
>
> - 可以用“**通缩过冷，需要加温**”帮助记忆，与治理通胀的政策方向比较。
> - **扩大有效需求**：居民购买商品和服务对应消费需求，企业为经营生产、扩大投资筹资对应投资需求。
> - **扩张的财政政策**：增加公共工程、财政支出和赤字以扩大需求。紧缩财政是“增收节支、减少赤字”，扩张财政是“增支减收、扩大需求”。
> - **扩张的货币政策**：降低存款准备金率、再贴现率及有关基准利率。公开市场操作的例子是“**央行买入国债→向交易对方支付资金→向金融体系投放流动性**”。
>
> *补充：这是政策方向与传导的基础模型，不代表每次降准、降息都必然产生同样的信贷和物价结果，也不能将公开市场买入国债混同于直接认购、包销政府债券。*

## 高频考点 3：经济周期

### 四个阶段及循环顺序

经济周期是经济活动随时间呈现的波动，分为四个阶段：

**复苏→繁荣→衰退→萧条→下一轮复苏。**

> 解释：可以用波形理解经济活动的上行与下行；不同阶段的企业经营、就业、消费和银行业务相互联系。

### 复苏阶段

- 公众对市场的**信心恢复**。
- 企业**投资意愿上升**，开始增加投资。
- 开展**固定资产更新**。
- 生产经营活动逐步趋于正常。
- 企业利润上升。
- 对借贷资金的需求显著增加。
- 商业银行**资产业务规模、利润**明显上升。

> 解释：
>
> - 衰退、萧条期间的政策刺激可能释放信号，部分企业率先恢复投资，并更新上一轮周期遗留的设备。
> - 判断经济周期阶段时要注意，**固定资产更新对应复苏阶段**，不能把“繁荣时投资很旺”误解为设备更新只能到繁荣时才开始。
> - 企业恢复经营后，销售和利润逐渐改善，融资需求增加；银行发放贷款属于资产业务，因此可带动银行资产规模和收益。

### 繁荣阶段

主要表现：

- **失业率下降**，就业机会增加。
- 居民收入增加，消费支出增加。
- 社会购买力增强，市场兴旺。
- 产品供不应求，价格上涨。
- 市场预期向好，企业投资意愿上升。
- 生产发展迅速，企业经营规模不断扩大。
- 投资数额、企业利润上升。
- 商业银行**资产规模和利润处于较高或最高水平**。

> 解释：
>
> - 传导链条：**就业增加→收入增加→消费增加→市场需求活跃→企业扩大生产与投资**。
> - 可以用“积极性指标上升，失业率这一负向指标下降”帮助识别繁荣阶段。
>
> *补充：这是阶段性特征的概括，不表示所有经济指标、所有银行都在同一时点达到绝对最高值。*

### 衰退阶段

- **失业人口增加**。
- 消费需求开始下降。
- 商品滞销，生产缩减。
- 企业资金周转困难。
- 商业银行**负债规模严重下降**。

> 解释：
>
> - 繁荣后产能和产品可能过剩，企业为压缩成本裁员；失业使居民收入下降、消费更谨慎，又进一步加重产品滞销。企业经营和还款能力转弱，银行利润也可能下降。
> - 判断银行资产与负债时要注意，衰退阶段强调银行“**负债规模下降**”，不能因此把贷款记成负债。贷款是银行资产，吸收存款等才属于负债业务。
>
> *补充：银行负债、资产和利润的实际变化受政策、客户结构等影响，上述方向是周期分析模型，不是每次衰退必然同步出现的会计结果。*

### 萧条阶段

- 企业破产、倒闭增多。
- 银行贷款**坏账增加**。
- 银行贷款收缩，信用投放能力减弱。
- 银行经营利润大幅下降，甚至亏损。

> 解释：传导链条：**企业经营难以维持→还款困难和倒闭增加→银行信用损失上升→信贷收缩、利润下降**。

### 经济周期与银行经营的关系

| 经济阶段 | 企业与融资                       | 银行经营的概括                   |
| -------- | -------------------------------- | -------------------------------- |
| 复苏     | 投资与设备更新恢复，资金需求增加 | 资产业务、利润改善               |
| 繁荣     | 生产投资活跃，经营规模扩大       | 资产规模与利润处于高位           |
| 衰退     | 滞销、裁员、资金周转困难         | 负债与盈利承压，客户还款风险增大 |
| 萧条     | 破产倒闭、坏账增加               | 信贷收缩，利润大降甚至亏损       |

## 高频考点 4：行业分析

行业分析主要有**市场结构特征、与经济周期的关系**两个分类维度。

### 四种市场结构

**完全竞争→垄断竞争→寡头垄断→完全垄断**，竞争程度整体减弱，垄断程度整体增强。

| 结构类型     | 生产者         | 产品与生产资料                             | 价格控制                     | 进入退出                 | 关键词             |
| ------------ | -------------- | ------------------------------------------ | ---------------------------- | ------------------------ | ------------------ |
| **完全竞争** | 众多           | 产品**同质**；生产资料可完全流动           | 没有价格控制权，接受市场价格 | 自由进入退出             | **众多＋同质**     |
| **垄断竞争** | 众多           | 产品**不同质**，具有差异；生产资料可以流动 | 对自身产品价格有一定控制     | 联系存在一定进入成本理解 | **众多＋不同质**   |
| **寡头垄断** | **少量**生产者 | 产品可同质，也可差异化                     | 市场集中，企业相互影响       | 进出壁垒较高             | **少数、集中度高** |
| **完全垄断** | **一家企业**   | 整个行业由一家企业控制                     | 对价格控制较强               | 存在较强限制             | **一家**           |

> 解释：判断不能只看“有没有竞争”，应组合观察**生产者数量、产品差异、价格控制、进入退出条件**。
>
> *补充：表中是市场结构模型，具体价格仍可能受成本、需求与监管等约束，“完全垄断”也不等于可以不受任何约束地任意定价。*
>
> 解释：
>
> - **完全竞争**：农产品市场常用作接近这一模型的例子，现实中未必存在绝对符合所有假设的完全竞争市场。它的典型特点包括：
>   - 种植者众多。
>   - 种子、化肥、农具等相对容易取得。
>   - 同类粮食、蔬菜具有较强同质性。
>   - 单个生产者难以决定市场价格。
> - **垄断竞争**：例如服装、纺织及有关制造企业，生产者虽然多，但不同企业产品具有品牌、设计等特点，属于“同种而不同质”，因此对自身产品有一定定价能力。进入行业也需要投入成本。
> - **寡头垄断**：可以用电信领域帮助理解。“寡”就是少，产品可以同质，也可以不同质，不能只凭产品差异判断。
> - **完全垄断**：可以用部分供水、供电等公用事业场景，理解一家企业控制相关市场的情形。
> - 判断题要注意，不能只抓“生产者众多”，还要看产品是否同质。
>
> *补充：垄断竞争通常仍强调相对容易进入、退出，不能把“有一定投入成本”直接等同于寡头市场的高进入壁垒。*
>
> *补充：判断是否垄断，要明确地区、业务环节和相关市场，不能断言所有水电业务在任何范围都只有一家企业。*

### 与经济周期关系的三类行业

| 行业类型   | 教材特征                                                     | 例子                                     |
| ---------- | ------------------------------------------------------------ | ---------------------------------------- |
| **增长型** | 运行状态与经济周期关联不大，较多依赖技术进步、研发和成长因素 | 生物技术、物联网、4 D 技术等新兴成长行业 |
| **周期型** | 运行状态直接与经济周期相关                                   | 耐用品制造业、房地产、**银行业**         |
| **防守型** | 产品需求相对稳定，周期变化影响较小                           | 食品、基本医疗、公用事业等               |

> 解释：
>
> - **增长型**：即使宏观经济下行，某些行业仍可能依靠技术进步和自身发展形成增长，因此不完全跟随经济周期。
> - **周期型**：经济上行时，耐用品购买、投资和房地产等需求较旺；经济下行时，更容易受需求收缩影响。银行利润与经济周期密切相关，因此银行也是典型的周期型行业。
> - **防守型**：无论经济上行还是下行，人们仍需要基本食品、医疗、公用服务，因此需求相对稳定。
>
> *补充：教材“不受经济周期变化影响”应按“相对不敏感、影响较小”理解，不能记成任何情况下完全不受影响；增长型行业也不是完全脱离宏观环境。*

## 高频考点 5：行业生命周期

### 四阶段顺序

**初创期→成长期→成熟期→衰退期。**

> 解释：以人的一生比喻行业从形成、发展到衰退的过程。

### 初创期

- **研发费用较高**。
- 产品质量较低且不太稳定。
- 市场需求较小。
- 销售收入较低。
- 可能出现**较大亏损**。

> 解释：行业刚形成，厂商较少，研发等投入较大；产品尚未充分成熟，也未被大量消费者接受，因此容易出现投入高、收入低的状态。

### 成长期

成长期是**黄金发展时期**，主要表现为：

- 需求量大幅增加。
- 价格稳步提高。
- 进入企业数量不断增加。
- **竞争压力非常大**。

> 解释：
>
> - 产品经过升级迭代、宣传后被更多消费者接受，获利机会吸引其他企业进入，行业迅速扩张，也带来激烈竞争。
> - **“黄金时期”对应成长，不要与成熟期的“巅峰、稳定”混淆。**

### 成熟期

成熟期是**巅峰时期**，主要表现为：

- 经营模式、产品等趋于成熟。
- 利润比较稳定。
- 是行业发展的**稳定阶段**。

> 解释：判断关键词：**成熟、稳定、巅峰**。

### 衰退期

主要表现：

- 产品竞争力不断削弱。
- 市场需求减少。
- 销量下降。
- 利润下降。
- 企业数量减少。

**行业衰退期往往可能比生命周期其他阶段的总和还长。**

> 解释：出现新技术、新产品替代，原产品逐渐不符合新的市场需求，行业可能走入衰退；如果缺少革新，衰退状态可能延续较长时间。
>
> *补充：这是对某些行业衰退延续时间的概括，不是所有行业必须满足的固定时长定律；行业也可能因技术革新、需求重构而出现新的发展路径。*

### 三个容易混淆的分类

| 维度                   | 分析对象                       | 教材分类               |
| ---------------------- | ------------------------------ | ---------------------- |
| **经济周期**           | 整体经济活动的阶段性波动       | 复苏、繁荣、衰退、萧条 |
| **行业与经济周期关系** | 某行业对宏观周期的敏感程度     | 增长型、周期型、防守型 |
| **行业生命周期**       | 行业自身从形成到衰退的发展过程 | 初创、成长、成熟、衰退 |

> 解释：**经济周期的“衰退”与行业生命周期的“衰退”名称相同，但观察对象不同。**防守型并不是行业永远不会衰退，增长型也不等于一定正处在行业生命周期的成长期。

## 高频考点 6：货币的职能

### 货币的本质与五项职能

按照传统货币理论，**货币是从商品世界中分离出来、固定充当一般等价物的特殊商品**，具有价值尺度、流通手段、贮藏手段、支付手段和世界货币五项职能。

| 职能     | 含义与识别点                                   | 判断重点                                                     |
| -------- | ---------------------------------------------- | ------------------------------------------------------------ |
| 价值尺度 | 用货币衡量、表现商品价值，形成价格             | **可以使用观念上的货币**，不要求现场拿出现金                 |
| 流通手段 | 在商品交换中充当媒介                           | **必须是现实的货币，但不必是足值货币**，可以使用货币符号、信用货币 |
| 贮藏手段 | 货币退出流通领域，作为社会财富的一般代表被保存 | 传统理论要求**现实、足值的货币**                             |
| 支付手段 | 清偿债务，或用于与商品交付不同步的支付         | 突破现货交易限制，能抵销债务、节约现金与流通费用，也可能形成支付链条风险 |
| 世界货币 | 在国际经济关系中发挥一般等价物作用             | 国际支付、国际购买、社会财富国际转移                         |

> *补充：上述本质表述属于传统商品货币理论；现代信用货币不以自身具有等额商品价值为前提。做题应先辨明采用的理论背景。*

### 价值尺度与流通手段的区别

> 解释：
>
> - 价值尺度解决的是“**值多少钱**”。给商品标价只是用货币表示价值，即使现场没有相应数量的现金，也可以标出价格。
> - 流通手段解决的是“**拿钱完成交换**”。可以用“一手交钱，一手交货”概括钱货同时交换的情形。此时必须存在现实的支付媒介，但不要求货币材料本身与其所代表的价值相等。

### 贮藏手段的理论条件

作为贮藏手段的货币**退出流通、静止保存**；按照传统金属货币理论，必须是**现实且足值的货币**。

> 解释：可以用长期保存后能否仍保有价值，理解传统金属货币理论对贮藏手段的要求。
>
> *补充：不能据此断言现代纸币、存款完全不能储藏价值。信用货币也具有价值储藏功能，只是实际购买力会受通胀等因素影响；“必须足值”应限定在教材采用的传统理论中。*

### 支付手段：延期支付、债务抵销与风险

> 解释：
>
> - 支付手段与流通手段的重要区别在于**商品交付和货币支付是否同步**。先取得商品、以后还钱，偿债时体现支付手段；不能只因出现“付款”二字就判为支付手段。
> - 支付手段的积极作用包括：突破现货交易的限制，促进商品生产与流通；通过债务抵销减少实际现金支出，节约流通费用。以双方互欠款项、最后只支付差额说明抵销效果。
> - 其风险在于：不同主体形成债权债务链条后，一环不能按时付款，可能导致其他环节也无法付款，从而引发支付困难甚至信用危机。

### 世界货币的三种表现

| 表现               | 主要用途                       |
| ------------------ | ------------------------------ |
| 一般支付手段       | 清偿国际债务、结算国际收支差额 |
| 一般购买手段       | 在国际贸易中购买商品和服务     |
| 社会财富的国际转移 | 资本转移、对外援助、战争赔款等 |

## 高频考点 7：货币的需求与供给

### 影响货币需求的因素

| 因素             | 结论                                                         | 理解路径                                                     |
| ---------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 收入水平         | **主要因素，正相关**                                         | 收入增加，购买与交易活动扩大，需要持有更多交易资金           |
| 利率水平         | **负相关**                                                   | 利率提高，持有不生息货币的机会成本提高；还可以通过存款吸引力、企业借款成本解释消费和融资行为变化 |
| 社会商品可供量   | 正相关                                                       | 待交易商品越多，所需货币越多                                 |
| 物价水平         | 正相关                                                       | 同样数量商品价格提高，需要更多名义货币完成交易               |
| 货币流通速度     | **负相关**                                                   | 同一单位货币周转越快，完成一定交易所需货币越少               |
| 信用制度发达程度 | 负相关                                                       | 信用支付、转账结算越便利，完成交易所需直接持有的货币减少     |
| 汇率             | 教材称“正相关”：本币汇率下降，本币需求下降                   | 这里的“本币汇率下降”采用本币贬值的语义                       |
| 公众预期与偏好   | 预期物价上涨、货币贬值，货币需求下降                         | 人们倾向于减少货币持有，转换为商品或其他资产                 |
| 其他因素         | 人口数量、人口密集程度、经济结构、社会分工、交通通信技术状况 | 共同影响交易规模、交易组织与结算效率                         |

> *补充：利率与货币需求负相关，主要指在其他条件不变时，持有货币相对于持有生息资产的选择，不能理解为“利率提高，所有存款必然下降”。信用制度、电子支付减少现金需求，也不意味着银行存款等广义货币一定同步减少。*
>
> *补充：汇率必须先说明报价方向。这里的“本币汇率下降”指本币对外价值下降，不等同于直接标价法下外币价格的数值下降。*

### 货币流通规律公式

$$
M=\frac{P\times Q}{V}
$$

| 符号 | 含义                         | 与所需货币量的关系 |
| ---- | ---------------------------- | ------------------ |
| M    | 一定时期流通所需要的货币量   | 被解释变量         |
| P    | 商品价格水平                 | 正相关             |
| Q    | 商品交易数量、社会商品可供量 | 正相关             |
| V    | 货币流通速度                 | 负相关             |

> 解释：可以用**同一张 5 元钱连续流转**说明流通速度：先用于买笔，收款人再拿它买包子，下一位收款人再用它买肉。一次次交易不需要分别新增一张 5 元钱；周转越快，既定交易总额所需要的货币量越少。
>
> *补充：公式中的 P、Q、V 应使用一致的时期与统计范围；它说明给定交易规模下的货币需要量，不能机械等同于现实货币供给的全部决定机制。*

### 货币供给层次

货币供给层次按流动性从强到弱分为**$M_0$、$M_1$、$M_2$**。

| 层次         | 教材构成                                                     | 理解                               |
| ------------ | ------------------------------------------------------------ | ---------------------------------- |
| $M_0$        | 流通中的现金，教材括注“包括数字货币”                         | 已进入社会流通的现金               |
| $M_1$        | $M_0$＋企业活期存款＋机关团体部队存款＋农村存款＋个人持有的信用卡类存款 | 狭义货币，现实购买力               |
| $M_2$        | $M_1$＋城乡居民储蓄存款＋企业存款中定期性质的存款＋外币存款＋信托类存款；教材另列证券公司客户保证金、住房公积金中心存款、非存款类金融机构存款 | 广义货币，同时包含现实和潜在购买力 |
| $M_2$－$M_1$ | 准货币                                                       | 主要体现潜在购买力                 |

**$M_0$ 不包括商业银行库存现金，也不包括中央银行发行库中的货币。**

> 解释：
>
> - 企业活期资金经常用于支付、周转较快；居民储蓄在旧口径中更多属于潜在购买力，可以据此理解层次差异。
> - 判断 $M_0$ 时，要区分“在库”与“已进入流通”。
>
> *补充：上表保留旧统计口径。人民银行自统计 2025 年 1 月数据起修订 $M_1$：$M_1$＝$M_0$＋单位活期存款＋个人活期存款＋非银行支付机构客户备付金。不能再把所有个人活期存款一概排除在 $M_1$ 之外。按人民银行现行概括，$M_2$ 包括 $M_1$、单位和个人定期存款及其他存款。[来源：人民银行《狭义货币和广义货币》](https://www.pbc.gov.cn/rmyh/109339/2025080818580470423/index.html)、[人民银行文告所载 $M_1$ 修订公告](https://www.pbc.gov.cn/chubanwu/fileDir/resource/cms/2025/06/2025062416082199683.pdf)。*
>
> *补充：教材“数字货币”应理解为纳入统计的流通中数字人民币，不能扩大为所有虚拟货币。人民银行从 2022 年 12 月起将流通中数字人民币计入 $M_0$。[来源：2022 年金融统计数据报告](https://app.www.gov.cn/govdata/gov/202301/12/496136/article.html)。*

### 基础货币、存款创造与货币乘数

货币供给既包括中央银行提供的基础货币，也与商业银行通过存贷款活动创造的存款货币有关。商业银行存款创造的重要条件是**基础货币**与**货币乘数**，后者影响信用创造规模。

| 货币乘数的影响因素     | 符号  | 影响方向           |
| ---------------------- | ----- | ------------------ |
| 法定存款准备金率       | $r_d$ | 提高，货币乘数下降 |
| 超额准备金率           | e     | 提高，货币乘数下降 |
| 定期存款的存款准备金率 | $r_t$ | 提高，货币乘数下降 |
| 现金漏损率             | c     | 提高，货币乘数下降 |

> 解释：
>
> - 银行收到存款后，如果必须留存的准备金更多，或现金流出银行体系更多，能继续贷出的资金就更少，存款派生能力也更弱。**四项因素与乘数均按负相关记忆。**
> - 可以用“1 除以若干准备金率、现金漏损率之和”的简式帮助记忆影响方向：
>
> $$
> k=\frac{1}{r_d+e+c+r_t}
> $$
>
> *补充：上述简式用于帮助记忆，不能作为不加条件的通用货币乘数公式。准备金率的计算基数不同，定期存款还需要相对于活期存款的比例等参数。若以 D 表示活期存款，c＝现金/D，e＝超额准备金/D，t＝定期存款/D，则在相应简化模型中，基础货币 B＝(c＋r_d＋e＋r_t t)D；若 $M_1$＝现金＋活期存款，则 $M_1$/B＝(1＋c)/(c＋r_d＋e＋r_t t)。计算题应以题设的货币范围、变量定义和假设为准。*

## 高频考点 8：货币政策

### 制定主体与目标层次

货币政策由**中央银行制定并实施**，通过调节货币、信贷和相关金融条件影响经济运行，目标分为**操作目标、中介目标、最终目标**。

| 层次     | 主要内容                                   | 提示                                       |
| -------- | ------------------------------------------ | ------------------------------------------ |
| 操作目标 | 准备金、基础货币、其他                     | 最接近中央银行操作；基础货币               |
| 中介目标 | 利率、货币供应量、其他                     | 位于政策操作与最终经济效果之间；货币供应量 |
| 最终目标 | 经济增长、物价稳定、充分就业、国际收支平衡 | 与宏观经济运行目标相联系                   |

> 解释：
>
> - 可以用“准备金、基础货币、其他”和“利率、货币供应量、其他”分别概括前两层，复习时应避免把**基础货币**与**货币供应量**放错层次。
> - 传导次序为：**货币政策工具影响操作目标，操作目标影响中介目标，再作用于最终目标。**设置中间层次，是因为工具与最终经济效果之间距离较远，需要观察并调节传导过程。

### 我国货币政策目标

**保持货币币值稳定，并以此促进经济增长。**

> 解释：可以将币值稳定分为：对内表现为物价稳定，对外表现为汇率稳定。
>
> *补充：币值稳定的内外含义并不意味着汇率数值必须始终不变。关于“当前主要操作目标、当前主要中介目标”的表述具有授课时期背景，不能据此排除价格型调控和利率传导的重要作用。*

### 操作目标和中介目标的选择标准

| 标准         | 含义                                               |
| ------------ | -------------------------------------------------- |
| **可观测性** | 指标能够被观察、统计，能识别其变化                 |
| **可控性**   | 中央银行能够施加影响，出现偏差后能进行调节         |
| **相关性**   | 不同层次目标之间存在较稳定的联系，能传导到最终目标 |

## 高频考点 9：货币政策工具

### 四类工具总表

| 类别                   | 主要类型                                                     | 识别重点                                   |
| ---------------------- | ------------------------------------------------------------ | ------------------------------------------ |
| **一般性货币政策工具** | 法定存款准备金、再贴现、公开市场业务                         | 传统“三大工具”，调节总体货币信用条件       |
| **选择性货币政策工具** | 证券市场信用控制、消费者信用控制、不动产信用控制、优惠利率、预缴进口保证金 | 针对特定领域或特定用途                     |
| **直接货币政策工具**   | 利率限制、信用配额、直接干预、流动性比率                     | 通过限制、配额或指标等方式直接约束金融机构 |
| **间接货币政策工具**   | 窗口指导、道义劝告、金融检查、公开宣传                       | 指导、劝告、沟通等较柔和的影响方式         |

### 一般性工具与公开市场业务

一般性货币政策工具可称为央行的“**三大法宝**”，其中**公开市场业务灵活性较强，是常用工具**。

> 解释：
>
> - **央行买入国债**：向市场支付资金，投放货币、释放流动性。
> - **央行卖出国债**：从市场收回资金，回笼货币、收紧银根。
>
> *补充：公开市场操作的交易形式不只限于现券买卖；判断题目方向时，应识别交易主体、资金流向及是否涉及到期回笼，不能只看到“买入”二字就脱离主体判断。*

### 其余三类工具的解释

> 解释：
>
> - 选择性工具针对特定领域：证券交易信用、消费信贷、不动产信贷，或针对特定经营者实施优惠利率；预缴进口保证金则用于影响进口相关资金占用。
> - 直接工具中，信用配额是对信贷投放额度等进行约束；流动性比率是对金融机构流动性指标提出要求；利率限制和直接干预也具有直接约束特点。
> - 间接工具中，将窗口指导、道义劝告等比作较柔和的沟通影响，帮助区分配额、限制等直接措施。
>
> *补充：这里保留教材分类；不能据此认定“金融检查完全没有强制性”，也不能把教材列举当成现行全部货币政策工具的完整清单。*

## 高频考点 10：货币政策的传导

货币政策主要通过**利率、信贷、资产价格、汇率**四个渠道传导。

### 利率渠道

**扩张性货币政策 → 货币供给增加 → 利率下降 → 企业融资成本下降 → 投资增加 → 总产出增加。**

> 解释：可以将利率理解为资金的价格：资金供给增加，在其他条件不变时价格趋于下降；企业借钱更便宜，就更愿意更新设备、建设生产线、扩大投资，进而带动生产。

### 信贷渠道

| 政策方向 | 传导链条                                                     |
| -------- | ------------------------------------------------------------ |
| 扩张性   | 货币供给增加 → 银行可贷资金增加 → 企业较容易取得贷款 → 投资、生产增加 → 总产出增加 |
| 紧缩性   | 银行可贷资金减少 → 企业难以取得贷款 → 投资、生产减少 → 总产出下降 |

> 解释：区分要点：利率渠道突出**借钱的价格**，信贷渠道突出**能否获得贷款、可贷资金数量**。

### 资产价格渠道之一：托宾 q 效应

$$
q=\frac{企业市场价值}{资本重置成本}
$$

**扩张性政策 → 货币供给增加 → 股票价格上涨 → 企业市场价值提高 → q 上升 → 新建、重置相对更划算 → 投资增加 → 总产出增加。**

> 解释：
>
> - 市场价值可以用企业在股票市场上的价值理解；重置成本是重新建设一家同样企业所需要的成本。
> - 假设希望取得一家企业，可以比较两种方式：一种是在股票市场收购现有企业，另一种是仿照它重新建厂、购置设备并组织生产。
> - 新建企业会带动厂房、设备、原材料和用工需求，产生对现实生产的拉动。反过来，q 较低时，购买现有企业相对更便宜，新建投资动力较弱。
>
> *补充：q 是比值，不等于股价本身；股价上涨只是影响企业市场价值的一条路径。收购现有企业的交易金额也不能直接当作同额新增实物投资。*

### 资产价格渠道之二：消费财富效应

**扩张性政策 → 股票等资产价格上涨 → 居民持有资产的财富增加 → 消费增加 → 商品需求增加 → 总产出增加。**

> 解释：持有的股票更值钱，人们感到更富有，消费意愿和能力相应增强。与托宾 q 效应相比，这条链突出的是**居民财富与消费**，前者突出的是**企业投资**。

### 汇率渠道

**扩张性政策 → 货币供给增加 → 国内利率下降 → 本币资产相对吸引力下降 → 本币贬值 → 出口增加、进口减少 → 净出口增加 → 总需求和总产出增加。**

> 解释：从交易双方的购买力解释：本币贬值后，外国购买者用外币购买本国商品相对更便宜，有利于本国出口；本国购买外国商品相对更贵，不利于进口。
>
> *补充：上述均为在其他条件不变、传导有效时的方向性分析。资本流动、汇率制度、预期、生产能力和进出口需求弹性都会影响实际结果；货币扩张不保证每一环都会按相同幅度变化。*

## 高频考点 11：利率与汇率

### 利率的含义

利率是资金的价格，基本关系是**利息与本金的比率**。计算时应保持期限口径一致。

### 利率的分类

| 分类标准           | 类型               | 说明                                                         |
| ------------------ | ------------------ | ------------------------------------------------------------ |
| 约定期限内是否调整 | 固定利率、浮动利率 | 固定利率便于核算收益成本，但市场利率变化时可能使借贷一方承担不利结果；浮动利率能随市场条件调整，但未来收支较难准确预估 |
| 存贷款业务关系     | 存款利率、贷款利率 | 存款利息是银行的资金成本，贷款利息是银行收入来源；存贷利差是商业银行的重要收益来源 |
| 利率发挥的作用     | 基准利率、市场利率 | 基准利率具有引导、参照作用；市场利率主要由市场资金供求等决定 |
| 是否考虑通货膨胀   | 名义利率、实际利率 | 名义利率未经通胀调整；实际利率反映购买力意义上的实际成本和收益 |
| 制定主体           | 官定利率、公定利率 | 官定由政府或中央银行等确定；公定由银行公会、同业协会等行业组织确定 |
| 地域               | 国内利率、国际利率 | 区分所处市场范围                                             |
| 期限               | 短期利率、长期利率 | 区分资金使用期限                                             |
| 是否具有优惠性质   | 一般利率、优惠利率 | 区分是否面向特定对象、用途给予优惠                           |

> 解释：**官定与公定的辨别重点是制定主体。**公定不是“政府公布的利率”；它从行业角度出发，由行业组织制定。

### 贷款市场报价利率与基准利率的作用

贷款市场报价利率 **LPR** 可以作为贷款利率定价的重要基础，由原有贷款基础利率机制改革而来。

> 解释：可以用“**我国再贷款利率、其他国家再贴现利率**”作为基准利率的例子。
>
> *补充：这是帮助理解基准利率的简化概括，不宜记成“我国只有再贷款利率这一种基准、所有外国都用再贴现利率”。不同国家、时期的政策利率与市场基准不同；LPR、央行政策利率、市场交易利率也不是同一个概念。*

### 名义利率与实际利率

$$
实际利率\approx名义利率-通货膨胀率
$$

> 解释：名义利率可从挂牌或合同中直接看到；实际利率还需要结合物价变化判断。关键问题是：取得利息后，资金是否还能买到原来相同数量的商品。
>
> *补充：严格关系为 1＋实际利率＝(1＋名义利率)/(1＋通胀率)。近似减法适用于相关比率较低等情形；利率与通胀率要使用一致期间。*

### 汇率与两种标价方法

汇率是两种货币之间的兑换比率，**外汇收支、外汇供求**是影响汇率的重要因素。

| 标价方法       | 固定为基准的货币 | 表达方式               | 示例                    |
| -------------- | ---------------- | ---------------------- | ----------------------- |
| **直接标价法** | 一定单位外币     | 需要多少本币购买该外币 | 1 美元＝7 元人民币      |
| **间接标价法** | 一定单位本币     | 本币能兑换多少外币     | 1 元人民币约＝0.14 美元 |

> *补充：0.14 是近似值，1/7 约为 0.142857。以上为教学假设，并非实时汇率。*
>
> *补充：在直接标价法下，1 单位外币能兑换的本币数增加，表示外币升值、本币贬值；在间接标价法下，1 单位本币能兑换的外币数增加，表示本币升值。不能脱离标价方法直接判断“汇率数值上升就是本币升值”。*

### 汇率变动的经济影响

| 影响领域               | 影响方向                                                     | 机制与重点                                                   |
| ---------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 对外贸易与国际收支     | 本币贬值有利于出口、不利于进口，净出口趋于增加；升值反向     | 出口相对便宜，进口相对昂贵；可以将出口收入增加与顺差联系起来 |
| 资本流动               | 本币贬值可能导致资本流出，本币升值可能吸引资本流入           | 从持有本币资产的意愿、收益预期解释                           |
| 国际储备               | 储备货币升值，储备按其他货币计价的价值可能增加；本币贬值、出口增加，也可能带来外汇收入增加 | 区分储备资产的估值变化与外汇流入带来的数量变化               |
| 通货膨胀               | 本币贬值可能加大通胀压力                                     | 一条路径是出口增加、国内商品供给相对减少；另一条是外汇收入增加可能带来货币投放压力 |
| 国际债务               | 债务计价货币升值，债务人以本币偿还的负担加重                 | 需要更多本币兑换同额外币偿债                                 |
| 世界财富分配           | 汇率改变资产、债权债务的相对价值                             | 不同持有者的财富发生重新分配                                 |
| 金融投机与国际金融秩序 | 汇率波动影响投机；竞争性贬值可能扰乱国际金融秩序             | 各国若竞相贬值刺激出口，可能形成恶性竞争                     |

> 解释：以美元储备举例：持有美元资产时，美元升值可能提高以其他货币衡量的储备价值。注意这里讨论的是**计价口径改变后的价值**，不能混同于美元资产数量自动增加。
>
> *补充：贬值不保证必然形成贸易顺差，更不能保证国际收支所有项目都顺差；资本流动还取决于预期、利差、风险与制度条件。外汇收入也不会不经任何结售汇、央行操作等环节就自动变成等额基础货币投放。*

## 高频考点 12：金融市场

金融是货币资金的融通；金融市场是**货币资金融通和金融工具交易的场所及相关关系**。

### 金融市场的六项功能

| 功能                   | 解释                                                         | 识别关键词             |
| ---------------------- | ------------------------------------------------------------ | ---------------------- |
| **货币资金融通**       | 使资金盈余方的资金流向需求方                                 | 最基本、最主要功能     |
| **优化资源配置**       | 资金跨时间、地区、行业流动，流向更需要资金或使用效率更高的领域 | 时间、地域、行业配置   |
| **风险分散与风险管理** | 利用投资组合、套期保值以及有关金融产品管理风险               | 分散、转移、对冲风险   |
| **经济调节**           | 通过资金聚集和配置影响经济活动，政府也可借助市场实施调控     | 引导资金流向、调节经济 |
| **交易与定价**         | 集中供求、便利交易，交易中形成价格并降低相关成本             | 价格发现、交易便利     |
| **反映经济运行**       | 金融价格、交易情况反映经济主体对经济状况的判断               | 经济“晴雨表”           |

> 解释：以股票市场作为“晴雨表”的典型例子：股票上涨可能反映市场对经济向好的判断，股票下跌可能反映经济或预期出现问题。
>
> *补充：股市包含预期、估值、流动性和风险偏好等信息，不能把“股价大跌”直接等同于实体经济必然已出现同等幅度衰退。风险管理也不等于消灭一切风险。*

### 六种分类标准

| 分类依据       | 分类结果                           | 例子与注意点                                                 |
| -------------- | ---------------------------------- | ------------------------------------------------------------ |
| 期限           | **货币市场、资本市场**             | 货币市场主要融通一年以内或不超过一年的短期资金；资本市场主要融通长期资金 |
| 金融工具类型   | 债券、票据、外汇、股票、黄金等市场 | 同一种工具还可按期限等标准交叉归类                           |
| 发行与流通阶段 | **发行市场、流通市场**             | 又称一级市场、二级市场                                       |
| 交割时间       | **现货市场、远期及期货市场**       | 区分近期交割与约定未来交割                                   |
| 场所与空间     | **有形市场、无形市场**             | 对应场内市场、场外市场                                       |
| 融资方式       | **直接融资市场、间接融资市场**     | 看资金供需方之间的融资关系与金融中介作用                     |

### 货币市场与资本市场

货币市场典型组成包括：**同业拆借市场、回购市场、票据市场、大额可转让定期存单市场**。资本市场典型代表为股票市场和长期债券市场；短期债券按期限应归入货币市场范畴。

> 解释：
>
> - 传统大额可转让定期存单具有以下特征：
>   - 金额较大。
>   - 不记名。
>   - 不能提前支取；需要提前变现时，主要通过转让。
> - 将其与普通定期存款比较：普通定期存款通常可以提前支取，但利息按相应提前支取规则处理；可以用按活期计息帮助理解两者差异。
>
> *补充：上面“不记名、不能提前支取”是介绍的传统可转让定期存单特征，不能直接套用到我国所有银行当前发行的“大额存单”。名称相近的产品仍须按具体制度和合同条款区分。*

### 一级市场与二级市场

**一级市场是新证券的发行市场**，解决金融工具从无到有、筹集新资金的问题。**二级市场是已发行证券的交易流通市场**，解决存量证券的买卖与转让。

> 解释：投资者平时在交易所买卖已上市股票，通常属于二级市场交易。发行完成后再转让，不再因为购买人换了就重新变成一级市场发行。

### 现货、远期与期货

现货交易并非一律要求成交瞬间完成全部交割；也包括当日、次日或相隔较短时间交割的交易。

远期交易是在当前约定未来交割。**期货是在远期交易基础上发展起来的，具有合约标准化特征**。因此不能把所有约定未来交割的交易都叫作期货。

### 场内、场外与直接、间接融资

| 融资方式 | 例子                                             | 理解                                                   |
| -------- | ------------------------------------------------ | ------------------------------------------------------ |
| 直接融资 | 商业信用、企业发行股票和债券、政府发行国债或公债 | 资金提供者与融资者直接形成相应债权或股权关系           |
| 间接融资 | 银行存贷款等                                     | 银行吸收存款后再发放贷款，分别与存款人、借款人建立关系 |

> 解释：
>
> - 以交易所解释有形、场内市场，以交易所以外的交易安排解释无形、场外市场。
> - 可以用“有没有银行等中介转接资金”帮助记忆：存款客户把钱存给银行，再由银行贷给借款人，不是存款人与贷款客户直接建立同一笔借贷关系。
>
> *补充：现代交易大量通过电子系统进行。“有形、无形”的传统用语不能仅按是否面对面、是否存在某一栋建筑来判断场内或场外。*
>
> *补充：直接融资也可以有证券公司承销、经纪等专业服务。判断重点不是交易过程中完全没有任何金融机构参与，而是是否由金融中介以自身资产负债承担资金转换、形成间接融资关系。*

### 中央银行的三项基本职能

| 职能           | 解释                                                         |
| -------------- | ------------------------------------------------------------ |
| **发行的银行** | 依法发行、管理货币                                           |
| **银行的银行** | 为银行等金融机构开立账户，集中存款准备金，提供相关资金支持与清算服务 |
| **政府的银行** | 经理国库等，为政府提供有关金融服务                           |

> 解释：以“政府的管家、出纳”帮助理解经理国库；以主要面对银行等机构、不以普通居民和企业日常存贷款业务为经营内容，解释“银行的银行”。
>
> *补充：中央银行的法定货币发行，与商业银行通过存贷款活动创造存款货币不同。不能由“中央银行发行货币”推导出商业银行没有信用创造功能，也不能把商业银行存款创造说成印制发行人民币现金。*

### 开发性金融机构与政策性银行

**国家开发银行**是开发性金融机构，成立于 **1994 年**；**中国进出口银行、中国农业发展银行**是政策性银行。

开发性金融机构、政策性银行按经济政策、发展战略和特定领域需要提供金融支持，发挥经济调控、政策导向、补充性和金融服务作用。

> 解释：开发性、政策性金融补充商业金融的原因在于：有些项目资金需求量大、建设和回收周期长，或收益、风险条件使商业银行不愿提供充分服务，需要开发性、政策性金融发挥作用。

>
> *补充：村镇银行另有准入规定。所核对监管规则区分县（区）域与乡（镇）设立，最低实缴注册资本分别为 300 万元、100 万元；不能把这些最低额理解为任何具体机构都只需该金额即可获批。[来源：金融监管部门农村中小银行机构行政许可规则](https://www.nfra.gov.cn/cn/view/pages/rulesDetail.html?docId=274180&itemId=4214)。*

## 高频考点 14：存款业务

存款业务分为**个人存款、单位存款、外币存款和其他存款业务**，重点是个人和单位存款。

### 个人活期存款与计息

活期存款在存入时不约定存期，具有随存随取、使用灵活的特点。

**个人活期存款采用积数计息，按季结息**：每季度末月的 **20 日结息，21 日付息**。计算关系为：

$$
利息=本金\times实际天数\times日利率
$$

$$
累计计息积数=\sum(每日存款余额)
$$

$$
利息=累计计息积数\times日利率
$$

利率与持有期限的单位应保持一致：

| 换算           | 换算公式           |
| -------------- | ------------------ |
| 年利率换月利率 | 月利率＝年利率÷12  |
| 年利率换日利率 | 日利率＝年利率÷360 |

> 解释：
>
> - 当本金余额发生变动时，不能把一个余额直接乘以全部天数，应按实际余额与其持续天数累计计息积数。
> - 可以用“利息并入本金继续计息”解释活期存款的复利效果，并将其与定期存款的逐笔计息作对比。
>
> *补充：“积数计息、逐笔计息”是计息方法，“单利、复利”是利息是否再生息的问题，二者不属于同一个分类维度。活期结息后利息转入本金，可在后续期间产生利息；不能由此推导“所有积数计息业务必然复利，只有活期业务才可能出现复利”。*

### 个人存款的其他类型

| 类型         | 主要内容                                               | 解释与识别点                                                 |
| ------------ | ------------------------------------------------------ | ------------------------------------------------------------ |
| 定期存款     | 整存整取、零存整取、整存零取、存本取息；逐笔计息       | “整、零”帮助识别存入和支取的次数、方式；比较中整存整取利率较高，其他三类较低 |
| 定活两便存款 | 存期灵活、利率优惠                                     | 存时不约定存期，按实际持有期限计算；相应定期整存整取利率的**六折** |
| 个人通知存款 | 支取时提前通知                                         | 分为**一天通知、七天通知**，并非要求必须存一天或七天后立即全部支取 |
| 教育储蓄存款 | 小学四年级及以上；一年、三年、六年；利率优惠、总额控制 | 用于以后非义务教育阶段的有关支出，属于零存整取性质的储蓄     |
| 保证金存款   | 个人购汇保证金存款                                     | 以出国、办理签证等涉及购汇保证的场景帮助理解                 |

> 解释：教育储蓄的利率优惠是指：虽然具有零存整取性质，但按相应优惠整存整取利率计息；**一年期按一年期、三年期按三年期，六年期参照五年期整存整取利率**。这里“参照五年期利率”不等于只计算五年的持有时间。另需注意其存款实行总额控制。以普通定期的一年、三年、五年等期限与教育储蓄的一年、三年、六年作比较。
>
> *补充：前述一年、三年、五年只是对比采用的期限，不是普通整存整取所有存期的完整清单。*
>
> *补充：教育储蓄的传统规则包括每一账户本金合计最高 2 万元等条件；具体办理须结合产品是否仍开办及相应规则。[来源：教育部公布的教育储蓄相关办法](https://www.moe.gov.cn/jyb_xxgk/gk_gbgg/moe_0/moe_495/moe_1113/tnull_13378.html)。不能把“六折”理解为任意期限都可选最高定期利率打折，也不能把通知期限当作固定存期。*

### 单位活期存款：四类账户

单位活期存款用于日常经营和结算，账户分为**基本存款账户、一般存款账户、专用存款账户、临时存款账户**。

| 账户             | 用途与规则                                   | 重点                                                         |
| ---------------- | -------------------------------------------- | ------------------------------------------------------------ |
| **基本存款账户** | 日常转账结算和现金收付的主办账户             | 一个单位只能开立一个基本存款账户；工资、奖金及有关现金支取通过基本账户办理 |
| **一般存款账户** | 因借款或其他结算需要开立，作为基本账户的补充 | 可以开立多个；**可以缴存现金，不能支取现金**                 |
| **专用存款账户** | 为特定用途资金进行专项管理和使用             | 以社保、专项建设、证券等特定资金用途解释，注意专款管理       |
| **临时存款账户** | 临时机构、临时经营活动、注册验资等需要       | 有效期**最长不超过 2 年**                                    |

> 解释：**基本账户的现金支取功能与一般账户不能支取现金，是账户判断的重点。**专用账户能否支取现金，要结合具体资金性质和管理要求判断，不能一概而论。
>
> *补充：上述为境内单位人民币银行结算账户的教材框架，不是对所有币种、所有特别制度下账户作无条件概括；临时账户期限亦须结合适用的账户管理制度。*

### 单位其他存款

| 类型             | 主要内容                                                     |
| ---------------- | ------------------------------------------------------------ |
| 单位定期存款     | 单位按约定期限存放资金                                       |
| 单位通知存款     | 与个人通知存款一样，区分**一天、七天**通知                   |
| **单位协定存款** | 银行与单位客户约定基本额度；**基本额度部分按活期利率，超额部分按协定利率**计息；教材以人民银行规定的上浮利率说明超额部分 |
| 单位保证金存款   | 银行承兑汇票保证金、信用证保证金、黄金交易保证金、远期结售汇保证金等 |
| 人民币同业存款   | 金融机构之间的存款，涉及同业存放、存放同业两个方向           |

| 从本银行角度看 | 含义                     | 资产负债属性   |
| -------------- | ------------------------ | -------------- |
| **同业存放**   | 其他金融机构把钱存入本行 | 本行的**负债** |
| **存放同业**   | 本行把钱存到其他金融机构 | 本行的**资产** |

> 解释：
>
> - 单位协定存款的识别重点是**同一账户资金按基本额度和超额部分适用不同计息安排**，不是整笔资金一律适用同一利率。
> - 单位保证金与相关授信、结算和交易义务相联系，用于保证相应责任履行；不要与个人购汇保证金的使用场景混同。
> - 判断时应先确定“谁的钱存到谁那里”，再判断资产或负债。

### 外币存款与外汇报价

外汇报价中的“买、卖”均以**银行**为主体：

| 报价   | 含义                   |
| ------ | ---------------------- |
| 汇买价 | 银行买入外汇现汇的价格 |
| 汇卖价 | 银行卖出外汇现汇的价格 |
| 钞买价 | 银行买入外币现钞的价格 |
| 钞卖价 | 银行卖出外币现钞的价格 |

> 解释：
>
> - 常见外币存款可以用“**九种外币**”概括。具体存款、兑换币种应结合银行办理范围。
> - 记忆口诀：**钞变钞，汇变汇。**现钞和现汇在处理成本、转换手续上有区别，不应不加区分地视作同一种资金形态。
> - 客户把外币卖给银行，使用银行买入价；客户向银行购买外币，使用银行卖出价。必须先判断交易方向，再判断是钞还是汇。
>
> *补充：“九种”不能理解为所有银行依法只能办理完全相同的九种外币。“钞变钞、汇变汇”是记忆方式，不表示现钞与现汇在任何条件下都禁止转换；实际办理及费用依规定、银行服务范围和产品条款。*

### 大额存单、同业存单与结构性存款

其他存款业务包括**大额存单业务、同业存单业务、个人结构性存款**。

大额存单的起点金额为**个人 20 万元、机构 1000 万元**。同业存单面向相应同业市场，与个人大额存单应区分。

> 解释：可以用“存款＋衍生品”解释结构性存款，指出其收益与相关衍生交易相联系。
>
> *补充：个人 20 万元是常见起点；机构 1000 万元也是大额存单相关办法所列起点；具体产品可以设置更高门槛。个人起点由原 30 万元调整为 20 万元，自 2016 年 6 月 6 日起施行。[来源：人民银行文告所载调整公告](https://wuhan.pbc.gov.cn/chubanwu/114566/114579/3842271/3842532/2019061117433378190.pdf)、[财务公司协会收录的大额存单管理暂行办法](https://www.cnafc.org/cnafc/front/detail.action?id=e24707081e7f4ee6a466ea9e80c1504a)。结构性存款可以是人民币或外币存款嵌入金融衍生产品，不能限定为只有外币存款；也不能把衍生部分可能带来的收益说成保证获得的额外收益。*

## 高频考点 15：贷款业务

贷款按借款人分为**个人贷款、公司贷款**。

### 个人住房贷款

| 类型                 | 说明                                                 |
| -------------------- | ---------------------------------------------------- |
| 个人住房按揭贷款     | 购买住房时办理的相应贷款                             |
| 二手房贷款           | 购买二手住房办理的贷款                               |
| 公积金个人住房贷款   | 利用住房公积金资金，由受托银行办理的相应贷款         |
| 个人住房组合贷款     | **公积金贷款＋商业性住房贷款**                       |
| 直客式个人住房贷款   | 客户不经有关中介介绍，直接向银行申请                 |
| 固定利率个人住房贷款 | 按约定固定利率安排办理的住房贷款                     |
| 个人商用房贷款       | 购买商铺等商用房产所涉及的贷款；在住房相关贷款中列示 |

> 解释：
>
> - 理解公积金贷款的**委托贷款性质**：资金来源于住房公积金，银行接受委托办理，而不是银行把自己的商业信贷资金作为公积金贷款直接出借。贷款对象、额度、期限和利率等须遵循公积金相关制度与委托安排。
> - 组合贷款用于公积金贷款不能完全满足购房融资需要的情形，差额再以符合条件的商业贷款补足。
> - **个人住房装修贷款虽然名称中有“住房”，归入消费贷款。**不能仅凭是否出现“住房”二字分类。

### 个人消费贷款

个人消费贷款包括**个人汽车贷款、助学贷款、个人消费额度贷款、个人住房装修贷款、个人耐用消费品贷款、个人权利质押贷款**。

#### 个人汽车贷款的比例

| 车辆或用途                       | 最高贷款发放比例       |
| -------------------------------- | ---------------------- |
| 商用传统动力汽车                 | **70%**                |
| 商用新能源汽车                   | **75%**                |
| 二手车                           | **70%**                |
| 自用传统动力汽车、自用新能源汽车 | **由金融机构自主确定** |

> *补充：上述数字与 2024 年《关于调整汽车贷款有关政策的通知》一致。“自主确定”是在依法合规、风险可控前提下，由金融机构结合借款人信用状况、还款能力等判断，不等于每位申请人均可获全额贷款。[来源：人民银行、金融监管总局联合通知](https://app.www.gov.cn/govdata/gov/202404/03/513639/article.html)。*

#### 助学贷款

| 类型             | 区别                                                         |
| ---------------- | ------------------------------------------------------------ |
| **国家助学贷款** | 具有政策支持、财政贴息特点，主要面向符合条件的家庭经济困难学生，支持高等教育阶段有关支出 |
| **商业助学贷款** | 对象范围相对较宽，不以所有借款人都必须家庭经济困难为前提，可用于符合条件的高等教育及其他非义务教育阶段支出 |

#### 其他消费贷款

**个人消费额度贷款**以核定额度为基础，在约定条件和有效期内使用、循环支用。**个人住房装修贷款**用于装修消费。**个人耐用消费品贷款**用于相关耐用消费品购置。**个人权利质押贷款**以符合条件、具有财产价值的权利作为质押担保。

> *补充：质押属于担保方式，消费、经营属于用途分类。不能把所有个人权利质押贷款都认定为必然只能用于消费。*

### 个人经营贷款与信用卡透支

个人经营贷款用于符合条件的个人生产经营活动，申请主体包括**个体工商户、个人独资企业投资人、合伙企业合伙人**，强调以相应个人身份承担借款关系，不等同于对企业法人直接发放公司贷款。

**个人信用卡透支**也是个人信贷业务的一类。

### 两种基础还款方式

| 对比               | 等额本息                       | 等额本金                       |
| ------------------ | ------------------------------ | ------------------------------ |
| 每期本金＋利息合计 | 通常相同                       | 逐期减少                       |
| 每期归还本金       | 前期较少，后期增加             | 每期相同                       |
| 每期利息           | 随剩余本金下降而减少           | 随剩余本金下降而减少           |
| 图示               | 总还款额大体水平，本息构成改变 | 本金部分固定，利息部分逐步下降 |
| 负担特点           | 便于按相近金额安排每期支出     | 前期还款较多，后期逐步减少     |

> 解释：等额本息是**本息合计相等**，并非每期本金、利息分别都相等；等额本金是**本金相等**，并非每期总还款额相等。
>
> *补充：上述比较以利率和约定还款条件不变为前提。在本金、期限、利率相同的常见模型中，等额本金因更早归还本金，利息总额通常更低；不能只比较每期金额而忽略资金占用时间。*

### 公司贷款：流动资金贷款

**流动资金贷款用于借款人的日常生产经营周转**，不得用于以下领域和用途：

- 不得用于股东分红。
- 不得用于金融资产投资。
- 不得用于固定资产投资。
- 不得用于股权投资。
- 不得用于国家禁止生产、经营的领域和用途。

> 解释：这些限制要求把贷款期限、资金用途和经营现金流相匹配，不能将经营周转贷款挪作长期资本性投入或其他禁止用途。

### 固定资产贷款与受托支付

固定资产贷款主要包括**基本建设贷款、技术改造贷款**，分别对应固定资产建设、升级改造等需要。

**向某一交易对象单笔支付金额超过 1000 万元人民币，应采用贷款人受托支付方式。**

> 解释：受托支付不是银行先把资金完全交由借款人自由支配，再由借款人决定是否付给交易对象；而是根据合同和支付申请，由银行将贷款资金支付给符合约定用途的交易对象。
>
> *补充：2024 年 7 月 1 日起施行的《固定资产贷款管理办法》第三十条采用“向借款人某一交易对象单笔支付金额超过一千万元人民币”的标准。“超过”不包含恰好等于 1000 万元；但不触发本条金额标准，不代表贷款人不能按合同、风险管理等要求采用受托支付。[来源：金融监管总局《固定资产贷款管理办法》](https://www.nfra.gov.cn/cn/view/pages/rulesDetail.html?docId=1151060)。*

### 项目融资与房地产贷款

**项目融资**主要面向一个或一组大型生产装置、基础设施、房地产项目或其他项目建设，也包括对在建或已建项目的再融资，具有**建设周期较长、资金需求较大、风险管理要求较高**等特点。

**房地产开发贷款**包括住房开发贷款、商业用房开发贷款。商住两用房可以用**商业用途超过 50%** 作为按商业用房相关口径判断的提示。

> 解释：
>
> - 项目融资、房地产开发贷款应结合固定资产贷款理解。
> - 最重要的识别点是**还款来源主要依靠项目自身产生的收入**，如项目销售收入、补贴收入或其他项目现金流。可以用“贷款建项目，再靠项目收入还贷款”解释这一点。
>
> *补充：“超过 50%”是用途分类的提示，不能脱离项目批准用途、面积口径和具体信贷制度，将任何商住项目一律按同一规则处理。公司房地产开发贷款与个人购买住房、商铺的贷款也不是同一业务。*

### 贸易融资：六类业务逐项区分

| 业务         | 融资对象                       | 依据或作用                                                   | 识别重点                     |
| ------------ | ------------------------------ | ------------------------------------------------------------ | ---------------------------- |
| **保理**     | 主要以出口商为例               | 应收账款转让及相应服务                                       | 应收账款                     |
| **信用证**   | 进口商申请开立，出口商为受益人 | 银行有条件付款承诺、信用便利                                 | 信用证、相符单据             |
| **福费廷**   | 出口商                         | 买入符合条件的远期债权，以汇票、本票为例                     | 远期票据或相关债权变现       |
| **打包放款** | 出口商                         | 以收到的信用证等为依据，为备货、生产、加工、包装、运输提供装运前融资 | 尚未完成装运，需要资金备货   |
| **出口押汇** | 出口商                         | 以出口后提交的相关单据为基础提前取得资金                     | 出口环节、单据融资           |
| **进口押汇** | 进口商                         | 银行为进口商支付相应进口款项提供融资                         | 进口环节、代为垫付并形成融资 |

#### 保理与福费廷

> 解释：
>
> - 以出口商已形成应收账款但尚未收到货款，需要提前变现为例解释保理：将相关应收账款转让给保理商，按约定取得融资及相关服务。
> - 福费廷则以出口商持有未来到期付款的票据为例：在到期前将其出售给银行，提前取得资金。**保理记“应收账款”，福费廷记“远期债权、票据”。**
>
> *补充：保理不仅限于国际贸易，也不仅仅是单一放款；福费廷的重要特征通常包括无追索权买入相关债权。实际适用债权和业务安排应以合同、规则为准，不能仅凭“提前拿钱”区分。*

#### 信用证的独立性与有条件付款

**信用证业务处理单据，与货物的实际流转相分离；银行承担的是按信用证条件付款的承诺。**

> 解释：
>
> - 可以用进口商申请开证、出口商收到信用证后组织发货并提交单据的过程理解信用证。
> - 出口商须提交符合要求的单据，才能依信用证条件要求付款。
>
> *补充：收到或通知信用证，并不当然使通知行必须先垫付款项；是否融资、承兑、议付或付款取决于银行角色、信用证条款、相符交单与有关安排。不能把信用证流程记成“出口商交单后，任何出口地银行都必须垫款”。*

#### 打包放款与进出口押汇

**打包放款发生在装运前**，融资资金应服务于该信用证项下货物的生产、加工、包装、运输等，不能任意挪作其他用途。

**出口押汇与进口押汇分别服务于出口商和进口商。**

> 解释：以信用证项下完备货运单据为例，出口商交单后提前取得资金，是出口端融资；银行为进口商先支付货款，再由进口商按约偿还，是进口端融资。
>
> *补充：上述例子采用信用证场景，并不意味着所有押汇业务都只能发生于信用证结算。打包放款所凭信用证也不宜简单理解为普通不动产式“抵押物”，应理解为融资依据与相应收款安排。*

## 高频考点 16：票据、保函与承诺业务

### 票据承兑：商业信用转化为银行信用

**商业银行承兑商业汇票，是银行承诺按约在到期日付款，使相关付款信用由商业信用转为银行信用。**票据业务应有真实商业背景。

商业汇票可按承兑人区分银行承兑汇票与商业承兑汇票。银行承兑汇票仍然是**商业汇票的一种**，不能因名称中有“银行”就当成银行汇票。

### 贴现、转贴现、再贴现与回购

| 业务                   | 转让或融资关系                                     | 重点                                                 |
| ---------------------- | -------------------------------------------------- | ---------------------------------------------------- |
| **贴现**               | 持票人将未到期商业汇票转让给银行等金融机构         | 提前取得票款，扣除相应贴现利息；依法以背书等方式办理 |
| **转贴现**             | 金融机构将已贴现、未到期商业汇票转让给另一金融机构 | 银行之间再次转让，教材强调卖断                       |
| **再贴现**             | 金融机构将有关已贴现票据向中央银行申请贴现         | 对手方是央行；也是货币政策工具                       |
| **买入返售、卖出回购** | 金融机构先买入或卖出金融资产，同时约定未来反向交易 | 既有初始资金、资产交换，也有到期返售或购回安排       |

对于同一笔回购：资金融入方先卖出资产、以后购回，称**卖出回购**；资金融出方先买入资产、以后返售，称**买入返售**。名称应随观察主体变化。

> 解释：
>
> - 以“我现在需要钱，不想等票据到期”为贴现的出发点：票面金额与提前取得资金之间的相应差额，体现融资成本。
> - **贴现看持票人与银行，转贴现看金融机构之间，再贴现看金融机构与央行。**不能把第二次转让一概叫再贴现，关键是交易对手是否为央行。

### 保函业务的两大类别

保函是银行按照申请和约定向受益人出具的书面担保安排，在符合约定条件时承担相应责任，具有**银行向第三方提供保证**的性质。

| 类别             | 主要类型                                                     |
| ---------------- | ------------------------------------------------------------ |
| **融资类保函**   | 授信额度保函、借款保函、有价证券保付保函、融资租赁保函、延期付款保函 |
| **非融资类保函** | 投标保函、预付款保函、履约保函、关税保函、即期付款保函、经营租赁保函 |

| 融资类保函       | 解释                                 |
| ---------------- | ------------------------------------ |
| 授信额度保函     | 为授信项下相应信用责任提供保证       |
| 借款保函         | 保证借款人按约归还贷款本息           |
| 有价证券保付保函 | 对有关有价证券偿付责任提供保证       |
| 融资租赁保函     | 保证融资租赁项下租金等有关支付义务   |
| 延期付款保函     | 对延期付款形成的有关支付义务提供保证 |

> 解释：
>
> - 融资类保函口诀：**“授、借、有、融、延”**。
> - 将即期付款与延期付款、经营租赁与融资租赁成对比较，强调融资性质的差异。考试时先准确记住融资类五项，再识别非融资类项目。

### 非融资类保函

预付款保函涉及收取预付款一方未按合同履行时返还相应款项的保证；履约保函针对履约义务；关税保函针对关税缴付；即期付款保函针对相应即期付款责任；经营租赁保函针对经营租赁合同相关责任。

> 解释：投标保函可以联系“中标后获得资金支持、完成项目”的情景帮助理解。
>
> *补充：投标保函的核心是向招标人保证投标人履行投标义务，例如不在规定期间撤标、中标后不拒绝签约及提交约定履约担保；违约时银行按保函承担相应赔付责任。它本身并不等同于银行向投标人承诺贷款。不要与贷款承诺、授信安排混淆。[来源：工商银行投标保函业务说明](https://m.icbc.com.cn/page/721854788403609626.html)。*

### 承诺业务的四项内容

| 类型             | 内容                                                   |
| ---------------- | ------------------------------------------------------ |
| **项目贷款承诺** | 在约定条件满足时，承诺为有关项目提供贷款支持           |
| **客户授信额度** | 对客户核定一组信用业务额度，并非全部都是已经发放的贷款 |
| **票据发行便利** | **以短期融资方式取得中长期融资效果**                   |
| **信贷证明**     | 区分有条件的信贷证明、无条件的信贷证明                 |

客户授信额度所列项目包括：**贷款额度、开证额度、开立保函额度、开立银行承兑汇票额度、贴现额度、进口保理额度、出口保理额度、进口押汇额度、出口押汇额度**等。授信是信用支持的额度安排，具体使用仍须满足相应业务条件。

> 解释：
>
> - 票据发行便利的解释：银行等通过承销、包销或备用信贷等安排，支持企业在约定期限内持续发行短期票据，以短期票据的滚动融资满足较长期的资金需求。
> - 不要把这种具有特定制度和业务安排的融资方式，与所有其他情况下的违规期限错配简单等同。
>
> *补充：票据发行便利不意味着任何滚动发短债都合法、都无风险，仍有发行、信用、期限与流动性管理要求。信贷证明也不同于一般存款余额证明或银行询证函，其信用支持内容及是否具有约束力，应看具体条款，不能将各种“银行出具的证明”混为一类。[来源：中国银行工程招投标项下信贷证明说明](https://www.boc.cn/cbservice/cb3/cb31/200905/t20090520_706157.html)。*

## 高频考点 17：结算业务

结算业务是银行“存、贷、汇”业务中“**汇**”的重要内容，主要分为**国内结算、国际结算**。

### 国内票据结算

| 工具         | 签发人         | 付款特征               | 重点                                                 |
| ------------ | -------------- | ---------------------- | ---------------------------------------------------- |
| **银行汇票** | 出票银行       | 见票即付               | 多以异地使用解释；付款按实际结算金额办理             |
| **商业汇票** | 企业等出票主体 | 按指定付款日等约定付款 | 可以由银行或其他符合条件的主体承兑；不是一律见票即付 |
| **银行本票** | 银行           | 银行承诺见票即付       | 以本地使用解释，按确定金额付款                       |
| **支票**     | 银行存款客户   | 委托银行见票付款       | 出票人账户应有足够资金，不得签发空头支票             |

商业汇票是远期支付工具，付款期限在 **6 个月以内**。

> 解释：
>
> - 判断签发人时要注意：**银行汇票和银行本票由银行签发；支票由存款客户签发；银行承兑汇票属于商业汇票。**
> - 银行汇票的实际结算金额可以与出票金额存在差额，应依制度填写和结算；不能将“实际结算金额”理解为可以超过出票金额任意支付。
>
> *补充：票据是否可跨地区使用，应按相应票据制度和系统规则判断。“银行本票本地、银行汇票异地”是抓典型应用的方式；银行汇票并非只能用于异地。商业汇票期限还应区分具体种类、出票和承兑制度，不能把此处的半年表述扩展到所有名称带“票据”的产品。2023 年起施行的相关办法规定，商业汇票自出票日起至到期日止最长不得超过 6 个月，同时定义中也包括见票时或指定日期付款的情形，因此“商业汇票全部只能远期付款”同样过于绝对。[来源：人民银行、原银保监会《商业汇票承兑、贴现与再贴现管理办法》](https://www.yw.gov.cn/art/2023/1/13/art_1229129839_1792727.html)。*

### 支票的三种类型

| 支票     | 使用方式                         |
| -------- | -------------------------------- |
| 现金支票 | 用于支取现金                     |
| 转账支票 | 用于转账，不用于支取现金         |
| 普通支票 | 可以用于支取现金，也可以用于转账 |

> *补充：普通支票划线后属于划线支票，只能转账，不能支取现金。是否有足够存款和是否符合签章、金额等规定，也属于付款审查范围。*

### 国内非票据结算

| 方式         | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| **汇兑**     | 汇款人委托银行将款项汇给收款人，属于主动付款方向的安排       |
| **托收承付** | 收款方委托银行收款，付款方按约承认付款，教材列有邮划、电划   |
| **委托收款** | 收款人委托银行向付款人收取款项，教材列有异地、同城及同城特约委托收款 |

> 解释：拆解“托收承付”：收款方委托银行托收，付款方按约承担付款。它便利了异地商品交易中的收付款。委托收款则以水、电、煤气等费用收取作为日常例子。
>
> *补充：托收承付有特定适用主体、交易背景和办理条件，不能理解为任意个人、任意交易均可使用。委托收款也并非只能用于同城公用事业收费，教材本身即列有异地委托收款。*

### 国际结算三种主要方式

| 方式       | 资金方向                   | 主要类型                       |
| ---------- | -------------------------- | ------------------------------ |
| **汇款**   | 顺汇，付款方主动汇出       | 电汇、信汇、票汇               |
| **托收**   | 逆汇，由收款方向付款方收取 | 光票托收、跟单托收、直接托收   |
| **信用证** | 归入逆汇方式               | 不可撤销、跟单、不可转让等属性 |

#### 电汇、信汇、票汇

> 解释：比较来看，电汇通常速度较快、费用相对较高；信汇、票汇涉及相应信函或票据传递，速度相对较慢，费用安排不同。具体效率、收费应结合实际渠道和银行规则。

#### 光票托收、跟单托收、直接托收

跟单托收带有商业单据，可随附金融单据，也可以只有商业单据；不应把“没有汇票等金融单据”误判为不属于跟单托收。

> 解释：
>
> - **光票托收是否“光”，关键看不随附商业单据。**应将商业单据与金融单据区分。
> - 例如，出口商使用银行预先提供的托收指示格式寄送资料，可以简化直接托收的传递环节。
>
> *补充：直接托收一般指按约由出口商将有关托收单据直接寄送进口地代收行等安排，并非绕开银行，直接把空白托收指令交给进口商就完成银行托收。[参考：清华大学出版社国际贸易融资教材对直接托收流程的说明](https://www.tup.com.cn/upload/books/yz/066289-01.pdf)。光票托收则可以包含金融单据，只是不附商业单据。[来源：中国银行光票托收业务说明](https://www.bankofchina.com/se/cbservice/cb2/cb21/201807/t20180710_12848223.html)。*

#### 信用证的不同分类维度

常用类型包括**不可撤销信用证、跟单商业信用证、不可转让信用证**。这分别对应可否撤销、是否凭商业单据、是否允许转让等不同分类标准，不是互相排斥的三种业务。

> 解释：**同一信用证可以同时具有不可撤销、跟单和不可转让等属性。**信用证付款依条款及相符单据办理，不能用其项下货物存在与否直接替代银行的单据审查。

## 高频考点 18：代理业务

商业银行利用网点、人员、结算渠道及专业服务能力，接受其他主体委托办理业务，主要分为**代收代付、代理银行、代理证券、代理保险**。

### 代收代付

代收代付包括**委托收款、托收承付**等业务，还可以联系公共事业收费、代扣有关款项、代发工资等例子理解。

> 解释：理解时确定资金方向：代收是替委托人收取款项，代付是替委托人向有关对象支付款项，实际授权和扣款条件须依约办理。

### 代理银行业务

| 被代理对象     | 主要类型                                                     |
| -------------- | ------------------------------------------------------------ |
| **政策性银行** | 代理资金结算、代理现金支付、代理专项资金管理、代理贷款项目管理 |
| **中央银行**   | 代理财政性存款、代理国库、代理金银                           |
| **商业银行**   | 代理结算业务、代理外币清算业务、代理外币现钞业务等           |

> 解释：
>
> - 以中央银行、政策性银行网点覆盖有限说明代理的必要性：在没有相应网点、需要当地服务的地区，由符合条件的商业银行受托办理相关业务。
> - 代理商业银行结算业务，包括**代理银行汇票业务，以及汇兑、托收承付等**。代理外币清算与代理外币现钞业务应分别识别。

### 代理证券业务：一级清算与二级清算

银行为证券交易相关资金清算、结算提供服务，联系到证券交易资金第三方存管。

> 解释：代理证券业务包括**一级清算业务、二级清算业务**。可以用中国结算与证券公司总部、证券公司总部与分支机构之间的层次帮助理解。
>
> *补充：市场通常所称分级结算，是证券登记结算机构与结算参与人之间进行一级结算，再由结算参与人与客户之间进行二级结算。不能把二级结算的普遍定义仅写为“证券公司总部与分支机构内部结算”；内部核算安排与证券市场分级结算应区分。[来源：证监会年报对分级结算制度的说明](https://www.csrc.gov.cn/csrc/c100024/c1492162/1492162/files/4e653cb908754c5a8078deb5410cc7e7.pdf)。*

### 代理保险业务

| 教材项目                     | 内容                           |
| ---------------------------- | ------------------------------ |
| 代理人寿保险业务             | 受托开展相应人身保险销售等业务 |
| 代理财产保险业务             | 受托开展相应财产保险销售等业务 |
| 代理收取保费及支付保险金业务 | 按委托和授权进行有关款项收付   |
| 代理保险公司资金结算业务     | 提供相关资金结算服务           |

> 解释：商业银行代理保险属于**保险兼业代理**，与专门经营保险代理业务的专业代理机构相区分。银行代理销售保险，不等于银行成为保险合同的承保人。

## 高频考点 19：银行卡业务

### 借记卡

借记卡分为**转账卡（含储蓄卡）、专用卡、储值卡**。

借记卡具有**存取现金、转账汇款、刷卡消费、代收代付、资产管理及其他服务**等功能。

**借记卡不具有信用透支功能。**

> 解释：日常使用的储蓄卡通常联系活期账户，可以据此理解借记卡的常见使用方式。
>
> *补充：上述功能是类别层面的概括，不表示每种借记卡都可以无条件办理全部功能；例如专用卡、储值卡有相应用途与功能限制。*

### 信用卡的分类

| 分类标准         | 分类                 | 解释                                                         |
| ---------------- | -------------------- | ------------------------------------------------------------ |
| 是否交存备用金等 | **贷记卡、准贷记卡** | 贷记卡主要凭信用额度使用；准贷记卡先交存备用金，余额不足时可以在规定额度内透支 |
| 发行对象         | **个人卡、单位卡**   | 个人卡下又列标准卡、联名卡、主题卡等                         |

> 解释：不要混淆“借记卡、贷记卡、准贷记卡”：借记卡无信用透支；贷记卡和准贷记卡属于信用卡分类，备用金要求不同。

### 信用卡的特点与额度、期限

| 特点           | 主要内容                                                     |
| -------------- | ------------------------------------------------------------ |
| **信用属性强** | 可在核定额度内透支；教材写免息期 **20—56 天**、信用额度 **10 万元人民币以内** |
| **功能丰富**   | 刷卡消费、预借现金、存取现金、转账、支付结算、代收代付、通存通兑、网上购物等 |
| **双重属性**   | 兼具支付和信贷功能                                           |

> 解释：教材或题目也可能出现 **20—60 天**的免息期表述；同时明确 **10 万元不是绝对上限，实际也有超过 10 万元的额度**。
>
> *补充：20—56 天、20—60 天属于常见或教材区间，不是所有信用卡统一必须适用的法定区间。人民银行关于信用卡业务的规定已明确，透支消费享受免息还款期、最低还款额待遇的条件和标准由发卡机构自主确定。做题不能将“给哪个选哪个”泛化为不看题干、产品和规则都无条件选对。[来源：人民银行《关于信用卡业务有关事项的通知》](https://www.beijing.gov.cn/zhengce/zhengcefagui/201905/t20190522_59094.html)。*
>
> *补充：预借现金、取现等交易通常与普通刷卡消费适用不同计息和费用条件，不能因为信用卡有免息期，就认定所有透支均免息；具体看发卡协议和产品条款。*

## 高频考点 20：理财业务

### 业务性质

理财业务是银行接受投资者委托，将相应资金按约进行投资运作，按约分配投资收益、收取有关管理服务费用的业务。**理财资金不是银行可以作为自有资金任意使用的财产。**

> 解释：理财业务按表外业务管理，可以与银行自营资产业务进行对比，理解两者的区别。
>
> *补充：表外管理不意味着没有风险或没有银行管理责任；理财也不等于银行存款，不应保证本金和收益。收费项目、收益归属与风险承担应依合同和规则确定，不能把全部投资收益都当作银行自己的利息收入。*

### 按募集方式分类

| 类别         | 核心区别                                               |
| ------------ | ------------------------------------------------------ |
| **公募理财** | 面向不特定社会公众公开募集，仍须遵守投资者适当性等规定 |
| **私募理财** | 面向符合条件的合格投资者非公开募集                     |

> 解释：可以用“面向合格投资者、非公开募集”记忆**私募理财**，不能将其扩大为“银行理财都是私募”。
>
> *补充：银行理财有公募和私募两类，教材分类表也明确列出。合格投资者的特定资产、收入门槛主要用于私募理财准入，不能套成所有普通公募银行理财都必须满足同样的 300 万、500 万等门槛。[来源：《商业银行理财业务监督管理办法》](https://www.beijing.gov.cn/zhengce/zhengcefagui/201905/t20190522_61486.html)。*

### 按投资性质分类：80% 是关键

| 类型                   | 标准                                                         |
| ---------------------- | ------------------------------------------------------------ |
| **固定收益类**         | 投资于存款、债券等债权类资产的比例**不低于 80%**             |
| **权益类**             | 投资于股票、股权等权益类资产的比例**不低于 80%**             |
| **商品及金融衍生品类** | 投资于商品及金融衍生品的比例**不低于 80%**                   |
| **混合类**             | 投资于上述相关资产，但任一类资产投资比例均未达到对应类别标准 |

> 解释：**“固定收益类”描述主要投资资产的性质，不等于向投资者承诺固定收益。**恰好 80% 属于“不低于 80%”，应按符合的类别判断，不是只有超过 80% 才算。

### 按运作方式分类

| 对比               | 封闭式                                         | 开放式                                   |
| ------------------ | ---------------------------------------------- | ---------------------------------------- |
| 存续期内申购、赎回 | 通常不开放申购和赎回                           | 按约定开放安排办理                       |
| 份额规模           | 通常相对固定                                   | 可随申购赎回变化                         |
| 提示               | 需要变现时，若规则和产品支持，可通过转让等方式 | 可以设置固定周期、开放日，不必每天都开放 |

> *补充：封闭式“不能赎回”不代表净值不变化，也不代表一定存在二级市场；开放式“可以申赎”须符合产品开放期、确认和流动性管理等要求。*

### 合格投资者：主体、期限与金额

合格投资者应具备相应风险识别能力、风险承受能力，并符合单只产品投资金额等要求。其具体条件分为自然人、法人或其他组织两组。

#### 自然人

先满足**具有 2 年以上投资经历**，再符合下列财务条件之一：

| 财务条件       | 金额与时间                                  |
| -------------- | ------------------------------------------- |
| 家庭金融净资产 | **不低于 300 万元人民币**                   |
| 家庭金融资产   | **不低于 500 万元人民币**                   |
| 本人收入       | **近 3 年本人年均收入不低于 40 万元人民币** |

> 解释：逻辑关系是：**投资经历条件＋三个财务条件中的任意一个**。不能理解为三个财务条件必须同时满足，也不能忽略投资经历要求。

#### 法人或其他组织

法人或其他组织的标准是**最近 1 年末净资产不低于 1000 万元人民币**，不是连续一年日均资产或营业收入。

> *补充：不同制度对法人、其他组织、依法认定机构等主体的表述和直接认定情形可能不同。考试应对照题目适用的理财或资管制度，不宜把一张门槛表直接套用于所有私募基金、证券资管和理财产品。*

> 解释：
>
> 记忆口诀为“**一法、二年、三净、四收、五金**”，对应关系如下：
>
> | 口诀 | 对应内容                               |
> | ---- | -------------------------------------- |
> | 一法 | 法人等主体，最近一年末净资产 1000 万元 |
> | 二年 | 自然人具有 2 年以上投资经历            |
> | 三净 | 家庭金融**净资产** 300 万元            |
> | 四收 | 近 3 年本人年均**收入** 40 万元        |
> | 五金 | 家庭**金融资产** 500 万元              |
>
> 其中 300 万与 500 万的区别在**净资产**与**资产**；40 万要保留“近 3 年、本人、年均”三个限定。
>
> *补充：按《商业银行理财业务监督管理办法》，私募理财还区分单只产品投资金额：固定收益类不低于 30 万元，混合类不低于 40 万元，权益类、商品及金融衍生品类不低于 100 万元。它们与上表资产、收入准入条件不是同一个金额概念。[来源：办法第八条](https://www.beijing.gov.cn/zhengce/zhengcefagui/201905/t20190522_61486.html)。*

### 理财业务的参与主体

| 主体               | 主要内容                                                     |
| ------------------ | ------------------------------------------------------------ |
| 投资者             | 认购产品并按约承担风险、取得收益；区分一般适当性与私募合格投资者要求 |
| 经营机构           | 教材列商业银行理财子公司，强调专业化经营                     |
| **理财产品管理人** | 商业银行或理财公司，负责相应管理、投资运作等                 |
| **理财产品托管人** | 教材列具有托管资质的商业银行，强调需要相应资质               |
| **销售机构**       | 直销与代销，既可自行销售，也可由符合条件的其他机构代理销售   |

> 解释：**管理人和托管人不能是同一主体。**销售、管理、托管是不同职责，不能只因客户在某银行购买，就认定该银行同时是产品管理人、托管人并为收益担保。
>
> *补充：不同理财制度下可承担托管的机构范围应按相应规定判断，不宜把教材概括视为任何制度中都只允许同一种机构。*

## 高频考点 21：同业业务

同业业务是金融机构之间开展的有关业务，主要分为**同业融资、同业投资**。

### 主要类型与关键条件

| 类型                   | 内容                                           | 重点                                                     |
| ---------------------- | ---------------------------------------------- | -------------------------------------------------------- |
| **同业拆借**           | 金融机构之间无担保的资金融通                   | 信用融资，与质押式回购相比较                             |
| **同业存款**           | 金融机构之间的存款业务                         | **资金存入方须具有吸收存款资格**；对应同业存放、存放同业 |
| **同业借款**           | 相应金融机构间的借款                           | **最长期限 3 年（含），到期不得展期**                    |
| **同业代付**           | 一家金融机构按约为另一机构有关业务代为支付资金 | 教材强调原则上适用于银行业金融机构办理跨境贸易结算       |
| **买入返售、卖出回购** | 以金融资产交易及约定反向交易进行融资           | 区分资金方向、初始交易与到期交易                         |
| **同业投资**           | 购买或按约投资同业金融资产及有关产品等         | 与同业融资分别识别                                       |

同业融资一般为短期业务。**同业借款最长 3 年（含），其他同业融资业务最长期限一般不超过 1 年，到期不得展期。**

> *补充：该期限框架来自《关于规范金融机构同业业务的通知》，同业借款不超过 3 年，其他同业融资不超过 1 年；具体业务还要遵守相应更严格规则。例如同业拆借须结合机构类别、拆借管理制度确定，不能因总框架有 1 年上限就认定每家机构都能拆入满 1 年。[来源：五部门《关于规范金融机构同业业务的通知》](https://www.csrc.gov.cn/csrc/c100028/c1002125/content.shtml)。*

### 同业拆借与回购的比较

| 比较       | 同业拆借                     | 债券质押式回购融资               |
| ---------- | ---------------------------- | -------------------------------- |
| 信用支持   | 无担保，主要依靠交易对手信用 | 有债券等合格资产提供相应担保支持 |
| 利率比较   | 相对较高                     | 相对较低                         |
| 交易量比较 | 相对较少                     | 相对较大                         |

> 解释：有相应资产支持时，资金出借方面临的信用风险通常较低，因此在其他条件相近时，融资利率可能更低；据此帮助记忆回购市场活跃的特点。
>
> *补充：利率高低与交易量不是任何日期、任何机构、任何期限下都成立的恒等关系，还受流动性、资产质量和市场供求影响。回购也有质押式、买断式等不同结构，不能把所有买入返售、卖出回购都简单等同于传统抵押贷款。*

### 同业存款与同业投资的识别

同业投资则侧重金融机构购买同业金融资产、相关产品或特定目的载体等投资行为，不只限于“购买别家银行的一种存款”。

> 解释：同业存款先看**存入方资格**，再看记账方向：同业把钱存入本行，是本行负债；本行存到同业，是本行资产。同业存款与考点 14 形成对应。

## 高频考点 22：银行组织架构

### 从企业法人角度分类

从企业法人角度，银行组织架构分为**统一法人制、多法人制**。

| 类型           | 组织关系                           | 法人资格                                     | 主要特点                             |
| -------------- | ---------------------------------- | -------------------------------------------- | ------------------------------------ |
| **统一法人制** | 总行与分支机构，类比总公司与分公司 | 总行具有法人资格，分支机构不具有独立法人资格 | 我国主流形式；具有较强的集中管理特征 |
| **多法人制**   | 母公司与子公司                     | 母公司和子公司分别具有法人资格               | 相对分权，各主体在相应范围内开展业务 |

> 解释：在统一法人制下，分支机构按照总行授权开展经营，受到总行管理。**分行不是子公司，不能因为分行独立核算就认定其具有独立法人资格。**
>
> *补充：《商业银行法》规定，分支机构不具有法人资格，在总行授权范围内依法开展业务，其民事责任由总行承担。母子公司结构中的子公司则是独立法人，两者不能混淆。*

### 从内部管理模式分类

从内部管理模式看，银行组织架构分为**以区域管理为主的总分行型、以业务线管理为主的事业部制、矩阵型**。

#### 以区域管理为主的总分行型

总分行型是我国银行的主流形式，以不同区域及其分支机构为组织基础，各区域分支机构开展相应业务。

**分行为利润中心。**

> 解释：
>
> - 有利于总部管理意图通过各区域和分支机构落实。
> - 各区域之间相对平行，可能出现各自为政、跨区域沟通障碍。
> - 同一区域内包含多种业务，而不是只按单一业务条线组织。

#### 以业务线管理为主的事业部制

按业务条线进行组织，自总部向下形成相应管理线条。**每个事业部都是一个利润中心。**

> 解释：
>
> - 有利于加强专业业务管理，将业务管理要求沿条线贯彻。
> - 管理要求更多集中于总部，对总部及事业部管理者的专业能力要求较高。
> - 不同业务条线之间可能沟通不畅、争夺资源。
> - 可以用“风险集中在总部”提示集中管理下的责任和协调压力。
>
> *补充：这不表示风险事件只会在总部发生，也不表示分支机构无需承担业务管理责任。*

#### 矩阵型

矩阵型结合区域管理与业务条线管理：**区域总部的事业部接受区域总部负责人和总行相同事业部负责人的双重领导。**

| 模式     | 主要组织轴线   | 利润中心或管理特征     |
| -------- | -------------- | ---------------------- |
| 总分行型 | 区域           | 分行为利润中心         |
| 事业部制 | 业务条线       | 事业部为利润中心       |
| 矩阵型   | 区域＋业务条线 | 双重领导、协调要求更高 |

> 解释：
>
> - 兼顾区域与专业条线两方面管理。
> - 存在双重领导，组织协调和管理成本可能增加。
> - 区域总部运转失灵时，可能影响相应区域整体运作。
>
> *补充：双重领导的核心是有关事业部同时受区域管理和相应业务条线管理，并非笼统地说同一“区域总部”一定同时由两个完全相同层级的负责人管理。*

### 从管理会计角度分类

从管理会计角度，银行组织架构分为**成本中心、利润中心**。

| 类型         | 通俗理解                                                     | 教材例子                           |
| ------------ | ------------------------------------------------------------ | ---------------------------------- |
| **成本中心** | 主要承担管理、运行、支持等任务，重点控制成本，不以自身直接经营收入衡量全部工作 | 管理部门、运作中心、培训机构       |
| **利润中心** | 既要关注收入，也要关注成本与利润                             | 独立核算的分支机构、产品线和子公司 |

> 解释：可以用“花钱的”与“赚钱的”帮助记忆。
>
> *补充：这是管理责任划分，不意味着成本中心没有价值，也不意味着利润中心只要有收入就可以不管成本和风险。*

### 我国银行组织架构发展趋势

1. **渐进式推进事业部制改革**：在区域管理基础上加强业务条线管理，使区域与条线更好结合。
2. **建立垂直化风险管理体系**：从总部向下形成风险管理线条，强化风险管理独立性、专业性和贯彻落实。
3. **建设流程银行**：以客户需求为中心，安排业务运作、各业务环节和部门协作，使各项工作衔接规范、运行顺畅。

> 解释：
>
> - **垂直化风险管理**：风险管理是银行管理重点，需要明确总部及各层级的职责。
> - **流程银行**：重点是围绕客户需求重组和协调业务流程，不能只理解为“多写几份制度”。
>
> *补充：事业部制改革是一种教材归纳的发展方向，不代表所有银行最终都必须采用完全相同的矩阵组织，具体架构应适合自身规模、业务和管理需要。*

## 高频考点 23：银行管理基本指标

### 八类指标完整清单

| 指标类型       | 教材列举                                                     |
| -------------- | ------------------------------------------------------------ |
| **规模指标**   | 资产规模、市值；市值是衡量银行规模的重要综合性指标           |
| **结构指标**   | 资产结构、贷款结构、负债结构、收入结构、客户结构             |
| **效率指标**   | 成本收入比、人均净利润                                       |
| **市场指标**   | 市盈率、市净率                                               |
| **安全性指标** | 不良贷款率、不良贷款拨备覆盖率、拨贷比、资本充足率           |
| **流动性指标** | 流动性覆盖率、净稳定资金比例、流动性比例、流动性匹配率、优质流动性资产充足率 |
| **集中度指标** | 单一最大客户贷款比例、最大十家客户贷款比率、单一集团客户授信集中度、大额风险暴露集中度 |
| **盈利性指标** | 拨备前利润、平均总资产回报率、平均净资产回报率、每股收益、净息差、净利息收益率 |

> 解释：**复习时应先区分指标类别，再记公式与数值。**不要只记名称而忽略分类。

### 规模指标：资产规模与市值

规模指标包括**资产规模、市值**。

> 解释：
>
> - 资产规模反映银行经营资源的规模，但**不是越大越好**。如果资产增长伴随大量不良资产，仍然不利于稳健经营。
> - 市值主要对应上市银行，综合反映市场对银行经营、风险和未来发展的判断。不能仅凭市值较高就认定银行所有经营指标均更优秀。

### 结构指标：五类结构

| 结构     | 具体内容                                                     |
| -------- | ------------------------------------------------------------ |
| 资产结构 | 生息资产占比，关注能够创造收益的资产                         |
| 贷款结构 | 关注零售贷款，以客户分散说明其分散风险的特点                 |
| 负债结构 | 存款是主要负债；关注定期、活期存款构成，以及由此反映的成本变化 |
| 收入结构 | 利息收入与非利息收入的组合                                   |
| 客户结构 | 个人与单位客户、大客户与小客户等构成                         |

> 解释：
>
> - 可以用“**资负客贷入**”的谐音顺序，回忆资产、负债、客户、贷款、收入五类结构指标。
> - 结构指标关注占比、组合及分布，而不是单一总量。
>
> *补充：零售贷款相对分散不等于必然低风险；还要看客户信用、产品、行业及共同风险因素。存款结构影响成本，但不能仅凭某一比例就断言银行整体负债风险高低。*

### 效率指标与市场指标

效率指标包括**成本收入比、人均净利润**。

市场指标包括**市盈率（PE）、市净率（PB）**。

$$
市净率（PB）=\frac{股票价格}{每股净资产}
$$

> 解释：
>
> - 成本收入比关注取得一定收入需要消耗多少成本，人均净利润关注每名员工对应创造的净利润。
> - 在分母不变时，价格提高会使 PE、PB 上升。高比率可能意味着估值偏高和风险累积，也可能反映市场对银行未来的认可，需要综合分析。
> - 可以用“超过一百倍”和“几十倍”等数量级辅助说明估值差异。
>
> *补充：这些不是银行股票统一适用的监管阈值或投资安全线，不能记成“几十倍就安全、超过百倍才危险”。投资价值还受盈利、成长预期、资产质量、市场环境等因素影响。*
>
> *补充：市值属于规模指标，市盈率与市净率属于市场指标。名称中都有“市”，不能据此归成同一类。*

### 安全性指标

安全性指标包括**不良贷款率、不良贷款拨备覆盖率、拨贷比、资本充足率**。

> 解释：其中，资本充足率反映银行整体资本稳健水平；不良贷款及拨备指标反映资产质量和风险抵补情况，不能互相替代。

### 流动性指标

1. **流动性覆盖率。**
2. **净稳定资金比例。**
3. **流动性比例。**
4. **流动性匹配率。**
5. **优质流动性资产充足率。**

> 解释：可以用**“四流动、一稳定”**帮助记忆，稳定对应净稳定资金比例，其余四项名称包含流动性。

#### 数值要求与适用规模

| 指标                 | 最低水平 | 期限或适用提示                                         |
| -------------------- | -------: | ------------------------------------------------------ |
| 流动性覆盖率         | **100%** | 压力情景下 30 日内；主要对应规模较大银行               |
| 净稳定资金比例       | **100%** | 稳定融资安排                                           |
| 流动性比例           |  **25%** | 五项中需要单独记忆的比例                               |
| 流动性匹配率         | **100%** | 资金来源与运用的匹配                                   |
| 优质流动性资产充足率 | **100%** | 关注短期流动性，联系 30 日内资金需求；主要对应较小银行 |

**流动性比例不低于 25%，其余四项在适用时的最低标准为不低于 100%。**这不表示每家银行都必须同时适用五项指标。

> 解释：可以用 **2000 亿元**作为规模分界，说明流动性覆盖率和优质流动性资产充足率的适用差别，后者的计量相对简化。
>
> *补充：正式口径是资产规模不小于 2000 亿元（含 2000 亿元）的银行适用流动性覆盖率、净稳定资金比例、流动性比例、流动性匹配率；小于 2000 亿元的银行适用优质流动性资产充足率、流动性比例、流动性匹配率。不能把“以下”口头概括理解成 2000 亿元整两边都可归。具体切换、监管许可及其他适用安排依规定处理。*

### 集中度指标

| 指标                   | 教材提示               |
| ---------------------- | ---------------------- |
| 单一最大客户贷款比例   | 联系经营安全性         |
| 最大十家客户贷款比率   | 联系资产负债比例管理   |
| 单一集团客户授信集中度 | 关注集团客户授信集中   |
| 大额风险暴露集中度     | 关注大额暴露的集中风险 |

> 解释：这些指标用于观察业务是否过度集中，不能因为借款主体数量很多，就忽略其可能属于同一集团或具有相关性。

### 盈利性指标

盈利性指标包括**拨备前利润、平均总资产回报率、平均净资产回报率、每股收益、净息差、净利息收益率**。

> 解释：
>
> - 可以用“**一股、二息、两回报，加拨备前利润**”串联：一股为每股收益，二息为教材列出的净息差与净利息收益率，两回报为平均总资产回报率与平均净资产回报率。
> - 比较总资产回报与净资产回报时应注意：银行总资产中既有自身资本支持的部分，也有负债融资支持的部分；净资产回报更关注股东权益对应的回报。
>
> *补充：净资产回报率不是把利润中的“负债部分”简单减掉，而是以相应利润与平均净资产比较；总资产回报率与净资产回报率的分母、含义和适用口径不同。*

### 重点指标公式与理解

#### 市盈率

$$
市盈率（PE）=\frac{股票价格（P）}{每股收益（E）}
$$

> 解释：**分母是每股收益，不是全行净利润。**
>
> *补充：市盈率的比较应使用相同收益口径。当每股收益为负或接近零时，简单用数值高低判断估值容易失真。*

#### 不良贷款率

贷款五级分类为：**正常、关注、次级、可疑、损失**。其中**次级、可疑、损失**属于不良贷款。

$$
不良贷款率=\frac{不良贷款余额}{总贷款余额}\times100\%
$$

> 解释：关注贷款不属于本公式分子中的不良贷款，不能将后三类记成后四类。

#### 拨备覆盖率

拨备覆盖率的教材写法为“**不良贷款损失准备÷不良贷款余额×100%**”。

> 解释：
>
> - 拨备用于应对**预期损失**，经济资本主要用于覆盖**非预期损失**，两者作用需要区分。
> - 可以用“拨备最好达到不良贷款的 100% 以上”理解拨备覆盖风险的关系。
>
> *补充：规范口径使用“贷款损失准备”，不能将分子狭义理解成仅针对不良贷款单独计提的准备。*
>
> *补充：规范公式为：*
>
> $$
> \text{拨备覆盖率}=\frac{\text{贷款损失准备}}{\text{不良贷款余额}}\times100\%
> $$
>
> *补充：贷款损失准备不仅与已列为不良的贷款有关。上文保留教材原有用语，规范公式用于帮助区分分子的范围。*
>
> *补充：“最好达到 100% 以上”不是对所有银行现行最低监管要求的完整陈述，不能直接记成“监管底线统一为 100%”。具体要求应看适用制度、差异化安排及监管要求。*

#### 拨贷比

拨贷比的教材写法为“**不良贷款损失准备÷总贷款余额×100%**”。

> 解释：**拨备覆盖率分母是不良贷款，拨贷比分母是全部贷款。**二者不能交换。
>
> *补充：规范公式为：*
>
> $$
> 拨贷比=\frac{贷款损失准备}{总贷款余额}\times100\%
> $$

##### 两个比率与不良贷款率的关系

$$
拨贷比=拨备覆盖率\times不良贷款率
$$

> 解释：由两项公式代入、约分即可得到这一关系。
>
> *补充：相乘时用实际比率。若拨备覆盖率为 150%、不良贷款率为 2%，则 1.5×0.02＝0.03，即拨贷比 3%；不能把 150×2 直接当成百分比结果。此算例为公式补充说明。*

#### 资本充足率

$$
资本充足率=\frac{总资本-对应资本扣除项}{风险加权资产}\times100\%
$$

如果计算一级资本充足率、核心一级资本充足率，则分子改用相应层级资本，并扣除对应扣除项。

> 解释：可以用“扣除不能发挥相应损失吸收作用的项目”解释资本净额：不能把所有账面项目不作调整直接用于计算。
>
> *补充：不能从“附属资本也能相减”推导出存在与三类法定资本充足率完全并列的通用“附属资本充足率”监管要求。应区分巴塞尔历史用语与现行核心一级、一级、总资本的指标体系。题目已给资本净额时，也不要重复扣除。*

#### 公式对照

| 指标       | 分子           | 分母         |
| ---------- | -------------- | ------------ |
| 市盈率     | 每股价格       | 每股收益     |
| 不良贷款率 | 不良贷款余额   | 总贷款余额   |
| 拨备覆盖率 | *贷款损失准备* | 不良贷款余额 |
| 拨贷比     | *贷款损失准备* | 总贷款余额   |
| 资本充足率 | 合格总资本净额 | 风险加权资产 |

## 高频考点 24：内部控制与合规管理

### 内部控制的理解

内部控制是银行为实现合规经营和风险管理目标，建立制度并采取相应控制措施的安排。

> 解释：内部控制不是某个部门单独做的一次检查，而是贯穿银行经营管理的制度、流程和执行安排。

### 内控四项原则

内部控制遵循**全覆盖、制衡性、审慎性、相匹配**四项原则。

| 原则           | 说明                                         |
| -------------- | -------------------------------------------- |
| **全覆盖原则** | 覆盖全部业务、部门、分支机构和人员           |
| **制衡性原则** | 通过独立履职、合理分工和相互约束发挥控制作用 |
| **审慎性原则** | 风险为本、审慎经营                           |
| **相匹配原则** | 内控制度与银行经营状况、规模和发展需要相适应 |

> *补充：2014 年《商业银行内部控制指引》进一步明确，全覆盖贯穿决策、执行和监督全过程；制衡涉及治理、权责与流程的相互制约，不只是设置独立部门；审慎原则强调设立机构、开办业务均坚持内控优先。*

### 内控措施：十项

| 序号 | 措施         |
| ---- | ------------ |
| 1    | **内控制度** |
| 2    | **风险识别** |
| 3    | **信息系统** |
| 4    | **岗位设置** |
| 5    | **员工管理** |
| 6    | **授权管理** |
| 7    | **会计核算** |
| 8    | **监控对账** |
| 9    | **外包管理** |
| 10   | **投诉处理** |

> 解释：内控措施与内控保障容易混淆，使用谐音口诀将各项对应记忆。其中“**全员风控**”对应**授权管理、员工管理、风险识别、内控制度**，其余项目对应信息系统、岗位设置、会计核算、投诉处理、监控对账、外包管理。
>
> *补充：口诀只用于提示项目，不能以谐音替代正式名称；应将口诀与上表正式名称对应记忆。*

### 内控保障：六项

内控保障包括**信息系统控制、报告机制、业务连续性管理、人员管理、考评管理、内控文化**。

> 解释：
>
> - 记忆口诀为：**“文人联系报考”。**
>
> | 口诀字 | 对应保障       |
> | ------ | -------------- |
> | 文     | 内控文化       |
> | 人     | 人员管理       |
> | 连     | 业务连续性管理 |
> | 系     | 信息系统控制   |
> | 报     | 报告机制       |
> | 考     | 考评管理       |
>
> - **措施和保障清单中可能出现相近用语，不能仅凭某个词重复就认定笔记列错。**应按题目所用的清单和具体内容判断。

### 合规及合规风险管理

合规是经营管理和员工履职行为符合相应法律、法规、规则及内部要求。**合规管理的重点是对合规风险的管理**，应建立组织架构、明确职责、各司其职。

### 合规管理的职责分工

| 主体             | 教材职责                                                     |
| ---------------- | ------------------------------------------------------------ |
| **董事会**       | 监督合规政策有效实施；对实施效果承担最终责任                 |
| **高级管理层**   | 贯彻执行合规政策，建立合规管理部门的组织结构                 |
| **合规管理部门** | 在合规负责人管理下，协助高级管理层有效管理合规风险，制定并执行以风险为本的合规管理计划，实施合规风险识别和管理流程，开展员工合规培训与教育 |

> 解释：合规负责人属于高级管理人员，合规管理部门在其管理下开展具体工作。不能把部门、合规负责人和高级管理层完全混作同一个主体。
>
> *补充：《金融机构合规管理办法》自 2025 年 3 月 1 日起施行，过渡期一年，并废止《商业银行合规风险管理指引》。上表保留教材的复习口径，不是新制度全部职责的完整清单。*
>
> *补充：新办法明确首席合规官、合规官等制度安排，同时区分：业务及职能部门、下属机构承担合规主体责任；合规管理部门承担管理责任；内部审计部门承担监督责任。因而“合规是合规部门自己的事”是错误理解。具体适用范围、岗位设置与职责以新办法为准。*

## 高频考点 25：银行资产负债管理

### 基本概念与管理范围

传统管理主要围绕资产负债表展开；随着业务拓展，现代管理强调**表内外、本外币、集团化**等综合管理。

管理重点是对资产、负债及有关风险、收益、期限和资金安排进行统筹。

### 九项管理内容

| 项目                     | 教材具体内容                                 |
| ------------------------ | -------------------------------------------- |
| **资本管理**             | 监管资本管理、经济资本管理、账面资本管理     |
| **资产负债组合管理**     | 资产组合管理、负债组合管理、资产负债匹配管理 |
| **资产负债计划管理**     | 资产负债总量计划、结构计划                   |
| **定价管理**             | 外部产品定价、内部资金转移定价               |
| **银行账户利率风险管理** | 管理相应银行账户业务的利率风险               |
| **资金管理**             | 自下而上集中资金、自上而下配置资金           |
| **流动性风险管理**       | 统筹流动性风险                               |
| **投融资业务管理**       | 统筹投资、融资业务安排                       |
| **汇率风险管理**         | 管理汇率变化带来的风险                       |

#### 资本管理

资本管理围绕**监管资本、经济资本、账面资本**三种资本展开。账面资本又称会计资本。

#### 组合管理

组合管理从资产、负债两端分别组织业务组合，再统筹两端的匹配。

> 解释：不能只管资产组合而不考虑负债来源，也不能只看负债规模而不考虑资金用途与风险。

#### 计划管理

- **总量计划：**控制和安排资产负债总体规模。
- **结构计划：**安排各类资产、负债及有关业务比例和组合。

> 解释：“有多少”与“怎样构成”是两个不同层次。

#### 定价管理

**外部产品定价**：对客户存款、贷款等产品确定相应价格，例如存贷款利率。

**内部资金转移定价：**通过内部资金定价中心等安排，对资金来源和资金使用设定内部价格，用于衡量业务贡献与资金成本。

> 解释：吸收一笔存款，关注其在内部可以取得的资金收益；发放一笔贷款，关注其应承担的内部资金成本。通过统一管理，提高资金使用效率。
>
> *补充：内部资金转移定价是一种内部计价与管理机制，不能简单等同于每一笔资金都必须以某种物理方式先转到总行再转出。它与资金集中、配置有联系，但不是同一概念。*

#### 银行账户利率风险管理

银行账户利率风险管理关注利率变化导致的收益或价值变化。

> 解释：例如，存款、贷款等业务对利率变化敏感，因此需要管理相应风险。
>
> *补充：银行账户不只有存贷款，不能把它直接定义为“全部且只有存贷款业务”；其与交易账户的边界应按适用规则确定。*

#### 资金管理

**自下而上集中资金，自上而下配置资金。**方向不能记反。

> 解释：银行内部通过统一调度、划拨安排资金，满足业务需要并提高使用效率。

#### 其他三项

**流动性风险管理、投融资业务管理、汇率风险管理**均属于资产负债管理的内容。

### 三项管理策略

#### 表内资产负债匹配：核心策略

**表内资产负债匹配是核心、最重要的策略。**

表内匹配强调三种对称：**规模对称、结构对称、期限对称**。

| 对称关系     | 理解                               |
| ------------ | ---------------------------------- |
| **规模对称** | 资产与负债数量安排相协调           |
| **结构对称** | 各类业务与资金来源、运用结构相协调 |
| **期限对称** | 短、中、长期资产负债期限安排相协调 |

> 解释：应先通过表内资产和负债的协调匹配管理风险。
>
> *补充：对称不是要求每笔存款与每笔贷款在金额、期限上完全一一相等。银行具有期限转换等职能，关键是整体错配可识别、可承受、可管理，而不是消灭所有差异。*

#### 利用表外工具管理表内风险

当表内匹配仍不能充分处理风险时，利用**以衍生金融工具为主的表外工具**，辅助管理相应风险。

> 解释：可以理解为对表内无法匹配部分的补充处理。
>
> *补充：衍生工具的效果取决于标的、期限、规模和交易安排，并不保证全部风险都被消除，也可能产生交易对手等其他风险。*

#### 利用证券化剥离表内风险

通过资产证券化等安排，发行资产支持证券，实现有关风险转移和资金回收，帮助盘活存量资金。

> 解释：例如，不良资产可以通过证券化安排进行处置，以兼顾风险处理与回笼资金。
>
> *补充：资产证券化并不只针对不良资产，也不因发行证券就自动实现会计出表、资本风险转移或风险完全消失；这些结果须满足各自条件。不能把“剥离到表外”直接理解成风险可以不再管理。*

## 高频考点 26：银行资本管理

### 资本的作用

资本的重要作用是**吸收和消化损失**，同时为银行经营提供资本金，并向社会公众传递有关信息。

> 解释：资本管理与风险管理密切相关。不能只看银行账面上有多少资产，还要判断能够承担损失的资本是否足够。

### 三种资本

| 分类         | 主要内容                                                     | 关键词                     |
| ------------ | ------------------------------------------------------------ | -------------------------- |
| **账面资本** | 又称会计资本，反映银行实际拥有的资本水平，是资本的静态反映；包括实收资本或普通股、资本公积、盈余公积、未分配利润等 | 会计、已经持有、静态       |
| **监管资本** | 一是实际持有、符合监管规定的合格资本；二是按监管要求应持有的最低资本量或最低资本要求 | 合格、最低                 |
| **经济资本** | 又称风险资本，主要用于抵御非预期损失，是基于风险判断应当持有的资本 | 风险、非预期损失、应当持有 |

#### 账面资本

> 解释：
>
> - 从资产负债表理解，资产减负债后的所有者权益，是理解账面资本的基本入口。
> - 可以用“真金白银、直接可用”辅助记忆已有资本，但这里强调的是已持有的资本水平。
>
> *补充：所有者权益是一种会计权益，不等于全部以现金形式存放。“真金白银、直接可用”的说法用于强调已有资本，不能推导成资本与现金、流动性资产完全相同。*

#### 监管资本

**监管资本不仅强调“有资本”，还强调资本质量与符合监管要求。**

> 解释：部分账面项目不能充分吸收损失，例如商誉、某些无形资产等，需要按规定扣除，才能判断合格资本。
>
> *补充：具体资本认定还涉及合格资本工具、分层计入和扣除规则，不能把监管资本完全简化成账面所有者权益减去几个项目。*

#### 经济资本与实际资本的关系

**银行持有的资本数量应大于经济资本。**

> 解释：
>
> - 若刚好相等，一方面风险估计可能不完全准确，另一方面一旦资本被用于吸收损失，银行还需要资源维持持续经营。因此，应保持一定余量。
> - **三种资本不是简单互斥、可以直接相加的三个资金池，其内涵相互联系、存在交叉。**
>
> *补充：正式比较需要统一定义和计算口径。“大于”的重点是实际可用资本应充分覆盖风险资本需要并保有余量，而不是三种资本之间存在一条无需条件的固定数量排序。*

### 巴塞尔协议的时间主线

| 时间            | 版本                | 核心要求                                       |
| --------------- | ------------------- | ---------------------------------------------- |
| **1988 年**     | 巴塞尔Ⅰ             | 统一资本定义、统一风险衡量、规定资本比例       |
| **2004 年**     | 巴塞尔Ⅱ             | 最低资本要求、监督检查、市场纪律三支柱         |
| **2010 年**     | 巴塞尔Ⅲ             | 强化资本要求、引入杠杆率、流动性量化监管       |
| 2017 年最终改革 | 巴塞尔Ⅲ的进一步修订 | 属于第三版的最终改革，不作为正式独立第四版理解 |

> 解释：以拉美债务危机说明第一版以信用风险为重点的背景；以 2008 年前后的金融危机说明第三版进一步改革的背景。
>
> *补充：巴塞尔标准是国际监管标准，需要通过各辖区制度落实，不能理解为不经国内规则转化就直接适用于全球所有银行的统一法律。*

### 巴塞尔Ⅰ的三件事

#### 统一资本定义

巴塞尔Ⅰ将资本分为**核心资本、附属资本**，分别联系一级资本、二级资本的历史概念理解。

> *补充：历史“核心资本”不等于现行“核心一级资本”。现行一级资本还包括其他一级资本，不能只凭名称相近就直接替换。*

#### 建立资产风险衡量体系

资产风险衡量体系按规定风险权重折算资产风险，采用标准法或权重法。

**五档权重：0、10%、20%、50%、100%。**

> 解释：统一权重便于计算，但划分较粗，可能难以反映不同银行、不同业务的具体情况。

#### 确定资本比例

**总资本充足率不低于 8%；核心资本充足率不低于 4%。**

> 解释：分子是按规定认定的资本，分母是风险加权资产。第一版依次解决资本定义、风险衡量和比例底线三个问题。

### 巴塞尔Ⅱ三支柱

| 支柱                       | 内容                                 | 理解重点                                                 |
| -------------------------- | ------------------------------------ | -------------------------------------------------------- |
| **第一支柱：最低资本要求** | 全面覆盖信用风险、市场风险、操作风险 | 不包括把流动性风险直接列为本支柱第四类风险               |
| **第二支柱：监督检查**     | 内部资本充足评估程序、监管检查程序   | 对内自我评估，对外监管检查                               |
| **第三支柱：市场纪律**     | 又称市场约束，核心是信息披露         | 市场参与者了解银行情况，以市场行为形成约束；补充前两支柱 |

> 解释：可以用“用脚投票”说明第三支柱：股东、债权人等了解银行经营和风险后，决定是否投资、存款或交易，反过来促使银行规范经营。

#### 风险计量方法的补充

巴塞尔Ⅱ允许符合条件的银行运用更精细的内部评级等方法，可广义称为“高级法”。信用风险内部评级法又分为基础层次和高级层次。

> 解释：自行估计参数可能存在偏差或操纵风险，低估风险会导致应持有资本不足。
>
> *补充：运用内部方法不是允许随意选参数或造假，须符合相应监管条件。标准法与不同风险的高级方法也不能不加区分地合并成完全相同的算法。市场风险资本要求在 1996 年修正案中已被纳入原框架，不能认为直到 2004 年才首次管理市场风险。*

### 巴塞尔Ⅲ三方面要求

#### 强化资本充足率监管

| 指标                   | 核心一级资本 |             一级资本 |    总资本 |
| ---------------------- | -----------: | -------------------: | --------: |
| **最低资本要求**       |     **4.5%** |               **6%** |    **8%** |
| 储备资本要求           |     **2.5%** | *同一项缓冲向上计入* |    *同左* |
| **最低要求＋储备资本** |       **7%** |             **8.5%** | **10.5%** |

**一级资本＝核心一级资本＋其他一级资本；总资本＝一级资本＋二级资本。**不能把核心一级资本与一级资本整体再次相加。

**逆周期资本要求：0—2.5%。**

**系统重要性银行附加资本要求：1%—3.5%。**

> 解释：
>
> - 一级资本最低要求从原先 4% 提高到 6%，总资本 8% 保留，同时明确更高质量的核心一级资本最低比例。
> - 在经济上行、贷款增长较快时积累资本，有助于防止风险累积，并应对未来下行。
> - 系统重要性银行规模大、相互关联程度高，一旦出问题，容易影响整个体系，因此需要更严格的资本要求。
>
> *补充：上表是国际框架。我国《商业银行资本管理办法》的核心一级资本基础最低要求为 5%，不是 4.5%；一级 6%、总资本 8%。1%—3.5% 也不能直接作为所有国内系统重要性银行统一适用范围。逆周期缓冲的框架范围不代表任何时点都实际启用 2.5%。*

#### 引入杠杆率

**国际基础杠杆率不低于 3%。**

杠杆率以一级资本与按规则计算的表内外风险暴露相比，补充风险加权资本指标，限制银行过度扩大规模。

> 解释：可以用此说明，不能仅靠降低估计风险权重，就无限压低对整体业务规模的资本约束。
>
> *补充：我国《资本办法》基础杠杆率最低要求为 4%，系统重要性银行另有相应附加要求，不能套用国际 3% 作我国统一底线。*

#### 流动性量化监管

流动性量化监管引入**流动性覆盖率、净稳定融资比率**，分别关注短期承压与稳定融资，**两项指标均不低于 100%**。

> *补充：流动性监管不是在资本充足率的风险加权资产中再简单增加一项“流动性风险资产”；资本与流动性需要分别管理。*

## 高频考点 27：银行风险管理

### 八类风险总览

银行主要面临**信用、市场、操作、流动性、国别、声誉、法律、战略**八类风险，其中信用风险是商业银行面临的主要风险。

### 信用风险的三组分类

| 分类角度       | 教材内容                                               |
| -------------- | ------------------------------------------------------ |
| 是否具有系统性 | **系统性、非系统性**                                   |
| 交易过程       | **结算前风险、结算风险**                               |
| 风险暴露类别   | **主权、金融机构、零售、公司、股权、其他信用风险暴露** |

> 解释：按不同角度形成的分类不能混为一组，也不能简单相加成一种排他分类。

### 市场风险

市场风险分为**利率风险、汇率风险、股票价格风险、商品价格风险**。

**商业银行主要关注利率风险、汇率风险；黄金纳入汇率风险。**

> 解释：
>
> - 利率、汇率等市场价格变动，可能使银行出现损失。
> - 在分业经营背景下，股票、商品期货价格等可能通过有关渠道间接影响银行。
>
> *补充：黄金分类是银行风险框架的特定口径，不代表黄金在所有场景中不属于商品。关于银行不经营股票、期货的概括，也不能扩大成银行在任何条件下都不可能持有任何权益或开展经批准的衍生品业务。*

### 操作风险：四类原因、七类事件

#### 四类原因

操作风险的四类原因是**人员因素、内部流程、系统因素、外部事件**。

#### 七类事件

| 事件                           | 例子或重点                                             |
| ------------------------------ | ------------------------------------------------------ |
| **内部欺诈事件**               | 内部人员故意欺诈等                                     |
| **外部欺诈事件**               | 第三方欺诈                                             |
| **就业制度和工作场所安全事件** | 工伤、就业制度与工作场所安全问题                       |
| **客户、产品和业务活动事件**   | 未履行适当性要求，向不适合的客户推荐高风险产品造成损失 |
| **实物资产损坏**               | 实物资产损毁                                           |
| **信息科技系统事件**           | 系统故障、漏洞等                                       |
| **执行、交割和流程管理事件**   | 未按要求执行、结算或交付                               |

> 解释：**原因分类回答“为何发生”，事件分类回答“以何种事件表现”。**不能将外部欺诈仅因涉及人，就机械归为内部人员因素；两套分类不是严格的一一对应。

#### 非营利性与法律风险

**操作风险具有非营利性**。

**法律风险是一种特殊类型的操作风险。**

> 解释：信用风险等通常与银行为取得收益而主动承担风险有关；操作风险往往客观存在于经营过程中，并非银行为了取得风险收益而主动追求。
>
> *补充：非营利性不是不产生损失，也不是只在非营利机构存在。监管操作风险定义包括法律风险，不包括战略风险和声誉风险。*

### 流动性风险

流动性风险是银行不能在需要的时间内、以合理成本取得资金支持的风险。

| 类型               | 含义                                         |
| ------------------ | -------------------------------------------- |
| **市场流动性风险** | 有资产，但市场深度不足或不活跃，难以卖掉变现 |
| **融资流动性风险** | 需要资金时难以从同业等渠道取得融资           |

> 解释：可以分别用“卖不掉”“借不来”帮助理解。
>
> *补充：包括只能以过低价格变现、融资成本过高或资金到账过晚等问题，不必完全无法交易才构成风险。融资流动性风险也并非只发生在银行没有任何可出售资产时。*

### 国别风险

国别风险具有以下特点：

1. 发生在国际经济金融活动中。
2. 不论政府、银行、企业或个人，都可能遭受有关国家风险造成的损失。

> 解释：与仅受境内因素影响的业务相比，跨境活动还需关注其他国家或地区层面的风险因素。
>
> *补充：正式理解应关注某国家或地区政治、经济、社会变化等对债务偿付、商业存在或其他利益造成的影响。不能仅凭交易地点在国内，就认定相关国家风险绝无可能传导；也不是同一事件必然使所有参与者遭受完全相同的损失。*

### 声誉风险

负面舆论、负面评价可能影响银行声誉并造成损失。

**四项原则：前瞻性、匹配性、全覆盖、有效性。**

- **前瞻性：**提前识别、防范，不能只等事件发生后被动处理。
- **匹配性：**与银行规模、业务、风险等情况相适应。
- **全覆盖：**覆盖有关经营管理主体与环节。
- **有效性：**制度、措施本身有效，并得到有效执行。

### 战略风险

战略风险的来源包括：

- 战略本身不正确。
- 战略与目标、经营状况不适合。
- 执行缺少足够资源。
- 战略难以有效实施。

> 解释：不应仅把战略风险理解成“制定战略那一刻出错”，实施和资源配置同样重要。

### 风险管理四流程

**风险识别→风险计量→风险监测→风险控制。**

| 流程         | 主要内容                                                     |
| ------------ | ------------------------------------------------------------ |
| **风险识别** | 包括**感知风险、分析风险**；良好识别应有**全面性、前瞻性**   |
| **风险计量** | 衡量风险及可能损失，判断所需资本、资源等；教材联系信用、市场、操作风险的计量发展 |
| **风险监测** | 监测关键指标和环节，跟踪风险变化，建立预警，并向内外部不同层级报告定性、定量结果以及措施质量和效果 |
| **风险控制** | 对识别和计量的风险采取相应策略和措施，实施有效管理           |

### 风险控制五种策略

| 策略     | 说明与例子                                         |
| -------- | -------------------------------------------------- |
| **分散** | 不把鸡蛋放在一个篮子里，通过组合分散风险           |
| **对冲** | 利用套期保值等交易，使相反方向的损益相互抵补       |
| **转移** | 以担保、保险等安排说明转移部分风险                 |
| **规避** | 对不愿承担的风险业务选择不做或退出                 |
| **补偿** | 对风险较高客户要求更高利率等，以收益补偿承担的风险 |

> *补充：担保、抵质押常作为信用风险缓释安排，其实际效果和是否构成风险转移须具体判断。对冲不保证风险完全消失；提高贷款利率也不能代替授信准入和风险控制。分散主要降低可分散风险，不能据此消除系统性风险。*

## 高频考点 28：金融资产风险分类与不良金融资产处置

### 五级分类与不良资产

**正常、关注、次级、可疑、损失。后三类合称不良资产。**

> *补充：关注、次级、可疑和损失类的相关触发条件，在《商业银行金融资产风险分类办法》中属于最低分类要求；风险更严重时，可以作更差分类，不能认为符合一个条件后就永远只能归为该类。*

### 正常类

> *补充：正常类指债务人能够履行合同，没有客观证据表明本金、利息或收益不能按时足额偿付。不能仅因尚未逾期，就忽略已有的信用恶化证据。*

### 至少关注类：四项

| 情形                             | 完整要求                                                     |
| -------------------------------- | ------------------------------------------------------------ |
| **逾期**                         | 本金、利息或收益逾期；**操作性或技术性原因导致的 7 天内短期逾期除外** |
| **改变用途**                     | 未经商业银行同意，擅自改变资金用途                           |
| **借新还旧等**                   | 通过借新还旧或其他债务融资方式偿还；**债券、符合条件的小微企业续贷业务除外** |
| **非零售债务人其他债务出现不良** | 同一非零售债务人在本行或其他银行的债务出现不良               |

> 解释：
>
> - **7 天例外必须同时满足原因与期限限定。**可以用“7 天以内不算”辅助记忆技术性短期逾期的例外，不能把它记成所有贷款都有普遍 7 天宽限期。
> - **借新还旧的例外不能省略。**不是所有续贷都必然分类为关注，也不是凡称作小微企业贷款就自动符合例外条件。

### 至少次级类：四项

1. **本金、利息或收益逾期超过 90 天。**
2. **金融资产已发生信用减值。**
3. **债务人或金融资产外部评级大幅下调，导致债务人履约能力显著下降。**
4. **同一非零售债务人在所有银行的债务中，逾期超过 90 天的债务已经超过 20%。**

> 解释：第四项须完整记住：**同一非零售债务人—所有银行—逾期超过 90 天—债务占比超过 20%**。
>
> *补充：各项是触发最低分类的不同情形，不要求四项同时发生。“超过 90 天”和“发生信用减值”是不同触发条件，不要求两项同时满足。20% 的分母是相应债务总额，不是该银行资产或债务人全部资产。*

### 至少可疑类：三项

1. **本金、利息或收益逾期超过 270 天。**
2. **债务人逃废银行债务。**
3. **金融资产已发生信用减值，且预期信用损失占其账面余额 50% 以上。**

> 解释：可以用“借出 100 元，可能损失 50 元”帮助理解损失程度加重。
>
> *补充：50% 是预期信用损失占该金融资产账面余额的比例，不是借款人其他资产中“有一半还不上”，也不是必须已经实现的现金损失率。*

### 损失类：三项

1. **本金、利息或收益逾期超过 360 天。**
2. **债务人已进入破产清算程序。**
3. **金融资产已发生信用减值，且预期信用损失占其账面余额 90% 以上。**

> 解释：**破产清算程序不能缩写成任何“破产程序”。**判断题要注意“清算”二字，不能仅凭一般的破产程序判断。

### 数字与边界

| 考点                 | 数值与限定                                      |
| -------------------- | ----------------------------------------------- |
| 关注类技术性例外     | **7 天内**，且属于操作性或技术性原因            |
| 次级逾期             | **超过 90 天**                                  |
| 非零售债务人跨行条件 | 逾期超过 90 天的债务已**超过 20%**              |
| 可疑逾期             | **超过 270 天**                                 |
| 可疑损失程度         | 已信用减值，预期信用损失占账面余额 **50% 以上** |
| 损失逾期             | **超过 360 天**                                 |
| 损失程度             | 已信用减值，预期信用损失占账面余额 **90% 以上** |

> 解释：“超过”与“以上”不要混用：例如刚好 90 天未满足“超过 90 天”这一个条件，但仍可能因信用减值等其他条件被分为次级或更差类别。

### 不良金融资产的八种处置方式

不良金融资产的八种处置方式是**现金清收、资产重组、以资抵债、呆账核销、批量转让、不良资产证券化、市场化债转股、破产清偿**。

#### 现金清收

| 方式         | 主要内容                                     |
| ------------ | -------------------------------------------- |
| **直接追偿** | 最基本、最常用的处置方式，直接向债务人等追索 |
| **诉讼追偿** | 通过诉讼或仲裁                               |
| **委外清收** | 委托第三方机构开展清收                       |

> 解释：还可以联系将不良债权交由其他机构处置等方式帮助理解。
>
> *补充：委托第三方催收不等于已经出售债权。委外清收与债权转让的权利归属、责任和程序不同，不能因为都涉及第三方就混成同一方式。*

#### 资产重组

资产重组可以从两个方面理解：

- 借款人对自身资产或经营进行重组，改善持续经营和还款能力。
- 对债务条款重新协商，如还款期限、金额、利率等安排。

目的在于使具备条件的债务人恢复经营和偿债能力。

> *补充：资产重组与债务重组有联系，但不完全同义。调整债务条款是债务重组的常见内容，调整资产、业务或组织结构则可能属于更广泛重组；不能简单说两者任何情况下都可以互换。*

#### 以资抵债

以资抵债分为**协议抵债、裁定抵债**。

| 类型     | 形成方式                       |
| -------- | ------------------------------ |
| 协议抵债 | 有关主体依法协商达成抵债安排   |
| 裁定抵债 | 按法院等有权机关的相应裁定处理 |

> 解释：
>
> - 抵债后取得的资产还需后续处置，可联系批量转让等渠道理解。
> - 教材以“银行一般不直接处置、需交资产管理公司”帮助理解抵债资产的后续处置。
>
> *补充：不能将“银行一般不直接处置、需交资产管理公司”理解为银行对所有抵债资产都绝无自行依法处置权限。是否可以批量转让、采用何种处置方式，应遵守具体资产、权属和业务规则。*

#### 呆账核销

呆账核销是按条件使用已计提准备等进行账务核销，处理无法收回或符合核销条件的资产。

> *补充：核销是一种会计处理，既不自动免除债务，也不等于银行放弃追索。*

##### 五类不得核销事项

| 序号 | 债权、股权情形                                               |
| ---- | ------------------------------------------------------------ |
| 1    | **借款人或者担保人有经济偿还能力，银行未按规定履行必要措施和实施必要程序追偿的债权** |
| 2    | **违反法律、法规规定，以各种形式逃废或悬空的银行债权**       |
| 3    | **因行政干预造成逃废或悬空的银行债权**                       |
| 4    | **银行未向借款人、担保人追偿的债权**                         |
| 5    | **其他不应核销的银行债权、股权**                             |

> 解释：不能因不愿追偿、未履行追偿职责，或相关主体恶意逃废债，就随意通过核销了结。
>
> *补充：上表保留教材使用的禁止性清单。2017 年核销办法以认定条件、证据、必要措施与程序、内部审核及核销后管理等作出规定，不能把旧清单替代全部现行核销判断。具体能否核销还须结合相关适用标准，不能仅因有争议、涉及违规等就永远停止依法处置。*

##### 核销后的管理

> 解释：核销后不能放任不管。核销到表外后仍应管理，可结合转让、追偿等方式处置。
>
> *补充：除依法终结权利义务等情形外，应按“账销案存、权在力催”原则继续尽职追偿、保全和管理。核销与债权最终消灭是两回事。*

#### 批量转让

可按规定批量转让的资产包括**有关不良资产、抵债资产、已核销但仍保有权利的资产**等，由合格受让方受让并处置。

> 解释：**不是所有批量转让都必须先核销，也不是核销后就不再有可以依法转让的权利。**

##### 六类不得批量转让的资产

1. **债务人或担保人为国家机关的资产。**
2. **经国务院批准列入全国企业政策性关闭破产计划的资产。**
3. **国防军工等涉及国家安全和敏感信息的资产。**
4. **个人贷款。**
5. **借款合同或担保合同中有限制转让条款的资产。**
6. **国家法律法规限制转让的其他资产。**

> 解释：可以分别联系国家机关、政策性关闭破产的专门安排、国防军工保密以及合同约束解释限制原因。

##### 个人贷款转让的试点例外

**个人贷款原则上不能按上述一般规则批量转让，但已经存在试点例外。**

> *补充：2021 年起开展个人不良贷款批量转让试点，之后有扩围和延期安排。2026 年公开信息显示试点继续延续，因此“个人贷款一律不得批量转让”不是完整结论。仍须限定试点机构、贷款类型、受让主体、业务渠道和适用条件，不能反过来理解为所有个人贷款都可以自由买卖。*

#### 不良资产证券化

**不良信贷资产支持证券在全国银行间债券市场发行和交易。**

> 解释：
>
> - 将有关信贷资产通过证券化安排发行资产支持证券，回收资金、分散或转移有关风险。
> - 对比交易所市场的企业资产支持证券，可以注意两者基础资产性质和产品规则的不同。
>
> *补充：此处应按课程中的不良信贷资产证券化渠道理解，不能推导出“任何种类资产证券化只能在银行间市场发行”。发行证券也不自动保证会计出表或彻底消除风险，须分别满足相应条件。*

#### 市场化债转股

债权转为对债务人的股权，权利性质由债权关系向股权关系转变。

**银行不得直接将债权转为股权。**银行可向符合条件的实施机构转让债权，再由实施机构开展转股。

> *补充：有关政策完整表述是“除国家另有规定外，银行不得直接将债权转为股权”。应保留这一限定，也不能把实施机构概括为任意第三方公司；主体资格、洁净转让、真实出售、风险隔离等均须符合规定。*

#### 破产清偿

破产清偿可以联系**灭亡程序、重生程序**两类路径理解。

| 路径         | 含义                                               |
| ------------ | -------------------------------------------------- |
| **灭亡程序** | 无法通过重整、和解等恢复，进入破产清算等终结性安排 |
| **重生程序** | 通过重整、和解等保留恢复经营的可能                 |

> 解释：破产有关最终裁定须依法由法院作出。
>
> *补充：“灭亡”“重生”是教材便于理解的概括，应与法定破产清算、重整、和解程序对应，不能理解为银行自行决定企业进入或退出破产。重整、和解也不保证一定成功。*

## 高频考点 29：中国人民银行法

### 央行的定位与职责

中国人民银行在**国务院领导下**，制定和执行货币政策，防范和化解金融风险，维护金融稳定。

| 序号 | 职责                                             | 记忆重点                 |
| ---- | ------------------------------------------------ | ------------------------ |
| 1    | 发布与履行其职责有关的命令和规章                 | 履职相关的规则制定       |
| 2    | 依法制定和执行货币政策                           | 宏观调控                 |
| 3    | 发行人民币，管理人民币流通                       | 发行的银行               |
| 4    | 监督管理银行间同业拆借市场和银行间债券市场       | 两个银行间市场           |
| 5    | 实施外汇管理，监督管理银行间外汇市场             | 外汇管理及银行间外汇市场 |
| 6    | 监督管理黄金市场                                 | 黄金市场管理             |
| 7    | 持有、管理、经营国家外汇储备、黄金储备           | 国家储备的管理与经营     |
| 8    | 经理国库                                         | 政府的银行               |
| 9    | 维护支付、清算系统的正常运行                     | 银行的银行               |
| 10   | 指导、部署金融业反洗钱工作，负责反洗钱的资金监测 | 指导部署与资金监测       |
| 11   | 负责金融业统计、调查、分析和预测                 | 金融统计与研究           |
| 12   | 作为国家的中央银行，从事有关国际金融活动         | 国际金融交往             |
| 13   | 国务院规定的其他职责                             | 其他法定职责             |

> 解释：
>
> - 理解央行职责，可以联系三个基本角色：**发行的银行、银行的银行、政府的银行**。此外，央行还承担相应的金融监督管理职责。
> - 经理国库可以理解为承担国家国库出纳方面的工作；支付清算系统服务于商业银行之间、不同系统之间的资金清算。反洗钱工作中，央行承担整体指导、部署及资金监测方面的职责。

### 禁止从事的业务和工作

#### 两类透支禁止

- 不得对**银行业金融机构的账户透支**。
- 不得对**政府财政透支**。

> 解释：从风险控制角度理解，一方面，避免金融机构过度依赖央行而放松自身风险管理；另一方面，避免财政资金需求通过央行透支直接转化为货币供给扩张，影响币值稳定。

#### 不得直接认购、包销政府债券

中国人民银行不得**直接认购、包销国债和其他政府债券**。

> 解释：央行可以承担有关政府债券的组织发行、兑付工作，不能因此混同为直接认购或包销。
>
> *补充：禁止“直接认购、包销”不等于禁止公开市场买卖。教材所对应的《中国人民银行法》第二十三条允许央行为执行货币政策在公开市场买卖国债、其他政府债券等；第二十五条允许代理国务院财政部门组织发行、兑付政府债券。*

#### 贷款对象限制及例外

不得向以下主体提供贷款：

1. **地方政府、各级政府部门**。
2. **非银行金融机构**。
3. **其他单位和个人**。

例外：**国务院决定中国人民银行可以向特定的非银行金融机构提供贷款的除外**。

> 解释：注意：例外有特定的决定主体和贷款对象，不能扩大为央行可以自行向任何单位、个人贷款。

#### 担保禁止

不得向**任何单位和个人提供担保**。

### 央行的三类检查监督权

| 类型                   | 教材要点                                             | 判断重点               |
| ---------------------- | ---------------------------------------------------- | ---------------------- |
| 直接检查监督权         | 央行在法定职责范围内直接检查监督                     | 央行自身的法定职权     |
| 建议检查监督权         | 建议国务院银行业监督管理机构对银行业金融机构检查监督 | 接受建议机关的回复期限 |
| 特定情况下的检查监督权 | 特定金融风险情况下进行检查监督                       | 特定情形及批准条件     |

**建议检查：国务院银行业监督管理机构应当自收到建议之日起 30 日内予以回复。**

> *补充：30 日是“回复建议”的期限，不能写成必须在 30 日内完成全部检查。特定情况下检查监督的条件是银行业金融机构出现支付困难、可能引发金融风险，并须经国务院批准。国务院银行业监督管理机构与中国人民银行各依法履职，不能将前者理解为后者的下属机构。*

## 高频考点 30：银行业监督管理法

### 监管机构的监督管理职责

#### 制定、发布监管制度

银行业金融机构应当严格遵守**审慎经营规则**。

#### 准入职责

准入包括**机构准入、业务准入、人员准入、股东变更审查**。

| 准入事项                   | 审批期限或比例                    | 重点                                 |
| -------------------------- | --------------------------------- | ------------------------------------ |
| 银行业金融机构设立         | 自收到申请文件之日起 **6 个月内** | 设立期限较长                         |
| 银行业金融机构变更、终止   | 自收到申请文件之日起 **3 个月内** | 与设立区分                           |
| 业务范围准入               | 自收到申请文件之日起 **3 个月内** | 业务审批                             |
| 董事、高级管理人员任职资格 | 自收到申请文件之日起 **30 日内**  | 不是所有银行员工均须进行任职资格审批 |
| 股东变更审查               | 教材提示 **5%**                   | 主要股东资格审查                     |

监管机构应当在规定期限内作出**批准或者不批准的书面决定**；不批准的，应当说明理由。

> 解释：股东审查涉及两种情形：申请设立银行时审查有关股东；银行成立后，符合规定的股东变更也需要审查。以持股达到 5% 的主要股东为记忆重点。
>
> *补充：第二十二条的 3 个月还包括“增加业务范围内的业务品种”。5% 不能概括全部主要股东认定标准：《商业银行法》第二十四条规定变更持有资本总额或者股份总额 5% 以上的股东须经批准；具体监管规则还可能根据重大影响等情形认定主要股东。*

#### 非现场监管

非现场监管不以检查人员亲临现场为前提，可以通过报送的报表、数据和资料分析机构的经营及风险情况。

国务院银行业监督管理机构负责**统一编制全国银行业金融机构的统计数据、报表**。

各金融机构既要按要求报送资料，也要保证资料真实、准确、完整。

- 未按规定报送资料：**10 万元以上 30 万元以下罚款**。
- 提供虚假资料：**20 万元以上 50 万元以下罚款**。

> *补充：按教材对应的《银行业监督管理法》第四十七条，未按规定提供报表、报告等文件资料，先责令改正；逾期不改正，才处 10 万元以上 30 万元以下罚款。第四十六条对提供虚假或者隐瞒重要事实的报表、报告等文件资料规定责令改正，并处 20 万元以上 50 万元以下罚款。不能省略违法情形和处罚前提，仅凭“不报”和“报错”机械套用。*

#### 现场检查

现场检查是监管人员到机构现场，对业务活动及风险状况进行检查。

国务院银行业监督管理机构收到中国人民银行提出的检查建议后，**自收到建议之日起 30 日内回复**。

> *补充：“30 日内检查完成并回复”属于不准确的概括。法条规定的是 30 日内回复，未规定该条下所有检查均须在 30 日内完成。*

#### 报告职责：先内部报告，再依法对外报告

发现**可能引发系统性银行业风险、严重影响社会稳定的突发事件**时：

1. 立即向**国务院银行业监督管理机构负责人**报告。
2. 负责人认为需要向国务院报告的，立即向**国务院**报告。
3. 同时告知**中国人民银行、国务院财政部门等有关部门**。

> 解释：区分“向谁报告”和“告知谁”，并保留“立即”和“负责人认为需要”的条件。

#### 其他职责

- 对银行业自律组织的活动进行**指导和监督**。
- 开展与银行业监督管理有关的**国际交流与合作**。

> 解释：行政监管与行业自律的性质不同，监管机构依法对自律组织的活动进行指导、监督。

### 对问题银行业金融机构的监管措施

主要包括**接管、促成重组、撤销**。

#### 接管

适用条件：银行业金融机构**已经或者可能发生信用危机，严重影响存款人和其他客户合法权益**。

实施主体：**国务院银行业监督管理机构**。

目的：对被接管机构采取必要措施，**保护存款人的利益，恢复机构正常经营能力**。

> 解释：接管涉及印章、财务、业务、数据等经营管理事项的接手与整顿；实际操作中可能由监管机构指定其他金融机构承担具体接管工作，不能因此混淆依法实施接管的监管主体。

#### 促成重组

适用条件与接管相同：**已经或者可能发生信用危机，严重影响存款人和其他客户合法权益**。

从风险处置效果看，促成重组是对机构采取对银行业体系冲击较小的处置或市场退出安排，以维护市场信心与秩序，保护存款人等债权人的利益。

重组失败时，监管机构可以决定终止重组，转由人民法院依法宣告破产。

> 解释：例如，通过**业务整合、剥离不良资产、引入新的注资**等方式帮助机构调整；重组成功后，可以恢复正常经营。
>
> *补充：重组也可能使机构恢复持续经营，不能把所有重组都理解为退出市场。“转由法院宣告破产”是课程概括，破产仍须满足法定条件并履行司法程序，不是监管机构终止重组后自动发生的结果。*

#### 撤销

适用条件：银行业金融机构存在**违法经营、经营管理不善等情形**，且**不予撤销将严重危害金融秩序、损害公众利益**。

国务院银行业监督管理机构有权予以撤销。

| 措施     | 核心触发条件                                                 | 教材强调的目的或结果         |
| -------- | ------------------------------------------------------------ | ---------------------------- |
| 接管     | 已经或可能发生信用危机，严重影响客户合法权益                 | 保护存款人，恢复正常经营能力 |
| 促成重组 | 与接管相同                                                   | 减少体系冲击，维护信心和秩序 |
| 撤销     | 违法经营、管理不善等，且不撤销将严重危害金融秩序、损害公众利益 | 依法撤销问题机构             |

## 高频考点 31：商业银行法

### 经营原则：“三性、四自”

**三性：安全性、流动性、效益性。**

**四自：自主经营、自担风险、自负盈亏、自我约束。**

> 解释：
>
> - “安全性、流动性”列在“效益性”之前，体现银行经营以风险管理为重要基础，不能只看盈利。
> - 记忆时将三性作为经营目标，将四自作为经营责任和约束要求。

### 组织机构与分支机构责任

商业银行根据业务需要，可以在**中华人民共和国境内外**设立分支机构。

商业银行分支机构：

- **不具有法人资格**。
- 在**总行授权范围内**依法开展业务。
- 其**民事责任由总行承担**。

商业银行对分支机构实行：**全行统一核算、统一调度资金、分级管理的财务制度**。

> 解释：
>
> - 财务制度可以概括为**“两统一、一分级”**，并联系内部资金转移定价说明统一调度资金。讲解还将民事责任与刑事责任作区别，强调“民事责任由总行承担”不能直接套用于刑事责任。
> - “分级管理”不改变分支机构不具有法人资格的性质。授权范围、法人资格和责任承担主体是相互关联的考点。
>
> *补充：刑事责任应依具体犯罪构成及单位犯罪等规则认定，不宜仅以“谁犯错谁承担”替代法律判断。*

### 财务管理制度

1. 会计年度：**公历 1 月 1 日起至 12 月 31 日止**。
2. 信息公布期限：**每一会计年度终了 3 个月内**，按规定公布上一年度的**经营业绩和审计报告**。
3. 编制年度财务会计报告，及时向以下主体报送：
   - **国务院银行业监督管理机构**；
   - **中国人民银行**；
   - **国务院财政部门**。

> 解释：
>
> - 还可以用“银行年后 3 个月、普通企业年后 4 个月”作比较帮助记忆。
> - 区分“向社会公布”的内容与期限，以及“向监管和财政等部门报送”的要求，不要把两者混成同一动作。
>
> *补充：普通企业并不存在一律适用的“年后 4 个月”报告期限，具体要看企业类型、报告种类及适用规则；这里应重点掌握商业银行法规定的 3 个月。*

## 高频考点 32：反洗钱法相关基础

### 洗钱的概念

洗钱，是为掩饰犯罪收益的真实来源和存在，通过各种手段使犯罪收益**表面合法化**的行为。

> 解释：重点在于：资金源于犯罪，通过后续安排掩饰其来源、性质等，使其看似来自正常合法活动。

### 洗钱的三个阶段

| 阶段         | 含义                                                     | 识别重点                         |
| ------------ | -------------------------------------------------------- | -------------------------------- |
| **处置阶段** | 将非法所得投入金融系统                                   | 讲解强调这是较容易被侦察到的阶段 |
| **培植阶段** | 通过一系列复杂交易分散、转移资金，模糊来源               | 复杂交易掩饰资金轨迹             |
| **融合阶段** | 将经过掩饰的资金投入正常经济活动，使其呈现合法收入的外观 | 重新进入看似合法的经济活动       |

> 解释：记忆顺序：**处置→培植→融合**。

### 八种常见方式及例子

| 序号 | 方式                           | 说明                                                         |
| ---- | ------------------------------ | ------------------------------------------------------------ |
| 1    | 借用金融机构                   | 匿名存储、利用银行贷款掩饰犯罪收益、控制银行和其他金融机构；也需关注异常的大额资金往来 |
| 2    | 藏身保密天堂                   | 利用某些地区严格的信息保密安排，增加外部获取企业、交易信息的难度；提及开曼群岛 |
| 3    | 使用空壳公司                   | 通过缺乏实质经营的公司虚构交易、安排资金往来                 |
| 4    | 利用现金密集行业               | 例如赌场、娱乐场所等大量使用现金的场景，说明现金来源混杂时可能被利用 |
| 5    | 伪造商业票据                   | 利用虚假票据贴现、承兑或要求付款等安排掩饰资金               |
| 6    | 走私                           | 以将非法所得运往境外、脱离原有监管为例说明                   |
| 7    | 用犯罪所得直接购置不动产和动产 | 再通过出售财产，使所得呈现为正常财产交易收入                 |
| 8    | 通过证券和保险业洗钱           | 利用证券投资收益或购买保险后退保等交易掩饰资金来源           |

> *补充：上述例子用于识别犯罪资金掩饰活动。不能仅因交易发生于某个地区、行业或使用某种金融产品，就认定交易构成洗钱；应结合资金来源、交易目的和具体行为判断。*
>
> *补充：2024 年修订的《反洗钱法》自 2025 年 1 月 1 日起施行。这里仅归纳洗钱概念、阶段与常见方式，不涵盖新法下全部机构义务和处罚。*

## 高频考点 33：民事主体

### 民法调整的关系与主体范围

民法调整**平等主体之间的人身关系和财产关系**。

民事主体分为：**自然人、法人、非法人组织**。

### 自然人

#### 范围与民事权利能力

自然人的范围包括**公民、在本国的外国人、无国籍人**。

自然人的民事权利能力**始于出生，终于死亡**。

> 解释：人格权、健康权、生命权等可以帮助理解自然人的权利。

#### 三类民事行为能力

| 类别             | 教材年龄标准                                   | 实施民事法律行为的规则                                       |
| ---------------- | ---------------------------------------------- | ------------------------------------------------------------ |
| 完全民事行为能力 | **18 周岁以上**；另有 16—18 周岁劳动收入的例外 | 可以独立实施民事法律行为                                     |
| 限制民事行为能力 | 教材以 **8 周岁以上的未成年人**为重点          | 可以独立实施纯获利益，或与其年龄、智力相适应的民事法律行为；其他行为需依法代理、同意或追认 |
| 无民事行为能力   | **不满 8 周岁**                                | 由法定代理人代理实施民事法律行为                             |

**16 周岁以上的未成年人，以自己的劳动收入为主要生活来源的，视为完全民事行为能力人。**不能仅凭年满 16 周岁判断其完全民事行为能力。

> 解释：
>
> - 联系此前劳动力人口统计中的 16 周岁帮助记忆，并以能够通过劳动收入维持生活解释这一例外。
> - 纯获利益的例如，**收红包、成为信托财产受益人**。需要把纯获利益与同时承担义务的安排区分开。
>
> *补充：行为能力还与辨认能力有关。不能辨认自己行为的成年人属于无民事行为能力人；不能完全辨认自己行为的成年人属于限制民事行为能力人。因此“成年人均具有完全民事行为能力”是过度概括。*

#### 监护的三种分类

- **法定监护**：依法律规定形成监护关系，如父母担任未成年子女的监护人。
- **协议监护**：依法具有监护资格的人之间，通过协议确定由谁担任监护人。
- **指定监护**：监护人确定存在争议等情形下，由有权机关依法指定。

> 解释：例如，父母不能担任监护人时，其他依法有监护资格的亲属可能通过协商确定人选；无法确定时，通过指定解决。
>
> *补充：协议应在依法具有监护资格的人之间作出，并尊重被监护人的真实意愿。指定监护依法涉及居委会、村委会、民政部门及人民法院；没有依法具有监护资格的人时的监护安排，不能简单等同于“有亲属但无人愿意监护”。*

#### 宣告失踪与宣告死亡

| 制度               | 基本时间条件                  | 提示                        |
| ------------------ | ----------------------------- | --------------------------- |
| 宣告失踪           | 下落不明满 **2 年**           | 通过法院依法宣告            |
| 宣告死亡的一般情形 | 下落不明满 **4 年**           | 不应只记为“失踪后再过 2 年” |
| 因意外事件宣告死亡 | 因意外事件下落不明满 **2 年** | 与一般 4 年区分             |
| 意外事件的特殊情况 | 经有关机关证明不可能生存      | **不受 2 年时间限制**       |

> 解释：宣告失踪、死亡制度用于处理下落不明导致的人身、财产关系不确定问题，可能涉及财产管理、债务清偿及继承等安排。
>
> *补充：由利害关系人向人民法院申请；宣告死亡不以先宣告失踪为前提。宣告失踪并不等于自然人死亡，也不会直接启动死亡继承。“宣告失踪以后两年”的说法只宜作为一般 4 年条件的辅助记忆，不能作为法定计算起点。*

### 法人

#### 三类法人

| 类别           | 说明与例子                                 |
| -------------- | ------------------------------------------ |
| **营利法人**   | 以营利为目的，举有限责任公司、股份有限公司 |
| **非营利法人** | 举社会团体、公益组织、基金会等             |
| **特别法人**   | 举机关法人、农村集体经济组织法人等         |

> 解释：法人是指依法赋予组织参与民事活动的主体资格，不能将法人理解为某一个自然人。

#### 权利能力的期间

法人权利能力：**始于成立，终于法人终止**。

> 解释：可以用领取营业执照理解企业法人取得主体资格的时间。
>
> *补充：领取营业执照适合说明依法登记设立的有关企业法人，不能推及所有法人。例如机关法人的成立规则不同。*

#### 法人机关

| 机关     | 例子与功能                     |
| -------- | ------------------------------ |
| 意思机关 | 股东大会等，决定重大事项和方向 |
| 执行机关 | 董事会等，执行、管理有关事务   |
| 代表机关 | 以法定代表人说明对外代表法人   |
| 监察机关 | 教材用语，以监事会说明监督作用 |

> *补充：本表主要以公司法人为例整理，不是所有法人都设置同样机关。公司监督机构的设置还须结合现行《公司法》与章程判断。*

### 非法人组织

1. **个人独资企业**。
2. **合伙企业**。
3. **不具有法人资格的专业服务机构**。

> 解释：以律师事务所、会计师事务所等帮助理解，并提及特殊普通合伙形式。还联系个人经营贷款的借款主体帮助记忆。
>
> *补充：非法人组织不等于自然人。个人经营贷款的借款人及企业贷款的借款人，须按具体产品与制度判断，不能由“不具有法人资格”直接推出组织可以按自然人身份借款。*
>
> *补充：专业服务机构存在不同组织形式，不能把所有律师事务所、会计师事务所一概视为同一种合伙形式；应以具体机构的依法设立形式判断。*

## 高频考点 34：民事法律行为与代理

### 有效民事法律行为的三个条件

1. 行为人具有**相应的民事行为能力**。
2. **意思表示真实**。
3. **不违反法律、行政法规的强制性规定，不违背公序良俗**。

> 解释：三个条件分别从主体能力、意思表示和行为内容三个方面判断。判断时要注意是**“相应”民事行为能力**，不是要求所有行为人一律具有完全民事行为能力。

### 可撤销的民事法律行为

1. **重大误解**：基于重大误解实施的民事法律行为。
2. **一方欺诈**：一方以欺诈手段，使对方违背真实意思实施行为。
3. **第三人欺诈**：第三人实施欺诈，使一方违背真实意思实施行为。
4. **一方或者第三人胁迫**：以胁迫手段，使对方违背真实意思实施行为。
5. **显失公平**：一方利用对方处于危困状态、缺乏判断能力等情形，致使行为**成立时**显失公平。

> *补充：第三人欺诈的撤销还要求“对方知道或者应当知道该欺诈行为”。教材列举时省略了这一条件，复习应补齐。第三人胁迫不适用这一相同的知情条件。*

### 撤销权期限与案例

#### 重大误解：古董低价出售

**重大误解的撤销权期间：自知道或者应当知道撤销事由之日起 90 日内。**

> 解释：例如，一件价值 **10 万元**的古董，出售人误以为是赝品，以 **1000 元**出售。讲解用此说明对交易标的产生重大误解，可能依法请求撤销。

#### 欺诈、胁迫与显失公平

撤销权期间的一般记忆：**重大误解为 90 日，其余几类为 1 年**。

> 解释：
>
> - 欺诈：房屋内曾发生凶杀案件，却向购买人作出相反陈述，用于说明隐瞒、虚构情况使对方违背真实意思交易。
> - 胁迫：以有关照片威胁对方，迫使其从事交易。
> - 显失公平：利用对方生病急需资金的危困状态，低价购买其房屋。
> - 这些例子用于理解相应要件，判断时仍应结合具体事实，不能仅凭“低价”或“交易后反悔”认定可撤销。
>
> *补充：欺诈、显失公平的 1 年一般自知道或者应当知道撤销事由之日起算；胁迫的 1 年自胁迫行为终止之日起算。此外，自民事法律行为发生之日起 5 年内没有行使撤销权的，撤销权消灭。撤销由有权一方向人民法院或者仲裁机构请求，并非自行宣布撤销即可。*

### 代理的概念与四项法律特征

代理人以被代理人的名义，在代理权限范围内实施民事法律行为，其法律后果直接归属于被代理人。

1. 代理行为属于能够引起**民事法律后果的民事法律行为**。
2. 代理人一般应以**被代理人的名义**从事代理活动。
3. 代理人在**代理权限范围内独立进行意思表示**。
4. 法律后果**直接归属于被代理人**。

> 解释：例如，代理公司到银行开户，所开立的是公司的账户，相关法律后果归公司。只要不超越授权范围，代理人可以根据现场情况决定具体办理时间等事项，体现其独立意思表示。

### 无权代理的五项表述

1. 行为人既没有代理权，也没有令人相信其具有代理权的事实或理由。
2. 行为人以**本人的名义**与他人实施民事行为。
3. 第三人须为**善意且无过失**。
4. 行为人的行为不违法。
5. 行为人与第三人具有相应的民事行为能力。

> 解释：其中“本人”在此指被代理人，不是无权代理行为人自己。
>
> *补充：以上五项不能理解为《民法典》规定的所有无权代理情形的共同成立条件，尤其相对人善意并非无权代理成立的必备条件。第一百七十一条涵盖没有代理权、超越代理权或者代理权终止后仍实施代理行为的情形；未经被代理人追认，对被代理人不发生效力。相对人是否知道无权代理，将影响其保护与责任分担。*

### 表见代理：四个判断要点

1. 代理人**没有代理权**。
2. 相对人主观上为**善意**。
3. 客观上存在使相对人相信无权代理人具有代理权的情形。
4. 相对人基于该客观情形，与无权代理人实施民事行为。

> 解释：**核心区别：虽然实际没有代理权，但相对人有理由相信其具有代理权。**
>
> *补充：符合《民法典》第一百七十二条的表见代理，代理行为有效，对被代理人发生效力。普通无权代理则应判断追认等因素，不能一概写成“当然无效”。*

### 案例：已被辞退人员继续以银行员工外观办理业务

| 对比事项                                 | 普通无权代理                 | 表见代理                               |
| ---------------------------------------- | ---------------------------- | -------------------------------------- |
| 实际代理权限                             | 无相应代理权限               | 无相应代理权限                         |
| 是否存在足以使相对人合理相信的代理权外观 | 强调没有相应外观             | 有相应外观，且相对人善意信赖           |
| 效力概括                                 | **效力待定，需判断追认**     | **有效**                               |
| 被代理人态度的作用                       | 追认与否影响是否对其发生效力 | 符合表见代理条件时，不以事后追认为前提 |

> 解释：
>
> - 假设客户到银行办理业务，遇到一名在营业大厅内、穿银行制服、持银行名片或有关标识的人员。该人员表示可以帮助办理业务，客户据此交付材料，但其实际上刚被银行辞退，已无相应代理权限。
> - 判断这个案例时，应关注以下几点：
>   - **实际无代理权**，是无权代理的基本背景。
>   - 制服、名片、所在场所等可能形成**有代理权的外观**。
>   - 客户主观善意，并基于该外观办理业务，是判断表见代理的重点。
>   - 表见代理的法律后果对被代理人发生效力；被代理人因此受到损失，可以依法向无权代理行为人追偿。
>
> *补充：制服、名片并非单独足以当然成立表见代理，仍需审查相对人是否有合理信赖、是否存在过失及其他具体事实。案例用于说明判断结构。*
>
> *补充：普通无权代理未获追认，是“对被代理人不发生效力”，不等于该行为在任何主体之间都当然无效。表见代理是无权代理情形中的特殊保护规则，不能因“实际没有授权”便否定其效力。*

## 高频考点 35：物权

### 概念与三类物权

物权是权利人依法对**特定的物**享有**直接支配和排他**的权利，包括**所有权、用益物权和担保物权**。

| 类型     | 理解                                                         |
| -------- | ------------------------------------------------------------ |
| 所有权   | 对物享有所有权利，是可以用来解释物权特点的主要例子           |
| 用益物权 | 不拥有物的所有权，但依法享有使用、收益方面的权利；以土地使用权为例 |
| 担保物权 | 为债权提供保障；债务不履行时，债权人可以依法就担保财产优先受偿 |

> 解释：
>
> - 例如，将一支笔用作借款担保，若债务不能清偿，债权人依法处置担保物，以变价所得受偿。
> - 以国有土地为例，土地所有权属于国家，使用者可以依法享有土地使用权。
>
> *补充：以“土地所有权属于国家”解释土地使用权，这对国有土地的例子适用；我国土地还包括依法属于集体所有的土地，不能概括全部土地均为国家所有。*

### 五项特点

1. **绝对权，又称对世权**：可以对抗不特定的人，其他人均负有不侵害物权的义务。
2. **支配权**：权利人依法直接支配特定的物。
3. **标的是物**。
4. **排他性**：排除他人不相容的权利与干涉。
5. **追及力**：物转移至他人手中，物权原则上仍可依法追及该物。

> *补充：追及力不是无条件“无论流向哪里都能追回”，还须考虑善意取得等法定规则。*

### 四项基本原则

| 原则           | 解释                                                   |
| -------------- | ------------------------------------------------------ |
| **平等保护**   | 依法平等保护物权，不因主体地位、财富多寡而作不同保护   |
| **物权法定**   | 物权的种类与内容由法律规定                             |
| **一物一权**   | 同一个物上不能并存相互冲突的所有权                     |
| **公示、公信** | 通过登记等法定方式公示物权状态；以房产买卖变更登记为例 |

> 解释：**一物一权不等于一个物上只能存在一个物权。**同一财产上可以同时存在所有权、依法设立的抵押权等不同性质的权利；例如，一项价值较高的财产可以在符合法律要求的情况下设立多项抵押。

## 高频考点 36：担保

担保包括**保证、抵押、质押、留置、定金**五种方式。

### 保证

保证是第三方保证人为债务履行提供保障，分为**一般保证、连带责任保证**。

| 类型         | 概括                                                       |
| ------------ | ---------------------------------------------------------- |
| 一般保证     | 责任承担存在先后顺序，先向债务人主张，再依条件向保证人主张 |
| 连带责任保证 | 不存在同样的先后顺序，债权人可依法向债务人或保证人请求履行 |

**保证方式没有约定或者约定不明确，按一般保证承担责任。**

不得作为保证人的主体包括**机关法人、以公益为目的的非营利法人和非法人组织**。

> *补充：一般保证不是债务人一旦“不还钱”便可直接要求保证人清偿。保证人原则上享有先诉抗辩权，在主合同纠纷未经审判或仲裁、并就债务人财产依法强制执行仍不能履行债务前，可拒绝承担保证责任；法律另有例外。连带责任保证也须以债务人不履行到期债务或发生约定情形等为前提。*
>
> *补充：“以公益为目的”同时限定这里的非营利法人和非法人组织，不能误读为所有非法人组织均不得提供保证。机关法人存在经国务院批准为使用外国政府或者国际经济组织贷款进行转贷的法定例外。*

### 抵押

抵押可以涉及依法允许抵押的**动产或不动产**。判断时可先掌握禁止抵押的财产，再判断其他财产是否具备法定条件。

禁止抵押的财产包括六类：

1. **土地所有权**。
2. **宅基地、自留地、自留山等集体所有土地的使用权**，但法律规定可以抵押的除外。
3. 学校、幼儿园、医疗机构等**为公益目的成立的非营利法人**的教育设施、医疗卫生设施及其他公益设施。
4. **所有权、使用权不明或者有争议**的财产。
5. 依法被**查封、扣押、监管**的财产。
6. 法律、行政法规规定不得抵押的其他财产。

**抵押期间，抵押财产可以依法转让。**

> 解释：
>
> - 权属不明、存在争议或被依法控制的财产，不利于将来依法处置；公益设施的限制用于维护有关公益活动正常进行。
> - 例如，抵押房屋出售后，可以用所得款项偿还银行贷款。
>
> *补充：抵押通常不转移财产占有。抵押财产转让应遵守法律和当事人约定，转让本身原则上不影响抵押权，不能简化为“卖掉后抵押权自动消灭”。*

### 质押

质押分为**动产质押、权利质押**。

动产质押的重要特征是**转移质押财产的占有**。

可出质的权利包括：

- **汇票、支票、本票**。
- **债券、存款单**。
- **仓单、提单**。
- **可以转让的基金份额、股权**。
- 可以转让的注册商标专用权、专利权、著作权等**知识产权中的财产权**。
- **应收账款**。

质权设立方式可以概括为：

- 有实物权利凭证的，通过**交付凭证**设立。
- 没有实物凭证、依法需要登记的，通过**办理出质登记**设立。

> 解释：
>
> - 可以用“房子不能搬到银行”帮助区分不动产抵押与动产质押。
> - 这些权利具有财产价值，并须具备依法可以转让等条件；知识产权出质涉及其财产权部分。
> - 质押期间的转让，可以先用“不能转让”作概括记忆。
>
> *补充：不同权利的公示规则不同，不能只按“有没有实物”一刀切。票据、债券、存款单、仓单、提单等依法律规定适用权利凭证交付或登记；基金份额、股权、有关知识产权财产权及应收账款等，须按各自法定登记规则设立质权。*
>
> *补充：例如基金份额、股权出质后原则上不得转让，但经出质人与质权人协商同意可以转让；转让价款应依法提前清偿或提存，不能记为绝对禁止。*

### 留置

留置针对**动产**。债务人不履行到期债务时，债权人可以依法留置其已经合法占有的债务人动产，并依法优先受偿。

留置重点联系**保管、运输、加工承揽**等合同关系理解。

留置的两项效力为：

1. **留置效力**：依法继续占有、扣留该动产。
2. **优先受偿效力**：满足法定条件后，依法以该物变价所得受偿。

> 解释：例如，将动产交给他人保管、运输或加工，却未支付相应费用，对方依法将该物扣留，符合条件后再依法变价受偿。
>
> *补充：现行《民法典》不把留置权绝对限定为上述三种合同。原则上留置动产应与债权属于同一法律关系，企业之间留置除外；法律规定或约定不得留置的动产不能留置。扣留也不意味着可以立即任意变卖。*

### 定金与订金

**定金数额由当事人约定，但不得超过主合同标的额的 20%；超过部分不产生定金效力。**

| 对比       | 定金（宝盖头）                         | 订金（言字旁）              |
| ---------- | -------------------------------------- | --------------------------- |
| 性质       | 担保性质                               | 一般作为预付款理解          |
| 金额上限   | 定金效力部分不超过主合同标的额 **20%** | 不适用同一法定 20% 定金上限 |
| 收款方违约 | 符合定金罚则条件时**双倍返还**         | 不当然适用双倍返还          |

> *补充：定金罚则要求违约达到不能实现合同目的等法定条件；给付定金一方符合相应违约条件时，无权请求返还。订金退还及其他违约责任仍应结合合同和法律判断，并非任何情况下都只退本金、不承担其他责任。*

## 高频考点 37：合同

### 要约与承诺

要约是希望与他人订立合同的意思表示，承诺是受要约人同意要约的意思表示。

**要约到达受要约人时生效；承诺生效时，合同成立。**

> *补充：合同不仅可以采用书面形式，还可依法采用口头等形式。合同成立与合同生效也应区分，不能将“承诺生效、合同成立”无条件替换为“合同生效”。*

### 要约撤回、撤销与失效

#### 撤回与撤销

- **撤回**：针对尚未生效的要约，撤回通知须在要约到达受要约人**之前或者同时**到达。
- **撤销**：针对已经生效的要约，依法使其不再具有约束力。

> *补充：要约并非一律可以撤销。以确定承诺期限等形式明示不可撤销，或受要约人有理由认为不可撤销且已为履约作合理准备等情形，适用不可撤销规则。*

#### 要约失效的四种情形

1. **要约被拒绝**。
2. **要约被依法撤销**。
3. **承诺期限届满，受要约人未作出承诺**。
4. **受要约人对内容作出实质性变更**。

> 解释：以金额、期限等重要条款发生变化说明实质性变更，此时可能构成新的要约，原要约失效。

### 承诺的撤回

承诺可以撤回。撤回通知应在承诺通知到达要约人**之前或同时**到达。

> 解释：承诺生效时合同成立，不能再按要约撤销的思路随意“撤销承诺”；此后应依合同解除、撤销等相应制度判断。

### 合同效力的分类

| 类别                     | 教材列示                                                     |
| ------------------------ | ------------------------------------------------------------ |
| **无效合同**             | 虚假合同；恶意串通损害他人合法权益；违背公序良俗；违反法律、行政法规的强制性规定 |
| **可变更、可撤销的合同** | 重大误解、显失公平、欺诈、胁迫、乘人之危等                   |
| **效力未定的合同**       | 教材概括为订立后尚未生效、须权利人追认才能生效的合同         |

> *补充：现行《民法典》对重大误解、欺诈、胁迫、利用危困状态或缺乏判断能力导致显失公平等，主要规定请求撤销；“可变更、可撤销”带有旧法表述痕迹。第三人欺诈另须对方知道或应当知道欺诈。违反强制性规定还存在“该规定不导致行为无效”的例外。*
>
> *补充：效力待定与所有“尚未生效”的合同不同；附生效条件未成就、待批准等不能一概按追认处理。课程重点是依法需要追认的情形。*

## 高频考点 38：婚姻与继承

### 夫妻共同财产与一方个人财产

| 夫妻共同财产的教材清单       | 夫妻一方个人财产的教材清单       |
| ---------------------------- | -------------------------------- |
| 工资、奖金、劳务报酬         | 一方婚前财产                     |
| 生产、经营、投资收益         | 一方因人身损害获得的赔偿或者补偿 |
| 知识产权收益                 | 遗嘱或赠与合同确定只归一方的财产 |
| 继承或受赠财产，注意右列例外 | 一方专用的生活用品               |
| 其他应归共同所有的财产       | 其他应归一方的财产               |

**继承或赠与所得，若遗嘱、赠与合同明确只归一方，则属于一方个人财产。**

> *补充：共同财产清单应放在婚姻关系存续期间所得、且未依法另行约定等前提下理解。知识产权本身与知识产权收益也不能混为同一概念。*

### 法定继承顺序

- **第一顺序：配偶、子女、父母。**
- **第二顺序：兄弟姐妹、祖父母、外祖父母。**

> 解释：子女不仅指亲生子女，还包括养子女、有扶养关系的继子女；父母还包括养父母、有扶养关系的继父母。还提及尽赡养义务的儿媳、女婿等情形。
>
> *补充：丧偶儿媳对公婆、丧偶女婿对岳父母尽了“主要赡养义务”的，作为第一顺序继承人，不是所有儿媳、女婿均可按子女直接继承。依法继承时，有第一顺序继承人继承，第二顺序不继承；没有第一顺序继承人继承时，由第二顺序继承人继承，不能仅理解为第一顺序所有人必须均已死亡。*

### 遗嘱继承

遗嘱形式包括**自书、代书、打印、录音录像、口头、公证遗嘱**。

**遗嘱继承的效力优于法定继承。**

> *补充：这里指依法有效的遗嘱在其处分范围内优先适用，不能据此认为任何形式的“遗嘱”都当然有效；不同形式各有法定要求。*

## 高频考点 39：公司法

### 成立与章程

**公司营业执照签发日期，即为公司成立日期，也是公司取得法人资格的日期。**

公司章程对**公司、股东、董事、监事、高级管理人员**具有约束力。

> 解释：公司章程可以比喻为“公司的宪章”。上述法定列举不表示普通员工完全不受约束，员工日常还受具体规章制度管理。

### 公司治理机构

| 机构或岗位 | 教材定位                                               |
| ---------- | ------------------------------------------------------ |
| **股东会** | 公司的权力机构                                         |
| **董事会** | 公司的经营决策机构                                     |
| **监事会** | 公司的法定监督机构，教材注明可由审计委员会行使相关职权 |
| **经理**   | 对公司日常经营管理负总责的高级管理人员                 |

> 解释：“董事会中设置审计委员会、依法不另设监事会”与“董事会、监事会分别设置”是不同治理安排；经理在董事会之下负责日常经营管理。
>
> *补充：公司机关的具体设置须结合公司类型、规模及法律规定判断；审计委员会替代监事会等安排有相应法定条件，不是任意互换。*

### 公司解散的五种事由

1. 公司章程规定的**营业期限届满**，或章程规定的其他解散事由出现。
2. **股东会决议解散**。
3. 因公司**合并或者分立**需要解散。
4. 依法被**吊销营业执照、责令关闭或撤销**。
5. **人民法院依法予以解散**。

**除因合并、分立解散外，依法应清算的公司应进行清算，清理债权债务。**

> 解释：可以将章程事由、股东会决定、合并分立等联系主动解散理解，将吊销、关闭、撤销、法院解散等联系被动解散理解；合并、分立由其他主体或形式承继有关关系，因此与一般解散清算不同。
>
> *补充：依法出现解散事由不等于公司法人立即终止；清算和注销等程序应依法完成。公司也可能在法律允许的情形下通过修改章程或股东会决议存续。*

## 高频考点 40：证券法

### 公开发行与非公开发行

公开发行包括以下情形：

1. 向**不特定对象**发行证券。
2. 向**特定对象**发行证券累计**超过 200 人**。
3. 法律、行政法规规定的其他发行行为。

非公开发行又称**私募发行**，可以联系向特定对象发行理解。

> *补充：依法实施员工持股计划的员工人数，不计入上述 200 人的计算。向特定对象发行也可能因人数等条件构成公开发行，不能只看对象是否特定。*

### 证券承销

我国《证券法》规定的承销方式：**代销、包销**。

**代销、包销期限最长不得超过 90 日。**

> 解释：包销还可分为**全额包销、余额包销**；股票承销联系证券公司，银行可依法参与有关债券承销，不能把所有证券承销均理解为银行业务。

### 证券交易

- 交易的证券须**依法发行并交付**。
- 依法有转让期限限制的证券，**在限定期限内不得买卖**。
- 依法适用的交易，应在**依法设立的证券交易所**或**国务院批准的其他全国性证券交易场所**进行。
- 在证券交易所上市交易，应采用**公开的集中交易方式**或国务院证券监督管理机构批准的其他方式。

> *补充：《证券法》对公开发行证券的交易场所有相应规定；非公开发行证券可依规定在证券交易所、国务院批准的其他全国性证券交易场所及依法设立的区域性股权市场等转让。不要把不同发行类型的交易场所要求混为一条。*

### 证券交易限制

证券交易限制应分别记住适用主体：

- 证券公司、证券交易场所、证券登记结算机构等有关人员，在任职期间受证券买卖限制。
- 为发行提供有关服务的会计师事务所、律师事务所等相关人员，涉及承销期间及期满后 **6 个月**的限制。
- 上市公司董监高等主体 **6 个月内买入又卖出，或卖出又买入**的短线交易，有关收益归公司。
- 公开发行前已发行股份，提示上市后 **1 年内**不得转让。
- 董监高离职后**半年内**不得转让其所持本公司股份。

> *补充：任职限制须按法定机构、人员及股票等具体证券范围理解，不是相关人员不得买卖任何金融产品；为证券发行出具审计报告、法律意见书等文件的证券服务机构和人员，在承销期内及期满后 6 个月内不得买卖“该证券”。短线交易还涉及持有 5% 以上股份的股东等主体及法定例外，不能只记董监高；上市后 1 年、离职后半年也有各自适用股份范围。*

### 禁止行为

证券市场禁止行为包括**内幕交易、操纵市场、虚假陈述和信息误导、违背客户真实意思损害客户利益**。

## 高频考点 41：基金法相关知识

### 基金的四种分类口径

| 分类依据     | 类型                                                         |
| ------------ | ------------------------------------------------------------ |
| **募集方式** | 公募基金、私募基金                                           |
| **组织形式** | 契约型、公司型、合伙型基金                                   |
| **运作方式** | 开放式、封闭式基金                                           |
| **投资对象** | 证券投资基金、私募股权基金（PE）、风险投资基金（VC）、对冲基金、另类投资基金 |

> 解释：
>
> - 组织形式的解释：以基金合同为基础的是契约型；以公司形式运作、投资人作为股东的是公司型；以合伙企业形式运作的是合伙型。
> - 投资对象的解释：
> - **证券投资基金**：投资证券等有关资产。
> - **PE**：主要联系未上市企业股权理解。
> - **VC**：联系企业早期阶段、风险较高的股权投资理解。
> - **对冲基金**：利用有关金融工具、交易策略进行投资，以对冲方式帮助记忆。
> - **另类投资基金**：举黄金、房地产、字画等投资方向。

### 证券投资基金的具体类别

| 类别                  | 教材标准                                                     |
| --------------------- | ------------------------------------------------------------ |
| **股票基金**          | **80% 以上**基金资产投资于股票                               |
| **债券基金**          | **80% 以上**基金资产投资于债券                               |
| **货币市场基金**      | **仅投资于货币市场工具**                                     |
| **基金中基金（FOF）** | **80% 以上**基金资产投资于其他基金份额                       |
| **混合基金**          | 投资股票、债券、货币市场工具或其他基金份额，且股票、债券、基金投资比例不符合上述相应类别标准 |

> 解释：记忆时可以注意：股票、债券、基金中基金抓住 **80%**；货币市场基金抓住**“仅”**，口头用“100%”帮助理解这一限定。

## 高频考点 42：保险法相关知识

### 保险合同主体

| 分类               | 主体                                   |
| ------------------ | -------------------------------------- |
| **保险合同当事人** | **保险人（承保人）、投保人（要保人）** |
| **保险合同关系人** | **被保险人、受益人**                   |

> 解释：保险人可联系保险公司理解；投保人是与保险人订立合同的主体。投保人、被保险人、受益人可能由同一人担任，但概念和法律地位不同。

### 保险代理与保险经纪

| 对比           | 保险代理                       | 保险经纪                             |
| -------------- | ------------------------------ | ------------------------------------ |
| 基本立场       | **接受保险人委托**             | **基于投保人利益**                   |
| 业务           | 在保险人授权范围内代办保险业务 | 为投保人与保险人订立合同提供中介服务 |
| 收入           | 依法收取佣金                   | 依法收取佣金                         |
| 主体的教材表述 | 机构或个人                     | 机构                                 |

保险代理机构包括**保险专业代理机构、保险兼业代理机构**。**商业银行属于保险兼业代理机构**。

> 解释：以“从保险公司角度寻找客户”和“从客户角度寻找适合的保险公司、产品”区分二者。

### 商业银行代理保险的条件

1. 每个营业网点在代理保险业务前取得监管部门颁发的有关**保险兼业代理业务许可证**，并获得商业银行**一级分支机构授权**。
2. 销售人员符合资格条件，并取得《**保险销售从业人员资格证书**》。
3. 销售**投资连结保险**的人员，至少有 **1 年以上保险销售经验**，接受不少于 **40 小时专项培训**，并无不良记录。

> *补充：2015 年已经取消保险销售（含保险代理）、保险经纪从业人员资格核准审批，不能将教材所写资格证书作为现行一律必备条件。2019 年《商业银行代理保险业务管理办法》采用法人机构或授权分支机构办理有关许可、销售人员执业登记等安排，不宜继续按“所有网点逐一领同一旧证”的表述理解。该办法对投连险销售人员还明确“每年”不少于 40 小时专项培训；原资料中的条件省略了年度口径。*

## 高频考点 43：信托法

### 信托的五项特征

1. **以信任为基础**，受托人应有良好信誉。
2. 成立前提是委托人将其财产委托给受托人。
3. **信托财产独立**：信托依法成立后，与委托人、受托人及受益人的自有财产相区分，独立运行。
4. 受托人应为**受益人的最大利益**管理信托事务。
5. 具有一定的**连续性、稳定性**。

> 解释：信托财产应当合法、能够确定和区分；信托不当然因为委托人死亡等个人变故而终止，以此解释连续性与稳定性。
>
> *补充：信托财产独立与是否终止仍须依具体法律规则判断；“不因死亡当然终止”不能扩大为任何情况下都不终止。*

## 高频考点 44：票据法

### 票据的七项特征

| 特征             | 理解                                   |
| ---------------- | -------------------------------------- |
| **完全有价证券** | 票据权利与票据具有紧密联系             |
| **要式证券**     | 依法具备必要形式和记载事项             |
| **无因证券**     | 合法取得票据后，票据关系具有相对独立性 |
| **流通证券**     | 可依法通过背书等方式转让               |
| **文义证券**     | 按票据文字记载确定权利义务             |
| **设权证券**     | 依法出票等行为创设票据权利             |
| **债权证券**     | 体现请求支付票据金额的债权             |

> 解释：无因性应以合法取得等条件理解，不能拿非法取得的票据当然请求付款。
>
> *补充：持有票据不等于当然享有票据权利，还应判断取得方式、法定记载和抗辩等规则。无因性也不意味着票据可以脱离一切法定交易、债权债务要求。*

### 票据的五项功能

票据具有**汇兑、支付与结算、融资、替代货币、信用**五项功能。

> 解释：联系具体业务理解：票据可以用于付款、结算和异地资金安排；远期付款及贴现等可体现融资功能；商业汇票由银行承兑时，体现银行信用。可以用商业汇票可能在数月后付款帮助理解期限与融资。

### 四类票据行为

1. **出票**：包括**做成、交付**两种行为。
2. **背书**：以转让票据为重点。
3. **承兑**：**汇票所特有**。
4. **保证**：适用于**汇票、本票**，不适用于支票。

> *补充：承兑是付款人承诺在汇票到期日支付金额的票据行为，不能简单等同于实际付款。支票不适用票据保证制度，也不是因为“支票可能空头所以任何保证均无效”。*

### 付款请求权与追索权

- **付款请求权**：称**第一顺序请求权**，依法请求付款。
- **追索权**：称**第二顺序请求权**，在依法可以追索的情形下，向有关前手等票据债务人主张。

> *补充：追索并非任何情形都必须先等到实际拒付；法律规定的到期前追索情形也应考虑。*

### 票据权利期间

| 权利                             | 教材期限                |
| -------------------------------- | ----------------------- |
| 持票人对出票人、承兑人的有关权利 | 自票据到期日起 **2 年** |
| 见票即付汇票、本票的相应权利     | 自出票日起 **2 年**     |
| 持票人对支票出票人的权利         | 自出票日起 **6 个月**   |

> 解释：银行汇票、本票联系见票即付理解；商业汇票存在到期日，注意 2 年的起算点不同。
>
> *补充：上述 2 年和 6 个月只对应列明的权利主体与请求，不能推及全部票据权利。例如对前手追索、再追索另有期限。教材未展开这些期限。*

### 票据丧失的三种补救

票据丧失的补救方式包括**挂失止付、公示催告、提起诉讼**。

- 挂失止付：依法通知付款人暂停支付。
- 公示催告：依法向法院申请，由法院公告，利害关系人依法申报权利。
- 提起诉讼：依法请求法院解决有关权利问题。

> 解释：法院程序用于依法确定权利归属，不能只把票据丢失理解为普通财物丢失。

## 高频考点 45：刑法基础

### 三项基本原则

1. **罪刑法定原则**：对法律明文规定的犯罪行为，依法定罪处罚。
2. **刑法面前人人平等原则**：对任何人犯罪，在适用法律上一律平等。
3. **罪责刑相适应原则**：刑罚应与犯罪和刑事责任相适应。

> 解释：可以用“王子犯法，与庶民同罪”理解刑法面前人人平等原则。

### 犯罪构成的四个方面

| 方面         | 含义                                                         |
| ------------ | ------------------------------------------------------------ |
| **主体**     | 实施犯罪行为、依法承担刑事责任的主体，涉及自然人及依法成立的单位犯罪 |
| **主观方面** | 故意、过失等心理态度，部分犯罪还有特定目的                   |
| **客体**     | 犯罪所侵犯的、刑法保护的社会关系                             |
| **客观方面** | 危害行为、危害结果等外在表现                                 |

> 解释：犯罪客体可以概括为刑法保护的“社会主义社会关系”。判断犯罪构成时，尤其要注意**主体与主观方面**，客观行为可结合罪名帮助记忆。

#### 刑事责任年龄

| 年龄                           | 教材记忆点                                 |
| ------------------------------ | ------------------------------------------ |
| **已满 16 周岁**               | 犯罪应当负刑事责任                         |
| **已满 14 周岁、不满 16 周岁** | 对特定严重犯罪承担刑事责任，称相对刑事责任 |
| **已满 12 周岁、不满 14 周岁** | 特定严重情形下，经核准追诉承担刑事责任     |
| **不满 18 周岁**               | 应当从轻或者减轻处罚                       |

> 解释：
>
> - 将刑事责任年龄 **16 周岁**与一般成年、完全民事行为能力的 **18 周岁**作比较，提醒两者不是同一制度。
> - 列举 14—16 周岁涉及故意杀人、故意伤害致人重伤或者死亡，以及强奸、抢劫、贩卖毒品、放火、投毒等严重行为。
>
> *补充：已满 14 周岁不满 16 周岁，对故意杀人、故意伤害致人重伤或者死亡、强奸、抢劫、贩卖毒品、放火、爆炸、投放危险物质犯罪负刑事责任。“投毒”是俗称。*
>
> *补充：已满 12 周岁、不满 14 周岁的人，犯故意杀人、故意伤害罪，致人死亡，或者以特别残忍手段致人重伤造成严重残疾，情节恶劣，经最高人民检察院核准追诉。不能简化为所有“故意杀人、重伤案件”都当然追诉。*
>
> *补充：对已满 12 周岁不满 18 周岁、依法应负刑事责任的人，是“应当”从轻或者减轻处罚，不是可以任意不予从宽。*

#### 一般主体与特殊主体

- **一般主体**：不以特定职业、身份为成立条件。
- **特殊主体**：须具有法定身份或资格，如特定金融机构人员。

> *补充：一般主体不等于单位与自然人均可构成该罪。单位犯罪须有法律明文规定，贷款诈骗罪、信用卡诈骗罪就是单位不能构成的例子。*

### 主刑与附加刑

| 类别       | 教材清单                                               |
| ---------- | ------------------------------------------------------ |
| **主刑**   | **管制、拘役、有期徒刑、无期徒刑、死刑**               |
| **附加刑** | **罚金、剥夺政治权利、没收财产**；教材同时列出驱逐出境 |

> 解释：主刑不能在同一罪的刑罚中任意并用多种；附加刑可以依法独立适用或附加适用。**驱逐出境针对犯罪的外国人**，可依法独立或附加适用。
>
> *补充：主刑并非全部都直接剥夺人身自由，例如管制实行非监禁监管。驱逐出境是针对外国人的特别规定，应与刑法列明的三种附加刑区分记忆。*

## 高频考点 46：金融犯罪种类

### 金融犯罪的分类

#### 破坏金融管理秩序类

**危害货币管理类犯罪**包括：

- 金融机构人员购买假币、以假币换取货币。
- 持有、使用假币。

**破坏银行和其他金融机构管理类犯罪**包括：

- 非法吸收公众存款。
- 高利转贷。
- 违法发放贷款。
- 吸收客户资金不入账。
- 伪造、变造金融票证。
- 违规出具金融票证。
- 对违法票据承兑、付款、保证。
- 骗取贷款、票据承兑、金融票证。
- 背信运用受托财产。
- 洗钱。

#### 金融诈骗类

**集资诈骗、贷款诈骗、信用证诈骗、信用卡诈骗、票据诈骗、金融凭证诈骗**。

> 解释：以罪名中的“诈骗”帮助识别，并将其主观方面概括为**故意且以非法占有为目的**。

#### 银行业相关职务犯罪

**职务侵占、挪用资金、非国家工作人员受贿、签订、履行合同失职被骗**。

> *补充：以上是这里列举的分类与罪名，不是刑法中全部金融犯罪、金融诈骗犯罪或职务犯罪的穷尽清单。*

### 破坏金融管理秩序类：主体、主观与行为

| 罪名                                   | 教材主体     | 教材主观             | 客观行为重点                                                 | 教材客体         |
| -------------------------------------- | ------------ | -------------------- | ------------------------------------------------------------ | ---------------- |
| 金融机构人员购买假币、以假币换取货币罪 | **特殊主体** | 故意                 | 购买假币；利用职务便利，以假币换取货币                       | 货币管理制度     |
| 持有、使用假币罪                       | 一般主体     | 故意                 | 持有、使用伪造货币，数额较大                                 | 货币管理制度     |
| 非法吸收公众存款罪                     | 一般主体     | 故意                 | 非法吸收或变相吸收公众存款                                   | 银行管理制度     |
| 高利转贷罪                             | 一般主体     | 故意                 | 套取金融机构信贷资金，高利转贷他人，违法所得数额较大         | 贷款管理制度     |
| 违法发放贷款罪                         | **特殊主体** | 故意                 | 违反国家规定发放贷款                                         | 贷款管理制度     |
| 吸收客户资金不入账罪                   | **特殊主体** | 故意                 | 吸收客户资金不入账，数额巨大或造成重大损失                   | 存款管理制度     |
| 伪造、变造金融票证罪                   | 一般主体     | 故意                 | 伪造、变造金融票证                                           | 金融票证管理制度 |
| 违规出具金融票证罪                     | **特殊主体** | 故意                 | 违反规定，为他人出具信用证、保函、票据、存单、资信证明等，情节严重 | 金融票证管理制度 |
| 对违法票据承兑、付款、保证罪           | **特殊主体** | 教材标**故意／过失** | 票据业务中，对违法票据予以承兑、付款、保证，造成重大损失     | 票据管理制度     |
| 骗取贷款、票据承兑、金融票证罪         | 一般主体     | 故意                 | 以欺骗手段取得银行等金融机构贷款、票据承兑、信用证、保函等   | 金融管理制度     |
| 背信运用受托财产罪                     | **特殊主体** | 故意                 | 违背受托义务，擅自运用客户资金或其他委托、信托财产           | 金融管理制度     |
| 洗钱罪                                 | 一般主体     | 故意                 | 对有关犯罪所得及收益实施掩饰、隐瞒来源、性质的洗钱行为       | 金融管理制度     |

> 解释：
>
> - 判断犯罪主体时，**“一般主体”不等于当然存在单位犯罪，“特殊主体”须结合具体法条确定范围**。
> - 辨认各罪的思路：
>   - **“金融机构人员”**直接提示特殊主体。
>   - 违法放贷、吸收客户资金不入账、违规出具金融票证、承兑违法票据等，涉及特定金融业务职责，不能只因一般人能接触资金，就认定主体没有身份限制。
>   - 伪造、变造与违规出具不同：前者重点是造假，后者重点是有权办理有关业务的主体违反规定出具。
>   - 高利转贷要抓住**先套取信贷资金，再高利转贷**的过程。
>   - 背信运用受托财产要抓住**财产基于委托、信托等受托关系交付，却被违背义务擅自运用**。
>
> *补充：高利转贷罪还须注意“以转贷牟利为目的”；违法发放贷款罪不能遗漏数额巨大或者造成重大损失等构成条件；骗取贷款等罪也须依法判断给金融机构造成重大损失等要求，不能仅有材料不实即当然定罪。背信运用受托财产罪的法定犯罪主体为有关金融机构单位，应注意单位与直接责任人员的不同责任地位。*
>
> *补充：教材把“对违法票据承兑、付款、保证罪”记为“故意／过失”。复习时应明确金融机构人员对违法票据实施有关行为，并须达到重大损失等条件；对行为的认识与对损失结果的心理态度应区分，不宜仅凭“故意／过失”两个词判断个案是否构罪。*

### 金融诈骗类：共同点与分别识别

金融诈骗类的共同记忆点是**故意，并以非法占有为目的**。重点区分**贷款诈骗与骗取贷款**，以及单位能否成为具体犯罪主体。

| 罪名               | 教材主体                       | 行为重点                                                     | 客体或识别重点                   |
| ------------------ | ------------------------------ | ------------------------------------------------------------ | -------------------------------- |
| **集资诈骗罪**     | 一般主体                       | 以诈骗方法非法集资                                           | 社会公众财产与国家金融秩序       |
| **贷款诈骗罪**     | 一般主体，**单位不能构成本罪** | 以有关虚假理由、材料、担保等诈骗银行或其他金融机构贷款       | 贷款及有关权益                   |
| **信用证诈骗罪**   | 一般主体                       | 利用伪造、变造、作废信用证，骗取信用证或以其他方法实施信用证诈骗 | 有关当事人财产及国家金融管理制度 |
| **信用卡诈骗罪**   | 一般主体，**单位不构成本罪**   | 使用有关伪造、变造信用卡、冒用他人信用卡或恶意透支等，骗取财物，数额较大 | 信用卡管理秩序及有关财产权益     |
| **票据诈骗罪**     | 一般主体                       | 利用汇票、本票、支票等实施诈骗                               | 票据管理及有关财产权益           |
| **金融凭证诈骗罪** | 一般主体                       | 利用有关银行结算凭证实施诈骗                                 | 银行结算凭证管理及有关财产权益   |

> 解释：可以用“非法吸收公众存款的进阶版”比喻集资诈骗，重点提示**非法占有目的**。
>
> *补充：这一比喻不能替代法律构成判断，也不能仅因资金被挥霍或未能偿还便机械认定集资诈骗。*

#### 贷款诈骗的五类行为

1. 编造引进资金、项目等**虚假理由**。
2. 使用**虚假经济合同**。
3. 使用**虚假证明文件**。
4. 使用虚假产权证明作担保，或**超出抵押物价值重复担保**。
5. 以其他方法诈骗贷款。

> 解释：**贷款诈骗罪须注意非法占有目的；骗取贷款等罪不能只凭罪名中都有“骗”就与其等同。**

#### 信用证诈骗的四类行为

1. 使用**伪造、变造的信用证或附随单据、文件**。
2. 使用**作废信用证**。
3. **骗取信用证**。
4. 其他信用证诈骗方法。

#### 信用卡诈骗

信用卡诈骗的行为包括使用伪造、变造信用卡、冒用他人信用卡、恶意透支等。

> *补充：《刑法》第一百九十六条列示使用伪造信用卡或以虚假身份证明骗领的信用卡、使用作废信用卡、冒用他人信用卡、恶意透支等情形。恶意透支有非法占有目的、超过规定限额或期限、经催收仍不归还等要件，不能将一般逾期还款直接认定为犯罪。*

#### 票据诈骗的五类行为

1. 明知是**伪造、变造的汇票、本票、支票**而使用。
2. 明知是**作废的汇票、本票、支票**而使用。
3. **冒用他人的汇票、本票、支票**。
4. 签发**空头支票或与预留印鉴不符的支票**，骗取财物。
5. 汇票、本票出票人签发**无资金保证**的汇票、本票，或出票时作虚假记载，骗取财物。

> *补充：金融凭证诈骗罪应联系使用伪造、变造的委托收款凭证、汇款凭证、银行存单等其他银行结算凭证理解，不能把任何涉及“凭证”的欺骗都直接归入该罪。*

### 银行业相关职务犯罪

| 罪名                         | 主体重点                                             | 主观                       | 教材行为                                                     | 教材客体                             |
| ---------------------------- | ---------------------------------------------------- | -------------------------- | ------------------------------------------------------------ | ------------------------------------ |
| **职务侵占罪**               | 公司、企业或其他单位工作人员；重点联系非国家工作人员 | **故意且以非法占有为目的** | 利用职务便利，将本单位财物非法占为己有，数额较大             | 公司、企业或单位的财产权益           |
| **挪用资金罪**               | 特殊主体；重点联系非国家工作人员                     | 故意                       | 利用职务便利，擅自挪用本单位资金归个人使用或借贷给他人       | 公司、企业或单位资金权益             |
| **非国家工作人员受贿罪**     | **非国家工作人员**等法定主体                         | 故意                       | 利用职务便利索取或收受财物；经济往来中违规收受回扣、手续费归个人所有等 | 公司、企业或单位有关管理秩序         |
| **签订、履行合同失职被骗罪** | 特殊主体；用国家工作人员帮助区分                     | **过失**                   | 签订、履行合同中严重不负责任而被骗，致使国家利益遭受重大损失 | 公司、企业有关管理秩序及国家财产利益 |

> 解释：
>
> - 四类职务犯罪可以作以下对比：
>   - 职务侵占重在**非法占为己有**。
>   - 挪用资金重在**挪作他用**，不能与侵占混同。
>   - 非国家工作人员受贿重在**利用职务便利收受、索取好处**。
>   - 签订、履行合同失职被骗重在**未尽职责、严重不负责任、被骗及重大损失**，教材特别标注主观为过失。
>
> *补充：“签订、履行合同失职被骗罪”的法定主体是国有公司、企业、事业单位直接负责的主管人员，不能泛化为任何国家工作人员，也不能遗漏“直接负责的主管人员”。同样，前三罪与贪污、挪用公款、受贿等罪的区分，须依法判断人员身份及从事公务等情形，不能只凭所在单位名称判断。*
>
> *补充：挪用资金、非国家工作人员受贿等还涉及法定用途、期限、数额或其他条件；上表是构成要点的归纳，不应视为完整定罪标准。*

## 高频考点 47：我国银行监管框架

### 四个层次

银行监管包括对银行的监督和管理。我国银行监管框架可以按**自我监管、外部监管、行业自律、市场约束**四个层次理解。

| 层次         | 主要机制或主体           | 教材重点                         |
| ------------ | ------------------------ | -------------------------------- |
| **自我监管** | 商业银行内部             | **内部治理、内部控制、内部审计** |
| **外部监管** | 银行业监督管理机构       | 教材称其为监管的最高层次         |
| **行业自律** | 中国银行业协会等自律组织 | 通过行业规则、自律管理发挥作用   |
| **市场约束** | 有关市场参与者           | 又称**市场纪律**，强调信息披露   |

> 解释：内部审计可以联系事后评估理解；外部监管则由银行业监督管理机构依法实施，例如国家金融监督管理总局。
>
> *补充：以上是银行监管框架的概括；“外部监管”不能扩张解释为金融体系内只有一个监管部门，也不能把行业协会视为行政监管机关。*

### 中国银行业协会

#### 性质与定位

中国银行业协会是我国银行业自律组织，属于**全国性非营利社会团体**。

> 解释：对比来看，公司通常以股东会作为权力机构，协会等社会团体则由会员依法参与治理。

#### 治理结构

| 机构           | 职责关系与会议频率                                   |
| -------------- | ---------------------------------------------------- |
| **会员大会**   | 教材称最高权力机构；**每 5 年召开一次**              |
| **理事会**     | 会员大会的执行机构，对会员大会负责；**每年召开一次** |
| **常务理事会** | 理事会闭会期间行使相应职责，处理有关日常工作         |
| **监事会**     | 发挥监督作用                                         |

常务理事会的构成为：

- **会长 1 名**。
- **专职副会长 1 名**。
- **副会长若干名**。
- **秘书长 1 名**。

监事会的构成为**监事长 1 名、监事若干名**。

> *补充：协会官网现行简介使用“会员代表大会”为最高权力机构，正文保留教材“会员大会”的原有称谓以便对照。复习协会现行治理安排时应以现行章程为准，不宜把公司股东会、协会会员代表大会及商业银行自身的治理机关混为一谈。*

### 市场约束：信息披露是核心

市场约束又称**市场纪律**，具体体现形式之一是**强化信息披露**。

> 解释：
>
> - 联系巴塞尔协议第二版的**第三支柱**理解：银行披露经营、风险等有关信息，股东、债权人和其他市场参与者据此判断、作出选择，从而督促银行规范经营。
> - **市场约束依靠信息披露与市场参与者的反应发挥作用，不等同于行政处罚或银行内部审计。**

## 高频考点 48：从业人员职业操守

### 七项职业操守

从业人员的七项职业操守是**爱国爱行、诚实守信、依法合规、专业胜任、勤勉履职、服务为本、严守秘密**。

> 解释：职业操守与行为规范相互联系：职业操守提供价值要求，行为规范将要求落实到业务操作、履职纪律等具体场景中。

### 行为守法：“八严禁”

1. **违法犯罪行为**。
2. **非法催收**。
3. **参与非法金融活动**。
4. **信用卡业务领域违法犯罪行为**。
5. **信息领域违法犯罪行为**。
6. **内幕交易行为**。
7. **挪用资金行为**。
8. **骗取信贷行为**。

> 解释：记忆重点：既包括一般违法犯罪，也包括催收、信用卡、信息、信贷等具体业务领域的禁止行为。

### 业务合规：“八遵守”

1. **岗位管理规范**。
2. **信贷业务规定**。
3. **销售业务规定**。
4. **公平竞争原则**。
5. **财务管理规定**。
6. **出访管理规定**。
7. **外事接待规定**。
8. **离职交接规定**。

> 解释：业务合规要求从业人员在开展业务时遵守银行有关规章、流程和岗位要求，不能只看业务最终有没有办成。

### 履职遵纪

- 贯彻**“八项规定”**，反对**“四风”**。
- **如实反馈信息**。
- 按照纪律要求处理**利益冲突**。
- 严禁**非法利益输送交易**。
- 实行**履职回避**。
- 严禁**违规兼职**。
- 抵制**贿赂及不当便利行为**。
- **厉行勤俭节约**。
- **塑造职业形象**。
- 营造**风清气正的职场环境氛围**。

> 解释：判断具体业务或工作行为时，应结合职业操守、业务规则和纪律要求。

## 高频考点 49：清廉金融

从业人员不得利用职务便利谋取、收受或输送不当利益。清廉金融要求可以落实到**柜员卡与密码、现金与印章及凭证、柜台业务、贷款业务、票据业务**五类场景。

### 柜员卡和密码管理

#### 严禁混岗操作

**严禁一人持多张柜员卡混岗操作。**

> 解释：柜员卡和密码是办理业务的重要身份凭据，应由对应人员按规定使用，不能随意借给他人或交由他人操作。

#### 密码管理

严禁：

- 不执行**定期更换密码（或口令）**的要求。
- 输入密码（或口令）时**不采取遮挡措施**。

#### 离岗管理

严禁在**未签退系统**，且**未妥善保管**下列物品或信息的情况下离开岗位：

- 操作卡。
- 授权卡。
- 个人名章。
- 密码或口令等。

> 解释：记忆链条：**本人身份本人使用→密码依规更换并遮挡→离岗签退、妥善保管**。

### 现金、印章和重要空白凭证管理

#### 现金与账务处理

严禁：

- **超额使用、保管现金**。
- 不按规定处理**长款、短款**。
- 随意**调整、冲正、撤销账务**。

> 解释：不能通过随意改账掩盖差错，应按制度处理。

#### 凭证、印章及重要物品

严禁：

- **超额领用**有价单证、重要空白凭证。
- **私自调剂**有价单证、重要空白凭证。
- 将本人保管的**业务印章、有价单证、重要空白凭证**等重要物品交给他人使用。

> 解释：既要注意保管，也要注意领用、使用环节，不能把保管责任理解为可以私自转交使用权。

### 办理具体柜台业务

#### 收付款顺序

**收款业务：先收款，后记账。**

**付款业务：先记账，后付款。**

严禁违反上述顺序办理收、付款业务，严禁**空存、空取资金**。

> 解释：可以用存款业务解释：尚未收到资金就记入账户，容易形成账实不符和现金差错；支取时也应先依程序完成账务处理，再付款。

#### 大额支付

办理大额支付业务，严禁：

- 不执行**分级授权、双签制度**。
- 不按规定与**企业相关负责人验证**。
- 不按规定对**大额款项收付进行登记和报备**。

> 解释：授权和双签有相互监督作用，不能因为经办人员觉得业务熟悉或紧急而省略。

#### 本人业务回避

**严禁办理本人业务。**

> 解释：这里指从业人员不能利用经办权限自行办理本人有关业务。自行经办本人业务可能带来利益冲突、利益输送风险。
>
> *补充：这不是说银行从业人员不能作为客户购买金融产品或接受服务，而是不得违反经办回避和授权制度，自己处理须回避的本人业务。*

### 贷款业务

#### 审批权限与程序

严禁：

- 以**化整为零**等方式越权或变相越权审批贷款。
- **逆程序、缺程序**审批贷款。

> 解释：不能将一项业务拆分以规避审批权限，也不能省略应履行的审查程序。

#### 放款手续和审批意见

严禁：

- 不按规定审核、办理贷款发放手续，**直接发放贷款**。
- **未落实贷款审批意见**即发放贷款。
- **擅自变更审批意见**发放贷款。

> 解释：**审批通过不等于可以忽略审批意见中要求落实的条件。**

#### 支付方式与资金用途监控

严禁：

- 不按规定采用**受托支付**。
- 按规定采用**自主支付**时，未对借款人的**资金使用情况进行监控**。

> 解释：
>
> - 区分两个层次：一是按规定选择支付方式；二是自主支付也不意味着银行可以不再监测资金用途。
> - 联系**流动资金贷款**举例，提到超过 **1000 万元**时应关注受托支付要求。
>
> *补充：相关规则关注“支付对象明确且单笔支付金额超过 1000 万元”等受托支付情形，不能把贷款合同总金额超过 1000 万元直接等同于每笔支付都必须采用同一方式；还应结合其他法定情形及约定。*

#### 贷款风险分类

**严禁随意调整贷款风险分类。**

贷款五级分类为**正常、关注、次级、可疑、损失**，并应联系**每季度**分类复核及类别迁徙理解。

> 解释：分类应按规则反映资产风险，不能将其当作人为调节经营结果的工具。
>
> *补充：至少每季度开展分类，不代表每季度必须改变类别；风险状况发生变化时还应依法及时调整。禁止的是脱离规则、事实随意调整，不能理解为未到季度末就一律不得调整。*

### 票据业务

#### 真实贸易背景

严禁对下列商业汇票、票据办理承兑、贴现：

- **不具有真实贸易背景**。
- **不能确认具有真实贸易背景**。

> 解释：注意：“不能确认”也是教材强调的禁止情形，不能因为没有直接发现虚假就视同已核实真实。
>
> *补充：现行商业汇票有关规定强调真实交易关系和债权债务关系，并对因税收、继承、赠与依法无偿取得票据等情形另作规定。教材“真实贸易背景”的概括不宜理解为所有合法取得票据都必须对应持票人本人购买商品。*

#### 保证金来源与承兑汇票签发

严禁以**贷款或贴现资金缴存保证金**，严禁**滚动签发银行承兑汇票**。

#### 贴现资金跟踪

严禁：

- 放松对**贴现资金使用情况**的跟踪检查。
- **贴现资金直接转回出票人账户**。

#### 票据和办理程序

严禁：

- **无票据贴现**。
- **先贴现、后见票**。
- 以**先转后贴**的方式，逆程序办理贴现和转贴现业务。

> 解释：**先有合规真实的业务基础、完成规定核验，再按程序办理；不能先放款或转资金，事后补手续。**

## 高频考点 50：消费者权益保护

### 银行消费者的九项主要权利

| 权利           | 教材重点                                   |
| -------------- | ------------------------------------------ |
| **安全权**     | 包括**人身安全权、财产安全权**             |
| **隐私权**     | 保护消费者隐私                             |
| **知情权**     | 消费者自由选择并实现公平交易的**前提条件** |
| **自主选择权** | 不受任何单位、个人的**不合理干预**         |
| **公平交易权** | 依法公平交易                               |
| **依法求偿权** | 依法获得救济、请求赔偿                     |
| **受教育权**   | 银行消费知识、消费者权益保护知识的教育     |
| **受尊重权**   | **人格尊严、民族风俗习惯**受到尊重         |
| **监督权**     | 对有关经营、服务行为等依法监督             |

### 例子与责任主体

**银行业金融机构承担保护消费者合法权益的主体责任。**

> 解释：
>
> - **安全权**：把钱存入银行，涉及财产安全；到营业柜台办理业务，也涉及人身安全。
> - **隐私权**：银行掌握客户信息后，不能随意泄露。
> - **自主选择权**：消费者根据自身需求，自愿选择银行、产品和服务，不能受到强迫或不合理干预。
> - **公平交易权**：不能通过霸王条款、显失公平的强制安排侵害客户。
> - **依法求偿权**：权益受到侵害时，依法请求补偿、赔偿等救济。
> - **受教育权**：包括理解产品、服务，以及了解自身权利和维权途径，并非泛指义务教育或高等教育。
> - **监督权**：联系信息披露、市场约束说明，消费者也可以依法监督银行规范经营。
> - 消费者权益保护也是银行业金融机构自身的责任，不能只理解为监管部门的责任。

### 重点区分

> 解释：
>
> - **知情权是自主选择、公平交易的重要前提。**消费者充分了解产品和服务，才能作出符合真实意愿的选择。
> - **自主选择权重在选择自由**，不能被不合理强制；**受尊重权重在人格尊严与民族风俗习惯**，不能把二者混为一项。
> - **受教育权包含两方面：银行消费知识、消费者权益保护知识。**既包括了解业务，也包括知道自身权利及保护途径。
>
> *补充：按教材列出九项银行消费者权利，不能与其他规范中“金融消费者八项基本权利”等概括机械一一对应。现行银行保险消费者保护规则还明确关注个人信息安全等要求，隐私权与个人信息保护相关但不完全相同。*
