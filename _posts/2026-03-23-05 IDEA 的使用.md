## IDEA 的介绍

**IDEA** 的全称是 **IntelliJ IDEA**，它是一个面向 Java 开发的 **集成开发环境（IDE，Integrated Development Environment）**。所谓“集成开发环境”，可以简单理解为：把**写代码、运行程序、管理项目、调试程序、查看报错**等常用功能集中到一个软件里，而不必像前面那样频繁手动敲 `javac`、`java` 命令。

也就是说，使用 IDEA 之后，我们写 Java 程序时，工作方式会从“**命令行驱动**”逐步过渡到“**图形界面驱动**”。这并不表示前面学习的命令行知识没用了，恰恰相反，正因为已经理解了 `.java` 如何编译成 `.class`、程序如何运行，后面再使用 IDEA 时，才不会只会点按钮而不明白它在做什么。

例如，前面在命令行中运行一个 Java 程序，通常要经历下面这个过程：

1. 编写 `HelloWorld.java`
2. 执行 `javac HelloWorld.java`
3. 执行 `java HelloWorld`

而在 IDEA 中，这些步骤往往会被整合成更方便的操作。你只需要在界面中创建项目、编写代码，然后点击运行按钮，IDEA 就会在背后帮你完成编译和运行。

### 为什么要使用 IDEA

当程序非常简单时，使用记事本加命令行也能完成开发；但当类越来越多、包越来越多、项目结构越来越复杂时，手动管理文件和命令就会变得低效而且容易出错。这时，IDEA 的价值就体现出来了。

它的主要作用可以概括为以下几个方面：

- **更方便地管理项目结构**
- **更高效地编写和修改代码**
- **自动提示、自动补全，减少低级错误**
- **更容易运行、调试和定位问题**
- **更适合后续学习模块化、面向对象、框架开发等内容**

例如，假设一个项目中有几十个类，分别位于不同包下。如果只靠文件夹和命令行手动管理，不仅查找麻烦，编译运行时也容易写错路径；而在 IDEA 中，这些内容会以清晰的树状结构展示出来，查找和维护都更直观。

## IDEA 的基本使用

### 创建空项目和模块

#### 项目与模块

在 IDEA 中，**项目（Project）** 是一个总的工作空间，**模块（Module）** 是项目中的具体组成部分。一个项目中可以包含一个或多个模块。

例如，一个 Java 学习项目可以按章节建立多个模块：

- `chapter01`
- `chapter02`
- `chapter03`

这样便于分类管理代码。

#### 第一步：打开 IDEA

启动 IDEA 后，会先进入欢迎界面。新建项目通常从欢迎界面的 **New Project** 进入。

#### 第二步：新建空项目

创建项目时，先选择 **Empty Project**，然后设置：

1. **项目名**
2. **项目存放位置**

创建空项目的目的是先建立项目工作区，后续再在项目中添加模块。

> 注意：项目名应尽量做到见名知意，便于后续管理和查找。

#### 第三步：认识 IDEA 的主要窗口区域

IDEA 窗口中当前阶段需要重点认识以下几个区域：

- **菜单区**：用于进入各种功能设置，例如新建、运行、项目结构设置等。
- **工具区**：提供常用快捷操作，例如运行程序。
- **项目结构区**：通常位于左侧，用树状结构展示项目、模块、包和类。
- **代码区**：位于中间，用于编写和修改 Java 代码。

其中，**项目结构区** 负责查看和管理文件，**代码区** 负责实际编写程序。

#### 第四步：设置项目的 JDK 和语言级别

进入路径：`File -> Project Structure`。

这里主要配置两项内容：

1. **SDK / JDK**：JDK 表示项目使用哪一个 Java 开发环境进行编译和运行。项目若未正确设置 JDK，程序可能无法正常编译或运行。
2. **Language level**：**Language level** 表示项目允许使用的 Java 语法版本。它决定当前项目按哪一版 Java 语法规则进行检查和编译。

通常应让 **JDK 版本** 和 **语言级别** 保持协调，避免因为版本不一致导致语法报错或运行异常。

> 注意：如果代码本身没有问题，但 IDEA 出现大面积标红，应先检查项目 JDK 和语言级别是否配置正确。

#### 第五步：新建模块 Module

进入路径：`File -> New -> Module`。

创建模块时，通常需要设置以下内容：

1. **模块类型**：选择 `Java`
2. **模块名称**
3. **模块使用的 JDK**
4. **构建方式**：当前阶段一般选择 `IntelliJ`

模块创建完成后，会出现在左侧的项目结构区中。

例如，一个项目 `java-study` 中可以创建模块：

- `chapter01-basic`
- `chapter02-method`
- `chapter03-array`

这样每个模块对应一部分学习内容，结构更清晰。

### 设置字符编码方式

在 IDEA 中，字符编码建议**统一设置为 `UTF-8`**。这样做的主要目的是避免中文注释、中文字符串、配置文件内容出现**乱码**问题。

如果项目、编辑器、文件的编码设置不一致，常见现象包括：

- 源代码中的中文显示异常
- 控制台输出中文乱码
- 不同电脑打开同一项目时文字显示不一致

#### 设置步骤

1. 打开 IDEA 的设置界面。
2. 进入 **Editor** 下的 **File Encodings**。
3. 将与文件编码相关的主要选项统一设置为 **`UTF-8`**。

通常需要重点关注：

- **Global Encoding**
- **Project Encoding**
- **Properties Files** 的默认编码

> 注意：字符编码最好在**项目刚创建完成时**就统一设置，避免后面已经写了很多中文内容后再去修改，增加乱码风险。

### 创建包（Package）

包用于对类进行分类管理。创建包时，一般是在 **`src` 目录** 或某个已有包上右键，选择：`New -> Package`。然后输入包名并确认。

#### 创建包的基本步骤

1. 选中 `src` 目录，或者选中某个已有包。
2. 鼠标右键，选择 **New**。
3. 选择 **Package**。
4. 输入包名并创建。

#### 包名命名要求

包名必须同时满足两类要求：

1. **符合标识符命名规则**
2. **符合包名命名规范**

包名的常见规范是：

- **全部小写**
- 多个单词之间用 **`.`** 连接
- 通常采用 **域名倒序 + 项目名 + 模块名 + 功能名** 的形式

例如：

- `com.example.study`
- `com.company.javase.method`
- `org.demo.chapter03`

其中：

- `com`、`org` 这类部分通常表示顶级域名倒序后的开头
- 后面的 `study`、`javase`、`method` 则表示项目或功能层级

> 注意：包名不是随便写一个英文单词即可。它除了要合法，还应尽量体现层级关系和功能归属。

### 创建类（Class）

类一般应创建在某个包下。创建类时，通常是在**某个包上右键**，然后选择：`New -> Java Class`。接着输入类名并确认。

#### 创建类的基本步骤

1. 先选中目标包。
2. 鼠标右键，选择 **New**。
3. 选择 **Java Class**。
4. 输入类名并创建。

#### 类名命名要求

类名也必须符合**标识符命名规则**，并且通常遵循 Java 中常见的命名规范：

- 类名由字母、数字、下划线、美元符组成，但不能以数字开头
- 类名通常采用 **大驼峰命名法（Upper Camel Case）**
- 每个单词首字母大写

例如：

- `HelloWorld`
- `MethodTest`
- `StudentService`

### 项目结构

在 IDEA 左侧的项目结构区中，最上层是**项目**，项目下面可以有一个或多个**模块**；模块内部会包含自己的源码目录、编译输出目录以及运行所依赖的**类库**。理解这一层级关系后，后面创建包、创建类、运行程序时就不容易混乱。

最外层的是**项目（Project）**。项目是 IDEA 中的总工作区，用来统一管理一整套开发内容。一个项目往往对应一个总目录，例如 `java-study`。它本身更像一个“总容器”，主要作用是把若干学习内容或功能内容组织在一起，而不是直接拿来写具体代码。

项目下面通常会有一个或多个**模块（Module）**。模块是项目中的具体组成部分，也是实际编写代码时更常接触的层级。可以把模块理解为项目中的一个独立单元。例如，在 `java-study` 这个项目中，可以建立 `chapter01-intro`、`chapter02-variable`、`chapter03-method` 等多个模块。这样划分后，每个模块负责一部分相对独立的内容，代码更清晰，也更便于查找和复习。

进入某个模块后，最重要的目录通常是 **`src`**。`src` 是**源码目录**，主要用于存放自己编写的 Java 源代码。后面创建的包、类，一般都放在这里。例如，某个类 `MethodTest01.java`，本质上就是放在某个模块下的 `src` 目录及其子包路径中。日常开发时，主要操作的就是这一部分，因为这里放的是手写源码。

与 `src` 对应的，通常还会看到 **`out`** 目录。`out` 是**编译输出目录**，用于存放编译后生成的内容，例如 `.class` 文件。也就是说，`src` 中保存的是你写的 `.java` 文件，而 `out` 中保存的是 IDEA 编译之后产生的结果。`out` 不是用来手动写代码的，而是编译过程自动使用和维护的目录。理解这一点很重要，因为它说明“源码”和“编译结果”在项目结构中是分开的。

除了模块内部自己的目录外，项目结构中通常还会看到 **类库（External Libraries）**。这部分不是你手动编写的代码，而是当前项目运行和编译所依赖的外部资源，最典型的就是 **JDK 类库**。例如平时使用的 `String`、`System`、`Scanner` 等类，都不是写在自己项目的 `src` 目录中的，而是来自 JDK 提供的现成类。IDEA 会把这些依赖统一显示在类库区域中，方便查看当前项目可使用哪些外部类。

因此，从整体上看，一个 IDEA 项目结构可以这样理解：**项目**负责整体组织，项目中包含一个或多个**模块**；模块内部有自己的 **`src`**，用于存放源码，也有自己的 **`out`**，用于存放编译结果；而**类库**则提供项目运行和开发所需的外部类支持。以后在左侧看到这些结构时，应先分清它们分别属于“总容器”“开发单元”“源码区域”“编译结果区域”还是“外部依赖区域”。

#### 一组完整的结构理解例子

例如，一个项目结构可以理解为：

```text
java-study                         ← 项目
├── chapter01-intro                ← 模块
├── chapter02-variable             ← 模块
└── chapter03-method               ← 模块
    ├── src                        ← 源码目录
    │   └── com
    │       └── example
    │           └── method
    │               └── MethodTest01.java
    ├── out                        ← 编译输出目录
    │   └── production
    │       └── chapter03-method
    │           └── com
    │               └── example
    │                   └── method
    │                       └── MethodTest01.class
    └── External Libraries         ← 类库
```

在这个结构中：

- `java-study` 是总项目；
- `chapter03-method` 是项目中的一个模块；
- `src` 中放的是自己写的 `MethodTest01.java`；
- `out` 中放的是编译后生成的 `MethodTest01.class`；
- `External Libraries` 中放的是 JDK 等外部类库。

## IDEA 的编译和运行

### 使用 IDEA 编写程序

在 IDEA 中编写 Java 程序时，常用的快捷输入有两个：

- `psvm`：生成 `main` 方法
- `sout`：生成输出语句 `System.out.println();`

### 使用 IDEA 编译程序

在常见使用过程中，IDEA 会自动保存代码，并在运行程序或相关操作时完成编译。编译后的字节码文件通常输出到 **`out`** 目录下。

也就是说：

- `.java` 文件是源代码
- `.class` 文件是编译后的字节码文件

例如，写好下面这个类：

```java
public class Test {
    public static void main(String[] args) {
        System.out.println("test");
    }
}
```

编译后，在 `out` 目录中可以找到对应的 `Test.class` 文件。

如果当前项目中暂时还没有看到 `out` 目录，通常运行一次程序后就会生成。

### 使用 IDEA 运行程序

运行 Java 程序时，通常要求当前类中有 **`main` 方法**，因为程序的执行入口就是 `main` 方法。

常见运行方式有两种：

1. 在代码区中打开带有 `main` 方法的类，点击 `main` 方法左侧的运行按钮
2. 右键当前类，选择 **Run '类名.main()'**

程序运行后，运行结果会显示在 IDEA 下方的 **Run** 窗口中。

例如，运行下面这个程序：

```java
public class Demo {
    public static void main(String[] args) {
        System.out.println("IDEA run");
    }
}
```

运行后，在下方窗口中会看到输出结果：

```
IDEA run
```

## IDEA 实用快捷键

IDEA 中的常用快捷操作，主要可以分为：**新建与代码生成、窗口与导航、编辑与注释、查找与查看、代码整理与辅助** 五类。熟悉这些操作后，可以明显减少鼠标点击，提高编写和阅读代码的效率。

### 新建与代码生成

这类操作主要用于快速创建类、方法、对象或常见代码结构。

| 快捷键 / 模板    | 功能说明             | 例子                                                         |
| ---------------- | -------------------- | ------------------------------------------------------------ |
| `Alt + Insert`   | 新建或生成内容       | 可新建类、接口、包，也可生成 `getter`、`setter`、构造方法等  |
| `psvm`           | 生成 `main` 方法     | 输入 `psvm` 后展开为 `public static void main(String[] args)` |
| `sout`           | 生成输出语句         | 输入 `sout` 后展开为 `System.out.println();`                 |
| `fori`           | 生成 `for` 循环      | 输入 `fori` 后可快速生成普通 `for` 循环                      |
| `.var`           | 自动生成变量         | 例如 `new Scanner(System.in).var` 可快速生成变量接收对象     |
| `布尔变量.if`    | 自动生成 `if` 语句   | 例如 `flag.if` 可展开为 `if (flag) {}`                       |
| `类名.new.var`   | 快速生成创建对象语句 | 例如 `Scanner.new.var` 可快速生成对象创建代码                |
| `变量名.castvar` | 快速向下转型         | 例如父类引用变量可快速生成强制类型转换后的新变量             |

### 窗口与导航

这类快捷键主要用于切换窗口、定位资源和快速回到之前的位置。

| 快捷键                    | 功能说明                     |
| ------------------------- | ---------------------------- |
| `Esc`                     | 退出当前小窗口，并回到代码区 |
| `Ctrl + Shift + F12`      | 最大化源码窗口               |
| `Alt + 1`                 | 打开 Project 窗口            |
| `Alt + 左右方向键`        | 切换窗口                     |
| `敲两次 Shift`            | 查找任何资源                 |
| `Ctrl + Alt + 左右方向键` | 回到上一个位置 / 下一个位置  |

例如，正在看某个类源码后，想快速回到刚才编辑的位置，就可以使用：

- `Ctrl + Alt + 左方向键`：回到上一个位置
- `Ctrl + Alt + 右方向键`：再回到下一个位置

这个功能在查看源码、跳转方法后尤其常用。

### 编辑与注释

这类快捷键主要用于修改代码、复制代码、删除代码以及批量编辑。

| 快捷键                     | 功能说明               |
| -------------------------- | ---------------------- |
| `Ctrl + Y`                 | 删除一行               |
| `Ctrl + X`                 | 剪切一行，并放入剪贴板 |
| `Ctrl + D`                 | 复制一行               |
| `Ctrl + /`                 | 单行注释               |
| `Ctrl + Shift + /`         | 多行注释               |
| `Alt` 不松手，鼠标拖动多行 | 多行编辑               |
| `Alt + Shift + 上下方向键` | 移动代码               |
| `Ctrl + Z`                 | 撤销                   |
| `Ctrl + Shift + Z`         | 反撤销                 |

例如，选中下面这一行代码：

```java
System.out.println("hello");
```

按 `Ctrl + /` 后，会变成：

```java
// System.out.println("hello");
```

如果要把一段代码整体上移或下移，可以直接使用 `Alt + Shift + 上下方向键`，而不必先剪切再粘贴。

### 查找与查看

这类快捷键主要用于查看方法、参数、继承关系以及源码内容。

| 快捷键                            | 功能说明             |
| --------------------------------- | -------------------- |
| `Ctrl + F12`                      | 在当前类中查找方法   |
| `Ctrl + P`                        | 查看方法参数         |
| `Ctrl` 不松手，鼠标指向类名并点击 | 查看类源码或跳转定义 |
| `Ctrl + H`                        | 查看类的继承结构     |

### 代码整理与辅助

这类快捷键主要用于自动修复、格式化、替换和包裹代码。

| 快捷键           | 功能说明           |
| ---------------- | ------------------ |
| `Alt + Enter`    | 自动纠错、快速修复 |
| `Ctrl + O`       | 快速重写方法       |
| `Ctrl + Alt + L` | 代码格式化         |
| `Ctrl + Alt + T` | 自动代码包裹       |
| `Ctrl + R`       | 替换               |
