## 第一章、银行管理基础：商业银行的组织架构

*先分清法人结构、内部管理和管理会计三个分类角度，再比较各类架构的管理重点、利润中心及优缺点，最后认识中外银行的架构与发展趋势。*

### 一、组织架构的含义与内容

#### 组织架构的含义

**组织架构是企业流程运转、部门设置及职能规划等最基本的结构依据。**商业银行组织架构，是商业银行业务运行和管理实施的组织方式。

> 解释：它不仅是画出“总行、分行、支行”的层级图，还涉及部门怎么设置、有哪些权限、相互如何协作，以及业务如何组织运行。

#### 组织架构的四方面内容

| 方面 | 主要内容 | 理解重点 |
| --- | --- | --- |
| **总部部门** | 总部部门设置及其功能和权限、部门之间的相互关系 | 总部有哪些部门，各自做什么，如何沟通协作 |
| **分支机构** | 分支机构的功能、权限和部门设置 | 分支机构承担什么职责，拥有什么权限 |
| **全行业务运作** | 全行业务运作的组织架构模式 | 业务按什么方式组织、运行和管理 |
| **总行对分支机构的管理** | 总行对分支机构实施管理的模式等 | 总部与分支之间如何管理和协调 |

> 解释：
>
> - 可以用“**总、分、业务**”理解组织架构：有总部，也有分支；两者需要明确关系并协调管理；机构设置之外，还要把全行业务运作纳入整体架构。
> - **总部部门的设置、功能权限与部门关系，属于同一方面内容。**题目可以把这一项拆成两个选项，因此“主要内容有四方面”并不意味着多选题最多只能选四项。

> 真题示例
>
> **【2025 年多项选择题】关于商业银行组织架构包含的主要内容，正确的有（　）。**
>
> A. 包含分支机构的功能、权限和部门设置  
> B. 包含总行对分支机构实施管理的模式  
> C. 包括总部部门的设置及其功能和权限  
> D. 包含部门之间的相互关系  
> E. 包含全行系统运作的组织架构模式
>
> **答案：A、B、C、D、E。**
>
> 解释：
>
> - **A 项**：分支机构，功能、权限和部门设置，属于分支层面的安排。
> - **B 项**：总行对分支的管理，将总部与分支的关系和管理方式纳入架构。
> - **C 项**：总部部门，部门设置、功能和权限，属于总部层面的内容。
> - **D 项**：部门相互关系，与 C 一起对应总部部门安排及部门间关系。
> - **E 项**：全行业务运作，属于全行运作的组织模式，不能只看机构层级。
> - 可以按“总、分、管理、业务”逐项对应：C、D 属于总部层面，A 属于分支，B 属于总行对分支管理，E 属于全行运作。**四方面内容可以拆成五个正确选项。**

### 二、组织架构的分类角度

| 分类角度 | 具体形式 | 回答的问题 |
| --- | --- | --- |
| **企业法人角度** | 统一法人制、多法人制 | 总部与下属机构是否具有独立法人资格 |
| **内部管理模式** | 总分行型、事业部制、矩阵型 | 主要按区域、业务线还是两者结合进行管理 |
| **管理会计角度** | 成本中心、利润中心 | 主要承担成本责任还是经营利润责任 |

> 解释：这三个角度不能混为同一分类。统一法人制与多法人制相比较，总分行型与事业部制相比较，成本中心与利润中心相比较。
>
> *补充：不同维度可以同时存在。例如，一家银行在法人层面实行统一法人制，在内部管理层面采用区域与业务线结合的安排，同时将相关部门和经营单元设为成本中心或利润中心。不能将六、七种名称拼成一组互斥类别。*

### 三、统一法人制与多法人制

#### 企业法人

企业法人是将企业作为独立经营主体赋予相应主体资格，企业可以拥有财产、开展经营，并承担相应责任。

> 解释：**法人指组织主体，不是把某一位负责人称为“法人”。**

#### 统一法人制

**统一法人制是一种相对集权的组织形式。**总部与分支机构之间是直接隶属关系，分支机构不具备独立法人资格，在经营上接受总部管理和指导。

| 内容 | 统一法人制特点 |
| --- | --- |
| 法人资格 | 总部与分支属于同一法人体系，分支机构没有独立法人资格 |
| 隶属关系 | 总部与分支之间为直接隶属关系 |
| 管理取向 | **相对集权** |
| 经营自主权 | 分支机构经营自主权较小 |
| 总部意志 | 能够得到直接、有效贯彻 |

> 解释：
>
> - 可以用总公司与分公司的关系类比统一法人制，也可以用“一个人的身体与手臂”理解：分支是整体的一部分，不是与总部完全独立的另一个主体。银行的总分行关系属于此类理解。
> - 统一的业务规则、管理制度与财务要求有助于形成整体，总部对分支机构控制力较强。
>
> *补充：《商业银行法》规定，商业银行分支机构不具有法人资格，在总行授权范围内依法开展业务，其民事责任由总行承担。没有独立法人资格，不等于分行不能办理业务、签订相应业务合同或履行授权范围内的管理职责。*
>
> *补充：[中华人民共和国商业银行法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_35aff5bda2374572b8eb87cafcd1541a.html)：第二条明确商业银行为企业法人；第十九条规定境内分支机构不按行政区划设立；第二十二条规定全行统一核算、统一调度资金、分级管理，以及分支机构不具有法人资格、在总行授权范围内依法开展业务、民事责任由总行承担。*

#### 多法人制

**多法人制是题目一种“相对彻底分权”的组织形式。**集团总部下设置若干子公司，子公司是具有独立法人地位的企业，母子公司之间主要通过资本关系联结。

| 内容 | 多法人制特点 |
| --- | --- |
| 法人资格 | 母公司和子公司分别具有独立法人地位 |
| 联结方式 | 母子公司主要通过资本关系联结 |
| 管理取向 | **相对分权** |
| 经营自主权 | 子公司具有较大的经营自主权 |
| 管控特点 | 可以概括为母公司对子公司的管控力度相对较弱 |

> 解释：
>
> - 例如，**平安、中信**这类金融集团中，可以有银行、证券、保险等不同业务的子公司，各子公司有自己的业务范围和相应经营主体资格。
> - 子公司的业务范围可以不同，集团因而能够在不同业务领域展开经营。
>
> *补充：“相对分权”不等于母公司没有控制权或不能实施集团管理。母公司可以通过股权关系和公司治理安排行使相应权利；子公司仍是独立法人，不能与不具独立法人资格的分行、支行混同。*

#### 两种法人结构的比较

| 比较项目 | 统一法人制 | 多法人制 |
| --- | --- | --- |
| 类比 | 总公司—分公司 | 母公司—子公司 |
| 下属单位法人资格 | 不具有独立法人资格 | 子公司具有独立法人资格 |
| 主要关系 | 直接隶属关系 | 资本联结关系 |
| 权力取向 | 相对集权 | 相对分权 |
| 下属单位自主权 | 较小 | 较大 |

> *补充：一家银行本身实行总分行统一法人架构，不妨碍其所在集团拥有其他独立法人子公司。银行法人层面的总分行关系，与集团层面的母子公司关系，是不同观察层次。*

### 四、总分行型、事业部制与矩阵型

#### 总分行型

总行、分行、支行等各级机构形成**垂直管理体系**，同一层级各职能部门之间的职责协调和信息沟通，由相应层级的行长负责。**分行为利润中心**。

| 要点 | 内容 |
| --- | --- |
| 管理重点 | **区域** |
| 机构关系 | 总行、分行、支行等分层管理 |
| 协调主体 | 相应层级的行长 |
| 利润中心 | **分行** |
| 指标传递 | 总行向分行下达，分行向辖属机构分解 |

> 解释：
>
> - 区域布局可以横向展开：不同地区设置相应机构，关注各地区业务发展；经营指标由总行向下分解，分行承担经营和盈利责任。
> - 例如，银行在不同省份、城市设置机构，各区域都有经营任务，也会开展存款、贷款等同类业务。
>
> *补充：“区域横向展开”讲的是区域之间的布局；“总、分、支垂直管理”讲的是同一区域机构的层级。二者并不矛盾，不能因为板书画横线就认为总分行型没有上下级管理。*

##### 总分行型的优缺点

| 优点 | 缺点 |
| --- | --- |
| 能够保证总行统一指挥 | **各层级自成体系，难以沟通，效率较低** |
| 能够调动分行、支行拓展业务、实现经营目标的主动性与积极性 | 容易干扰总行指挥 |
|  | 对外部环境变化反应较迟钝 |
|  | 增加管理费用 |

> 解释：
>
> - 区域经营主体有自己的任务和目标，能够产生经营积极性；但如果只关注本地区利益，也容易形成各自为政的小范围体系，跨地区沟通和指令落实就可能受影响。
> - 各地区重复设置和管理相关业务，也可能增加管理费用。优点中的“统一指挥”是架构希望实现的管理效果；缺点中的“干扰指挥”是实际运行中可能出现的问题，不应认为两条表述必然互相排斥。

#### 事业部制

全行所有业务划分为若干业务线，总行按业务线设置若干事业部。**每个事业部都是一个利润中心，对本业务线各项业务指标和利润指标的实现负全责。**

| 要点 | 内容 |
| --- | --- |
| 管理重点 | **业务线** |
| 事业部设置 | 总行按业务线设置 |
| 业务组织 | 每项业务形成相应垂直管理线条 |
| 利润中心 | **事业部** |
| 责任范围 | 本业务线的业务指标、利润指标及相应经营管理责任 |

> 解释：
>
> - 例如，**普惠金融事业部**将普惠金融业务自上而下形成专门业务线，实行垂直化运作和管理。划分重点由“在哪个地区经营”转为“经营哪条业务线”。
> - 事业部负责本业务条线的经营决策、业务考核等。判断事业部制时，抓住“**业务线—事业部—利润中心**”，不要误选“每家分行是利润中心”。

##### 事业部制的优缺点

| 优点 | 缺点 |
| --- | --- |
| 强化业务线管理与利润责任，有利于业务发展和持续利润来源 | **对事业部领导人要求很高** |
|  | 管理成本集中在总行层面 |
|  | 可能对全行经营目标产生严重影响 |
|  | 各事业部之间可能产生利益冲突 |

> 解释：
>
> - 事业部运作始终以**实现利润目标**为核心，有利于整个银行获得稳定、持续的利润来源。
> - 领导人需要了解不同地区业务特点并管理整条业务线，因而能力要求较高。若某条业务线出现问题，其影响可能跨越多个地区，而不是只限于某一家分行。
> - 例如，**普惠金融与其他贷款业务**对客户群体、风险与收益的关注可能不同，若缺乏协调，就可能产生利益冲突，影响业务推进。
>
> *补充：此例用于说明组织协调问题，不能将其直接当作所有普惠金融业务必然高风险、低收益，或所有贷款部门都不支持普惠业务的事实结论。*

> 真题示例
>
> **【2025 年单项选择题】下列选项中，不属于以业务线管理为主的事业部制组织架构特征的是（　）。**
>
> A. 事业部行使本业务条线的经营决策权、业务考核权  
> B. 每家分行是一个利润中心  
> C. 全行将业务划分为若干业务线  
> D. 总行按业务线设立若干个事业部
>
> **答案：B。**
>
> 解释：
>
> - **A 项**：属于，事业部围绕本业务条线开展经营管理与考核。
> - **B 项**：**不属于，选此项**，以分行为利润中心，是总分行型架构的识别特征；事业部制以事业部为利润中心。
> - **C 项**：属于，划分若干业务线，是事业部制的基本组织逻辑。
> - **D 项**：属于，总行按业务线设事业部，符合业务线管理模式。
> - 这是一道反向选择题。抓住**“分行利润中心”与“事业部利润中心”**的区别，即可区分区域管理和业务线管理。

#### 矩阵型

**总分行型组织架构与事业部型组织架构相互叠加，形成矩阵型组织架构。**它同时考虑区域和业务线两个维度。

在总行与分支机构之间设置若干区域总部，总行与区域总部按相同序列设置若干事业部；区域总部的事业部接受**区域总部领导人和总行对应事业部领导人的双重领导**。

> 解释：将区域横线和业务纵线交叉，可以理解矩阵型：它把区域管理与业务线管理结合起来，同时考虑两种维度。
>
> *补充：下面以两个区域、两条业务线示意矩阵关系，名称仅用于帮助理解：*
>
> | 区域维度 | *零售业务线* | *公司金融业务线* |
> | --- | --- | --- |
> | *区域 A 总部* | *区域 A 零售事业部* | *区域 A 公司金融事业部* |
> | *区域 B 总部* | *区域 B 零售事业部* | *区域 B 公司金融事业部* |
>
> *补充：每个区域事业部，一方面接受本区域总部领导，另一方面接受总行对应业务线领导。例如，区域 A 零售事业部同时联系区域 A 总部和总行零售事业部。具体银行的机构名称、权责和报告关系应按其实际制度判断。*

##### 矩阵型的优缺点

矩阵型既可以实施**全行统一战略规划**，又可以针对**区域市场差异**采取不同推进策略，有助于适应外部环境变化和市场需求多样性。

| 优点 | 缺点 |
| --- | --- |
| 综合区域管理与业务线管理的优势 | **对全行授权管理系统要求很高** |
| 全行统一战略与区域差异化策略相结合 | 管理成本较高昂 |
|  | 可能对整个区域业务发展产生严重影响 |
|  | 容易因争夺资源发生内耗 |

> 解释：
>
> - 双重领导需要明确权责和授权，避免不同管理线条的要求发生冲突；区域与业务线同时设置管理安排，也会提高协调和管理成本。
> - **矩阵型兼顾两种维度，并不意味着自动消除所有缺点。**它有自身的授权、协调、资源竞争和成本问题。

#### 三种内部管理模式的比较

| 架构 | 核心组织维度 | 识别词 |
| --- | --- | --- |
| **总分行型** | 区域 | 各级行、区域管理、分行利润中心 |
| **事业部制** | 业务线 | 总行设置事业部、业务条线、事业部利润中心 |
| **矩阵型** | 区域＋业务线 | 相互叠加、区域总部、双重领导 |

### 五、成本中心与利润中心

#### 管理会计中的责任划分

| 类型 | 例子 | 理解方法 |
| --- | --- | --- |
| **成本中心** | 管理部门、运作中心、培训机构等 | 重点是成本消耗，可以概括为“花钱” |
| **利润中心** | 独立核算的分支机构、产品线、子公司等 | 承担经营利润责任，可以概括为“赚钱” |

> 解释：前面的“总分行型以分行为利润中心”“事业部制以事业部为利润中心”，是在说明相应经营单元的利润责任。管理部门、培训机构等主要提供支持和保障，按成本中心理解。
>
> *补充：“花钱／赚钱”是记忆用语，不是对机构价值的评价。成本中心同样为银行提供管理、运营和人才支持，不能因为不直接形成销售收入就认为没有价值；利润中心也不是只考核收入而不考虑成本。*

#### 独立核算与独立法人

> *补充：管理会计中的利润中心、独立核算，是内部责任划分和经营评价安排；法人资格则是法律主体问题。分行可以按利润中心管理，但仍不具有独立法人资格。商业银行对分支机构依法实行全行统一核算、统一调度资金、分级管理的财务制度，与内部利润责任评价并不矛盾。*
>
> *补充：说明利润中心时，将分支机构与子公司一起归入下属经营单元。二者可以同为集团或银行的下属单位，但法律性质不同：子公司是独立法人，银行分行、支行是分支机构，不能把“子公司”和“分行”当作同义词。*

### 六、西方商业银行的组织架构

#### 以客户为中心的矩阵型架构

发达国家商业银行的主流组织架构是**以客户为中心的矩阵型组织架构**。

> 解释：先看客户需求，再组织业务线，并与区域需求相结合。“客户为中心”不是取消内部管理，而是使业务组合和组织安排更贴近客户属性与需求。
>
> *补充：这是对成熟银行组织实践的概括，并不表示每个国家、每家银行都采取完全相同的矩阵结构。实际架构会随业务、规模和战略调整。*

#### 基于客户需求的五大业务线

| 业务线 | 服务对象与内容 |
| --- | --- |
| **零售业务** | 为个人和小微企业提供零售银行服务 |
| **财富管理业务** | 为中高端个人客户提供财富管理服务 |
| **商业银行业务** | 为公司客户提供常规金融服务 |
| **金融市场业务** | 向大型企业和机构客户提供高端金融服务 |
| **投行业务** | 为大型企业和机构客户提供相关服务 |

> 解释：可以通过“个人／对公”和“基础／高端”理解这五条业务线：个人基础需求主要对应零售，个人高端需求主要对应财富管理；公司基础需求主要对应商业银行业务，公司或机构的高端需求主要对应金融市场和投行业务。
>
> *补充：这一记忆分组用于理解上述分类，并非严格排除交叉服务。零售业务明确还包括小微企业，不能因此把零售业务一概等同于只服务个人。表中的“商业银行业务”是五条业务线中的常规公司金融板块，不是所有商业银行经营活动的总称。*

#### 三类顶层组织架构设计

| 设计方式 | 组合逻辑 | 例子 |
| --- | --- | --- |
| **“大个金”与“大公金”两大板块** | 按客户属性组合：零售＋财富管理；商业银行业务＋金融市场＋投行 | 渣打、德意志、花旗 |
| **按客户需求层次组合业务板块** | 基础需求组合为一组，高端需求组合为一组 | 法国巴黎银行 |
| **按业务线职能设置组织架构** | 按不同业务线及其职能进行设置 | 摩根大通银行、巴克莱银行、苏格兰皇家银行 |

> 解释：可以用编号帮助记忆：五条业务线中，**第一种组合是“1＋2”和“3＋4＋5”**；第二种组合是**“1＋3”和“2＋4＋5”**；第三种侧重按业务线设置。
>
> *补充：以上是对案例的复习映射，具体银行现行板块名称、结构和品牌可能调整，不能把历史教材例子直接作为当前组织架构清单。*

### 七、我国商业银行组织架构及发展趋势

#### 组织架构的主流形式

| 观察角度 | 我国商业银行的主流形式 |
| --- | --- |
| **企业法人角度** | **统一法人组织架构** |
| **内部管理角度** | **以区域管理为主的总分行型组织架构** |
| **基本机构层级** | 总行、分行、支行三个层级 |

> 解释：我国传统架构按总行和各地区分支机构进行区域管理，在此基础上逐渐加入业务线管理，可以向区域与业务结合的矩阵型发展。
>
> *补充：“总行、分行、支行”是基本分类，并不意味着每家银行实际管理链条只能有三层。分行内部还可能有不同管理层级；也不能理解为法律要求必须按每个省、市机械设置一家对应机构。《商业银行法》规定境内分支机构不按行政区划设立。*

#### 三方面发展趋势

| 方向 | 主要要求 | 理解重点 |
| --- | --- | --- |
| **渐进式推进事业部制改革** | 在原有区域管理基础上推进业务线管理 | 逐步加入纵向业务线，与区域维度结合 |
| **建立垂直化风险管理体系** | 加强贯穿管理层级的风险管理 | 不只限于总部，也不只限于基层，应贯穿总行至基层 |
| **建设流程银行** | 以客户为中心，通过业务流程落实管理与控制 | 围绕客户接受服务的环节建立流程和管理要求 |

#### 流程银行的六项特征

| 特征 | 复习重点 |
| --- | --- |
| **以客户为中心** | 从客户服务和需求出发组织流程 |
| **以业务线垂直运作和管理为主** | 强调业务线的纵向组织和管理 |
| **前中后台相互分离、相互制约，以流程落实内控** | 职责分离与相互制衡不能省略 |
| **以业务单元纵向为主的矩阵考核方式** | 不只保留区域单一考核维度 |
| **中后台集中式运作和管理** | 中后台的集中安排是特征之一 |
| **业务流程信息化、自动化、标准化、智能化** | 四个表述应完整记忆 |

> *补充：流程银行不是只把线下业务搬到手机或电脑上，也不是把所有岗位合并为一个岗位。其核心还包括围绕客户需求重组业务流程、明确职责、落实控制并提高协作效率；信息化是支持这种运作的重要手段。*

### 八、重点小结

- 组织架构内容：**总部部门及其相互关系、分支机构、全行业务运作、总行对分支机构的管理**。
- 法人角度：**统一法人制、多法人制**；前者相对集权、直接隶属，后者相对分权、资本联结。
- 内部管理：**总分行型、事业部制、矩阵型**；分别以**区域、业务线、区域＋业务线**为核心。
- 利润中心：总分行型为**分行**；事业部制为**事业部**；矩阵型强调**双重领导**。
- 管理会计：**成本中心、利润中心**。
- 西方主流架构：**以客户为中心的矩阵型**；我国主流架构：**统一法人、区域管理为主的总分行型**。
- 发展趋势：**渐进推进事业部制、垂直化风险管理、流程银行**。
- 流程银行：**客户中心、业务线垂直管理、前中后台分离制约、纵向矩阵考核、中后台集中运作、流程信息化与自动化及标准化和智能化**。

## 第二章、银行管理基础：银行管理的基本指标

*先记八类指标的归属，再逐项掌握分子、分母、计算单位与指标意义，重点比较名称相似但口径不同的指标，以及监管比例和适用范围。*

### 一、银行管理的八类指标

| 类别 | 具体指标 | 记忆方法 |
| --- | --- | --- |
| **规模指标** | 资产规模、市值 | 两项直接记；规模有多大 |
| **结构指标** | 资产结构、贷款结构、负债结构、收入结构、客户结构 | **“资负可贷入”**，谐音“支付可带入”；资、负、客、贷、入分别对应资产、负债、客户、贷款、收入 |
| **效率指标** | 成本收入比、人均净利润 | 投入成本和人力后，取得多大经营效果 |
| **市场指标** | 市盈率、市净率 | 两项均有“市”；注意市值另属于规模指标 |
| **安全性指标** | 不良贷款率、不良贷款拨备覆盖率、拨贷比、资本充足率 | **“拨资两不良”**：拨贷比、资本充足率、两个以“不良”开头的指标 |
| **流动性指标** | 流动性覆盖率、净稳定资金比例、流动性比例、流动性匹配率、优质流动性资产充足率 | **“四流动，一稳定”** |
| **集中度指标** | 单一最大客户贷款比率、最大十家客户贷款比率、单一集团客户授信集中度、大额风险暴露集中度 | **“一十二单，风险暴露”**：一个“十”、两个“单”，再加风险暴露 |
| **盈利性指标** | 拨备前利润、平均总资产回报率、平均净资产回报率、每股收益、净息差、净利息收益率 | **“一股、二息、两回报，加拨备前利润”** |

> 解释：
>
> - 指标题既可能考查归属，也可能考查公式、分子分母、意义及监管比例。先掌握八类，再重点掌握市场、安全性、流动性和大额风险暴露等内容。
> - **安全性：**把“拨资两不良”联想到“脖子凉不凉”，刀架脖子意味着不安全，由此联系银行需关注不良贷款、拨备和资本。
> - **集中度：**把鸡蛋全部放在一起，一个冲击就可能使全部鸡蛋破碎；对应“不要把鸡蛋放在同一个篮子里”的风险分散思路。“一十二单”谐音“一石二蛋”，用于串联四项指标。
>
> *补充：章末小结写“盈利性指标（7）”，但开头总表、详细指标和口诀均实际对应 **6 项**。这里按实际讲授的六项整理，不因数量标注添加第七项。八类指标按实际展示计数为 2、5、2、2、4、5、4、6。*

### 二、规模指标

#### 资产规模

**资产规模**反映银行经营体量。资产是创造收益的基础，银行规模会影响收入的大小，但**并非规模越大越好**，还要考虑资产质量。

> 解释：例如，贷款属于银行资产；如果新增或存量贷款中不良贷款较多，资产总额虽然很大，却可能带来较大损失和风险。因此不能只看资产数量，还要看资产质量。

#### 市值

**市值**是衡量银行规模的重要综合性指标，也反映一家上市银行在资本市场上的影响力，影响其在资本市场上的权重，是投资者进行资金配置的重要参考。

**市值＝股价×股数。**部分银行同时在内地 **A 股**和香港 **H 股**市场上市，计算时应将两部分市值相加并统一币种。

##### 市值的两种折算路径

令 A 股股价为 $P_A$，股数为 $N_A$；H 股股价为 $P_H$，股数为 $N_H$。以下两条路径最终均以美元表示市值。

**以 A 股为基准的市值（美元）：**

\[
\frac{P_A N_A+P_H N_H\div\text{港元对人民币汇率}}{\text{人民币对美元汇率}}
\]

**以 H 股为基准的市值（美元）：**

\[
\frac{P_A N_A\div\text{人民币对港元汇率}+P_H N_H}{\text{港元对美元汇率}}
\]

**共同原则：先统一两部分市值的币种，再换成最终列报币种。**不能把人民币金额与港元金额直接相加。

> 解释：
>
> - **A 股折算路径**：A 股市值直接用人民币表示；将 H 股市值折成人民币；两者相加后再折成美元。
> - **H 股折算路径**：H 股市值直接用港元表示；将 A 股市值折成港元；两者相加后再折成美元。
>
> *补充：原公式仅用“某币对某币汇率”命名，不能仅凭名称判断应乘还是除。要先读题目给出的报价单位。例如，H 股市值从港元换成人民币：若汇率是“人民币元／港元”，应乘；若是“港元／人民币元”，才应除。上述除法成立，需要分母分别采用对应的倒数报价。*
>
> *补充：若 $r$ 表示人民币元／港元，$u$ 表示人民币元／美元，$v$ 表示港元／美元，则美元市值可以写为 $(P_A N_A+rP_H N_H)/u$，也可以写为 $(P_A N_A/r+P_H N_H)/v$。在一致汇率下 $u=rv$，两条折算路径应得到同一结果；“基准不同”主要改变中间币种，不能据此认为同一组数据必然产生两种美元市值。*

### 三、结构指标

> 解释：结构指标观察银行资源和业务如何构成。它们的共同问题是：**某一部分占比多少，这种结构会如何影响收益、成本和风险？**

#### 资产结构：生息资产占比

\[
\text{生息资产占比}=\frac{\text{生息资产平均余额}}{\text{资产总额}}\times100\%
\]

**生息资产**是贷款及投资资产、存放央行款项、存放或拆放同业款项等能够产生相应收益的资产总称。银行资产中既有能产生收益的资产，也有非生息资产，资产结构分析重点关注生息资产。

> 解释：生息资产金额是测算**净利息收益率（NIM）**的基础，也是考察银行盈利性的重要基础数据。银行不能只看资产多不多，还要看其中能创造收益的部分有多少。
>
> *补充：原公式分子写“平均余额”，分母写“资产总额”。实际分析时应核对所用报表是否采用期末或平均口径，跨行、跨期比较必须保持可比；不要未经说明自行把期末总资产替换为平均总资产。*

#### 贷款结构：零售贷款占比

**零售贷款占比是贷款结构的重要指标。**

> 解释：
>
> - 贷款可以区分为对公贷款与个人贷款，可用个人贷款理解零售贷款。
> - 个人客户数量多、单笔贷款相对分散，因此零售贷款占比较高，通常有利于分散客户集中风险。这解释了为什么该占比值得关注。
>
> *补充：通常可用“零售贷款余额／贷款总余额 ×100%”表达零售贷款占比，具体零售贷款范围以统计口径为准。客户分散主要缓解集中度风险，不能据此认定零售贷款一定风险更低；共同经济冲击仍可能影响大量零售借款人。*

#### 负债结构：定活比

\[
\boxed{\text{定活比}=\frac{\text{定期存款}}{\text{活期存款}}\times100\%}
\]

> 解释：
>
> - 从客户看，存款是其资产；从银行看，吸收的存款是银行需要偿还的**负债**。银行对存款付息，存款结构直接关系资金成本。
> - 定期存款利率通常高于活期存款利率，因此**定活比高，意味着定期存款相对较多，资金成本通常较高**。分析存款资金成本，应联系负债结构中的定活比。
> - 定活比的分母是活期存款，不是存款总额；它与“定期存款占全部存款的比例”不同。

> 真题示例
>
> **【2025 年单项选择题】在进行商业银行存款资金成本分析时，通常最受关注的指标是（　）。**
>
> A. 生息资产占比  
> B. 资产规模  
> C. 定活比  
> D. 市值
>
> **答案：C。**
>
> 解释：
>
> - **A 项**：错，生息资产占比属于资产结构，观察资产收益基础。
> - **B 项**：错，资产规模属于规模指标。
> - **C 项**：对，定期、活期存款的相对占比影响存款付息成本。
> - **D 项**：错，市值属于规模指标，反映上市银行资本市场价值。
> - 本题也说明，分类题和理解题往往结合出现：不是看到某个重要指标就选，而要先判断题干关心的是资产、负债、效率、市场还是其他问题。

#### 收入结构

银行收入结构主要体现为**净利息收入与非利息收入**。

非利息收入主要包括**收费收入、投资业务收入和其他中间业务收入**。

\[
\text{非利息收入占营业收入比}=\frac{\text{非利息收入}}{\text{营业收入}}\times100\%
\]

> 解释：
>
> - 例如，理财产品管理费、支付结算手续费，都是银行利息以外的收入来源。
> - 非利息收入占比较高，说明业务收入来源更广，有利于平衡单纯依赖贷款利息收入所带来的风险。
>
> *补充：净利息收入是利息收入扣除利息支出后的净额。非利息收入占比上升不必然代表全部风险下降，还要结合收入质量、波动性和业务本身的风险判断。*

#### 客户结构

| 客户大类 | 进一步划分 |
| --- | --- |
| **公司客户** | 大客户、中小客户 |
| **零售客户** | 高净值客户、普通客户 |

> 解释：客户结构是观察客户类型和分布；贷款结构则主要观察贷款业务构成。考试中不要因为“客户”和“贷款”都能区分对公、零售，就把两项混为一项。

### 四、效率指标

#### 成本收入比

\[
\text{成本收入比}=\frac{\text{营业费用（含营业税）}}{\text{营业净收入}}\times100\%
\]

\[
\text{营业净收入}=\text{营业收入}-\text{营业支出和费用}
\]

**成本收入比是评价银行经营效率的重要指标之一。**

> 解释：成本收入比反映取得一定收入需要投入多少成本。成本和费用主要包括**人工、固定资产折旧、摊销**等。
>
> *补充：在相同统计口径和可比条件下，成本收入比下降通常说明每单位收入承担的运营成本减少。但不能仅凭比率判断效率改善，也要看收入是否持续、成本是否被延后确认。*
>
> *补充：原公式和题目均采用“营业净收入”表述，并保留“含营业税”的旧用语。实际年报中，应查看该银行对成本收入比的定义及分母范围；不能将该分母直接理解为净利润，也不能把不同机构的“营业收入”“营业净收入”未经核对混用。上述公式保留原材料口径，不代替所有财务报表口径。*

#### 人均净利润

**人均净利润衡量每名员工创造净利润的能力，也是评价经营效率的重要指标之一。**

\[
\text{人均净利润}=\frac{\text{净利润}}{\text{员工数量}}
\]

| 指标 | 主要观察对象 | 记忆抓手 |
| --- | --- | --- |
| 成本收入比 | 收入相对于成本投入的效率 | 成本／收入 |
| 人均净利润 | 员工创造净利润的能力 | 利润／人数 |

> 解释：其基本计算逻辑是“净利润除以员工数量”。原公式及下列题目还在公式后加“×100%”，单位问题见补充。
>
> *补充：原公式和效率指标题在此公式后加“×100%”。但人均净利润是金额／人数，通常用“元／人”“万元／人”表示，不是百分比指标。上式给出符合量纲的计算写法。相应题目和答案也保留在此处，以区分原材料答案和公式校正。*

> 真题示例
>
> **【2025 年多项选择题】关于银行的效率指标，下列说法正确的有（　）。**
>
> A. 人均净利润是评价银行经营效率的重要指标之一  
> B. 营业净收入＝营业收入－营业支出和费用  
> C. 人均净利润＝净利润／员工数量 ×100%  
> D. 成本收入比＝营业费用／营业净收入 ×100%  
> E. 成本收入比是评价银行经营效率的重要指标之一
>
> **答案：A、B、C、D、E。**
>
> 解释：
>
> - **A 项**：对，人均净利润评价员工创造利润的效率。
> - **B 项**：对，课程按营业收入扣除营业支出、费用解释营业净收入。
> - **C 项**：对，净利润除以员工数量；原公式保留了“×100%”。
> - **D 项**：对，分子是营业费用，分母是题目所称营业净收入。
> - **E 项**：对，成本收入比也是重要效率指标。
>
> *补充：C 的百分比写法不符合人均净利润的金额／人数单位。若严格按量纲审查，应写“净利润／员工数量”，不作为百分比列报。本题保留原答案 ABCDE，但“×100%”的单位问题仍需区分。B、D 的具体财务口径同样应以题目定义或年报释义为准。*

### 五、市场指标

两个市场指标都与股票价格有关，主要针对上市银行。**市值属于规模指标，市盈率和市净率属于市场指标。**

#### 市盈率 PE

\[
\boxed{PE=\frac{\text{股票价格 }P}{\text{每股收益 }E}}
\]

股价通常采用最新收盘价。**PE 是衡量股票投资价值的重要指标**，反映股票估值、风险程度，以及市场对公司的重视程度和预期。

| 类型 | 每股收益的取值 | 判断关键词 |
| --- | --- | --- |
| **静态市盈率** | 已公布的上年度每股收益 | 已公布、上年度 |
| **动态市盈率** | 对今年及未来每股收益的预测值 | 预测、未来 |

- 每股收益一定，股价越高，PE 越高。
- **股价一定，每股收益越高，PE 越低。**这是第一道原题的关键。

> 解释：每股收益一定时，股价过高会推高 PE，可能意味着股票被高估，价格回落风险更大。相对温和的较高 PE，也可能反映投资者看好公司未来发展。可用“**十几倍**”与“**七八十倍、一百多倍**”作直观比较，提醒自己关注高估风险。
>
> *补充：这些倍数是示意用语，不是通用于所有银行或行业的投资阈值。高 PE 可能反映增长预期，低 PE 也可能反映盈利不可持续或风险较高；不能仅凭一个倍数认定股票一定安全或值得买入。对于零收益或负收益，PE 的解释还需另作处理。*

> 真题示例
>
> **【2025 年单项选择题】关于市盈率，在股票价格一定的时候，每股收益越高，（　）。**
>
> A. 市盈率越高，股票风险越高  
> B. 市盈率越低，股票风险越低  
> C. 市盈率越高，股票风险越高  
> D. 市盈率越高，股票风险越低
>
> **答案：B。**
>
> 解释：
>
> \[
> PE=P/E\quad\Longrightarrow\quad P\text{一定，}E\text{提高，}PE\text{降低}
> \]
>
> - **A 项**：错，每股收益提高，分母变大，市盈率应降低。
> - **B 项**：对，市盈率降低，按题目的简化估值逻辑，股票被高估的风险相对降低。
> - **C 项**：错，与 A 相同，市盈率变化方向错误。
> - **D 项**：错，即使后半句符合题目的风险方向，前半句“市盈率越高”仍错误。
>
> *补充：原题 A 与 C 完全重复，选项按原文保留。“风险越低”是本题的简化判断，不代表现实中低 PE 股票必然风险低。*

#### 市净率 PB

\[
\boxed{PB=\frac{\text{每股市价 }P}{\text{每股净资产 }B}}
\]

在每股净资产一定时，PB 较高意味着股价较高，可能存在高估；PB 较低的股票，投资价值相对较高，反之相对较低。

| 对比项 | 市盈率 PE | 市净率 PB |
| --- | --- | --- |
| 分子 | 股票价格／每股市价 | 股票价格／每股市价 |
| 分母 | **每股收益** | **每股净资产** |
| 主要比较基础 | 盈利 | 净资产 |
| 与后续指标的联系 | 每股收益属于盈利性指标 | 净资产与所有者权益有关 |

> *补充：低 PB 是相对账面净资产便宜，不能证明资产质量良好或未来盈利增长。上述结论用于理解估值关系，实际判断仍需结合不良资产、收益能力和资本情况。*

### 六、安全性指标

#### 不良贷款率与五级分类

贷款按风险基础分为**正常、关注、次级、可疑、损失**五类。**后三类，即次级、可疑、损失，合称不良贷款。**

\[
\text{不良贷款率}=\frac{\text{不良贷款余额}}{\text{总贷款余额}}\times100\%
\]

> 解释：
>
> - 关注类虽然也有风险，但不属于这里的不良贷款口径；不应把“存在风险”与“已列为不良”混为一谈。
> - 不良贷款率观察全部贷款中不良贷款所占的比例。可以联系理财业务中曾提及的“次级”理解风险属性，但贷款次级类与证券次级档应作区分。
>
> *补充：贷款五级分类中的“次级类”，与资产证券化分层中的“次级档”是两个概念。前者描述贷款信用质量，后者描述证券偿付顺序和承担损失的层级；不能仅因都含“次级”而认为其基础贷款必然属于不良贷款。*

#### 不良贷款拨备覆盖率

银行要为可能发生的贷款损失计提准备，以吸收和消化风险。**拨备覆盖率衡量银行对不良贷款进行账务处理时所持审慎程度。**

\[
\text{拨备覆盖率}=\frac{\text{不良贷款损失准备}}{\text{不良贷款余额}}\times100\%
\]

> 解释：
>
> - 关键是：分母为**不良贷款余额**，用准备与不良贷款相比较，观察准备覆盖程度。
> - 例如，覆盖超过 **100%**，可直观理解为准备金额能够覆盖账面不良贷款余额。
>
> *补充：实际监管统计常用“贷款损失准备／不良贷款余额”计算拨备覆盖率，不宜将分子仅理解为专门对应不良贷款的那部分准备。关于 100% 的解释不是普遍适用的最低监管标准；例如人民银行《中国金融稳定报告 2018》介绍的差异化监管要求为拨备覆盖率 120%—150%、贷款拨备率 1.5%—2.5%。这些是注明年份的政策背景，不应拿来直接推定某家银行当下适用的具体要求。*
>
> *补充：[人民银行《中国金融稳定报告 2018》](https://www.gov.cn/xinwen/2018-11/04/5337137/files/48b31c0c3cec41ac977b18a2b6b9590a.pdf)：注明年份的贷款损失准备、拨备覆盖率和贷款拨备率政策背景。*

#### 拨贷比及三项指标的关系

\[
\text{拨贷比}=\frac{\text{贷款损失准备}}{\text{贷款余额}}\times100\%
\]

| 指标 | 分子 | 分母 | 关注的问题 |
| --- | --- | --- | --- |
| 不良贷款率 | 不良贷款余额 | 全部贷款余额 | 有多少贷款已经列为不良 |
| 拨备覆盖率 | 贷款损失准备 | 不良贷款余额 | 准备与不良贷款相比是否充足 |
| 拨贷比 | 贷款损失准备 | 全部贷款余额 | 全部贷款对应多大准备规模 |

\[
\boxed{\text{拨贷比}=\text{拨备覆盖率}\times\text{不良贷款率}}
\]

> 解释：原公式分子同样写作“不良贷款损失准备”。与拨备覆盖率相比，拨贷比的分母变为**全部贷款余额**，包括五级分类中的所有贷款。
>
> *补充：令准备为 $R$、不良贷款为 $N$、全部贷款为 $L$。则 $R/L=(R/N)(N/L)$，因为中间的 $N$ 抵消。计算时，先把百分比转成小数再相乘，最后转换为百分数；若直接用百分数中的数值计算，应除以 100。不要把百分数的数值相乘后直接在结果后加百分号。*

#### 资本充足率

\[
\boxed{\text{资本充足率}=\frac{\text{总资本}-\text{对应资本扣除项}}{\text{风险加权资产}}\times100\%}
\]

资本是银行经营的前提，重要作用是**吸收、消化损失**。资本充足率把能够用于抵御风险的资本与风险加权资产相比较，观察资本能否支持银行承担的风险。

> 解释：
>
> - 并非所有账面资本项目都能有效吸收损失，因此要扣除相应项目。例如，部分无形资产等不能用于实际弥补损失。
> - 分母是风险加权资产，不是总资产，也不是贷款总额；分子是扣除相应扣除项后的监管资本。
>
> *补充：2024 年起施行的《商业银行资本管理办法》规定最低核心一级资本充足率、一级资本充足率、资本充足率分别为 5%、6%、8%；另有 2.5% 的储备资本要求，并可能叠加逆周期、系统重要性银行及第二支柱要求。因此，“8%”只是最低资本要求中的一项，不能当作所有银行完整的资本监管要求。*
>
> *补充：[《商业银行资本管理办法》](https://www.hunan.gov.cn/zqt/zcsd/202311/t20231102_31809282.html)：第二十五至二十九条，最低资本、储备资本及其他要求。*

### 七、流动性指标

> 解释：流动性指标回答银行是否有足够资产或稳定资金，满足到期支付和业务需要。重点掌握**公式、30 天、2000 亿元规模分界、最低比例**。

#### 五项公式与最低标准

| 指标 | 公式 | 最低监管标准 | 理解重点 |
| --- | --- | --- | --- |
| **流动性覆盖率** | 合格优质流动性资产／未来 **30 天现金净流出量** | **不低于 100%** | 短期压力下，现有合格优质资产能否覆盖净流出 |
| **净稳定资金比例** | 可用的稳定资金／所需的稳定资金 | **不低于 100%** | 中长期稳定资金来源能否覆盖稳定资金需求 |
| **流动性比例** | 流动性资产余额／流动性负债余额 | **不低于 25%** | 流动资产与流动负债的相对规模 |
| **流动性匹配率** | 加权资金来源／加权资金运用 | **不低于 100%** | 资金来源和资金运用的匹配程度 |
| **优质流动性资产充足率** | 优质流动性资产／短期现金净流出 | **不低于 100%** | 短期压力下，优质流动资产能否满足流动性需要 |

这些公式表示比值，换成百分数列报时再按百分比表达。**只有流动性比例为 25%，其余四项为 100%。**

#### 银行规模与指标适用范围

流动性覆盖率与优质流动性资产充足率都强调短期流动性保障，均联系**未来 30 天**的需求，但并非重复指标：它们适用的银行规模以及计算细节不同。

> 解释：流动性覆盖率对合格优质流动性资产划分更细，主要适用于规模较大的银行；优质流动性资产充足率相对简化，主要适用于规模较小的银行。
>
> *补充：《商业银行流动性风险管理办法》第三十七条细化了默认适用范围：*
>
> | *资产规模* | *应达到的指标最低标准* |
> | --- | --- |
> | *不小于 2000 亿元人民币，即 **含 2000 亿元*** | *流动性覆盖率、净稳定资金比例、流动性比例、流动性匹配率* |
> | *小于 2000 亿元人民币* | *优质流动性资产充足率、流动性比例、流动性匹配率* |
>
> *补充：经监管批准，小于 2000 亿元的银行可以适用流动性覆盖率和净稳定资金比例要求，并不再适用优质流动性资产充足率要求。规模分界是默认适用规则，不能忽略批准后的例外。*

#### 短期覆盖、稳定资金与期限匹配

> 解释：
>
> - **短期覆盖：**流动性覆盖率看未来 30 天现金净流出；优质流动性资产充足率也考察短期流动性需求。
> - **稳定资金：**净稳定资金比例偏重中长期资金来源和需求。
> - **期限匹配：**流动性匹配率关注加权资金来源与加权运用，避免过度依赖短期资金支持长期业务。
> - **余额比例：**流动性比例比较流动性资产余额与流动性负债余额，最低 25%。
>
> *补充：流动性覆盖率中的现金净流出量，是监管规定的压力情景下计算值，不是简单把未来 30 天日常现金支出相加。各项公式要使用规定的资产范围、权重和净流出口径，不能仅凭名称互换分子分母。*
>
> *补充：[《商业银行流动性风险管理办法》](https://policy.mofcom.gov.cn/claw/clawContent.shtml?id=64650)：第三十七至四十二条及第七十三条，五项公式、最低标准、2000 亿元适用范围及批准后的例外。*

### 八、集中度指标

> 解释：集中度管理是为了避免银行把过多资金或风险集中在少数客户身上。客户越集中，某个客户违约时对银行的冲击可能越大。

#### 客户贷款与授信比例

| 指标 | 公式 | 作用／要求 |
| --- | --- | --- |
| **单一最大客户贷款比率** | 对同一借款客户贷款总额／资本净额 ×100% | 衡量银行经营安全性的重要指标之一 |
| **最大十家客户贷款比率** | 对最大十户借款客户贷款总额／资本净额 ×100% | 衡量银行资产负债比例管理的指标之一 |
| **单一集团客户授信集中度** | 最大一家集团客户授信总额／资本净额 ×100% | **不应高于 15%** |

> 解释：三者的逻辑相同：将某类客户的贷款或授信规模，与银行自身资本净额比较。区别在于观察的是同一借款客户、最大十户，还是同一集团。
>
> *补充：授信不只包括已发放贷款，还可能包括承兑、保函、信用证等信用风险业务。因此单一集团客户“授信集中度”不能直接替换为该集团“贷款占比”。集团授信 15% 与后文非同业关联客户风险暴露 20%，其分子范围和资本分母也不同。*
>
> *补充：[《商业银行集团客户授信业务风险管理指引》](https://policy.mofcom.gov.cn/claw/clawContent.shtml?id=46512)：第十二条，单一集团客户授信与资本净额 15% 的规定。*

#### 风险暴露与大额风险暴露

**风险暴露**是商业银行对单一客户或一组关联客户的信用风险暴露，包括**银行账簿和交易账簿**内各类信用风险暴露。

**大额风险暴露**是商业银行对单一客户或一组关联客户**超过其一级资本净额 2.5%** 的风险暴露。

> 解释：
>
> - 例如，贷款业务，以及外汇、利率衍生品等交易都可能因客户违约给银行带来损失，信用风险不只来自贷款。
> - 判断是否属于大额风险暴露时，要同时注意三个限定：**单一客户或一组关联客户、一级资本净额、超过 2.5%**。
>
> *补充：“超过 2.5%”是识别大额风险暴露的标准，不是统一监管上限；恰等于 2.5% 与“超过”也不同。风险暴露是按规则计量的暴露金额，不等于已经实现的损失金额。*

#### 大额风险暴露的集中度上限

| 客户及业务情形 | 分子 | 资本分母 | 上限 |
| --- | --- | --- | --- |
| 非同业单一客户的贷款 | 贷款余额 | **资本净额** | **不得超过 10%** |
| 非同业单一客户的风险暴露 | 风险暴露 | **一级资本净额** | **不得超过 15%** |
| 一组非同业关联客户 | 风险暴露 | **一级资本净额** | **不得超过 20%** |
| 同业单一客户或集团客户 | 风险暴露 | **一级资本净额** | **不得超过 25%** |
| 全球系统重要性银行对另一家全球系统重要性银行 | 风险暴露 | **一级资本净额** | **不得超过 15%** |

**关键区别：贷款 10% 用资本净额；风险暴露 15%、20%、25% 用一级资本净额。**不能只背百分数。

我国入选全球系统重要性银行的五家银行为**工商银行、农业银行、中国银行、建设银行、交通银行**。

> 解释：
>
> - 这是集中度部分的重点。先区分**同业／非同业**，再区分**单一／关联客户**，最后看**贷款余额／风险暴露**及对应资本分母。
> - 可以按 **10%、15%、20%、25%** 依次递增、每档相差 **5 个百分点**的方式记忆，再另记全球系统重要性银行之间的 **15%**。
> - 全球系统重要性银行对全球金融稳定具有重要意义。若银行之间风险过度集中，一家出问题可能传导至另一家重要银行，形成较大系统影响，因此约束更严格。
>
> *补充：FSB 于 2025 年 11 月发布的名单仍包括上述五家中国银行。名单按年更新；这里按该年度名单核对课程例子，不把“五家”当成永久不变的数量。*
>
> *补充：上述上限用于掌握课程一般规则。正式法规还规定部分中央政府、央行、政策性银行非次级债权、合格中央交易对手清算暴露等豁免或特殊规则；不能把一般上限扩大为对全部主体和全部交易无例外适用。*
>
> *补充：[《商业银行大额风险暴露管理办法》](https://policy.mofcom.gov.cn/claw/clawContent.shtml?id=64561)：第三、四条及第七至十五条，风险暴露定义、资本分母、上限及豁免范围。*
>
> *补充：[FSB《2025 年全球系统重要性银行名单》](https://www.fsb.org/uploads/P271125.pdf)：附录列示工、农、中、建、交五家中国银行。*

### 九、盈利性指标

> 解释：这一组看银行赚取利润的能力。学习时抓住三种不同基础：**利润总额、每单位资产／权益、每股或每单位生息资产**。

#### 拨备前利润

\[
\text{拨备前利润}=\text{当期营业利润}+\text{当期提取拨备}
\]

> 解释：
>
> - 拨备是银行对经营中可能形成的风险和损失计提的准备，反映承担的风险成本。营业利润中已经扣除了相应拨备；要观察“拨备前”的经营利润，就要把当期提取拨备加回。
> - 这个指标帮助观察计提贷款或资产准备前的经营表现，并联系银行经营水平和信贷资产质量。
> - “拨备前”要加回拨备，不能再扣一次；公式用的是当期营业利润，不是直接用净利润。

#### 平均总资产回报率

\[
\text{平均总资产回报率}=\frac{\text{净利润}}{\text{总资产平均余额}}\times100\%
\]

它反映银行**全部资产获取收益的能力**，是考察盈利能力的关键指标之一。其有助于增加不同银行盈利性的可比性，但不能完全反映银行自有资金取得收益的能力。

\[
\text{资产}=\text{负债}+\text{所有者权益}
\]

> 解释：
>
> - 可以从资产负债表理解总资产回报率：
> - 银行资产的资金来源既包括吸收存款等负债，也包括股东投入的自有资金。因此，总资产回报率观察的是整体资产产出，不能单独回答股东权益创造多少收益。

#### 平均净资产回报率

\[
\text{平均净资产回报率}=\frac{\text{净利润}}{\text{净资产平均余额}}\times100\%
\]

净资产是资产扣除负债后的余额，即所有者权益。平均净资产回报率侧重观察**自有资金、股东权益创造利润的能力**。

其被称为评价银行盈利性的**最重要指标**，也是开展比率分析的出发点。

| 对照 | 平均总资产回报率 | 平均净资产回报率 |
| --- | --- | --- |
| 分子 | 净利润 | 净利润 |
| 分母 | **总资产平均余额** | **净资产平均余额** |
| 观察基础 | 由负债和权益共同支持的全部资产 | 股东权益／自有资金 |
| 记忆重点 | 资产获取收益能力 | 自有资金获取收益能力 |

> *补充：常用简称分别为 ROA、ROE。使用平均余额是为了使一个期间的利润与对应期间的资产或权益规模相匹配；若题目采用期初期末简单平均，应按 ((期初余额+期末余额)/2) 计算，不能用期末减期初作为平均余额。*

#### 每股收益 EPS

\[
EPS=\frac{\text{本期净利润}}{\text{期末总股本}}
\]

> 解释：
>
> - 它用于测定银行股票投资价值，综合反映获利能力，也反映每一股份创造的税后利润；与市盈率中的每股收益直接相连。
> - “期末总股本”在此指**股份数量**。只有普通股时，收益用税后净利润，股数用流通在外普通股股数；有优先股时，应从税后净利润中扣除分派给优先股股东的股息，再观察普通股对应收益。
>
> *补充：《企业会计准则第 34 号——每股收益》规定，基本每股收益用“归属于普通股股东的当期净利润／发行在外普通股的加权平均数”计算，而非一律用期末股数。上述公式是简化表达；期内发行、回购等导致股数变化时，应注意加权平均。每股收益通常以元／股表示，不乘 100%。*
>
> *补充：[财政部《企业会计准则第 34 号——每股收益》](https://www.asc.net.cn/News/NewsContent.aspx?NewsID=089DD9B6-494D-457A-ACED-DA5F22AF370C&PageCode=MENU_AW)：第四、五条，普通股净利润与发行在外普通股加权平均数。*

#### 净息差

\[
\text{净息差}=\text{生息资产平均收益率}-\text{付息负债平均付息率}
\]

**净息差是两个比率相减，不是两个金额相减。**

> 解释：可用存贷款利差帮助理解：资产端赚取收益，负债端支付资金成本，两者收益率或成本率的差额形成息差。
>
> *补充：生息资产与付息负债的范围不限于贷款和存款，存贷例子用于理解基本机制；息差结果通常以百分比或基点表达。*

#### 净利息收益率 NIM

\[
\text{年均概念：}NIM=\frac{\text{净利息收入}}{\text{期初期末平均生息资产}}\times100\%
\]

\[
\text{日均概念：}NIM=\frac{\text{净利息收入}}{\text{日均生息资产}}\times100\%
\]

净利息收益率反映**单位生息资产创造净利息收入的能力**，是对银行盈利影响较大的指标之一。

| 对照项 | 净息差 | 净利息收益率 NIM |
| --- | --- | --- |
| 计算方式 | 生息资产收益率 **减** 付息负债付息率 | 净利息收入 **除以** 平均生息资产 |
| 观察对象 | 资产收益率和资金成本率之差 | 每单位生息资产的净利息产出 |
| 记忆抓手 | 两个率相减 | 一个净收入／资产平均额 |

> 解释：利率调整、贷存比、存款定活比等因素都会影响 NIM。
>
> *补充：期初期末平均生息资产通常按 ((期初生息资产+期末生息资产)/2) 理解；日均生息资产按期间每天余额的平均数理解。分子和分母必须覆盖可比期间，半年等非全年数据还要核对是否年化。原口头平均余额描述较含混，此处依据“平均”的含义给出计算说明。*
>
> *补充：两个指标受资产负债结构影响，数值不必相等。NIM 的分子是净利息收入，而不是全部营业收入、净利润或未扣利息支出的利息收入。*

### 十、重点小结

- 八类指标：**规模、结构、效率、市场、安全性、流动性、集中度、盈利性**。
- 规模看**资产规模、市值**；市场看 **PE＝股价÷每股收益，PB＝每股市价÷每股净资产**。
- 定活比：**定期存款÷活期存款**；成本收入比：**营业费用÷营业净收入**；人均净利润：**净利润÷员工数量**。
- 不良贷款：**次级、可疑、损失**；**拨贷比＝拨备覆盖率×不良贷款率**。
- 资本充足率：**扣除相应扣除项后的监管资本÷风险加权资产**。
- 流动性覆盖率联系 **30 天**；适用规模分界为 **2000 亿元**；最低标准除流动性比例为 **25%** 外，其余四项均为 **100%**。
- 大额风险暴露：**超过一级资本净额 2.5%**。
- 集中度上限：非同业单一贷款 **10%**，非同业单一暴露 **15%**，非同业关联客户 **20%**，同业单一或集团客户 **25%**；全球系统重要性银行之间为 **15%**。
- 贷款 **10%** 的分母是**资本净额**；风险暴露 **15%、20%、25%** 的分母是**一级资本净额**。
- 盈利性六项：**拨备前利润、平均总资产回报率、平均净资产回报率、每股收益、净息差、净利息收益率**。
- 净息差：**两个率相减**；NIM：**净利息收入÷平均生息资产**。
