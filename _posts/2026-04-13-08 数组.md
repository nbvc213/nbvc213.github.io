## 数组概述

### 数组的概念

数组可以理解为一个“有编号的容器”。这个容器中可以放多个数据，但这些数据的**类型必须一致**。例如，可以用数组存放一组学生成绩、一组商品价格、一组姓名，但不能在同一个数组中既放 `int`，又放 `String`。

例如，下面两个数组分别用于保存多 个整数和多个字符串：

```java
int[] scores = {90, 85, 100};
String[] names = {"张三", "李四", "王五"};
```

这里的 `scores` 中每个元素都是 `int` 类型，`names` 中每个元素都是 `String` 类型，这正体现了数组“同类型元素集合”的特点。

### 数组的特点

数组在使用时有几个非常重要的特点，需要先建立整体认识。

1. **数组中元素类型必须一致。**创建 `int[]` 数组后，其中只能存放整数；创建 `String[]` 数组后，其中只能存放字符串。这样设计的目的是让数组结构更统一，访问和管理更高效。
2. **数组长度一旦确定，就不能改变。**数组在创建时必须明确长度，创建完成后，这个长度就固定了，不能再增加或减少元素位置。可以修改某个位置上的值，但不能把数组本身“扩容”或“缩容”。
3. **数组中的元素有索引（下标）。**每个元素都有对应的位置编号，这个编号就是索引。索引从 `0` 开始，到 `数组长度 - 1` 结束。
4. **数组可以通过索引快速访问元素。**访问数组元素时，必须使用索引，例如 `arr[0]` 表示第一个元素，`arr[1]` 表示第二个元素。
5. **数组是一种引用数据类型。**虽然数组里存放的可能是基本数据类型，但“数组本身”仍然是对象，因此数组变量中保存的是数组对象的引用。

例如：

```java
int[] nums = {10, 20, 30};
```

这里 `nums` 不是直接保存三个整数本身，而是引用了一个数组对象，这个数组对象中再保存 `10`、`20`、`30` 这些元素。

> **注意：** 数组长度固定，指的是“元素个数固定”；并不是说元素值不能改。数组中的某个位置上的值是可以重新赋值的。

### 数组的创建

数组的创建方式主要有两种：**动态初始化** 和 **静态初始化**。二者的区别在于：创建数组时，是否已经明确知道每个位置要存放什么值。

#### 动态初始化

动态初始化是指：**创建数组时，只确定数组长度，不直接指定具体元素值。**

##### 语法格式

```java
数据类型[] 数组名 = new 数据类型[数组长度];
```

也可以写成：

```java
数据类型 数组名[] = new 数据类型[数组长度];
```

不过在 Java 中，更推荐第一种写法，因为 `[]` 紧跟类型，更容易看出这是一个数组类型。

##### 示例

```java
public class Test {
    public static void main(String[] args) {
        int[] scores = new int[3];
        String[] names = new String[5];
    }
}
```

上面代码中：

- `scores` 表示一个长度为 `3` 的 `int` 数组；
- `names` 表示一个长度为 `5` 的 `String` 数组。

这里虽然数组已经创建好了，但其中的元素值并不是手动写进去的，而是先使用**默认值**进行初始化，后面再按需要逐个赋值。

##### 什么时候使用动态初始化

当创建数组时，**已经知道要存多少个元素，但暂时还不知道每个位置具体存什么值**，就适合使用动态初始化。

例如，要录入 5 个学生的成绩，此时只知道一共要存 5 个分数，但每个分数还没输入，这时就适合先创建一个长度为 5 的数组。

```java
double[] grades = new double[5];
```

#### 静态初始化

静态初始化是指：**创建数组时，直接把元素值一并写出来。**

##### 语法格式一

```java
数据类型[] 数组名 = new 数据类型[]{元素1, 元素2, 元素3};
```

##### 示例

```java
public class Test {
    public static void main(String[] args) {
        int[] nums = new int[]{1, 2, 3, 4};
        String[] names = new String[]{"张三", "李四", "王五"};
    }
}
```

这种写法中，数组的长度不需要单独写，因为**元素个数已经决定了数组长度**。

##### 语法格式二

在声明数组变量的同时，还可以省略 `new 数据类型[]`，直接使用大括号。

```java
数据类型[] 数组名 = {元素1, 元素2, 元素3};
```

##### 示例

```java
public class Test {
    public static void main(String[] args) {
        int[] nums = {10, 20, 30, 40};
        String[] names = {"Java", "Python", "Go"};
    }
}
```

这种写法更简洁，因此在实际开发和学习中都很常见。

##### 为什么简化写法只能用于声明时

很多初学者会写出下面这样的代码：

```java
int[] arr;
arr = {1, 2, 3}; // 错误
```

这是不允许的。因为大括号的简化写法只能在**声明数组变量的同时**使用；如果声明和赋值分开写，就必须使用完整形式：

```
int[] arr;
arr = new int[]{1, 2, 3};
```

> **易错点：** `{1, 2, 3}` 这种简化写法不能单独作为赋值语句使用，只能出现在数组声明时。

### 数组的基本操作

数组创建完成后，最常见的操作有四类：**访问元素、修改元素、获取长度、遍历数组。**

#### 访问数组元素

数组中的元素必须通过索引访问。索引从 `0` 开始，因此第一个元素的索引是 `0`，第二个元素的索引是 `1`，依此类推。

```java
public class Test {
    public static void main(String[] args) {
        int[] nums = {11, 22, 33};

        System.out.println(nums[0]);
        System.out.println(nums[1]);
        System.out.println(nums[2]);
    }
}
```

运行结果分别是数组中的第 1、2、3 个元素。

#### 给数组元素赋值

数组中的某个位置可以重新赋值，语法格式如下：

```java
数组名[索引] = 值;
```

例如：

```java
public class Test {
    public static void main(String[] args) {
        int[] nums = new int[4];

        nums[0] = 100;
        nums[1] = 200;
        nums[2] = 300;

        nums[1] = 999;
    }
}
```

这段代码中，先给前三个元素赋值，后面又把索引为 `1` 的元素修改成了 `999`。

需要注意，赋给数组元素的值必须和数组类型匹配。例如，`int[]` 数组中不能存放字符串，`String[]` 数组中不能直接存放整数。

#### 获取数组长度

每个数组都有一个 `length` 属性，用来表示数组中元素的个数。

```java
public class Test {
    public static void main(String[] args) {
        int[] nums = {10, 20, 30, 40, 50};
        System.out.println(nums.length);
    }
}
```

输出结果为：

```java
5
```

这里要特别注意，`length` 是**属性**，不是方法，因此写法是 `数组名.length`，而不是 `数组名.length()`。

> **易错点：** 数组使用的是 `length` 属性；后面学习字符串时会遇到 `length()` 方法，两者不要混淆。

#### 数组遍历

所谓遍历，就是把数组中的元素一个一个取出来处理。遍历数组最常见的方式是使用 `for` 循环，因为数组索引是有规律的，正好适合循环控制。

```java
public class Test {
    public static void main(String[] args) {
        int[] scores = {88, 92, 76, 95};

        for (int i = 0; i < scores.length; i++) {
            System.out.println("第" + (i + 1) + "个成绩是：" + scores[i]);
        }
    }
}
```

这段代码中：

1. `i = 0` 表示从第一个索引开始；
2. `i < scores.length` 保证索引不越界；
3. `i++` 表示每次移动到下一个元素。

#### 数组索引的合法范围

数组索引的合法范围是：

```java
0 ~ 数组长度 - 1
```

例如，一个长度为 `5` 的数组，合法索引就是 `0`、`1`、`2`、`3`、`4`。

如果访问了不存在的索引，就会抛出 **数组索引越界异常**：`ArrayIndexOutOfBoundsException`。

例如：

```java
public class Test {
    public static void main(String[] args) {
        int[] nums = {10, 20, 30};
        System.out.println(nums[3]);
    }
}
```

这里数组长度为 `3`，合法索引只有 `0`、`1`、`2`，访问 `nums[3]` 就越界了。

> **注意：** 判断数组是否越界时，不要看“第几个元素”，而要看“索引是否在合法范围内”。

#### 数组的默认初始化

使用**动态初始化**创建数组时，如果没有手动赋值，那么数组元素会自动带有默认值。不同类型数组的默认值不同，这是 Java 为了保证数组创建后每个位置都有确定内容而做的统一处理。

默认值规则如下：

| 数组元素类型                   | 默认值   |
| ------------------------------ | -------- |
| `byte`、`short`、`int`、`long` | `0`      |
| `float`、`double`              | `0.0`    |
| `char`                         | `\u0000` |
| `boolean`                      | `false`  |
| 引用数据类型                   | `null`   |

示例

```java
public class Test {
    public static void main(String[] args) {
        int[] nums = new int[3];
        double[] prices = new double[2];
        boolean[] flags = new boolean[2];
        String[] names = new String[2];

        System.out.println(nums[0]);    // 0
        System.out.println(prices[0]);  // 0.0
        System.out.println(flags[0]);   // false
        System.out.println(names[0]);   // null
    }
}
```

这里虽然没有手动给数组元素赋值，但每个位置都已经有默认值。
