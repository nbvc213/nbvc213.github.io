## 面向对象概述

**面向对象**是一种组织和理解软件系统的思想。学习它之前，先要明确：软件开发中常见的两种基本思路是**面向过程**和**面向对象**。前者强调“按步骤完成事情”，后者强调“由哪些对象协作完成事情”。

### 软件开发方法

通常的软件开发方法主要包括两种：**面向过程**（Procedure Oriented，PO）与**面向对象**（Object Oriented，OO）。

它们都能解决问题，但**关注点不同**：

- **面向过程**：关注“做事的步骤”；
- **面向对象**：关注“谁来做这件事”。

这种区别看起来只是思考方式不同，但在实际开发中，会直接影响程序的结构、扩展性和维护难度。

#### 面向过程

**面向过程**是一种以“过程”或“步骤”为中心的开发思想。它会先分析解决问题需要经过哪些步骤，再把这些步骤依次写出来，最后按顺序执行。

`Procedure Oriented` 可以直译为“面向过程”。这类思想在早期程序设计中非常常见，**C 语言**就是典型代表。

面向过程解决问题时，通常遵循这样的思路：

1. 先确定要完成什么功能；
2. 再把这个功能拆分成若干个具体步骤；
3. 然后用函数或语句把每一步实现出来；
4. 最后按照顺序调用这些步骤，完成整个任务。

例如，假设要开发一个“计算学生总成绩并判断是否及格”的程序，若采用面向过程的思路，往往会这样考虑：

1. 输入语文、数学、英语成绩；
2. 计算总分；
3. 计算平均分；
4. 判断是否及格；
5. 输出结果。

此时，程序关注的重点是：**先做什么，后做什么，每一步如何衔接**。

这种方式的优点是**直观、简单、容易上手**，尤其适合处理**步骤固定、流程清晰、规模较小**的问题。但它也有明显局限：当系统越来越复杂时，程序会越来越依赖一连串流程和函数；一旦需求变化，往往需要修改很多地方，代码之间也容易互相牵连。

#### 面向对象

**面向对象**是一种以“对象”为中心的开发思想。它不再优先思考“先写哪一步”，而是先分析：**这个系统中有哪些对象，每个对象负责什么行为，对象之间如何协作**。

`Object Oriented` 即“面向对象”。在这一思想下，程序更像是在描述一个由多个角色共同工作的系统。**Java、C#、Python** 等语言都广泛采用面向对象思想。

在面向对象领域，常见的三个缩写如下：

| 缩写    | 全称                        | 含义                                                       |
| ------- | --------------------------- | ---------------------------------------------------------- |
| **OOA** | Object Oriented Analysis    | **面向对象分析**，分析系统中有哪些对象、对象之间有什么关系 |
| **OOD** | Object Oriented Design      | **面向对象设计**，设计对象的职责、结构和协作方式           |
| **OOP** | Object Oriented Programming | **面向对象编程**，把前面的分析和设计真正落地为代码         |

面向对象解决问题时，通常遵循这样的思路：

1. 先确定系统中有哪些对象；
2. 再明确每个对象负责什么事情；
3. 然后让对象之间彼此协作；
4. 最终完成整个系统功能。

例如，假设要开发一个“图书借阅系统”，若采用面向对象的思路，就不会只盯着“借书步骤”，而会先看到系统中的几个核心对象：`读者`、`图书`、`管理员`、`借阅记录`。
 其中：

- `读者`对象可以发起借书、还书请求；
- `图书`对象需要记录是否在馆、是否已借出；
- `管理员`对象可以办理借阅和归还；
- `借阅记录`对象负责保存借书时间、归还时间等信息。

这样一来，程序的重点就不再只是“先执行 A，再执行 B”，而是变成：**哪个对象负责什么行为，哪些对象需要互相配合**。

之所以说面向对象更适合复杂系统，是因为现实世界本身就是由许多“对象”和“角色”构成的。人类在理解现实问题时，往往天然会从“参与者”出发，而不是只从“固定步骤”出发。因此，当系统变复杂时，面向对象通常更符合人的思维习惯。

#### 面向对象为什么更适合复杂开发

面向对象的一个重要优势是：**耦合度相对较低，扩展能力通常更强**。

所谓**耦合度低**，可以简单理解为：模块之间不要绑得太死。一个对象只负责自己的事情，别的对象只通过明确的方式来使用它。这样即使某一部分发生变化，也不至于把整个系统都牵扯进去。

例如，在一个“在线购物系统”中，可以把 `商品`、`购物车`、`订单`、`支付方式` 设计成不同对象。
 假设后期系统要新增“微信支付”功能，如果原来的支付逻辑是按对象独立设计的，那么通常只需要新增一个新的支付对象，或者扩展支付模块，而不必把订单、购物车、商品等大量代码全部重写。

这就是面向对象中常说的**扩展性较好**：系统中的某个部分需要变更时，往往可以只调整相关对象，而不必推翻整体结构。

> **补充：** 面向对象并不表示程序里完全没有“过程”。程序运行时仍然有执行流程，只是这种流程不再是整个系统唯一的组织核心，而是建立在“对象分工与协作”之上的。

#### 面向过程与面向对象的区别

| 对比项           | 面向过程                           | 面向对象                         |
| ---------------- | ---------------------------------- | -------------------------------- |
| **关注点**       | 做事的步骤                         | 参与完成任务的对象               |
| **核心思路**     | 先分析流程，再逐步实现             | 先分析对象，再组织协作           |
| **适合场景**     | 简单、固定、线性的流程             | 复杂、可扩展、角色较多的系统     |
| **程序组织方式** | 以函数、步骤为中心                 | 以对象、职责为中心               |
| **扩展性**       | 一般较弱，改动时容易牵一发而动全身 | 一般较强，便于局部修改和功能扩展 |
| **代表语言**     | C 语言                             | Java、C#、Python 等              |

### 面向对象三大特征

面向对象之所以能够更好地描述复杂系统，核心就在于它提供了三种重要机制：**封装**、**继承**、**多态**。这三者不是彼此孤立的概念，而是面向对象程序设计中组织代码、复用功能、增强扩展性的基础。

面向对象的三大特征包括：**封装**（Encapsulation）、**继承**（Inheritance）和**多态**（Polymorphism）。

现阶段先对这三个特征建立整体认识即可：

- **封装**：把对象的属性和方法组织在一起，并尽量隐藏内部细节，只对外暴露必要的使用方式。
- **继承**：让一个类在已有类的基础上继续扩展，复用原有内容。
- **多态**：同一种行为在不同对象上可以表现出不同效果。

### 类与对象

学习面向对象时，**类**和**对象**是最核心的两个概念。可以先抓住一句话：

> **结论：类是模板，对象是根据模板创建出来的具体个体。**

例如，现实中有很多“学生”，虽然每个学生具体情况不同，但他们通常都有一些共性，如姓名、年龄、性别，也都可能具有学习、吃饭、休息等行为。把这类共同特征提取出来，就可以形成一个“学生类”；而某一个具体的学生，则是这个类创建出的对象。

#### 类

**类**是对一类事物共同特征的抽象描述，本质上是一个**模板**。

所谓“共同特征”，通常包括两部分：

- **状态**，即这个事物“有什么”；
- **行为**，即这个事物“能做什么”。

在 Java 中：

- **状态**通常用**属性**表示，属性本质上就是定义在类中的变量；
- **行为**通常用**方法**表示，方法用于描述对象能够执行的动作。

因此，可以把类理解为：

**类 = 属性 + 方法**

例如，定义一个“学生类”时，可以抽取出这类对象的共性：

- 姓名、年龄、性别，这些属于**属性**；
- 学习，这属于**方法**。

也就是说，类并不是现实中某一个具体存在的人，而是人脑对“这一类对象共同点”的归纳和抽象。

> **注意：** 类是**抽象概念**，它描述的是“这一类对象长什么样、能做什么”，而不是某一个真实存在的个体。

例如，对于“学生”来说：

- `name`、`age`、`gender` 表示学生的状态；
- `study()` 表示学生的行为。

#### 对象

**对象**是根据类创建出来的、实际存在的具体个体。

在 Java 中，对象也常称为**实例**（instance）。“实例”这个词可以理解为：**类这个模板被真正创建出来后的具体结果**。

例如，`Student` 是一个类，它只是一个模板；而“张三这个学生”“李四这个学生”则是具体对象。它们都来自同一个类，所以都具有同样的属性结构和方法结构，但每个对象内部保存的数据可以不同。

比如：

- 某个学生对象的姓名可能是 `"张三"`；
- 另一个学生对象的姓名可能是 `"李四"`。

它们都有 `name` 这个属性，但属性值不同。像这种“每个对象各自拥有一份”的属性，就称为**实例变量**。

#### 类与对象的关系

类和对象的关系，可以用“图纸与实物”来理解：

- **类**像一张设计图纸，只规定“应该有哪些部分”；
- **对象**像按照图纸造出来的具体实物，是真正可以使用的个体。

例如，`Student` 类规定了学生应该有 `name`、`age`、`gender` 这些属性，也规定了学生可以执行 `study()` 这个方法；而通过这个类创建出来的每一个学生对象，都会具有这些成员，只是各自的数据不同。

### 实例变量与实例方法

当属性和方法是“属于某个对象本身”的时候，它们分别称为**实例变量**和**实例方法**。

#### 实例变量

定义在类中、并且每个对象各自拥有一份的数据，称为**实例变量**。

例如，学生类中有 `name` 属性。
 当创建两个学生对象时：

- 第一个对象的 `name` 可以是 `"张三"`；
- 第二个对象的 `name` 可以是 `"李四"`。

虽然它们都来自同一个类，也都具有 `name` 这个属性，但每个对象保存的是**自己的那一份值**。这就是实例变量的特点。

#### 实例方法

定义在类中、供对象调用的方法，称为**实例方法**。

例如，学生都有“学习”这个行为，因此可以在 `Student` 类中定义 `study()` 方法。只要创建了某个学生对象，就可以让这个对象去调用 `study()`。

> **注意：访问实例变量、调用实例方法，都必须先有对象。**因为“实例”本来就表示“属于某个对象的内容”，没有对象，就谈不上访问该对象的数据或行为。

下面是一个典型的“学生类”定义：

```java
package com.jkweilai.p01;

/**
 * 学生类
 */
public class Student {
    // 属性（实例变量）
    String name;
    int age;
    boolean gender;

    // 方法（实例方法）
    public void study() {
        System.out.println("学生在学习...");
    }
}
```

这段代码中包含了一个最基本的类结构：

1. `Student` 是一个**类名**，表示学生这一类对象；
2. `name`、`age`、`gender` 是学生对象的**属性**，用于描述状态；
3. `study()` 是学生对象的**方法**，用于描述行为。

#### 为什么必须先创建对象，才能访问实例成员

这是初学面向对象时非常容易忽略的一点。

实例变量和实例方法都属于“某一个具体对象”。而类只是模板，本身不是某个具体学生，因此不能直接把“某个学生的姓名”或“某个学生正在学习”强行附到模板上。

例如，“姓名”一定是某个具体学生的姓名，而不是“学生类”这个抽象概念本身的姓名。同理，“学习”这个动作，也必须是某个具体学生在学习，而不是“模板在学习”。

所以，程序设计上必须先通过类创建对象，再通过对象去访问属于它的实例成员。

可以这样理解：

- **类**只负责规定“有什么”；
- **对象**才真正持有这些数据，并执行这些行为。

### 对象的创建和使用

前面已经认识了**类**和**对象**的基本含义，接下来要进一步掌握：在 Java 中，类是如何定义的，对象是如何创建的，以及创建出来之后如何访问对象的属性和方法。

#### 类的定义

类是对象的模板，因此在创建对象之前，必须先定义类。定义类的基本语法格式如下：

```java
[修饰符列表] class 类名 {
    // 属性（描述状态）

    // 方法（描述行为）
}
```

这里需要先掌握以下几点：

1. `class` 是定义类的关键字；
2. `类名` 是这个类的名字，用来标识这一类对象；
3. 类的大括号内部可以写**属性**和**方法**；
4. **属性**用于描述对象的状态，**方法**用于描述对象的行为；
5. 前面的“修饰符列表”是可选的，现阶段最常见的是 `public`。

下面是一个学生类的定义示例：

```java
public class Student {
    // 属性（实例变量）
    String name;
    int age;
    boolean gender;

    // 方法（实例方法）
    public void study() {
        System.out.println("正在学习");
    }
}
```

#### 对象的创建

类定义好之后，就可以根据类来创建对象。创建对象的基本语法如下：

```java
类名 对象名 = new 类名();
```

例如：

```java
Student s = new Student();
```

这行代码表示：根据 `Student` 类创建一个学生对象，并用变量 `s` 来接收它。

这句代码虽然很短，但实际包含三个层面的含义：

1. `Student` 表示变量 `s` 的数据类型是 `Student`；
2. `new Student()` 表示创建一个新的 `Student` 对象；
3. `=` 表示把创建出来的对象交给变量 `s` 保存。

这里要特别注意一个容易混淆的地方：**`s` 不是对象本身，而是一个引用变量。**

因为使用 `class` 定义出来的类型都属于**引用数据类型**，所以 `Student` 是引用数据类型，`s` 是一个 `Student` 类型的变量。这个变量中保存的是对象的引用信息，可以粗略理解为：**`s` 指向了这个学生对象**。

#### 对象的使用

对象创建完成之后，就可以使用它。对象的使用主要包括三类操作：

1. **读取属性值**
2. **修改属性值**
3. **调用对象的方法**

它们都通过“点”的方式完成，也就是 **`.` 运算符**。

##### 读取属性值

读取属性值的语法格式如下：

```java
对象名.属性名
```

例如：

```java
s.name
s.age
s.gender
```

这表示读取对象 `s` 中对应属性当前保存的值。

##### 修改属性值

修改属性值的语法格式如下：

```java
对象名.属性名 = 值;
```

例如：

```java
s.name = "Jack";
s.age = 20;
s.gender = true;
```

这表示把新的值赋给对象 `s` 的对应属性。

##### 调用方法

调用对象方法的语法格式如下：

```java
对象名.方法名();
```

例如：

```java
s.study();
```

这表示让对象 `s` 执行 `study()` 方法。

> **注意**：当对象刚被创建出来，而实例变量还没有手动赋值时，Java 会为它们自动提供默认值。**只有成员变量（实例变量）才有默认值，局部变量没有默认值。**例如，方法内部自己定义的变量，必须先赋值后使用，否则会报错。

#### 一个类可以创建多个对象

同一个类可以实例化出多个对象。每个对象都拥有相同的属性和方法结构，但各自保存的数据彼此独立。

例如：

```java
Student s1 = new Student();
Student s2 = new Student();
```

这表示根据同一个 `Student` 类创建了两个学生对象。

虽然 `s1` 和 `s2` 都有 `name`、`age`、`gender` 这些属性，也都可以调用 `study()` 方法，但它们互不影响。比如：

```java
s1.name = "张三";
s2.name = "李四";
```

此时：

- `s1.name` 是 `"张三"`；
- `s2.name` 是 `"李四"`。

这说明：**实例变量是“每个对象各自拥有一份”的数据。**

可以把它理解为：类只规定“学生都有姓名”，但并没有规定“所有学生姓名都一样”。真正创建出不同对象后，每个对象的属性值可以各不相同。

#### 为什么不能直接写变量名访问实例变量

在测试类的 `main` 方法中，如果直接写：

```java
System.out.println(name);
```

这是不可以的。因为 `name` 是 `Student` 对象中的实例变量，而不是 `main` 方法中的局部变量。`main` 方法本身并没有定义名为 `name` 的变量，所以编译器找不到它。

正确写法必须通过对象访问：

```java
System.out.println(s1.name);
```

因为这里的 `name` 明确属于对象 `s1`。

这再次说明：**实例变量不属于当前方法本身，而属于某个对象。**

#### 为什么不能用类名访问实例变量和实例方法

下面这样的写法也是错误的：

```java
System.out.println(Student.name);
Student.study();
```

原因是：

- `name` 是**实例变量**，属于某个具体对象；
- `study()` 是**实例方法**，也属于某个具体对象。

而 `Student` 只是类名，表示模板，不表示某个具体学生对象。因此不能直接用类名去访问实例成员。

正确方式应该是：

```java
Student s = new Student();
System.out.println(s.name);
s.study();
```

> **注意：** **实例变量**和**实例方法**必须通过对象访问，不能直接通过类名访问。后面学到 `static` 之后，才会接触“可以通过类名访问的成员”。
