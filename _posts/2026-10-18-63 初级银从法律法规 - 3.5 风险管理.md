## 第一章、风险管理：风险概述与全面风险管理

*先认识风险的内涵与分类，再掌握全面风险管理的框架、风险偏好、策略、组织架构和管理流程；随后分别学习各类风险的分类及管控。阅读时区分风险类型、管理职责、流程环节与控制措施。*

### 一、风险的内涵与分类

#### 风险的内涵

**风险是银行在经营过程中，由于一系列不确定因素的影响，导致资产和收益损失的可能性。**

风险的内涵包括两个方面：

1. **强调结果的不确定性。**
2. **强调不确定性带来的不利后果。**

| 表述 | 判断理由 |
| --- | --- |
| 风险是损失的可能性 | 符合风险定义 |
| 风险就是已经发生的损失 | 混淆风险与损失结果 |
| 风险是未来确定发生的损失 | 忽略结果的不确定性 |
| 只要结果不确定，就完整表达了银行风险 | 未体现不利后果 |

> 解释：这里的关键词是“可能性”。风险不是已经发生的损失，也不能简单表述为将来必然发生的损失。理解银行风险时需要同时保留不确定性与不利结果这两个要素。

#### 八类风险

银行主要面临**信用风险、市场风险、操作风险、流动性风险、国别风险、声誉风险、法律风险、战略风险**。其中，法律风险属于操作风险。

| 风险类型 | 核心内容 | 识别关键词 |
| --- | --- | --- |
| 信用风险 | 商业银行面临的主要风险，存在于贷款业务、担保、承兑、证券投资等活动中 | 违约、不履约、授信业务 |
| 市场风险 | 市场价格变化带来的风险，主要表现为利率风险和汇率风险 | 利率、汇率、股票价格、商品价格波动 |
| 操作风险 | 人员、程序、系统及外部事件等因素造成的风险 | 人员问题、程序缺陷、系统故障、外部事件 |
| 流动性风险 | 无法在合理成本下及时获得资金，通常被视为综合性风险 | 资金不足、支付困难、挤兑 |
| 国别风险 | 发生在国际经济金融活动中，政府、银行、企业和个人都可能受到影响 | 国家或地区因素、跨境活动 |
| 声誉风险 | 银行行为、从业人员行为或外部事件等导致利益相关方、媒体等形成负面评价 | 负面评价、市场信任受损 |
| 法律风险 | 一种特殊类型的操作风险 | 法律责任、合同、违法违规 |
| 战略风险 | 战略目标、战略制定、资源配置与实施质量方面的问题 | 目标不兼容、战略缺陷、资源匮乏、执行偏差 |

> *补充：上表列举了八类风险，不代表全面风险管理只需关注这八个名称；同一事件也可能引发多种风险，分类不等于切断风险之间的联系。*

#### 信用风险与市场风险

**信用风险是商业银行面临的主要风险**，存在于贷款、担保、承兑、证券投资等活动中。

市场风险涉及**利率、汇率、股票价格、商品价格**的变化，商业银行主要面临**利率风险和汇率风险**。

> 解释：
>
> - 例如，贷款客户未能按约履行义务，银行可能遭受损失。因此，信用风险不能只理解为“贷款不归还”，还应关注其他业务中交易对手不履约的情况。
> - 市场价格变化可能影响银行资产、负债或相关业务的收益与价值。利率风险、汇率风险是主要表现，不表示股票和商品价格变化永远不会形成银行的市场风险。

#### 操作风险与法律风险

**操作风险包括法律风险，但不包括战略风险和声誉风险。**法律风险是一种特殊类型的操作风险。

| 关系 | 应如何记忆 |
| --- | --- |
| 法律风险与操作风险 | 法律风险包含在操作风险中 |
| 战略风险与操作风险 | 战略风险不属于操作风险的定义范围 |
| 声誉风险与操作风险 | 声誉风险不属于操作风险的定义范围 |
| 操作事件与声誉影响 | 操作事件可能引发声誉影响，但不改变上述分类边界 |

> 解释：
>
> - 操作风险与内部人员、程序、信息科技系统及外部事件等因素有关。例如，系统故障、程序设置不当、人员问题和欺诈等。
> - **易混点是风险之间的联系与风险定义的包含关系。**人员行为可能同时造成操作损失和负面评价，但不能据此认为声誉风险属于操作风险。
>
> *补充：现行《银行保险机构操作风险管理办法》保留“包括法律风险，但不包括战略风险和声誉风险”的边界。法律风险不能只理解为员工违法：还可能涉及合同被撤销或无效、诉讼或仲裁赔偿责任等。*

#### 流动性风险

流动性风险是商业银行无法在一定时间内、以合理成本获得所需资金的风险，通常被视为**综合性风险**。

> 解释：银行挤兑是典型情形。其他风险可能造成资金短缺，流动性问题也可能进一步引发其他风险，因此不能只从某一笔资产或单一业务理解流动性风险。

#### 国别风险

国别风险具有以下特点：

- **发生在国际经济金融活动中。**
- 不论是政府、银行、企业还是个人，都可能遭受国家风险带来的损失。

> 解释：在国际金融往来中，对方国家或地区的相关变化可能带来风险。国别风险不能简单等同于“境外客户自己违约”，还需要关注该国家或地区的政治、经济、社会环境及相关事件。
>
> *补充：现行国别风险管理规定包括国家或地区变化导致债务人不能或拒绝偿付、银行在当地的商业存在遭受损失等情形，也列有间接国别风险。因此，“国际活动”这一限定不能扩大成“没有直接跨境交易，就绝不可能受国别因素影响”。重点仍是国家或地区因素与国际业务的关联。*

#### 声誉风险

**声誉风险与利益相关方、社会公众、媒体等对银行形成负面评价有关。**银行行为、从业人员行为和外部事件都可能引发这种影响。

> 解释：识别时应抓住“负面评价”，而不是只记某一种事件来源。人员问题是操作风险的一个来源，但声誉风险关注的是事件引发的评价与信任影响，两者侧重点不同。

#### 战略风险

战略风险主要有四类来源：

1. **战略目标缺乏整体兼容性。**
2. **制定的经营战略存在缺陷。**
3. **所需要的资源匮乏。**
4. **实施过程中的质量难以保证。**

> 解释：可以理解为目标与实际经营脱节、战略本身有问题、资源不足或实施质量不高，导致战略无法有效执行。

#### 风险的关联

各类风险可能**相互影响、传导和转化**。

> 解释：各类风险往往不是独立存在的。正因为存在这些联系，银行需要对风险进行全面管理，而不能只在某个业务或部门内分别处理。

### 二、全面风险管理的框架与原则

#### 相关框架与制度背景

国际全面风险管理框架主要包括：

- 美国反虚假财务报告委员会相关组织 **COSO** 发布的全面风险管理框架 **ERM**。
- 巴塞尔委员会发布的巴塞尔资本协议。

国内方面，原中国银监会于 **2016 年**发布《银行业金融机构全面风险管理指引》，对银行业金融机构建立全面风险管理体系提出系统要求。

> 解释：风险管理从信用风险管理起步，逐步加强流动性、市场等风险管理，再发展到全面风险管理，管理视角不断扩展。
>
> *补充：COSO 的 ERM 框架曾于 2017 年更新，强调与战略和绩效相结合。理解制度背景时，应注意区分 COSO 框架的不同版本。*

#### 全面风险管理的整体框架

| 方面 | 具体内容 | 核心问题 |
| --- | --- | --- |
| 公司治理与组织架构 | 董事会、高管层责任与履职；首席风险官的设置、责任与保护；风险管理职能部门的授权、资源配置与独立性；三道防线；自我约束、自我纠错机制 | 谁负责，如何分工和制衡？ |
| 基本要素框架 | 风险文化、风险策略、风险偏好、风险限额、风险政策和流程、压力测试、应急安排、管理信息系统 | 用什么制度、方法和工具管理？ |
| 风险管理的实际应用 | 结果应用于日常管理，与流动性和资本挂钩，并在新业务审批、内部定价、绩效考评等活动中考虑风险 | 管理结果是否进入经营决策？ |

> 解释：
>
> - 可以用“人、制度、实施”理解上表的三个方面：治理架构明确谁负责，基本要素明确用什么管理，实际应用强调管理结果进入经营决策。
> - **全面风险管理不能只停留在设部门或写制度，还应将风险管理结果用于实际经营管理。**例如，新业务审批需要考虑风险，内部定价需要反映风险，绩效评价也不能只看业务收入。

#### 全面风险管理的四项原则

全面风险管理遵循**匹配性、全覆盖、独立性、有效性**四项原则。

| 原则 | 主要含义 | 理解方式 |
| --- | --- | --- |
| 匹配性原则 | 管理安排与经营情况、风险状况相适应 | 面临什么风险，就配置相应管理能力 |
| 全覆盖原则 | 风险管理覆盖各业务、人员、部门、岗位和机构等 | 不留管理死角 |
| 独立性原则 | 风险管理具有独立的职责、组织与管理安排 | 专业管理职能应发挥独立作用 |
| 有效性原则 | 管理政策合理有效，并得到有效实施 | 制度本身有效，执行也有效 |

> *补充：这四项原则是全面风险管理原则，不要与内部控制原则直接混用。独立性也不表示风险管理部门可以脱离业务信息、无需协作。*

### 三、风险偏好、风险战略与风险文化

#### 风险偏好

**风险偏好是商业银行在追求实现战略目标的过程中，愿意承担的风险类型和总量。**它是统一全行经营管理和风险管理的认知标准，也是风险管理的基本前提。

风险偏好框架涉及五个相互联系的方面：**偏好、风险承受力、容忍度、风险目标或范围、限额。**

| 内容 | 理解 | 复习重点 |
| --- | --- | --- |
| 偏好 | 愿意承担什么样的风险 | 关注风险选择与意愿 |
| 风险承受力 | 用“愿意承受多少”帮助理解可承担的风险水平 | 不能与意愿完全混同 |
| 容忍度 | 对相关结果或风险偏离能否接受 | 与可接受程度有关 |
| 风险目标或范围 | 风险管理希望达到的目标或范围 | 将总体要求明确化 |
| 限额 | 对各主体、业务等设置具体额度限制 | 将风险管理要求落实到具体层面 |

> 解释：风险偏好关注两个问题：**愿意承担什么类型的风险，愿意承担多少风险。**
>
> *补充：风险偏好是“愿意承担”，风险承受能力是受资本、流动性和管理资源等约束的“能够承担”；风险偏好应在承受能力范围内设定。风险限额是将总体偏好分解到业务、机构或风险类型的具体约束。*
>
> *补充：不同框架对容忍度等术语的用法可能不同，上述五项内容相互联系，不表示它们是五个互不交叉、简单相加的数值。*

#### 风险战略

**风险战略是银行为实现总体发展目标而制定的一系列风险管理目标和方针政策，为整个银行的发展战略提供保障。**

风险战略分为三种类型：

| 类型 | 风险与收益取向 | 特点 |
| --- | --- | --- |
| 进取型 | 愿意承担较高风险，以争取较高收益 | 风险承担较积极 |
| 稳健型 | 在风险与收益之间保持匹配 | 不冒进，同时关注经营收益 |
| 保守型 | 更注重降低风险承担 | 接受相对较低的收益目标 |

> 解释：**风险战略说明总体目标和方向，风险策略则说明如何应对具体风险。**两者不能只因名称接近而混用。
>
> *补充：“高风险争取高收益”表示经营取向和预期要求，不表示风险越高就必然获得越高的实际收益。*

#### 风险文化

**风险管理文化又称风险文化**，融合银行经营思想、风险管理理念、风险管理行为、风险控制标准和风险管理环境等要素，是银行企业文化的重要组成部分，也是稳健经营与可持续发展的基础。

风险文化根据金融稳定委员会 **FSB** 的相关内容归纳为七项要求：

1. 健全的风险治理框架。
2. 在风险偏好内成功执行战略。
3. 薪酬激励体系与员工的风险表现挂钩。
4. 高层的榜样示范。
5. 被员工认可的个人风险责任。
6. 内部沟通中的开放性与可挑战性。
7. 风险文化受到财务和非财务激励机制支持。

> 解释：风险文化要贯穿思维与行为规范，并通过高层示范、员工认可、沟通渠道和考核激励落实，不能只停留在口号中。
>
> *补充：“可挑战性”指允许对现有判断、假设和做法提出建设性质疑与不同意见，并非鼓励无视职责或制度。教材七项归纳结合了 FSB 风险文化基础要素和观察指标，不能直接当作该文件唯一、固定的七项分类。*

### 四、风险控制的五种策略

风险控制可以采用**风险分散、风险对冲、风险转移、风险规避、风险补偿**五种策略。

#### 风险分散

风险分散强调避免业务或风险过度集中。

> 解释：
>
> - 例如，信贷业务不应集中于同一业务、同一性质，甚至同一个借款人。
> - 可以用“不要把鸡蛋放在一个篮子里”帮助记忆，并联系集中度和限额管理：通过限制某个主体或某类业务的风险暴露，分散集中风险。
>
> *补充：分散不能仅看客户或产品数量，还要注意风险之间的相关性；它也不能保证所有风险被消除。集中度比例应结合具体指标的适用对象和计算口径理解。*

#### 风险对冲

**风险对冲分为自我对冲和市场对冲。**

| 类型 | 对冲方式 | 理解与例子 |
| --- | --- | --- |
| 自我对冲 | 利用资产负债表或某些具有收益负相关性质的业务组合本身的对冲特性 | 通过资产与负债、相关业务安排进行匹配 |
| 市场对冲 | 对无法通过资产负债表及相关业务调整实现自我对冲的风险，利用衍生产品市场进行对冲 | 远期、期货及套期保值等市场安排 |

> 解释：自我对冲可以用存款与贷款的安排帮助理解，通过内部资产负债或业务组合匹配抵消部分风险；市场对冲则利用远期、期货等衍生产品。
>
> *补充：不能据此认定任意一笔存款和贷款天然具有完整对冲效果。实际效果还取决于重定价、期限、金额、币种等条件；对冲也可能留下基差、交易对手等风险。*

#### 风险转移

**风险转移可分为保险转移和非保险转移。**

- **保险转移**：通过购买保险，将相关风险按合同安排由保险机构承担。
- **非保险转移**：通过保证、抵押、质押等安排，在借款人不能履约时，通过其他责任主体或担保财产获得风险缓释。

> *补充：教材中的担保例子属于简化讲解。保证可以引入第三方履约责任；抵押、质押主要提供担保财产和受偿保障，并不等同于所有风险都转给另一主体。保险和担保的作用均取决于合同效力、赔付或执行条件，不能理解为无条件足额回收。*

#### 风险规避

风险规避通过不开展或退出相关业务，避免承担该项业务带来的风险。

风险规避是**一种消极的风险管理策略，不宜成为风险管理的主导策略**。

> 解释：例如，银行认为某项业务风险过高，可以选择不做。银行仍需要在风险管理基础上开展经营，不能以完全回避所有风险代替管理。
>
> *补充：不宜作为主导策略，不意味着任何情况下都不能规避；对不符合风险偏好或不具备管理条件的业务，规避可以是适当选择。*

#### 风险补偿

**风险补偿是通过提高风险回报，获得承担风险的价格补偿。**

> 解释：例如，承担较高信用风险时，可能要求较高利率，以补偿风险承担。
>
> *补充：提高利率并不直接消除违约风险，也不意味着只要价格足够高，就可以接受任何风险。风险补偿需要与风险识别、承受能力和业务约束共同考虑。*

**五种策略对照**

| 策略 | 识别关键词 |
| --- | --- |
| 分散 | 不集中、分布到不同业务或主体 |
| 对冲 | 负相关、抵消、资产负债匹配、衍生产品 |
| 转移 | 保险、第三方责任、合同安排 |
| 规避 | 不做、退出、避免承担相关风险 |
| 补偿 | 提高回报、风险溢价、价格补偿 |

> 真题示例
>
> **【2025 年单项选择题】下列不属于风险控制措施的是（　）。**
>
> A. 风险转移  
> B. 风险识别  
> C. 风险分散  
> D. 风险对冲
>
> **答案：B。**
>
> 解释：
>
> - 风险控制措施包括分散、对冲、转移、规避、补偿。风险识别是风险管理流程中的基础环节，不能与控制措施混在同一类别中。
> - **A 项**：五种策略之一。
> - **B 项**：属于风险管理流程环节。
> - **C 项**：通过避免集中来管理风险。
> - **D 项**：利用匹配或相关工具抵消相关风险影响。

### 五、风险管理的组织架构

#### 治理层级与职责

银行根据经营环境、制度和风险管理要求设置组织架构，主要包括董事会及其下设委员会、监事会、高级管理层、风险管理部门和其他风险控制部门等。

| 层级 | 职责 | 关键词 |
| --- | --- | --- |
| 董事会 | 最高风险管理和决策机构，承担风险管理最终责任；审批相关策略、政策和程序，确定可承受的总体风险水平 | 决策、最终责任 |
| 监事会 | 监督董事会和高级管理层是否尽责，对风险承担水平及体系有效性进行独立监督、评价 | 监督、评价 |
| 高级管理层 | 风险管理执行机构；执行政策，在授权范围内作决策，建立体系，组织管理并识别、计量、监测、控制风险 | 执行、组织落实 |
| 风险管理及相关部门 | 按职责具体实施专业风险管理与控制工作 | 专业管理、具体实施 |

> 解释：
>
> - **风险管理委员会**是董事会下设的专门委员会，记忆时应放在董事会的专门委员会层级，不要与高级管理层或独立风险管理部门混为一谈。
> - **董事会承担最终责任，不表示董事会亲自完成每一项日常管理；高级管理层负责执行，也不替代董事会的最终责任。**
>
> *补充：上表采用设有监事会的治理架构。根据公司法衔接规定，部分金融机构可由董事会下设审计委员会履行监事会职责、不设监事会或监事；具体设置需结合适用规则和章程，不能把教材架构理解为所有银行均须保持同一种组织形式。*

#### 三道防线

风险管理的三道防线依次是**业务团队、风险管理团队、内部审计团队**。

| 防线 | 团队 | 职责 | 重点记忆 |
| --- | --- | --- | --- |
| 第一道 | 业务团队 | 识别、评估、缓释和监控各自业务领域风险，对管理和控制经营活动承担的风险负首要、直接责任 | 风险首先由业务承担和管理 |
| 第二道 | 风险管理团队 | 建立风险政策制度体系，提供专业咨询与指导，通过风险偏好和限额等监控、评估和管理全行风险 | 专业管理与全行统筹 |
| 第三道 | 内部审计团队 | 对全行风险管理体系有效性进行监督和评估 | 独立监督评价 |

> 解释：
>
> - **三道防线不是把风险管理责任全部交给第二道防线。**业务团队不能因为有风险管理部门，就免除自身的首要、直接责任；内部审计也不能代替业务团队日常管理风险。
> - 可以用前台、中台、后台帮助记忆三类团队的作用。
>
> *补充：前中后台是教学上的对应方式，不能据此认定所有银行组织名称完全一致；三道防线也不只是风险依次通过三个部门的单向流程。内部审计不应被理解为只能在损失发生后检查，第二道防线的管理也不能保证系统性风险绝不发生。*

### 六、风险管理的主要流程

风险管理主要包括**风险识别、风险计量、风险监测、风险控制**四个流程。

| 流程 | 主要任务 | 关键词 |
| --- | --- | --- |
| 风险识别 | 感知风险并分析风险，发现风险来源与类型 | 感知、分析、全面性、前瞻性 |
| 风险计量 | 判断风险程度及可能损失，运用适当计量方法 | 风险大小、损失程度、计量方法 |
| 风险监测 | 跟踪关键指标和环节，观察风险变化，建立预警机制并报告 | 跟踪、预警、报告 |
| 风险控制 | 对已经识别和计量的风险采取策略与措施 | 分散、对冲、转移、规避、补偿 |

#### 风险识别

**风险识别包括感知风险和分析风险两个环节。**良好的风险识别应具有全面性和前瞻性。

- **感知风险：**发现风险可能存在。
- **分析风险：**判断风险的来源、类型和相关情况。

> 解释：只有先发现并识别风险，后续计量、监测和控制才能有明确对象。因此，**识别风险是各管理或监管环节的基础**。

#### 风险计量

风险识别之后，需要判断风险程度和潜在损失。巴塞尔委员会吸收国际先进银行管理经验，针对信用风险、市场风险、操作风险等形成计量方法。

> 解释：联系资本管理中的风险加权资产计量，可以理解风险计量与资本要求之间的关联。这一步回答的是“风险有多大”。

#### 风险监测

风险监测通过对关键风险指标和环节进行监测，关注风险变化程度，并建立预警机制。同时，需要向内外部不同层级报告：

1. 风险的定性、定量评估结果。
2. 已采取的风险管控措施。
3. 措施的质量与效果。

> 解释：风险计量不能代替持续监测。即使最初已经测算风险，后续环境或客户情况变化，仍需要跟踪、预警和报告。

#### 风险控制

**风险控制是对经过识别和计量的风险，采取分散、对冲、转移、规避、补偿等策略和措施，进行有效管理和控制的过程。**

> 解释：风险识别和风险控制有不同任务：识别是找到、判断风险；控制是采用适当措施应对风险。因此，风险识别属于管理流程，但不是五种风险控制措施之一。
>
> *补充：四步流程用于建立逻辑顺序，实际管理中需要持续反馈与更新，不表示每个环节完成一次后就不再回到前面的环节。*

> 真题示例
>
> **【2025 年单项选择题】在风险监管的各个环节中，最基础的是（　）。**
>
> A. 预警风险  
> B. 监测风险  
> C. 识别风险  
> D. 处置风险
>
> **答案：C。**
>
> 解释：
>
> - 风险监管方式的核心是监管当局能够识别、监测、预警和处置风险，**识别风险是各环节的基础**。只有先识别风险，才有后续监测、预警和处置的对象。
> - **A 项**：需要建立在风险识别和监测基础上。
> - **B 项**：需要先明确所监测风险。
> - **C 项**：是各环节的基础。
> - **D 项**：对已发现的风险采取应对措施。
> - **审题时注意：**本题问的是监管环节，选项不是前面四步流程的原样排列，但“识别是基础”的逻辑一致。

## 第二章、风险管理：信用风险的分类与管控

*先按不同依据区分信用风险，再掌握准入退出、限额、缓释和定价四项管控手段。*

### 一、信用风险的分类

| 分类依据 | 分类结果 | 理解重点 |
| --- | --- | --- |
| 风险能否分散 | 系统性信用风险、非系统性信用风险 | 是否能够通过分散降低相关风险 |
| 风险发生的形式 | 结算前风险、结算风险 | 与结算过程有关的风险发生阶段 |
| 风险暴露特征和引起风险的主体不同 | 主权、金融机构、零售、公司、股权和其他信用风险暴露 | 根据主体及风险暴露特点区分 |

> 解释：信用风险可以从风险能否分散、风险发生的形式，以及风险暴露特征和主体三个角度分类。不同分类依据回答的问题不同，不能将各类名称直接拼成同一个互不交叉的分类表。

#### 系统性与非系统性信用风险

**系统性信用风险不能通过分散加以消除；非系统性信用风险可以通过分散进行管理。**

> 解释：这里的系统性与非系统性是这一分类依据下的概念，不要与下面的主权、公司等暴露类型混用。

#### 结算前风险与结算风险

信用风险按发生形式分为**结算前风险和结算风险**，分别对应结算之前、结算过程中发生的信用风险。

#### 六类信用风险暴露

信用风险暴露分为六类：

1. 主权信用风险暴露。
2. 金融机构信用风险暴露。
3. 零售信用风险暴露。
4. 公司信用风险暴露。
5. 股权信用风险暴露。
6. 其他信用风险暴露。

其中，**主权信用风险暴露、金融机构信用风险暴露、公司信用风险暴露**统称为**非零售信用风险暴露**。

> 解释：可以用国家、金融机构、个人客户和公司说明前几类风险主体。正式记忆应保留教材名称，而不是仅用主体简称替代暴露分类。
>
> *补充：零售不能无条件等同于“全部个人业务且只有个人业务”。不同监管制度对零售暴露或零售资产有具体条件；例如金融资产风险分类规则中的零售资产还包括符合规定的小微企业债权。六类信用风险暴露分类与后面金融资产分类中的零售、非零售限定，应结合各自口径理解。*

### 二、信用风险的四项管控手段

信用风险管控包括**信贷准入和退出、限额管理、风险缓释、风险定价**四项手段。

| 管控手段 | 具体要求 | 关键词 |
| --- | --- | --- |
| 信贷准入和退出 | 考虑客户信用等级、财务与经营状况、风险调整后收益 RAROC 等；准入审查后仍需持续跟踪和管理退出 | 事前筛选、后续跟踪 |
| 限额管理 | 对单个客户设置风险限额或授信额度，也可按国别或区域、行业、产品类型等组合维度设置 | 单一客户与组合限额 |
| 风险缓释 | 使用合格抵质押品、净额结算、保证、信用衍生工具等方式转移或降低风险 | 合格工具、风险程度下降 |
| 风险定价 | 通过价格覆盖风险承担，并计提相应风险准备，在损失发生时抵补 | 风险回报、准备金 |

#### 信贷准入和退出

**准入关注是否适合开展业务，退出关注已开展业务如何及时收回或处置。**

> 解释：
>
> - 发放贷款前，需要审查客户资质、信用等级、财务与经营状况等。业务发生后，银行还应持续跟踪客户和资产风险变化，及时收回资金，必要时处理不良资产。
> - 因此，信贷风险管理不能在放款后结束，也不能只看客户当前是否愿意借款。

#### 限额管理

限额管理既可以针对**单个客户**，也可以针对**国别或区域、行业、产品类型等组合维度**。单一客户限额用于约束个别客户的风险承担，组合维度限额用于控制集中风险。

> 解释：例如，银行可以为风险情况不同的客户配置不同授信额度；具体额度判断需要结合客户情况及银行风险要求，不能只按某一个风险标签机械决定。

#### 风险缓释

信用风险缓释是银行运用**合格的抵质押品、净额结算、保证和信用衍生工具**等方式，转移或降低信用风险。

其效果可以体现为：

- **违约概率下降。**
- **违约损失率下降。**
- **违约风险暴露下降。**

> 解释：
>
> - 不同工具的作用并不完全相同，不能认为每一种缓释工具都同时使上述三项下降。
> - 可以用第三方保证、抵押或质押财产说明担保作用；用债权债务相互抵销说明净额结算，即按相关净额处理剩余应履行义务。
>
> *补充：净额结算需要有效的协议、法律条件和适用业务范围，不能理解为银行可以自行将客户任何债权债务任意抵销。合格抵质押品和保证也不意味着风险全部消失。*

#### 风险定价与准备

风险较高的业务通常需要相应的风险回报补偿。**预期损失与准备计提相联系，非预期损失与经济资本支持相联系。**

> 解释：例如，银行对信用风险较高的贷款要求较高利率，以取得风险回报补偿；风险定价还需要联系损失准备与经济资本。
>
> *补充：提高贷款利率提供的是价格补偿，不直接消除违约可能性；准备计提与经济资本也不能当成两笔用途相同的现金。定价、拨备和资本支持应与风险管理共同考虑。*

## 第三章、风险管理：金融资产风险五级分类

*先记住五类资产与不良资产的范围，再比较逾期天数、信用减值比例和其他分类条件，最后掌握分类频率与分类迁徙。*

### 一、五类资产与不良资产范围

金融资产按照风险程度划分为**正常类、关注类、次级类、可疑类、损失类**。

**次级类、可疑类、损失类后三类合称不良资产。关注类尚不属于不良资产。**对于贷款，相应后三类构成不良贷款。

| 类别 | 基本理解 | 是否属于不良资产 |
| --- | --- | --- |
| 正常类 | 债务人能够履行合同，能够正常偿付相关款项 | 否 |
| 关注类 | 虽可能仍在履约，但已存在需要关注的不利因素 | 否 |
| 次级类 | 风险已明显恶化，进入不良范围 | 是 |
| 可疑类 | 风险程度进一步加重 | 是 |
| 损失类 | 按相关条件确认最高风险分类 | 是 |

> 解释：不良贷款率和拨备覆盖率都涉及不良贷款口径，但两项指标的分子、分母不同。
>
> *补充：不良贷款率＝不良贷款余额÷各项贷款余额；拨备覆盖率＝贷款损失准备÷不良贷款余额。两个指标不能使用相同的分子分母。*

### 二、分类条件的使用

**符合规定情形之一，即可触发相应分类要求。**

> *补充：关注、次级和可疑的相关条件是“至少归为”该类的最低要求；已经符合更严重分类条件时，不能停留在较轻类别。分类也不能只看逾期天数，还要结合履约能力、信用减值等情况。*

### 三、关注类的四种情形

| 情形 | 分类条件 | 需记住的限定 |
| --- | --- | --- |
| 逾期 | 本金、利息或收益逾期 | 操作性或技术性原因导致的 7 天内短期逾期除外 |
| 用途改变 | 未经商业银行同意，擅自改变资金用途 | 关键是未经同意、擅自改变 |
| 借新还旧 | 通过借新还旧或其他债务融资方式偿还 | 债券、符合条件的小微企业续贷业务除外 |
| 其他债务出现不良 | 同一非零售债务人在本行或其他银行的债务出现不良 | 关注非零售债务人与债务关联情况 |

> 解释：
>
> - 可以用“七天以上”简化记忆关注类的逾期情形，但正式判断应保留原因和期限两个条件。
> - **“7 天内除外”不是所有贷款都有七天宽限期。**教材写明的例外同时包含原因与期限两个条件：操作性或技术性原因，且属于七天内短期逾期。
> - 借新还旧反映偿付来源依赖新的融资，但教材同时保留债券和符合条件的小微企业续贷例外。可以用小微企业连续融资说明支持经营的安排，不能将所有借新还旧一概排除，也不能将所有续贷一概视为正常。
>
> *补充：“七天以上”是对关注类逾期条件的简化说法。不能由此推出普通偿付困难造成的七天内逾期可以自动保持正常类。*

### 四、次级类的四种情形

| 情形 | 分类条件 |
| --- | --- |
| 逾期 | 本金、利息或收益逾期**超过 90 天** |
| 信用减值 | 金融资产已发生信用减值 |
| 评级变化 | 债务人或金融资产的外部评级大幅下调，导致债务人履约能力显著下降 |
| 跨行债务情况 | 同一非零售债务人在所有银行的债务中，逾期超过 90 天的债务已经**超过 20%** |

> 解释：
>
> - **跨行比例条件比较的是“逾期超过 90 天的债务”占“该非零售债务人在所有银行债务”的比例。**不能改成逾期银行家数占比，也不能只看本行这一笔贷款。
> - 假设银行应收 **100 元**，但预计只能收回其中一部分，可以据此直观理解信用减值。
>
> *补充：信用减值及预期信用损失并不等于已经实际确认收不回的现金额。正式记忆应保留“已发生信用减值”等规定术语，不将直观例子当作完整会计计量方法。*

### 五、可疑类的三种情形

| 情形 | 分类条件 |
| --- | --- |
| 逾期 | 本金、利息或收益逾期**超过 270 天** |
| 逃废债 | 债务人逃废银行债务 |
| 信用减值程度 | 金融资产已发生信用减值，且预期信用损失占其账面余额 **50% 以上** |

> 解释：**50% 的分子是预期信用损失，分母是该金融资产账面余额。**不能改为所有贷款总额，也不能只记“减值五成”而忽略计量口径。

### 六、损失类的三种情形

| 情形 | 分类条件 |
| --- | --- |
| 逾期 | 本金、利息或收益逾期**超过 360 天** |
| 破产程序 | 债务人已进入**破产清算程序** |
| 信用减值程度 | 金融资产已发生信用减值，且预期信用损失占其账面余额 **90% 以上** |

> 解释：**“破产清算”不能只记成任何一种破产程序。**下文还区分重整、和解与清算，分类条件中需要保留清算二字。
>
> *补充：归为损失类不表示实际回收金额必然为零，也不意味着可以不经规定程序立即核销。风险分类与损失核销是两个不同管理事项。*

### 七、关键数字对照

| 判断维度 | 关注类 | 次级类 | 可疑类 | 损失类 |
| --- | --- | --- | --- | --- |
| 逾期条件 | 已逾期；操作或技术原因造成的 7 天内短期逾期除外 | 超过 90 天 | 超过 270 天 | 超过 360 天 |
| 信用减值条件 | 未单列信用减值条件 | 已发生信用减值 | 已发生信用减值，预期信用损失占账面余额 50% 以上 | 已发生信用减值，预期信用损失占账面余额 90% 以上 |
| 其他重点 | 用途改变、借新还旧、相关非零售债务出现不良 | 外部评级大幅下降及跨行逾期债务超过 20% | 逃废银行债务 | 进入破产清算程序 |

> 解释：**逾期门槛用“超过”，损失比例用“以上”，不能互换。**例如“超过 90 天”不是“达到 90 天”；“50% 以上”包括 50%。

### 八、分类频率与分类迁徙

金融资产分类需要定期开展，并根据重大变化及时调整：

- 商业银行应**至少每季度**对全部金融资产进行一次分类。
- 债务人财务状况或债务偿还因素发生重大变化时，应**及时调整分类形态**。
- **分类迁徙**反映银行资产在一定时间内，通常为一年，**逆变的程度**。

| 内容 | 时间或含义 | 不能混淆的地方 |
| --- | --- | --- |
| 定期分类 | 至少每季度一次 | 不是一年才分类一次 |
| 重大变化调整 | 及时调整 | 不能机械等到下一季度 |
| 分类迁徙观察 | 通常观察一年内的分类变化 | 与分类的最低频率不同 |

> 解释：分类迁徙可以理解为一定时期内分类等级的变化，其中“逆变”强调资产质量向较差等级变化。
>
> *补充：重组、续贷或担保增加，不自动使资产恢复正常类；上调分类仍需符合相应条件。金融资产分类的适用范围也有专门规定，并非所有金融工具均一律按同一办法处理。*

## 第四章、风险管理：不良金融资产的处置

*八种处置方式解决的问题不同：清收取得现金，重组调整经营或债务条件，抵债取得资产，核销处理账务，转让与证券化引入其他处置安排，债转股改变权利形式，破产程序依法处理债权债务。*

### 一、八种主要处置方式

不良金融资产主要有**现金清收、资产重组、以资抵债、呆账核销、批量转让、不良资产证券化、市场化债转股、破产清偿**八种方式。

| 方式 | 主要做法 | 核心区别 |
| --- | --- | --- |
| 现金清收 | 直接追偿、诉讼追偿、委外清收 | 以回收现金为直接目标 |
| 资产重组 | 调整企业资产与经营安排，或协商调整债务条件等 | 争取恢复经营和偿债能力 |
| 以资抵债 | 接受相关资产抵偿债务 | 回收形式是资产 |
| 呆账核销 | 对符合条件的损失进行内部账务处理 | 不等于免除债务 |
| 批量转让 | 将符合条件的不良资产组包转让 | 转让给其他处置主体 |
| 不良资产证券化 | 以不良信贷资产为基础发行资产支持证券 | 利用证券化实现资金安排与风险分配 |
| 市场化债转股 | 通过实施机构按规定将债权转为股权 | 债权关系转为股权关系 |
| 破产清偿 | 通过司法程序公平处理债权债务 | 区分清算与重整、和解 |

### 二、现金清收

**直接追偿是最基本、最常用的处置方式。**现金清收还包括诉讼追偿和委外清收。

| 途径 | 内容 |
| --- | --- |
| 直接追偿 | 银行直接向债务人等追收欠款 |
| 诉讼追偿 | 通过诉讼取得法律支持并追收 |
| 委外清收 | 委托第三方机构开展清收 |

> 解释：可以用“让对方还钱”说明其基本目的。委托第三方清收不等于已经将债权出售给第三方；清收与债权转让是不同安排。

### 三、资产重组与债务重组

**对不良资产进行重组，是处置、化解风险的重要手段。**资产重组可以从企业资产与经营重组、债务或贷款重组两个角度理解。

#### 企业资产与经营重组

资产重组主要通过与债务人协商谈判推进；满足特定条件时，也可主动发起银行债权人委员会（债委会），或采用司法框架下的破产重整。

> 解释：企业经营困难、无法产生足够偿债资金时，可以通过引入外部资金、重新整合业务或资产等方式，争取恢复经营能力。可以用“起死回生”说明重组希望达到的效果。

#### 债务或贷款重组

债务重组着重**重新商定债务条件**，可以涉及企业，也可以涉及个人债务。可以调整的条件包括：

- 利率。
- 还款期限。
- 还款方式或计划。
- 相关担保条件。

> 解释：**改变企业经营与资产安排，与改变贷款合同条件，是两个不同侧重点。**判断贷款重组措施时，应选择贷款条件调整措施，不能把所有不良资产处置方式都选入。
>
> *补充：重组是争取改善偿债安排，不保证经营必然恢复，也不自动使信用风险消失。是否构成监管意义上的重组资产，还需结合债务人财务困难及合同调整条件判断。*

> 真题示例
>
> **【多项选择题】A 银行对 B 公司发放贷款，后因市场波动 B 公司无力按时偿还该笔贷款，但 B 公司长期经营向好，A 银行对该贷款进行重组化解风险，A 银行可以采取的方式有（　）。**
>
> A. 变更担保方式  
> B. 现金清收  
> C. 不良贷款证券化  
> D. 重新约定还款期限  
> E. 调整利率
>
> **答案：ADE。**
>
> 解释：
>
> - 题干限定的是**贷款重组**，不是泛指不良资产处置。贷款重组通过协商调整贷款相关条件化解风险，担保方式、还款期限和利率均属于可以调整的条件。
> - **A 项**：可以增加或更换担保物、引入新的担保人，改善贷款安全性。
> - **B 项**：是不良资产处置方式，但不属于题干所问的贷款条件重组。
> - **C 项**：是另一类处置安排，不是贷款重组的具体方式。
> - **D 项**：可通过展期、调整还款计划等减轻短期偿债压力。
> - **E 项**：可协商调整利息负担，改善借款人偿付安排。
> - **本题的陷阱是分类层级。**现金清收、重组、证券化都可用于处置不良资产，但题干已经指定重组，只能选择属于该方式内部的措施。

### 四、以资抵债

以资抵债通过取得资产抵偿债务，主要包括**协议抵债和裁定抵债**两种方式。

| 方式 | 内容 |
| --- | --- |
| 协议抵债 | 通过双方协议安排资产抵偿 |
| 裁定抵债 | 通过司法裁定安排资产抵偿 |

抵债资产收取后，**贷款将不再计息**。

> 解释：例如，借款人不能偿还贷款，可以依法用电脑等实物资产抵偿债务。银行取得的是资产，与直接收回现金不同。
>
> *补充：以资产抵债并不意味着银行或个人可以自行拿走债务人的财产。实际取得抵债资产需要有效法律程序，后续还应处理保管、管理和处置等问题。停止计息及抵偿范围也需结合具体生效安排。*

### 五、呆账核销

呆账核销是指：**使用资产减值准备，对呆账资产损失进行内部账务处理，纳入表外核算的行为。**

> 解释：联系此前计提拨备的安排理解：损失发生并符合核销条件时，可以按规则冲销相关资产和准备，不能长期不处理已确认的呆账，也不能以改善报表为理由随意核销。

#### 五种不得核销情形

1. 借款人或者担保人有经济偿还能力，银行未按规定履行必要措施、实施必要程序追偿的债权。
2. 违反法律、法规规定，以各种形式逃废或悬空的银行债权。
3. 因行政干预造成逃废或悬空的银行债权。
4. 银行未向借款人、担保人追偿的债权。
5. 其他不应核销的银行债权、股权。

> 解释：这些情形强调追偿程序和核销条件。**不能因为银行没有认真追收，就把仍有清收条件的资产直接当作呆账核销。**
>
> *补充：上述为教材概括，正式办理仍须依据现行核销办法的认定条件、法定例外、证据和审批要求，不能将教学清单当作全部操作规定。*

#### 核销之后仍需管理

**核销不是债务免除，也不是不用追收。**纳入表外管理后仍需继续管理资产。

> *补充：核销后，除法律法规和相关办法规定权利义务已经终结的情形外，应按照“账销案存、权在力催”的原则保全和追偿。内部会计处理与对外债权是否终止，不能直接画等号。*

### 六、批量转让

批量转让将符合条件的不良资产组包，转让给资产管理公司等符合规定的受让主体，银行通过转让取得相关资金，再由受让方处置资产。

#### 三类范围

1. 按规定程序和标准认定的**次级、可疑、损失类贷款**。
2. **已核销的账销案存资产**。
3. **抵债资产**。

> 解释：这三类资产并不都表现为表内不良贷款。已经核销的账销案存资产和抵债资产，也可能进入规定的转让范围。

#### 六类限制

| 类别 | 内容 |
| --- | --- |
| 国家机关相关 | 债务人或担保人为国家机关的资产 |
| 政策性关闭破产 | 经国务院批准列入全国企业政策性关闭破产计划的资产 |
| 国家安全相关 | 国防军工等涉及国家安全和敏感信息的资产 |
| 个人贷款 | 教材的一般清单列为不得批量转让 |
| 合同限制 | 借款合同或担保合同中有限制转让条款的资产 |
| 其他法定限制 | 国家法律法规限制转让的其他资产 |

#### 个人贷款的一般清单与试点例外

教材清单写有“个人贷款不得批量转让”，但 **2021 年以后已经开展相关试点**，个人消费类贷款、信用卡透支等符合条件的个人不良贷款可在试点安排下转让。

> 解释：**复习时应同时保留一般清单与试点例外，不能只记其中一边。**
>
> *补充：个人不良贷款转让确有试点政策，不能把“个人贷款一律不得批量转让”作为当前业务的绝对判断。是否可转让，应结合试点机构、贷款类型、期限和禁止情形。考试也应以当期教材、题干条件和适用规则为依据，不能因为记忆一般清单，就在试点题目中忽略例外。*

### 七、不良资产证券化

**不良贷款证券化是信贷资产证券化的一个子业务品种。**与一般信贷资产证券化相比，主要区别是**基础资产为不良资产**。

不良资产支持证券在**全国银行间债券市场**发行和交易。

> 解释：联系一般信贷资产支持证券及资产负债管理理解，不良资产证券化可以用于盘活资产和回收资金。

> *补充：证券化发行金额和资产账面本金并不必然相等，银行也不必然实现全部本金回收、全部风险转移或全部会计出表。它与呆账核销、贷款条款重组是不同安排。*

### 八、市场化债转股

债转股将相关债权转为企业股权，改变收益与权利的取得方式。对象企业应具有继续经营和改善偿债状况的前景，不能仅因目前不能还钱就认定适合债转股。

#### 对象企业的三项条件

1. **发展前景较好**，具有可行的企业改革计划和脱困安排。
2. 主要生产装备、产品、能力符合国家产业发展方向，技术先进、产品有市场，环保和安全生产达标。
3. **信用状况较好**，无故意违约、转移资产等不良信用记录。

#### 债转股的实施方式

**银行不得直接将债权转为股权。**银行先向实施机构转让债权，再由实施机构将债权转为对象企业股权。

| 主体 | 主要作用 |
| --- | --- |
| 银行 | 按规定转让相关债权 |
| 实施机构 | 受让债权，并按协议和规则实施转股 |
| 对象企业 | 配合转股及改革、脱困安排 |

> 解释：例如，银行先把相关债权转让给资产管理公司，再由资产管理公司作为实施机构将债权转为企业股权。
>
> *补充：正式规定保留“国家另有规定的除外”。实施机构也不只限于资产管理公司，可以包括符合条件的银行所属实施机构等。不能将“银行不得直接转股”误解为银行体系完全不能参与市场化债转股。*
>
> *补充：市场化债转股不只针对不良贷款，符合规定的正常、关注等质量类型债权也可能纳入。转成股权也不保证股息或本金回收，收益还取决于经营表现和退出安排。*

### 九、破产清偿

破产程序是在债务人不能清偿全部债务时，通过**司法力量介入**，使全体债权人获得依法处理的机会，避免不公平的个别清偿。

| 程序或结果 | 理解 | 核心区别 |
| --- | --- | --- |
| 破产清算 | 财产依法分配，企业主体资格依法终止，教材称“灭亡程序” | 结束企业主体并处理债权债务 |
| 破产和解、破产重整 | 通过和解协议或重整计划减轻压力，以时间换空间，争取恢复经营，教材称“重生程序” | 争取保留经营和改善清偿 |

> 解释：
>
> - 破产需由法院依法处理，不能由企业自己随意宣布后就结束债务。
> - **破产程序不全都等于企业立即消失。**清算与重整、和解具有不同作用。
>
> *补充：“灭亡”“重生”是教材帮助理解的称呼，不是独立的法定程序名称。正式法律程序分别为重整、和解、破产清算；依法公平处理也不表示所有债权人不分顺位、按相同比例受偿。*

## 第五章、风险管理：市场风险及其管控

*先区分四类市场风险，再比较利率风险的四种来源；管控重点是三类限额和风险对冲。*

### 一、市场风险的分类

市场风险是市场价格波动给商业银行带来损失的风险。根据价格类型，分为**利率风险、汇率风险、股票价格风险、商品价格风险**。其中，利率风险与汇率风险是商业银行市场风险中的主要部分。

| 类型 | 核心变化 | 理解重点 |
|---|---|---|
| 利率风险 | 利率水平及相关关系变化 | 资产、负债的利率安排不同，产生损失 |
| 汇率风险 | 外币汇率变化 | 外汇交易敞口、结构性币种不匹配 |
| 股票价格风险 | 股票价格变化 | 可通过客户、担保品等渠道影响银行 |
| 商品价格风险 | 商品价格变化 | 农产品、矿产品、金属等；不包括黄金 |

### 二、利率风险的四种来源

利率风险的四种来源是**重新定价风险、收益率曲线风险、基准风险、期权性风险**。

#### （1）重新定价风险

市场利率变化后，银行资产与负债的利率变化不能完全相互抵消，可能形成**重新定价风险**。

> *补充：更准确地说，重新定价风险与资产、负债和表外头寸的到期时间或重新定价时间不匹配有关。“利率变化”只是触发因素，不能用它单独区分此类风险与其他利率风险。*

#### （2）收益率曲线风险

从资产配置的角度理解**收益率曲线风险**：银行需要判断利率变化趋势，预判失误可能导致配置错误并产生损失。

> *补充：收益率曲线表示同一时点不同期限利率之间的关系。收益率曲线风险的核心是曲线形状、斜率等变化，尤其是不同期限利率的不平行变动；不能直接定义成“预测未来利率失败”。预测失误可以是管理上的原因，但不是这一风险的完整定义。*

#### （3）基准风险

不同业务采用的利率基准不同，调整时未必同步，导致银行原本安排好的收益、成本关系发生变化。

> 解释：例如，贷款业务以贷款市场报价利率（LPR）作为基准，存款业务采用不同的利率基准。如果两个基准调整不一致，就可能形成风险敞口。
>
> *补充：关键是不同利率基准之间的关系变化，不是仅仅“两个利率数值不同”。存款具体定价机制因产品而异，上述例子用于说明基准不一致。*

#### （4）期权性风险

客户行使某些合同中存在的选择权，可能改变银行原定的现金流和期限安排。

> 解释：
>
> - 客户行使选择权的例子包括：
>   - 贷款客户提前还贷。
>   - 存款客户提前支取定期存款。
> - 银行原本较为平衡的资产负债配置可能因此发生变化，形成不匹配。
>
> *补充：区分利率风险时，重新定价风险主要看“重新定价时间或到期时间不匹配”，收益率曲线风险主要看“不同期限利率的曲线关系变化”；基准风险看不同利率基准的关系，期权性风险看客户选择权。*

### 三、汇率风险

#### （1）外汇交易风险

外汇交易风险主要有两类来源：

1. **为客户提供外汇交易服务时，未能立即对冲的外汇敞口头寸。**
2. **银行基于对外币走势的预期而主动持有的外汇敞口头寸。**

> 解释：外汇交易风险既可能来自为客户交易后留下的敞口，也可能来自银行主动持有的敞口。汇率发生不利变化时，未被抵消的头寸可能产生损失。
>
> *补充：不能把所有客户外汇交易都直接等同于银行发生损失；关键在于银行是否留下承担汇率变化的敞口。*

#### （2）外汇结构性风险

外汇结构性风险来自**银行结构性资产与负债之间的币种不匹配**。

> 解释：银行经营本币业务和外币业务，需要持有外币头寸。持有数量、币种结构以及相应负债安排不同，会影响汇率变动时的损失。

#### 黄金的风险分类

**黄金纳入汇率风险考虑，不纳入商品价格风险。**

> 解释：黄金具有商品属性，但在历史上长期充当一般等价物，具有货币属性，因此在银行风险分类中按汇率风险处理。
>
> *补充：此处是银行风险分类的特定口径，不代表黄金在所有经济、投资或交易分类中都不属于商品。答题时应结合题目采用的监管或教材框架。*

### 四、股票价格风险与商品价格风险

#### （1）股票价格风险

在分业经营背景下，我国商业银行**不能从事证券经营业务**，很少直接面临股票价格风险；但股票价格变化仍可通过多种渠道**间接影响银行资产质量**。

> 解释：例如，客户提供与股票相关的担保品，以及银行涉及相关股票权益的情形，都可能受到股票价格变化影响。
>
> *补充：“不能从事证券经营业务”应在具体法律、业务许可及例外范围内理解，不宜扩大成银行不能开展任何证券相关业务、不能持有任何权益，或完全不受股价影响。*

#### （2）商品价格风险

商品主要指可以在二级市场交易的实物产品，包括：

- 农产品。
- 矿产品，**包括石油**。
- 金属，**不包括黄金**。

> 解释：银行不经营期货业务，商品价格风险并非商业银行最主要的市场风险，但大宗商品和期货市场的价格变化仍可能间接影响银行。
>
> *补充：“银行不经营期货业务”是分业经营和主营业务特点下的概括，不宜据此推导出商业银行在任何情况下都不能开展经批准的衍生品业务。*

### 五、市场风险管控：限额管理

市场风险管控手段主要有**限额管理、风险对冲**。

限额管理分为三类：

| 限额 | 限制对象 | 解释 |
|---|---|---|
| **交易限额** | 总交易头寸或净交易头寸 | 限制持仓及交易敞口规模 |
| **风险限额** | 按一定计量方法衡量的市场风险规模 | 限制能够承担的风险水平 |
| **止损限额** | 允许的最大损失额 | 损失达到规定标准时采取止损措施 |

#### （1）交易限额

> 解释：
>
> - 以多头、空头为例，买入持仓形成多头，卖出持仓形成空头；应关注多头、空头及总头寸规模，也要关注抵消后的净头寸。
> - **总头寸与净头寸不是同一个概念。**净头寸强调多空相抵后的差额，不能只看总交易规模或只看净额就认为所有风险已被覆盖。
>
> *补充：不同资产、币种、期限的头寸能否抵消，取决于具体计量规则；不能把所有多空头寸无条件相减。*

#### （2）风险限额

风险限额是对采用一定方法计量的市场风险设置上限。

> *补充：交易限额衡量头寸规模，风险限额衡量风险规模；相同金额的不同头寸可能具有不同风险。*

#### （3）止损限额

止损限额对最大可接受损失设定标准，可以针对单笔交易、某次交易或一段时期内的累计损失。

**止损限额具有追溯力**，可用于累计损失管理，观察期间可以是一日、一周、一个月或一年等。

> 解释：损失达到相应标准时，应按照制度采取停止交易、平仓等措施。具体处置方式应结合规定，而不是把任何止损限额都理解成同一种自动平仓规则。

### 六、市场风险管控：风险对冲

风险对冲是通过引入与原有风险具有相反变动效果的资产或交易，以其收益抵补原有损失。银行可以运用衍生品交易进行**套期保值**。

> 解释：
>
> - 假设银行持有某种外币，并预计该外币可能贬值，可以通过外汇期货对冲：
>   - 银行持有某种外币，预计其价值可能下跌。
>   - 在相应外汇期货市场建立空头。
>   - 如果外币贬值，原有外币头寸价值下降，产生损失。
>   - 期货价格相应下跌，空头可能产生收益。
>   - 利用空头收益抵补现货外币持仓损失。
> - 核心在于两项头寸的损益方向相反，尽量相互抵补。
>
> *补充：对冲不保证完全消除风险。期限、数量、合约标的或价格关系不完全匹配，以及交易成本等，都可能使抵补不充分。*

## 第六章、风险管理：操作风险及其管控

*操作风险要区分四类原因与七类损失事件，再掌握三项管理工具以及业务连续性管理的要求。*

### 一、操作风险的含义与特征

操作风险与**人员、内部流程、系统和外部事件**有关，损失可能来自员工行为、流程缺陷、系统故障或外部事件。

**操作风险具有非营利性；包括法律风险，但不包括战略风险和声誉风险。**

#### 操作风险的非营利性

> 解释：
>
> - 可以通过信用风险、市场风险与操作风险的比较，理解非营利性：
>   - 银行放贷是为了获得收益，主动承担对方违约带来的信用风险。
>   - 银行进行市场交易是为了获利，主动承担价格变化风险。
>   - 员工失误、系统故障等操作风险通常不是银行为了赚取风险收益而主动追求的风险。
> - **“非营利性”不等于不影响利润，也不等于只在非营利机构发生。**操作风险仍可能造成真实损失。
>
> *补充：《银行保险机构操作风险管理办法》于 2024 年 7 月 1 日起施行，定义同样以不完善或有问题的内部程序、员工、信息科技系统和外部事件为主要来源，保留“包括法律风险，不包括战略风险和声誉风险”的边界。*

### 二、操作风险的四类原因

| 原因 | 内容 | 例子 |
|---|---|---|
| **人员因素** | 内部欺诈、失职违规、知识或技能匮乏、关键人员流失、违反用工法、劳动力中断等 | 工作失误、挪用款项、员工违法违规 |
| **内部流程** | 财务／会计错误、文件／合同缺陷、产品设计缺陷、结算／支付错误、错误监控／报告、交易／定价错误 | 业务流程某个环节存在缺陷或问题 |
| **系统因素** | 信息科技系统开发不完善，软硬件失灵或瘫痪，功能漏洞，服务或业务中断，系统数据风险等 | 手机银行、网上银行系统中断或崩溃 |
| **外部事件** | 自然灾害、政治风险、外部欺诈、外部人员犯罪等 | 信用卡诈骗、贷款诈骗、不可抗力事件 |

> 解释：内部流程的六项内容应完整记忆，不要只记“流程有问题”。

### 三、操作风险的七类损失事件

| 损失事件 | 说明 | 例子或定位 |
|---|---|---|
| **内部欺诈事件** | 故意骗取、盗用财产，或违反监管规章、法律、公司政策导致损失 | 内部人员挪用资金 |
| **外部欺诈事件** | 第三方故意骗取、盗用、抢劫财产，伪造要件，攻击银行信息科技系统或规避监管导致损失 | 第三方信用卡诈骗 |
| **就业制度和工作场所安全事件** | 违反就业、健康或安全法律及协议，工伤赔付，歧视和差别待遇等 | 工伤、劳资纠纷及仲裁 |
| **客户、产品和业务活动事件** | 未按规定履行对特定客户的义务，如诚信责任、适当性管理，或产品性质、设计存在缺陷 | 未履行适当性要求向客户推荐高风险产品；客户本想存款却被办成保险 |
| **实物资产损坏** | 自然灾害或其他事件，如恐怖活动，造成实物资产丢失或毁坏 | 火灾、洪水损坏办公设备 |
| **信息科技系统事件** | 生产运行、应用开发、安全管理及软硬件、通信、电力、第三方等因素引发系统运行或业务连续性异常 | 系统崩溃 |
| **执行、交割和流程管理事件** | 交易处理、流程管理失败，以及与交易对手、供应商等关系造成损失 | 结算失误 |

> 解释：
>
> - 原因分类回答“为什么发生”，损失事件分类回答“以什么具体事件表现出来”。两种分类不能混为一组。
> - **易混点：**内部欺诈与外部欺诈看主体；实物资产损坏与系统事件看损失对象及事件性质；客户、产品和业务活动事件重点关注客户义务、适当性和产品缺陷。
>
> *补充：原因分类与事件分类不是严格的一一对应。例如，外部攻击可以涉及系统因素和外部欺诈；自然灾害也可能同时造成实物损坏和系统中断。正式归类应遵循适用的事件分类规则，不能仅凭某个词强行归类。*

> 真题示例
>
> **【2025 年多项选择题】下列属于商业银行操作风险表现形式的有（　）。**
>
> A. 外部欺诈  
> B. 就业制度和工作场所安全性有问题  
> C. 信息科技系统事件  
> D. 执行、交割和流程管理事件  
> E. 内部欺诈
>
> **答案：ABCDE。**
>
> 解释：
>
> - **A 项**：外部欺诈是七类损失事件之一。例如信用卡诈骗。
> - **B 项**：对应就业制度和工作场所安全事件，如工伤、劳资纠纷。
> - **C 项**：对应信息科技系统事件，如系统崩溃。
> - **D 项**：对应执行、交割和流程管理事件，如结算失误。
> - **E 项**：对应内部欺诈，如内部人员挪用资金。
> - **审题重点：**问“表现形式”或具体事件，要对应七类损失事件；如果问“原因”，应想到人员、内部流程、系统、外部事件四类。
> - 本题列出的五项全部正确，但操作风险事件分类仍为七类，另外两类是**客户、产品和业务活动事件、实物资产损坏**。

### 四、操作风险管理的三项工具

操作风险管理的三项工具是**操作风险与控制自评估、关键风险指标、损失数据库**。

#### （1）操作风险与控制自评估

银行开展业务、设置流程和制度时，应判断哪些业务、哪些环节是操作风险高发处，并安排相应控制措施。

> 解释：联系存款业务理解：个人存款重点面临操作风险；公司存款还需要关注流动性风险。应对具体业务重点环节设置管理制度，开展自评估。
>
> *补充：“自评估”既要识别操作风险，也要评估已有控制是否充分、有效，不只是列出可能发生的风险。*

#### （2）关键风险指标

为风险防范设置指标和标准，持续统计、比较，发现偏离或异常时及时管控。

> 解释：**轮岗和强制休假的例子：**某人在同一岗位任职过久，可能过度熟悉业务漏洞，增加挪用资金等风险。因此可以安排轮岗和强制休假，关注轮岗周期、频率以及强制休假执行情况等。相关指标异常时，应采取措施。
>
> *补充：轮岗、强制休假是控制措施；执行率、逾期未轮岗人数等才是衡量措施执行情况的指标。不要把措施名称与指标数值完全等同。*

#### （3）损失数据库

损失数据库收集操作风险造成的损失及相关事件数据，包括**内部损失数据、外部损失数据**，用于识别和管理风险。

> 解释：损失数据可以包括历史损失、违法违规罚款、纠纷仲裁等记录。
>
> *补充：内部与外部损失数据应按数据来源区分：本机构自身损失属于内部数据，其他机构等的损失事件可作为外部数据。监管罚款或仲裁损失不会因为处罚、仲裁来自机构外部，就自动变成外部损失数据。*

### 五、业务连续性管理

操作风险事件发生后，银行应尽量维持或尽快恢复关键业务。系统故障可能导致业务中断，客户信任下降，甚至诱发挤兑等其他风险。

主要要求：

1. **识别重要业务，明确恢复优先顺序。**
2. **明确恢复时间目标。**
3. 制定应急计划，明确突发事件下的措施与程序。
4. **定期开展培训和演练**，确保应急计划得到及时、正确执行。

> 解释：
>
> - 以存款业务为例，如果相关业务涉及客户资金需求，应优先恢复重要服务，避免客户无法获得必要服务。
> - **业务连续性管理不是等事故发生后临时想办法。**恢复优先级、责任分工、应急措施和演练应提前安排。

## 第七章、风险管理：流动性风险及其管控

*流动性风险既可能来自资产难以变现，也可能来自融资困难。管控时结合现金流、限额、融资渠道、压力测试和应急安排。*

### 一、流动性风险的含义与分类

流动性风险是商业银行无法在特定时间内、以合理成本获得资金支持的风险。流动性不足可能导致银行无法满足客户需求，并发生挤兑。

| 类型 | 含义 | 简化记忆 |
|---|---|---|
| **市场流动性风险** | 由于市场深度不足或市场动荡，不能以合理市场价格出售资产取得资金；关注迅速、无损或仅有微小损失变现的能力 | **卖不掉／难变现** |
| **融资流动性风险** | 无法及时、有效满足资金需求，或不能在不影响日常经营、财务状况的情况下，以合理时间和成本取得资金 | **借不来／难融资** |

- 资产变现能力越强，市场流动性越好，相关风险越低。
- 资产变现能力越弱，市场流动性越差，相关风险越高。
- 融资能力越弱，融资流动性风险越高。

> 解释：例如，银行持有票据、企业债券或金融债券，当市场不够活跃，相关资产难以出售换取资金，属于市场流动性问题。如果缺钱时其他交易对手不信任银行、不愿出借资金，则涉及融资流动性问题。
>
> *补充：“卖不掉”和“借不来”是简化用语，实际定义也包括只能以过低价格出售、融资成本过高或到账过迟等情形，不必达到完全无法出售或借款才构成风险。*

> 真题示例
>
> **【2025 年单项选择题】商业银行因为没有足够的现金来满足客户取款需求而引起的风险是（　）。**
>
> A. 国别风险  
> B. 信用风险  
> C. 流动性风险  
> D. 市场风险
>
> **答案：C。**
>
> 解释：
>
> - **A 项**：国别风险与国际经济金融活动中的国家或地区因素有关；题干未给出国家或地区层面的相关风险因素。
> - **B 项**：信用风险强调客户或交易对手违约，题干重点是银行现金不足。
> - **C 项**：无法及时满足客户取款的资金需求，直接对应流动性风险。
> - **D 项**：市场风险强调利率、汇率、股价、商品价格等波动，题干未以价格波动为直接原因。
> - 国别风险发生时可能影响与相关国家或地区有关的多个主体；信用风险是银行面临的主要风险；市场风险则与价格变动有关。
>
> *补充：国别风险不能仅凭交易是否发生在国内判断。题目应看风险是否来自有关国家或地区的经济、政治、社会变化等；这些因素的影响也可能通过相关主体传导。此题无须据“国内业务绝不会有国别风险”这一过度简化表述排除 A。*
>
> *补充：信用、市场、操作或声誉事件均可能进一步引发流动性困难，但本题按“现金不足，不能满足取款”这一直接表现选择流动性风险。*

### 二、流动性风险的五项管控手段

流动性风险管控的五项手段是**现金流量管理、限额管理、融资管理、压力测试、应急计划**。

#### 现金流量管理

银行应关注不同时段的现金流入、现金流出以及两者的错配情况。

结合融资能力和风险承受能力，设置**现金流期限错配限额**，保证各期限的现金流错配净额处于相应限额之内。

> 解释：不能只看银行有多少资产，应分析某一时间段有多少现金进来、有多少现金需要出去，再对差额或缺口设定上限并持续监测。
>
> *补充：计算现金流缺口时，要先明确流入减流出还是流出减流入的符号约定，再与限额比较；不能仅凭“净额低于限额”忽略负缺口的实际含义。*

#### 限额管理

流动性风险限额管理主要设置三项限额：

| 限额 | 关注内容 |
|---|---|
| **现金流缺口限额** | 不同时间段现金流入、流出之间的缺口 |
| **负债集中度限额** | 负债来源的集中情况，以及资金集中流出可能带来的压力 |
| **集团内部交易和融资限额** | 集团内部资金安排及其风险传播 |

**各类限额至少每年评估一次，必要时调整。**设定限额后不能长期固定不变。

> 解释：集团内部资金转移可以提高资金使用效率，但也可能使风险在集团内传递，因此同样应设置上限。
>
> *补充：负债集中度主要强调资金来源是否集中于少数客户、交易对手或其他特定来源，而不是仅看存款总额高低。存款集中流出可能引发流动性压力，但不能将“存款多”直接等同于“负债集中度高”。*

#### 融资管理

融资管理包括四方面：

1. **分析融资需求与来源**：分析正常和压力情景下，未来不同时间段的融资需求及融资来源。
2. **控制融资集中度**：关注负债品种、期限、交易对手、币种、融资抵质押品及融资市场的集中度，设置适当限额。同业批发融资应按**总量和主要期限**分别设置限额。
3. **维护融资渠道**：管理融资渠道，维护与主要融资交易对手的关系，保持适当市场活跃度，定期评估市场融资能力和资产变现能力。
4. **监测金融市场**：监测主要金融市场交易量、价格变化，以及市场流动性对银行融资能力的影响。

> 解释：
>
> - **需求与来源**：先判断将来需要多少资金，再决定通过哪些渠道、向哪些交易对手融资，做好前期准备。
> - **融资集中度**：不能仅设置同业批发融资总额上限，还要控制期限集中。
> - **融资渠道**：以同业往来为例，平时维护交易关系和市场参与，有助于银行在需要资金时获得支持，但不意味着对方一定会出借。
> - **市场监测**：同时关注所持资产的价值及可交易情况，避免需要资金时才发现资产难以出售，或只能以不合适的价格出售。

#### 压力测试

通过模拟不利或极端情况，检验银行能否承受流动性压力，是否有足够资金满足需求。

**流动性风险压力测试至少每季度进行一次。**

测试频率应与银行规模、风险水平、市场影响力等相适应；市场剧烈波动等情况下应增加频率。

> 解释：可以通俗理解为“自己给自己设置压力”，观察系统及资金安排能否扛住相应情景。
>
> *补充：2018 年《商业银行流动性风险管理办法》同样规定至少每季度开展一次流动性风险压力测试。判断频率时要注意，不是“至少每半年”。*

#### 应急计划

应急计划应明确触发条件和不同压力情景下的行动安排，提前准备可调用资源及处理程序。

主要要求：

- 明确在不同情况下启动计划的要求。
- 识别应急资金来源，合理判断资金规模和取得所需时间。
- 制定操作程序及应对措施。
- 措施至少从**资产方、负债方、内外部沟通**等方面考虑，通过沟通减少信息不对称。

| 容易混淆的要求 | 要求 |
|---|---|
| 流动性风险限额评估 | **至少每年一次**，必要时调整 |
| 流动性风险压力测试 | **至少每季度一次**，必要时增加频率 |
| 操作风险业务连续性演练 | **定期**开展；未规定统一的具体次数 |

> 解释：应通过提前制定程序、明确调用资源和实施措施，尽量帮助业务快速恢复正常。

## 第八章、风险管理：声誉风险及其管控

*声誉风险关注负面评价和信任受损。重点掌握四项原则、治理责任，以及评估到问责的六个管理环节。*

### 一、声誉风险的含义

银行自身行为、从业人员行为或外部事件引发负面评价、负面舆论及声誉影响，可能造成损失，妨碍银行经营。

> 解释：声誉风险可能与内部、外部负面舆论有关。需要关注的不仅是银行本身的行为，也包括员工行为和外部因素。

### 二、声誉风险管理的四项原则

声誉风险管理遵循**前瞻性、匹配性、全覆盖、有效性**四项原则。

| 原则 | 主要含义 |
|---|---|
| **前瞻性** | 提前预判、防控负面舆论和潜在声誉问题，不等发生后才处理 |
| **匹配性** | 与银行自身情况相适应 |
| **全覆盖** | 管理覆盖相关业务、人员和环节 |
| **有效性** | 管理措施能够发挥实际作用 |

> 解释：
>
> - 判断前瞻性时，可以看以下例子：通过制度约束员工未经授权随意对外发表言论，可以在源头减少负面声誉事件发生的可能。
> - 判断管理原则时要注意：**全面风险管理**强调匹配性、全覆盖、独立性、有效性；**声誉风险管理**强调前瞻性、匹配性、全覆盖、有效性。两组原则不能机械替换。
>
> *补充：声誉风险管理强调防控源头、与自身状况匹配、覆盖组织及管理环节，并以有效防控处置和修复声誉为标准。具体适用范围和职责应按相应制度落实。*

### 三、声誉风险管理的治理架构

| 主体 | 责任 | 具体职责 |
|---|---|---|
| **董事会** | **最终责任** | 确定策略和总体目标，掌握声誉风险状况，监督高级管理层开展管理 |
| **监事会** | **监督责任** | 监督董事会、高级管理层履职尽责，将相关情况纳入监事会工作报告 |
| **高级管理层** | **管理责任** | 建立健全制度、完善机制，制定重大事项应对预案和处置方案，安排并推进声誉事件处置 |
| 声誉风险管理部门等 | 具体实施 | 由相应风险管理部门进一步落实具体工作 |

> 解释：**记忆：董事会最终、监事会监督、高管层管理。**最终责任不等于董事会承担所有具体执行工作，监督责任也不等于直接处置全部事件。
>
> *补充：上表采用设有监事会的治理架构。实际机构的监督机制应结合其适用法律、章程和治理安排确定，不应据此认定所有机构必须采用完全相同的组织设置。*

### 四、声誉风险管理的六个环节

声誉风险管理包括**风险评估、风险监测、风险分级、风险处置、风险报告、考核问责**六个环节。

| 环节 | 主要内容 |
|---|---|
| **风险评估** | 判断哪些情况、哪些时点容易产生声誉风险，以及发生后的影响与后果 |
| **风险监测** | 监测网络、服务环境等，及时发现风险信号 |
| **风险分级** | 根据影响程度和后果大小分级，以便采取相应措施 |
| **风险处置** | 通过公关、记者会、说明会、公告等回应疑问并进行处理 |
| **风险报告** | 根据制度规定的情形、后果及要求，向上级、监管部门等报告 |
| **考核问责** | 对相关主体和管理人员追责，发挥事后追责与事前警示作用 |

> 解释：
>
> - 例如，可以用一级、二级、三级等说明分级处置思路。**这些例子没有给出统一的各级标准，不能将举例当成适用于所有银行的固定三级制度。**
> - **“风险传递”不属于六个声誉风险管理流程环节。**风险确实可能在不同主体或类型之间传播，但这是风险之间的关系，不属于声誉风险管理流程名称。
>
> *补充：声誉风险处置不能只理解为公关。核实事实、纠正业务或产品问题、控制相关方损失和恢复信任也很重要。*

> 真题示例
>
> **【2025 年单项选择题】下面不属于声誉风险管理流程环节的是（　）。**
>
> A. 考核问责  
> B. 风险评估  
> C. 风险分级  
> D. 风险传递
>
> **答案：D。**
>
> 解释：
>
> - **A 项**：六环节中的考核问责，关注责任落实与追责。
> - **B 项**：六环节中的风险评估，判断潜在风险与后果。
> - **C 项**：六环节中的风险分级，支持分级应对。
> - **D 项**：风险传递不在声誉风险管理的六环节名单内，因此是本题答案。
> - **完整名单：评估、监测、分级、处置、报告、考核问责。**本题是“不属于”，不要选成属于流程的项目。

## 第九章、风险管理：重点小结

| 内容 | 核心要点 |
| --- | --- |
| 风险内涵 | 不确定性；不利后果或损失的可能性 |
| 全面风险管理框架 | 公司治理与组织架构、基本要素、实际应用 |
| 全面风险管理原则 | 匹配性、全覆盖、独立性、有效性 |
| 风险战略 | 进取型、稳健型、保守型 |
| 风险策略 | 分散、对冲、转移、规避、补偿 |
| 三道防线 | 业务团队、风险管理团队、内部审计团队 |
| 管理流程 | 识别、计量、监测、控制 |
| 信用风险管控 | 准入退出、限额、缓释、定价 |
| 五级分类 | 正常、关注、次级、可疑、损失；后三类为不良 |
| 关注类逾期例外 | 操作性或技术性原因导致的 7 天内短期逾期 |
| 次级、可疑、损失逾期门槛 | 分别超过 90、270、360 天 |
| 非零售债务跨行比例 | 逾期超过 90 天的债务，占该债务人全部银行债务超过 20% |
| 可疑、损失信用减值比例 | 预期信用损失占账面余额分别为 50% 以上、90% 以上 |
| 金融资产分类频率 | 至少每季度一次；重大变化及时调整 |
| 不良资产八种处置方式 | 现金清收、资产重组、以资抵债、呆账核销、批量转让、不良资产证券化、市场化债转股、破产清偿 |
| 市场风险分类 | 利率、汇率、股票价格、商品价格风险 |
| 利率风险四种来源 | 重新定价、收益率曲线、基准、期权性风险 |
| 黄金风险分类 | 纳入汇率风险，不纳入商品价格风险 |
| 市场风险管控 | 限额管理、风险对冲；交易限额、风险限额、止损限额 |
| 操作风险范围 | 包括法律风险，不包括战略风险和声誉风险；具有非营利性 |
| 操作风险四类原因 | 人员、内部流程、系统、外部事件 |
| 操作风险七类损失事件 | 内部欺诈、外部欺诈、就业制度和工作场所安全、客户产品和业务活动、实物资产损坏、信息科技系统、执行交割和流程管理 |
| 操作风险三项工具 | 操作风险与控制自评估、关键风险指标、损失数据库 |
| 业务连续性管理 | 重要业务、恢复顺序、恢复时间目标、应急计划、定期培训和演练 |
| 流动性风险分类 | 市场流动性风险、融资流动性风险 |
| 流动性风险管控 | 现金流量、限额、融资、压力测试、应急计划 |
| 流动性管理频率 | 限额至少每年评估一次；压力测试至少每季度一次 |
| 声誉风险管理原则 | 前瞻性、匹配性、全覆盖、有效性 |
| 声誉风险管理责任 | 董事会最终责任、监事会监督责任、高管层管理责任 |
| 声誉风险管理流程 | 评估、监测、分级、处置、报告、考核问责 |
