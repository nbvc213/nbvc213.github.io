## CSS 简介

**CSS（Cascading Style Sheets，层叠样式表）**是一种用于描述 HTML 等结构化文档**显示效果和页面布局**的样式表语言。它主要负责控制网页元素的颜色、字体、大小、间距、位置、布局等视觉表现。

HTML 主要负责页面的**结构和内容**，CSS 主要负责页面的**样式和布局**，JavaScript 主要负责页面的**行为和交互**。三者共同构成现代 Web 前端开发的基础。

### 什么是 CSS

如果只使用 HTML，可以定义网页中有哪些标题、段落、图片、按钮等内容，但页面通常只能使用浏览器提供的默认样式。CSS 可以在不改变 HTML 内容结构的情况下，对这些元素的显示效果进行统一控制。

例如，HTML 定义一个标题：

```html
<h1>用户中心</h1>
```

可以通过 CSS 设置其颜色、大小和对齐方式：

```css
h1 {
    color: blue;
    font-size: 32px;
    text-align: center;
}
```

其中，HTML 负责说明“这是一个一级标题”，CSS 则负责决定“这个标题应该以什么样的视觉效果显示”。

这种设计实现了**内容结构与表现样式的分离**。页面需要修改外观时，通常只需要调整 CSS，而不必大量修改 HTML 结构。

> 结论：CSS 的核心职责是**控制网页的表现和布局**。HTML 解决“页面中有什么”，CSS 解决“这些内容应该怎样显示”。

---

### CSS 的主要功能

CSS 能够控制的内容非常丰富，基础阶段可以从**页面美化、页面布局和状态效果**三个方面理解。

#### 页面美化

CSS 可以控制元素的文字、背景、边框和间距等视觉效果，例如：

- 设置文字的颜色、字体、大小、粗细和对齐方式。
- 设置背景颜色、背景图片以及渐变效果。
- 设置边框的颜色、粗细和样式。
- 设置元素的内边距、外边距等间距。

例如：

```css
.notice {
    color: red;
    font-size: 18px;
    background-color: #f5f5f5;
    border: 1px solid #ccc;
    padding: 10px;
}
```

这样可以将原本由 HTML 负责结构的内容进一步美化，而不需要再使用 `color`、`align`、`bgcolor` 等旧式 HTML 表现属性。

#### 页面布局

CSS 还负责控制元素在网页中的**位置和排列方式**。

例如，可以使用 CSS 实现：

- 页面中的水平、垂直排列。
- 多栏布局。
- 元素之间的间距和对齐。
- 固定定位、相对定位、绝对定位等定位效果。
- 根据屏幕大小调整页面结构的响应式布局。

现代 CSS 中常用的布局技术包括 **Flexbox（弹性盒布局）**和 **Grid（网格布局）**。

例如：

```css
.container {
    display: flex;
}
```

这表示 `.container` 使用 Flexbox 布局，其内部元素可以按照弹性布局规则进行排列。

> 补充：Flexbox、Grid、定位等属于后续 CSS 布局知识。当前阶段只需要知道，现代网页的页面布局主要由 CSS 完成，而不是通过大量 `<table>`、`<br>` 或 HTML 样式属性实现。

#### 状态与视觉效果

CSS 可以根据元素当前所处的状态应用不同的样式。

例如，可以使用 `:hover` 设置鼠标悬停时的效果：

```css
button:hover {
    background-color: blue;
}
```

当鼠标移动到按钮上时，按钮背景颜色会发生变化。

CSS 本身还支持**过渡（Transition）**、**变换（Transform）**和**动画（Animation）**等功能，可以实现许多不依赖 JavaScript 的视觉效果。

对于需要根据业务数据、用户操作或者程序逻辑动态发生变化的效果，则通常由 JavaScript 修改元素的状态、类名或样式，再由 CSS 决定最终的视觉表现。

> 注意：不能简单将“点击效果”全部归为 CSS。CSS 可以根据 `:hover`、`:focus`、`:checked` 等状态设置样式，但复杂的点击逻辑和业务交互通常仍需要 JavaScript。

### CSS 的优势

#### 结构与样式分离

CSS 最重要的作用之一是将页面的**结构与表现分离**。

例如，不推荐在大量 HTML 元素中分别编写：

```html
<p style="color: red;">错误信息1</p>
<p style="color: red;">错误信息2</p>
<p style="color: red;">错误信息3</p>
```

可以统一给这些元素设置类名：

```html
<p class="error">错误信息1</p>
<p class="error">错误信息2</p>
<p class="error">错误信息3</p>
```

再通过 CSS 统一控制：

```css
.error {
    color: red;
}
```

如果以后需要把错误信息全部改成其他颜色，只需要修改一次 CSS。

#### 样式可以复用

同一套 CSS 规则可以应用到多个元素，外部 CSS 文件还可以被多个 HTML 页面共同使用。

例如：

```css
.title {
    font-size: 24px;
    font-weight: bold;
}
```

页面中所有使用 `class="title"` 的元素都可以复用这一套样式。

因此，当一个网站包含大量页面时，可以通过统一的 CSS 保持字体、颜色、按钮、间距等视觉风格一致。

#### 便于统一维护

如果把页面样式集中在 CSS 中，当网站整体设计需要调整时，可以统一修改相关 CSS 规则，而不需要逐个修改大量 HTML 标签。

这也是现代 Web 开发不再推荐使用 `<font>`、`bgcolor`、`align` 等 HTML 表现属性的重要原因。

#### 支持响应式页面

CSS 可以根据设备屏幕大小等条件应用不同的样式，使同一个网页能够适配电脑、平板和手机等不同设备。

例如，在较大的屏幕中可以采用多栏布局，而在较小的手机屏幕中调整为单栏布局。

这种根据不同设备和显示环境自动调整页面效果的设计方式称为**响应式 Web 设计（Responsive Web Design）**。

> 结论：CSS 不只是负责“把网页变漂亮”，还承担着**页面样式、布局、状态效果和不同设备适配**等重要职责。通过 CSS 将结构与样式分离，可以提高页面样式的复用性、一致性和可维护性。

## CSS 基础语法

CSS 通过**选择器找到 HTML 元素，再通过属性和值设置元素样式**。学习 CSS 时，可以将 [MDN Web Docs](https://developer.mozilla.org/zh-CN/) 作为重要的语法参考和技术文档来源。

### CSS 语法格式

一条基本的 CSS 规则由**选择器（Selector）**和**声明块（Declaration Block）**组成：

```css
选择器 {
    属性名1: 属性值1;
    属性名2: 属性值2;
    属性名3: 属性值3;
}
```

例如：

```css
p {
    color: red;
    font-size: 16px;
}
```

其中：

- `p` 是**选择器**，表示选中页面中的 `<p>` 元素。
- `color`、`font-size` 是 **CSS 属性**。
- `red`、`16px` 是对应的**属性值**。
- `color: red;` 称为一条**声明（Declaration）**。
- 多条声明共同放在 `{}` 中，组成声明块。

因此，可以将 CSS 的基本工作方式理解为：

`选择器 → 找到元素 → 属性: 属性值 → 设置样式`

属性名和属性值之间使用 `:` 分隔，一条声明结束后通常使用 `;`。最后一条声明理论上可以省略分号，但为了代码统一和后续修改方便，**建议每条声明都保留结尾分号**。

---

### CSS 注释

CSS 注释使用 `/* */`：

```css
/* 设置页面背景颜色 */
body {
    background-color: yellow;
}

/* 设置标题样式 */
h1 {
    color: blue;
    font-size: 30px;
}
```

CSS 注释可以写成单行，也可以跨多行：

```css
/*
    用户信息区域
    设置标题的基础样式
*/
.title {
    font-size: 24px;
}
```

> 注意：CSS 不能把 `//` 作为标准注释语法。JavaScript 中常见的 `// 注释` 不能直接当作普通 CSS 注释使用。

### CSS 的引入方式

HTML 页面使用 CSS 主要有三种方式：**内联样式、内部样式和外部样式**。

它们的区别主要在于 CSS 代码存放的位置不同。

#### 内联样式

**内联样式（Inline Style）**直接通过 HTML 元素的 `style` 属性设置样式：

```html
<p style="color: red; font-size: 14px;">这是一段文字</p>
```

`style` 属性内部直接按照 `属性名: 属性值;` 的形式编写 CSS 声明，不需要再写选择器。

例如：

```html
<div
    style="
        width: 200px;
        height: 100px;
        background-color: lightblue;
        color: white;
    "
>
    用户信息
</div>
```

附件中的内联样式示例也是直接在 `<div>` 的 `style` 属性中设置尺寸、背景、边框、Flex 布局和字体等样式。

内联样式的优点是**简单、直接，只影响当前元素**，但缺点也比较明显：

- HTML 结构与 CSS 样式混合在一起。
- 多个元素使用相同样式时，需要重复编写。
- 后期统一修改样式比较困难。
- 不利于大型页面的维护和样式复用。

因此，**普通项目开发中通常不把内联样式作为主要的样式编写方式**。

不过，内联样式并不是绝对不能使用。例如 JavaScript 根据运行结果临时修改某个元素的少量样式时，最终可能形成内联样式；某些特殊的邮件 HTML 等环境中也可能大量使用。

---

#### 内部样式

**内部样式（Internal Style Sheet）**使用 `<style>` 标签在当前 HTML 文档中集中编写 CSS。

通常将 `<style>` 放在 `<head>` 中：

```html
<head>
    <meta charset="UTF-8">
    <title>CSS 示例</title>

    <style>
        body {
            background-color: yellow;
        }

        h1 {
            color: blue;
            font-size: 30px;
        }
    </style>
</head>
```

与内联样式不同，内部样式已经开始使用完整的 CSS 语法：

```css
选择器 {
    属性: 属性值;
}
```

这样一条 CSS 规则可以同时作用于多个符合条件的元素。例如：

```css
p {
    color: red;
}
```

页面中所有被该选择器匹配的 `<p>` 都可以应用这套样式，不需要分别设置 `style` 属性。

附件中的内部样式示例通过 `<style>` 统一设置多个 `<p>` 的边框、大小和背景等样式，体现了内部样式能够统一作用于多个元素。

> 注意：附件中还演示了将 `<style>` 写在 `<body>` 中的形式。 在规范的普通 HTML 文档中，**样式表通常应统一放在 `<head>` 中**，不要把 `<style>` 随意穿插在页面正文结构中。

内部样式适用于**当前页面具有独立样式，并且样式数量不多、不需要在多个页面之间复用**的场景。

与内联样式相比，它已经实现了一定程度上的**结构与样式分离**，但 CSS 代码仍然保存在 HTML 文件内部，因此多个页面之间无法方便地共享同一套样式。

---

#### 外部样式

**外部样式（External Style Sheet）**是将 CSS 代码单独保存在 `.css` 文件中，再通过 HTML 的 `<link>` 元素加载。

例如，创建 `index.css`：

```css
body {
    background-color: yellow;
}

h1 {
    color: blue;
    font-size: 30px;
}
```

然后在 HTML 的 `<head>` 中引入：

```html
<head>
    <meta charset="UTF-8">
    <title>CSS 示例</title>

    <link rel="stylesheet" href="css/index.css">
</head>
```

其中：

- `rel="stylesheet"` 表示当前链接资源是一份**样式表**。
- `href="css/index.css"` 指定需要加载的 CSS 文件 URL。

附件中的外部样式示例也是通过 `<link rel="stylesheet" href="css/style.css">` 加载外部 CSS 文件。

`href` 可以使用不同形式的路径。例如 `css/style.css` 是相对于当前 HTML 文档 URL 解析的相对路径；`/css/style.css` 以 `/` 开头，表示从当前网站的**根路径**开始解析，而不能简单理解成计算机文件系统中的“项目根目录”。

外部样式是实际 Web 项目中最常见的 CSS 组织方式之一，主要具有以下优势。

##### 结构与样式分离

HTML 主要保存页面结构：

```html
<h1 class="title">用户中心</h1>
```

CSS 单独负责视觉效果：

```css
.title {
    color: blue;
    font-size: 30px;
}
```

修改视觉效果时通常无需修改 HTML 结构，使代码职责更加清晰。

##### 样式可以复用

多个 HTML 页面可以同时加载同一个 CSS 文件：

```html
<link rel="stylesheet" href="css/common.css">
```

例如 `index.html`、`login.html`、`user.html` 都可以加载 `common.css`，从而共享统一的字体、颜色和布局规则。

这既减少重复代码，也有利于保持网站整体视觉风格一致。

##### 便于维护和模块化管理

项目变大后，可以根据用途拆分 CSS，例如 `common.css` 保存公共样式、`layout.css` 保存布局样式、`login.css` 保存登录页面特有样式。

需要调整公共设计时，只需修改公共样式文件，而不必逐个修改每个 HTML 页面。

##### 有利于浏览器缓存

外部 CSS 文件属于独立资源，在服务器配置和 HTTP 缓存策略允许的情况下，浏览器可以缓存已经下载的 CSS 文件。

当多个页面使用同一个 CSS 文件时，后续页面可能直接使用缓存中的资源，从而减少重复传输。

> 注意：不能简单认为“使用外部 CSS 就一定加载更快”。实际性能还受到文件数量、文件大小、网络环境和 HTTP 缓存策略等因素影响。外部样式最主要的优势仍然是**复用性、可维护性和职责分离**。

---

### 三种引入方式的对比

| 方式     | CSS 编写位置              | 作用范围         | 复用性 | 常见使用场景               |
| -------- | ------------------------- | ---------------- | ------ | -------------------------- |
| 内联样式 | HTML 元素的 `style` 属性  | 当前元素         | 低     | 临时、动态或极少量特殊样式 |
| 内部样式 | 当前 HTML 的 `<style>` 中 | 当前页面         | 一般   | 单页面或少量独立样式       |
| 外部样式 | 独立 `.css` 文件          | 可供多个页面使用 | 高     | 实际项目中的主要方式       |

从长期维护角度来看，通常优先采用**外部样式**。内部样式适合页面独有且数量较少的 CSS，内联样式则应根据实际需要少量使用。

> 补充：一些页面性能优化会将少量“首屏关键 CSS”直接嵌入 HTML，但通常是写入 `<style>`，属于内部样式，而不是把大量 CSS 分散写进每个元素的 `style` 属性。

### 样式的层叠与优先级

同一个 HTML 元素可能同时被多条 CSS 规则匹配。例如：

```html
<head>
    <style>
        p {
            color: blue;
        }
    </style>
</head>

<body>
    <p style="color: red;">这是一段文字</p>
</body>
```

此时同一个 `<p>` 同时获得：

- 内部样式中的 `color: blue`。
- 内联样式中的 `color: red`。

浏览器需要通过 CSS 的**层叠（Cascade）规则**判断最终采用哪个值。

附件中的多重样式示例也是内部样式与内联样式同时作用于同一个 `<div>`，最终内联的 `color: red` 覆盖普通内部样式中的颜色。

#### 不能简单使用“就近原则”

初学阶段经常使用：

**内联样式优先级最高，谁离元素近谁优先。**

这种说法只能帮助理解部分简单情况，**不能作为完整的 CSS 优先级规则**。

例如，外部样式：

```css
p {
    color: red;
}
```

内部样式：

```css
p {
    color: blue;
}
```

如果两条规则的选择器优先级相同，而且不存在其他特殊规则，那么**后出现的规则会覆盖先出现的规则**。

因此，外部样式和内部样式本身并不存在固定的：

`内部样式 > 外部样式`

或者：

`外部样式 > 内部样式`

谁生效取决于它们最终参与层叠时的具体情况。

#### 基础阶段的判断顺序

在不考虑更复杂的层叠来源、层叠层等机制时，可以先按照以下思路判断普通样式：

1. 先判断声明是否存在类似 `!important` 的特殊重要性。
2. 再比较选择器的**优先级（Specificity）**。
3. 普通内联样式通常高于通过普通选择器定义的作者样式。
4. 如果选择器优先级仍然相同，则**后声明的样式覆盖先声明的样式**。

例如：

```css
p {
    color: blue;
}

p {
    color: red;
}
```

两条规则的选择器完全相同，因此后面的 `color: red` 生效。

而：

```css
p {
    color: blue;
}

.notice {
    color: red;
}
```

如果某个元素为：

```html
<p class="notice">提示信息</p>
```

此时 `.notice` 的选择器优先级高于 `p`，所以即使不能简单套用“距离远近”，仍可能由 `.notice` 的样式获胜。

> 易错点：**CSS 优先级的核心不是“内联、内部、外部谁离得近”**。内联样式通常具有很高的优先级，但内部样式和外部样式本身没有固定的高低关系。后续学习 CSS 选择器时，需要进一步掌握选择器优先级的计算规则。

#### `!important`（了解）

CSS 声明后还可以添加 `!important`：

```css
p {
    color: blue !important;
}
```

它会提高该声明在层叠过程中的重要程度，因此即使元素存在普通内联样式，也可能由带有 `!important` 的规则生效。

因此，“内联样式永远优先级最高”并不准确。

> 注意：`!important` 会增加样式覆盖和维护的复杂度，实际开发中不应为了“提高优先级”而随意大量使用。当前阶段只需要知道它是普通优先级规则中的一个重要例外，后续学习 CSS 层叠时再深入掌握。

> 结论：CSS 的三种常见引入方式是**内联样式、内部样式和外部样式**。实际项目通常以外部样式为主；多个样式同时作用于同一个元素时，最终结果由 CSS 的**层叠规则**决定，而不能只依靠“谁离得近谁优先”判断。

## CSS 参考手册

CSS 中存在大量属性和值，实际开发时不需要全部记忆，可以在掌握基本概念后配合 MDN 等参考手册进行查询。为了能够正确阅读 CSS 文档和代码，需要先认识一些常见的**长度单位、颜色表示方式以及资源路径写法**。

### 长度单位

CSS 中很多属性都需要表示长度，例如元素的宽度、高度、字体大小、边框宽度和间距等。

当前阶段重点认识 `px`、`em` 和 `%` 三种常见单位。

| 单位 | 类型         | 基本含义                                              |
| ---- | ------------ | ----------------------------------------------------- |
| `px` | 绝对长度单位 | CSS 像素                                              |
| `em` | 相对长度单位 | 相对于元素当前的 `font-size`                          |
| `%`  | 相对值       | 相对于某个参考值计算，具体参照对象取决于当前 CSS 属性 |

#### `px`

`px` 是 CSS 中最常见的长度单位之一，例如：

```css
.box {
    width: 200px;
    height: 100px;
    border-width: 1px;
}
```

可以将 `200px` 理解为元素宽度为 `200` 个 CSS 像素。

入门阶段经常将 `1px` 简单理解为“屏幕上的一个像素点”，这种理解有助于建立直观认识。不过更准确地说，**CSS 中的 `px` 是 CSS 像素，并不一定与物理显示器上的一个真实像素点严格一一对应**。在高分辨率屏幕、缩放等情况下，一个 CSS 像素可能对应多个物理像素。

#### `em`

`em` 是一个**相对长度单位**，其大小与当前元素计算后的 `font-size` 有关。

通常可以简单理解为：

```
1em = 当前元素的 font-size
```

例如：

```css
.box {
    font-size: 20px;
    width: 5em;
}
```

因为当前元素的 `font-size` 为 `20px`，所以：

```
5em = 5 × 20px = 100px
```

如果当前元素没有显式设置 `font-size`，字体大小通常会从父元素继承，因此 `em` 最终可能间接以父元素的字体大小作为计算基础。

例如：

```html
<div class="parent">
    父节点
    <div class="child">
        子节点
    </div>
</div>
.parent {
    font-size: 20px;
    width: 5em;
}

.child {
    width: 10em;
}
```

`.parent` 的 `font-size` 是 `20px`，因此：

```
5em = 5 × 20px = 100px
```

`.child` 没有单独设置 `font-size`，会继承父元素的 `20px`，所以：

```
10em = 10 × 20px = 200px
```

附件中的 `em` 示例正是通过父元素 `font-size: 20px`、`width: 5em` 和子元素 `width: 10em` 展示这一计算关系。

如果子元素自己重新设置：

```css
.child {
    font-size: 10px;
    width: 10em;
}
```

此时 `.child` 的 `10em` 就按照自己的 `10px` 计算：

```
10em = 10 × 10px = 100px
```

因此，可以将 `em` 的基本规律记为：**先确定当前元素最终使用的 `font-size`，再按照倍数计算 `em`。**

#### `%`

百分比 `%` 也是 CSS 中常见的相对值，例如：

```css
.parent {
    width: 400px;
}

.child {
    width: 50%;
}
```

对于这里的 `width` 来说，`50%` 通常按照包含块的宽度进行计算，因此子元素最终宽度为：

```
400px × 50% = 200px
```

附件中的示例同样使用 `width: 50%`、`height: 50%` 创建相对尺寸。

> 注意：不能把 `%` 统一记成“相对于父元素宽度或高度”。**百分比的具体参照对象由当前 CSS 属性决定。**例如 `width: 50%` 与 `font-size: 50%` 的计算基准并不相同。基础阶段遇到不确定的百分比属性时，应查询该属性的具体定义。

------

### 颜色表示

计算机中的很多颜色都可以通过**红（Red）、绿（Green）、蓝（Blue）**三种颜色分量组合得到，这种颜色模型称为 **RGB**。

CSS 中有多种颜色表示方式，当前阶段重点掌握 **RGB 表示法**和**十六进制表示法**。

#### RGB 表示法

基本语法为：

```css
rgb(red, green, blue)
```

传统写法中，每个颜色分量通常使用 `0`～`255` 的整数表示：

```css
.box {
    color: rgb(255, 0, 0);
}
```

其中：

- Red = `255`
- Green = `0`
- Blue = `0`

最终得到红色。

常见颜色例如：

```css
.red {
    color: rgb(255, 0, 0);
}

.green {
    color: rgb(0, 255, 0);
}

.blue {
    color: rgb(0, 0, 255);
}

.black {
    color: rgb(0, 0, 0);
}

.white {
    color: rgb(255, 255, 255);
}
```

RGB 分量也可以使用百分比形式表示，例如：

```css
color: rgb(100%, 0%, 0%);
```

同样表示红色。

附件中通过 `rgb(100, 20, 30)` 设置边框颜色，展示了 RGB 的基本写法。

#### 十六进制表示法

CSS 还可以使用十六进制表示 RGB 颜色：

```css
#RRGGBB
```

其中：

- `RR` 表示红色分量。
- `GG` 表示绿色分量。
- `BB` 表示蓝色分量。

每一部分的取值范围为：

`00`～`FF`

十六进制中的 `FF` 对应十进制的 `255`。

例如：

```css
.red {
    color: #FF0000;
}

.green {
    color: #00FF00;
}

.blue {
    color: #0000FF;
}

.black {
    color: #000000;
}

.white {
    color: #FFFFFF;
}
```

如果六位十六进制颜色中每两个字符都相同，还可以使用三位简写。

例如：

`#FFFFFF` 可以简写为 `#FFF`，`#000000` 可以简写为 `#000`，`#FF0000` 可以简写为 `#F00`。

三位形式 `#RGB` 展开时，相当于将每一位重复一次：

`#F00` → `#FF0000`

`#09F` → `#0099FF`

附件中的示例使用 `background-color: #000`，并说明了 `#RRGGBB` 和 `#RGB` 两种形式。

> 补充：CSS 还支持颜色名称、带透明度的颜色以及其他现代颜色表示方式。当前阶段先掌握 RGB 与十六进制写法即可，后续遇到其他形式时再根据需要学习。

### 相对路径与绝对路径

Web 页面通常需要引用各种外部资源，例如 CSS、JavaScript、图片、字体等，因此需要通过**路径（Path）**确定资源的位置。

按照路径的参照方式，可以先分为**相对路径**和**绝对形式的 URL**来理解。

#### 相对路径

相对路径根据**当前资源的位置**寻找目标资源。

常见写法如下：

| 写法               | 含义                                            |
| ------------------ | ----------------------------------------------- |
| `file.txt`         | 当前目录中的 `file.txt`                         |
| `./file.txt`       | `./` 表示当前目录，与直接写 `file.txt` 基本相同 |
| `../file.txt`      | 进入当前目录的上一级目录后寻找 `file.txt`       |
| `images/photo.jpg` | 进入当前目录下的 `images` 目录寻找 `photo.jpg`  |
| `../../file.txt`   | 连续返回两级目录后寻找文件                      |

假设目录结构如下：

```text
project/
├── index.html
├── css/
│   └── style.css
└── images/
    ├── logo.png
    └── bg/
        └── background.jpg
```

在 `index.html` 中引用 `style.css`：

```html
<link rel="stylesheet" href="css/style.css">
```

因为 `index.html` 与 `css` 目录同级，所以先进入 `css`，再找到 `style.css`。

引用 `logo.png`：

```html
<img src="images/logo.png" alt="网站 Logo">
```

引用 `background.jpg`：

```html
<img src="images/bg/background.jpg" alt="背景图片">
```

#### CSS 文件中的相对路径

如果在 `style.css` 中引用图片：

```css
body {
    background-image: url("../images/bg/background.jpg");
}
```

这里的路径并不是从 `index.html` 开始计算，而是从**当前 CSS 文件 `style.css` 所在位置**开始解析。

当前文件位于：

```
project/css/style.css
```

目标图片位于：

```
project/images/bg/background.jpg
```

因此需要：

1. 使用 `..` 从 `css` 返回 `project`。
2. 进入 `images/bg`。
3. 找到 `background.jpg`。

最终写成：

```
../images/bg/background.jpg
```

> 易错点：HTML 中 `src`、`href` 的相对路径通常根据当前文档 URL 解析，而 CSS 中 `url(...)` 引用的相对资源则通常根据**当前 CSS 文件自己的 URL**解析。实际项目中路径错误经常出现在这里。

------

#### 以 `/` 开头的路径

在 Web URL 中：

```html
<img src="/images/logo.png" alt="网站 Logo">
```

开头的 `/` 表示从当前网站的**源（Origin）根路径**开始解析。

假设当前页面地址为：

```
https://www.example.com/user/info/index.html
```

那么：

```html
<img src="/images/logo.png">
```

会指向：

```
https://www.example.com/images/logo.png
```

而：

```html
<img src="images/logo.png">
```

则会按照当前文档位置解析，通常指向：

```
https://www.example.com/user/info/images/logo.png
```

因此，以 `/` 开头的路径不会受到当前 HTML 文件目录层级的影响。

> 注意：这里所说的“根”是**网站 URL 的根路径**，不能简单理解成 Windows 的 `C:\`、Linux 的 `/`，也不一定等同于开发工具中看到的项目源码目录。

------

#### 完整 URL

还可以直接使用完整 URL 指定资源：

```html
<img
    src="https://www.example.com/images/logo.png"
    alt="网站 Logo"
>
```

或者：

```html
<link
    rel="stylesheet"
    href="https://cdn.example.com/css/style.css"
>
```

完整 URL 中已经包含协议、主机以及资源路径，因此不需要根据当前页面所在目录推导目标位置。

这种方式常用于加载其他服务器或 CDN 提供的资源。

------

### 路径对比

假设当前页面地址为：

```
https://www.example.com/user/index.html
```

则以下路径可以对比理解：

| 写法                                | 最终目标                                        |
| ----------------------------------- | ----------------------------------------------- |
| `photo.jpg`                         | `https://www.example.com/user/photo.jpg`        |
| `./photo.jpg`                       | `https://www.example.com/user/photo.jpg`        |
| `images/photo.jpg`                  | `https://www.example.com/user/images/photo.jpg` |
| `../photo.jpg`                      | `https://www.example.com/photo.jpg`             |
| `/images/photo.jpg`                 | `https://www.example.com/images/photo.jpg`      |
| `https://cdn.example.com/photo.jpg` | 直接访问指定的完整 URL                          |

因此，判断路径时最重要的是先确定：

**“当前是以哪个资源的位置作为参照点？”**

对于 HTML 中的普通相对 URL，通常以当前 HTML 文档的 URL 为基础；对于外部 CSS 文件中的 `url(...)`，通常以当前 CSS 文件的 URL 为基础。

> 结论：相对路径依赖当前资源的位置，适合描述项目内部资源之间的层级关系；以 `/` 开头的 URL 从当前网站根路径开始解析；完整 URL 则直接指定目标资源的位置。路径问题的核心不是死记 `../`，而是先找到**当前资源和目标资源分别在哪里**，再判断应该向上返回几级、进入哪个目录。

## CSS 选择器

**CSS 选择器（Selector）**用于从 HTML 文档中找到需要设置样式的元素。CSS 的基本工作过程就是：**通过选择器选中元素，再通过声明块为这些元素设置样式。**

当前阶段涉及的选择器主要包括：

1. 基础选择器。
2. 关系选择器。
3. 属性选择器。
4. 伪类选择器。
5. 通配符选择器。

### 基础选择器

基础选择器主要包括**标签选择器、类选择器和 ID 选择器**。

#### 标签选择器

标签选择器直接使用 **HTML 标签名**作为选择器，用于选中页面中所有指定类型的元素。

基本语法为：

```css
标签名 {
    属性: 值;
}
```

例如：

```css
p {
    color: blue;
    font-size: 18px;
    background-color: yellow;
}
```

对应 HTML：

```html
<p>第一个段落</p>
<p>第二个段落</p>
<p>第三个段落</p>
```

由于选择器是 `p`，页面中的所有 `<p>` 元素都会应用这套样式。附件中的示例也是通过 `p` 一次选中三个段落。

标签选择器适合对**同一类 HTML 元素设置统一的基础样式**，但选择范围通常比较大。

------

#### 类选择器

类选择器通过 HTML 元素的 `class` 属性选择元素，CSS 中使用：

```css
.类名 {
    属性: 值;
}
```

例如：

```css
.tag {
    color: blue;
}
```

HTML 中为需要应用该样式的元素设置对应的 `class`：

```html
<h1 class="tag">我是标题</h1>
<div class="tag">我是一个 div</div>
```

此时 `<h1>` 和 `<div>` 虽然属于不同的 HTML 标签，但因为都具有 `class="tag"`，所以都会被 `.tag` 选中。

因此，类选择器最大的特点之一就是：**同一个类可以被多个元素复用，而且这些元素不要求是同一种标签。**

一个元素还可以同时具有多个类名，不同类名之间使用空格分隔：

```html
<div class="tag container">我是一个 div</div>
```

此时该元素既属于 `tag` 类，又属于 `container` 类，可以同时应用 `.tag` 和 `.container` 对应的样式。附件中的类选择器示例就展示了这种写法。

> 结论：实际开发中，**类选择器是最常用的基础选择器之一**，因为它具有较好的复用性。

------

#### ID 选择器

ID 选择器通过元素的 `id` 属性选中元素，CSS 中使用：

```css
#id值 {
    属性: 值;
}
```

例如：

```css
#title {
    color: blue;
}

#block {
    color: red;
}
```

对应 HTML：

```html
<h1 id="title">我是标题</h1>
<div id="block">我是一个 div</div>
```

附件中的示例就是分别通过 `#title` 和 `#block` 对两个元素设置样式。

在一个 HTML 文档中，`id` 应作为元素的**唯一标识**，不应该让多个元素使用相同的 `id`。

因此，基础选择器可以简单记为：

| 选择器     | 写法     | 选中目标                         |
| ---------- | -------- | -------------------------------- |
| 标签选择器 | `p`      | 所有 `<p>`                       |
| 类选择器   | `.tag`   | 所有 `class` 中包含 `tag` 的元素 |
| ID 选择器  | `#title` | `id="title"` 的元素              |

------

### 关系选择器

课程材料中的关系选择器主要包括**交集选择器、并集选择器、后代选择器和亲子选择器**。其中，“亲子选择器”在 CSS 中更常称为**子选择器（Child Combinator）**。

#### 交集选择器

交集选择器将多个条件**紧密连接，中间不加空格**，用于选择同时满足这些条件的元素。

例如：

```css
div.tag {
    color: blue;
}
```

表示：

**既是 `<div>`，同时又具有 `class="tag"` 的元素。**

假设 HTML 为：

```html
<h1 class="tag">我是标题</h1>
<div class="tag">我是一个 div</div>
```

`.tag` 本来可以选中两个元素，但 `div.tag` 又增加了“必须是 `<div>`”这一条件，所以最终只选中：

```html
<div class="tag">我是一个 div</div>
```

同样：

```css
p#title {
    font-size: 30px;
}
```

表示选中：

**既是 `<p>`，同时 `id="title"` 的元素。**

附件中的交集选择器示例分别使用了 `div.tag` 和 `p#title`。

可以把交集选择器理解为：

```
条件1 AND 条件2
```

即**所有条件必须同时成立**。

------

#### 并集选择器

并集选择器使用逗号 `,` 将多个选择器连接起来，为多个不同选择器匹配到的元素设置相同样式。

例如：

```css
.search,
span,
#important {
    color: red;
}
```

表示以下元素都会被选中：

- `class="search"` 的元素。
- 所有 `<span>` 元素。
- `id="important"` 的元素。

因此，可以将并集选择器理解为：

```
选择器1 OR 选择器2 OR 选择器3
```

只要符合其中任意一个选择器，就会应用对应样式。

附件中的示例也是将类选择器、标签选择器和 ID 选择器通过逗号组合起来。

并集选择器最大的价值是**减少重复 CSS 代码**。

例如，不需要分别写：

```css
h1 {
    color: red;
}

h2 {
    color: red;
}

h3 {
    color: red;
}
```

可以直接写：

```css
h1,
h2,
h3 {
    color: red;
}
```

------

#### 后代选择器

后代选择器使用**空格**连接两个选择器：

```css
E F {
    属性: 值;
}
```

表示选择 **E 元素内部所有符合 F 条件的后代元素**。

例如：

```css
.box span {
    color: red;
}
```

HTML：

```html
<div class="box">
    <span>第一层 span</span>

    <div>
        <span>第二层 span</span>
    </div>
</div>
```

`.box span` 不只会选中直接位于 `.box` 内部的第一个 `<span>`，还会选中更深层嵌套的第二个 `<span>`。

也就是说，后代选择器关注的是：

**只要 F 位于 E 内部，不论中间隔了多少层，都可以被选中。**

附件中的 `.box span` 示例同时匹配了直接子元素和更深层的 `<span>`。

------

#### 子选择器

课程中称为“亲子选择器”，更常见的名称是**子选择器**。它使用 `>` 连接两个选择器：

```css
E > F {
    属性: 值;
}
```

表示：

**只选择直接以 E 为父元素的 F 元素。**

例如：

```css
.tag > span {
    color: red;
}
```

HTML：

```html
<div class="tag">
    <span>第一层 span</span>

    <div>
        <span>第二层 span</span>
    </div>
</div>
```

`.tag > span` 只会直接选中第一层 `<span>`，因为它的直接父元素就是 `.tag`。

第二层 `<span>` 的直接父元素是内部的 `<div>`，因此**不会被 `.tag > span` 直接选中**。附件中的子选择器示例体现的正是这一关系。

后代选择器与子选择器的区别可以概括为：

| 选择器     | 写法    | 范围                    |
| ---------- | ------- | ----------------------- |
| 后代选择器 | `E F`   | E 内部所有层级的 F      |
| 子选择器   | `E > F` | 只选择 E 的直接子元素 F |

------

### CSS 属性继承

理解子选择器时，很容易遇到一个看起来矛盾的现象。

例如：

```html
<div class="tag">
    <span>
        spanA
        <span>spanA1</span>
    </span>

    <span>spanB</span>
</div>
```

CSS：

```css
.tag > span {
    color: red;
    font-size: 30px;
    font-weight: bold;
}
```

从选择器关系来看，`.tag > span` 只直接匹配：

- `spanA`
- `spanB`

并**不会直接匹配 `spanA1`**，因为 `spanA1` 的父元素是 `spanA`，而不是 `.tag`。

但是页面最终显示时，`spanA1` 可能同样表现为红色、`30px`、粗体。

原因并不是子选择器匹配到了 `spanA1`，而是：

**`color`、`font-size`、`font-weight` 等属性默认可以从父元素继承。**

实际过程是：

```
规则匹配 spanA → spanA 得到样式 → spanA1 从父元素 spanA 继承部分样式
```

因此，必须区分两个概念：

- **选择器匹配**：决定 CSS 规则直接作用于哪些元素。
- **属性继承**：某些属性的计算值会从父元素传递给子元素。

> 易错点：看到子元素拥有某种样式，不代表 CSS 选择器一定直接选中了它。它也可能只是从父元素**继承**了该属性。

#### 常见可继承属性

CSS 中与**文字排版**相关的属性通常具有较强的继承特性，例如：

| 属性             | 作用           |
| ---------------- | -------------- |
| `color`          | 文字颜色       |
| `font-family`    | 字体           |
| `font-size`      | 字体大小       |
| `font-weight`    | 字体粗细       |
| `font-style`     | 字体样式       |
| `line-height`    | 行高           |
| `text-align`     | 文本对齐       |
| `text-indent`    | 文本缩进       |
| `letter-spacing` | 字符间距       |
| `word-spacing`   | 单词间距       |
| `text-transform` | 文本大小写转换 |

部分列表及其他属性也具有继承性，例如 `list-style-type`、`list-style-position`、`visibility`、`cursor` 等。

#### 常见不可继承属性

与**盒模型、布局、定位**相关的属性通常不会自动继承，例如：

| 类型     | 常见属性                                     |
| -------- | -------------------------------------------- |
| 尺寸     | `width`、`height`                            |
| 外边距   | `margin`                                     |
| 内边距   | `padding`                                    |
| 边框     | `border`                                     |
| 背景     | `background`、`background-color`             |
| 显示方式 | `display`                                    |
| 定位     | `position`、`top`、`right`、`bottom`、`left` |
| 浮动     | `float`、`clear`                             |
| 溢出     | `overflow`                                   |
| 层级     | `z-index`                                    |

`opacity` 本身也**不是继承属性**。但是父元素设置透明度后，整个元素及其子树会作为整体参与透明度合成，所以视觉上子元素也会一起变透明。这个效果和“子元素继承了 `opacity`”并不是同一回事。

例如给子选择器增加一个不会自动继承的 `border`：

```css
.tag > span {
    color: red;
    font-size: 30px;
    font-weight: bold;
    border: 1px solid black;
}
```

此时：

- `spanA`、`spanB` 会直接获得边框。
- `spanA1` 仍可能继承红色、字号、粗体。
- `spanA1` **不会因为继承而获得 `border`**。

这样就能够更加清楚地证明：`.tag > span` 确实只直接选中了 `.tag` 的直接 `<span>` 子元素。

> 结论：判断 CSS 效果时，需要分别考虑**“这个元素有没有被选择器直接选中”**以及**“这个属性是否可以从父元素继承”**。

------

### 属性选择器

属性选择器根据 HTML 元素是否具有某个属性，或者属性是否具有特定值来选择元素。

例如：

```html
<a href="#" id="link">链接</a>
```

其中，`href`、`id` 都是属性名，`#`、`link` 是对应属性值。

常见的基础写法包括：

`[attr]`、`E[attr]`、`E[attr="value"]`

#### `[attr]`

```css
[class] {
    color: red;
}
```

表示：

**选中所有具有 `class` 属性的元素，不关心 `class` 的具体值是什么。**

例如：

```html
<div class="block">div</div>
<p class="title">p</p>
```

两个元素都会被 `[class]` 选中。

#### `E[attr]`

```css
span[id] {
    font-size: 30px;
}
```

表示：

**选中所有具有 `id` 属性的 `<span>` 元素。**

它比单独的 `[id]` 多增加了一个“必须是 `<span>`”的条件。

#### `E[attr="value"]`

```css
a[id="tag3"] {
    text-decoration: none;
}
```

表示：

**选择 `id` 属性值恰好等于 `tag3` 的 `<a>` 元素。**

附件中的属性选择器示例同时演示了 `[class]`、`[id]`、`span[id]` 和 `a[id="tag3"]`。

基础阶段可以先记住：

| 写法              | 含义                             |
| ----------------- | -------------------------------- |
| `[attr]`          | 具有指定属性的任意元素           |
| `E[attr]`         | 具有指定属性的 E 元素            |
| `E[attr="value"]` | 指定属性值等于 `value` 的 E 元素 |

------

### 伪类选择器

**伪类（Pseudo-class）**用于选择处于某种特定状态的元素，语法通常是在选择器后添加：

```css
选择器:伪类 {
    属性: 值;
}
```

例如：

```css
a:hover {
    color: green;
}
```

这里的 `:hover` 表示元素处于**鼠标指针悬停**状态。

伪类并不是修改 HTML 元素本身，也不需要额外添加 `class`。它是根据元素当前状态或结构关系动态决定是否匹配。

#### `:hover`

`:hover` 表示鼠标指针停留在元素上时的状态：

```css
div:hover,
a:hover {
    color: green;
}
```

当鼠标移动到对应的 `<div>` 或 `<a>` 上时，文字颜色变为绿色。

#### `:active`

`:active` 表示元素处于**激活状态**。对于鼠标操作，通常可以理解为从按下鼠标到释放鼠标之间的短暂状态。

```css
div:active,
a:active {
    color: yellow;
}
```

附件中的示例分别通过 `:hover` 和 `:active` 设置悬停与激活状态的样式，并对一个模拟按钮的 `<div>` 使用了 `#btn:active`。

因此：

```
正常状态 → 鼠标移入 → :hover
鼠标按下激活 → :active
```

> 注意：不能把 `:active` 简单理解成“点击完成之后的状态”。它通常是元素**正在被激活的短暂状态**。对于超链接已经访问过的状态，则存在其他伪类，例如 `:visited`。

伪类选择器的意义在于：**不修改 HTML 结构，也可以根据元素状态应用不同样式**，从而实现悬停、聚焦、选中等交互反馈。

------

### 通用选择器

通用选择器使用 `*` 表示，用于匹配页面中的**所有元素**。

基本语法：

```css
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
```

例如：

```html
<html>
    <body>
        <div>
            <p>文本内容</p>
        </div>
    </body>
</html>
```

上述 `*` 会匹配 `<html>`、`<body>`、`<div>`、`<p>` 等所有元素，而不只是 `<body>`。

课程示例中通过 `*` 同时设置 `margin: 0`、`padding: 0` 和 `box-sizing: border-box`。

这种写法常用于进行一些全局基础样式设置：

```css
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
```

其中：

- `margin: 0;`：将匹配元素的外边距设置为 `0`。
- `padding: 0;`：将匹配元素的内边距设置为 `0`。
- `box-sizing: border-box;`：改变元素宽高的计算方式。

> 注意：这里的 `margin: 0` 和 `padding: 0` 作用于**所有被 `\*` 匹配的元素**，不能只理解为“清除 `<body>` 的默认间距”。例如标题、列表等 HTML 元素本身也可能存在浏览器默认的 `margin`，同样会受到影响。

#### `box-sizing`

CSS 中常见的盒模型计算方式包括 `content-box` 和 `border-box`。

默认情况下通常为：

```css
box-sizing: content-box;
```

例如：

```css
.box {
    box-sizing: content-box;
    width: 100px;
    padding: 10px;
    border: 5px solid;
}
```

这里的 `width: 100px` 只表示**内容区域宽度**，因此元素边框外侧实际占用的总宽度为：

```
100 + 10 × 2 + 5 × 2 = 130px
```

而：

```css
.box {
    box-sizing: border-box;
    width: 100px;
    padding: 10px;
    border: 5px solid;
}
```

此时 `width: 100px` 已经包含内容区域、左右 `padding` 和左右 `border`，因此边框盒总宽度仍然是 `100px`，内容区域会自动缩小。

附件中的盒模型示例正好对比了两种情况：`content-box` 最终占用 `130px`，而 `border-box` 的指定宽度保持为 `100px`。

可以简单理解为：

- `content-box`：设置的 `width` 主要控制**内容区域**。
- `border-box`：设置的 `width` 控制**包含 padding 和 border 在内的边框盒宽度**。

因此，实际页面布局中经常统一设置：

```css
* {
    box-sizing: border-box;
}
```

这样在计算元素宽高时通常更加直观。

> 补充：课程材料提到通用选择器“性能较差，应慎用”。实际理解时更应该关注的是：`*` 的**匹配范围非常广**，因此不要随意给所有元素添加大量不必要的样式。现代浏览器对通用选择器本身已经有较成熟的优化，不需要仅因为“性能”就完全避免使用。

------

### 属性选择器的匹配方式

前面已经学习了：

```css
[attr]
E[attr]
E[attr="value"]
```

CSS 属性选择器还可以根据属性值的**开头、结尾、包含关系以及单词关系**进行匹配。

常见形式如下：

| 写法              | 含义                                     |
| ----------------- | ---------------------------------------- |
| `[attr^="value"]` | 属性值以 `value` 开头                    |
| `[attr$="value"]` | 属性值以 `value` 结尾                    |
| `[attr*="value"]` | 属性值中包含 `value`                     |
| `[attr~="value"]` | 属性值的空格分隔单词中包含完整的 `value` |
| `[attr            | ="value"]`                               |

#### `[attr^="value"]`

`^=` 表示**从指定内容开始**。

例如：

```css
a[href^="https"] {
    color: green;
}
```

表示选择所有 `href` 属性值以 `https` 开头的 `<a>` 元素。

```html
<a href="https://www.example.com">HTTPS 链接</a>
<a href="http://www.example.com">HTTP 链接</a>
<a href="/user/index.html">站内链接</a>
```

只有第一个链接满足条件。

附件中的示例同样通过 `a[href^="https"]` 筛选 HTTPS 链接。

------

#### `[attr$="value"]`

`$=` 表示属性值**以指定内容结尾**。

例如：

```css
a[href$=".pdf"] {
    color: red;
}
```

可以选中：

```html
<a href="document.pdf">PDF 文档</a>
<a href="/files/report.pdf">PDF 报表</a>
```

而：

```html
<a href="photo.jpg">图片</a>
```

不会被选中。

附件中的示例正是利用 `a[href$=".pdf"]` 选择 PDF 链接。

------

#### `[attr*="value"]`

`*=` 表示属性值中**只要包含指定字符串即可**。

例如：

```css
div[class*="box"] {
    border: 1px solid blue;
}
```

以下元素都会匹配：

```html
<div class="box"></div>
<div class="content-box"></div>
<div class="box-container"></div>
```

而：

```html
<div class="container"></div>
```

不会匹配。

附件中的示例同样展示了 `box`、`content-box` 和 `box-container` 都能够被 `[class*="box"]` 匹配。

> 注意：`*=` 匹配的是**字符串包含关系**，不会判断 `box` 是不是一个完整的 class 类名。

例如：

```html
<div class="bigbox"></div>
```

同样包含字符串 `box`，因此也能被 `[class*="box"]` 匹配。

------

#### `[attr~="value"]`

`~=` 用于匹配**以空格分隔的一组单词中的完整单词**。

例如：

```css
p[class~="highlight"] {
    background-color: yellow;
}
```

以下内容可以匹配：

```html
<p class="highlight">匹配</p>
<p class="text highlight">匹配</p>
<p class="highlight important">匹配</p>
```

而：

```html
<p class="text-highlight">不匹配</p>
<p class="highlighted">不匹配</p>
```

因为其中并不存在一个完整、独立的 `highlight` 单词。

附件中的示例正好体现了这种区别。

对于 `class` 属性来说：

```css
[class~="highlight"]
```

在匹配效果上与：

```css
.highlight
```

非常相似，因为 `class` 本身就是由空格分隔的一组类名。

------

#### `[attr|="value"]`

`|=` 表示属性值必须满足以下两种情况之一：

1. 完全等于 `value`。
2. 以 `value-` 开头。

例如：

```css
div[lang|="en"] {
    background-color: lightblue;
}
```

可以匹配：

```html
<div lang="en">匹配</div>
<div lang="en-US">匹配</div>
<div lang="en-GB">匹配</div>
```

但不会匹配：

```html
<div lang="english">不匹配</div>
<div lang="en_UK">不匹配</div>
```

这种写法特别适用于类似 `lang` 的语言代码。

附件中的示例也是通过 `div[lang|="en"]` 匹配 `en`、`en-US` 和 `en-GB`。

------

### 结构伪类选择器

伪类不仅可以表示 `:hover`、`:active` 等交互状态，还可以根据元素在父元素中的**结构位置**进行选择。

当前重点认识：

```css
:nth-child()
:nth-of-type()
:not()
```

#### `:nth-child()`

`:nth-child()` 根据元素在**所有兄弟元素中的位置**进行匹配。

例如：

```css
li:nth-child(2) {
    background-color: #f0f0f0;
}
```

表示：

**选择本身是 `<li>`，并且在父元素所有子元素中排行第 2 的元素。**

例如：

```html
<ul>
    <li>第1项</li>
    <li>第2项</li>
    <li>第3项</li>
</ul>
```

最终第二个 `<li>` 被选中。附件中的示例就是这种情况。

除了具体数字，还可以使用：

- `odd`：奇数位置。
- `even`：偶数位置。

例如：

```css
li:nth-child(odd) {
    background-color: #f0f0f0;
}
```

会选中第 `1、3、5……` 个子元素中的 `<li>`。附件中通过 `li:nth-child(odd)` 实现了列表的奇数项背景。

类似地：

```css
tr:nth-child(even) {
    background-color: #f0f0f0;
}
```

可以实现常见的表格隔行变色效果。

------

#### `:nth-of-type()`

`:nth-of-type()` 与 `:nth-child()` 的区别在于，前者只在**同类型兄弟元素之间计数**。

例如：

```html
<div>
    <h2>标题</h2>
    <p>第一个 p</p>
    <p>第二个 p</p>
</div>
```

使用：

```css
p:nth-child(2) {
    color: red;
}
```

第二个子元素恰好是第一个 `<p>`，所以第一个 `<p>` 被选中。

而：

```css
p:nth-of-type(2) {
    color: red;
}
```

表示选择父元素下**第二个 `<p>` 类型的元素**，所以会选中：

```html
<p>第二个 p</p>
```

因此可以这样记：

- `:nth-child(n)`：先看它是父元素的**第几个孩子**。
- `:nth-of-type(n)`：先看它在**同类型元素中排行第几**。

> 易错点：`:nth-child(n)` 并不是“选择第 n 个某类型元素”。例如 `p:nth-child(2)` 的意思是“这个元素既必须是 `<p>`，又必须刚好是父元素的第 2 个子元素”。

------

#### `:not()`

`:not()` 称为**否定伪类**，用于排除满足指定条件的元素。

例如：

```css
#tag div:not(.hidden) {
    background-color: lightgreen;
}
```

可以理解为：

1. 找到 `#tag` 内部的 `<div>`。
2. 排除 `.hidden`。
3. 剩余 `<div>` 应用样式。

例如：

```html
<div id="tag">
    <div class="visible">匹配</div>
    <div class="hidden">排除</div>
    <div class="content">匹配</div>
    <div>匹配</div>
</div>
```

附件中的反选示例也通过 `#tag div:not(.hidden)` 排除了带有 `.hidden` 的元素。

可以简单理解为：

```css
:not(不希望匹配的条件)
```

------

### 选择器优先级

当**同一个元素的同一个 CSS 属性**同时受到多条规则影响，并且这些规则之间发生冲突时，浏览器需要通过 CSS 的层叠机制决定最终采用哪一个声明。

在前面已经学习过：不能单纯使用“离元素越近优先级越高”来判断。这里进一步学习其中非常重要的一部分——**选择器优先级（Specificity）**。

#### 单个选择器的优先级

在普通作者样式、同等重要性的前提下，可以先记住：

**ID 选择器 > 类选择器 / 属性选择器 / 伪类选择器 > 标签选择器 > 通用选择器**

例如：

```css
div {
    background-color: chocolate;
}

.container {
    background-color: green;
}

#tag {
    background-color: blue;
}
```

HTML：

```html
<div id="tag" class="container"></div>
```

三个选择器都能匹配这个 `<div>`，但 `#tag` 的优先级最高，因此最终背景为蓝色。

附件中的单个选择器示例正是同时使用了标签、类和 ID 选择器进行比较。

常见选择器可以归纳为：

| 类型       | 示例            | 优先级类别         |
| ---------- | --------------- | ------------------ |
| ID 选择器  | `#main`         | 高                 |
| 类选择器   | `.box`          | 中                 |
| 属性选择器 | `[type="text"]` | 中                 |
| 伪类选择器 | `:hover`        | 中                 |
| 标签选择器 | `div`           | 低                 |
| 通用选择器 | `*`             | 不增加选择器优先级 |

因此，之前学习的：

```css
a[href^="https"]
```

其中包含：

- 一个标签选择器 `a`。
- 一个属性选择器 `[href^="https"]`。

而：

```css
.box:hover
```

包含：

- 一个类选择器 `.box`。
- 一个伪类选择器 `:hover`。

------

#### 复合选择器的优先级

对于由多个简单选择器组成的复杂选择器，不能简单看“整个选择器属于哪一类”，而是需要统计不同级别选择器出现的数量。

基础阶段可以使用三组数字表示：

```text
(ID数量, 类/属性/伪类数量, 标签数量)
```

然后**从左向右逐级比较**。

例如：

```css
div.container
```

包含：

- ID：`0`
- 类：`1`
- 标签：`1`

所以可以记为：

```
(0, 1, 1)
```

而：

```css
.container.box
```

包含两个类选择器：

```
(0, 2, 0)
```

因此：

```
.container.box > div.container
```

再例如：

```css
#main p.highlight
```

包含：

- 一个 ID：`#main`
- 一个类：`.highlight`
- 一个标签：`p`

所以：

```
(1, 1, 1)
```

它的 ID 数量已经是 `1`，因此会高于前面的 `(0, 2, 0)`。

附件中的示例包含：

```css
div.container
.container.box
#main p.highlight
.highlight
p
```

最终作用于目标 `<p>` 的冲突规则中，`#main p.highlight` 的优先级最高，因此文字显示为红色。

可以把比较过程记成：

1. **先比较 ID 数量。**
2. ID 数量相同，再比较**类、属性选择器和伪类数量**。
3. 再相同，比较**标签选择器数量**。
4. 如果仍完全相同，再比较声明顺序。

> 注意：属性选择器和伪类选择器在优先级计算中与类选择器属于同一级别，并不只有 `class` 才参与第二级比较。

例如：

```css
input[type="text"]
```

其优先级可以理解为：

```
(0, 1, 1)
```

因为 `[type="text"]` 属于属性选择器，`input` 属于标签选择器。

------

#### 优先级相同时

如果多个规则的来源、重要性和选择器优先级都相同，那么**后出现的声明覆盖先出现的声明**。

例如：

```css
.text.special {
    color: blue;
}

.special.text {
    color: red;
}
```

两者都包含两个类选择器：

```
(0, 2, 0)
```

优先级完全相同。

由于：

```css
.special.text
```

写在后面，所以最终 `color: red` 生效。

附件中的“就近原则”示例演示的正是这种情况。

这里所谓的“**就近原则**”更准确地说，是：

**在前面的层叠条件都相同的情况下，源码中后出现的声明获胜。**

不能把它理解成“哪段 CSS 物理位置离 HTML 元素更近，哪段 CSS 就一定优先”。

------

#### `!important`

CSS 声明后可以添加 `!important`：

```css
.box {
    color: red !important;
}
```

`!important` 会提高该声明在 CSS **层叠重要性**上的等级。

例如：

```css
#title {
    color: blue;
}

.text {
    color: red !important;
}
```

即使 `#title` 的选择器优先级高于 `.text`，带有 `!important` 的红色声明仍可能优先生效。

不过需要特别区分：

**`!important` 并不是一种选择器，也不是把选择器的 specificity 数值变得无限大。它影响的是层叠中的“重要性”，发生在选择器优先级比较之前。**

如果两条冲突声明**都带有 `!important`**，仍然需要继续比较它们的选择器优先级：

```css
#title {
    color: blue !important;
}

.text {
    color: red !important;
}
```

此时 `#title` 的选择器优先级更高，因此蓝色生效。

所以，课程中的口诀：

```
!important > ID > Class > 标签 > *
```

可以作为初学阶段快速判断简单案例的记忆方式，但更准确的理解应该是：

**先判断声明的重要性，再比较选择器优先级；选择器优先级相同后，再比较出现顺序。**

> 注意：实际项目中不要为了“解决样式不生效”而频繁使用 `!important`。大量使用会使后续样式覆盖关系越来越难维护。

------

### 选择器优先级的基础判断流程

当发现“我明明写了 CSS，为什么这个样式没有生效”时，可以按照以下顺序进行基础排查：

1. **确认选择器是否真的匹配到了目标元素。**
2. 确认是不是多条规则同时修改了同一个 CSS 属性。
3. 判断是否存在 `!important` 等重要性差异。
4. 比较选择器优先级：
   - ID 数量。
   - 类 / 属性 / 伪类数量。
   - 标签数量。
5. 如果优先级仍相同，则查看哪条声明在最终样式表顺序中更靠后。

例如：

```css
p {
    color: black;
}

.content p {
    color: blue;
}

#main .content p {
    color: red;
}
```

目标元素：

```html
<div id="main">
    <div class="content">
        <p>测试文字</p>
    </div>
</div>
```

三个选择器都能选中 `<p>`：

```text
p                 → (0, 0, 1)
.content p        → (0, 1, 1)
#main .content p  → (1, 1, 1)
```

因此：

```
#main .content p
```

优先级最高，最终显示红色。

> 结论：选择器优先级不能只记成一句“ID > Class > 标签”。更完整的基础判断方式是：**先确定规则是否匹配，再处理重要性，然后按 ID → 类/属性/伪类 → 标签的数量逐级比较；完全相同时，后声明的规则获胜。**

## CSS 常用属性

CSS 提供了大量用于控制元素外观的属性。学习常用属性时，重点应掌握**属性的作用、常见属性值以及实际效果**，具体属性的完整取值范围可以在需要时查询参考手册。

### 背景属性

CSS 可以为元素设置背景颜色，也可以使用图片作为背景，并进一步控制背景图片的重复方式、显示位置以及滚动行为。

当前涉及的背景属性主要包括：

| 属性                    | 作用                   |
| ----------------------- | ---------------------- |
| `background-color`      | 设置背景颜色           |
| `background-image`      | 设置背景图片           |
| `background-repeat`     | 设置背景图片是否重复   |
| `background-position`   | 设置背景图片的位置     |
| `background-attachment` | 设置背景图片的滚动方式 |

#### `background-color`

`background-color` 用于设置元素的**背景颜色**。

基本语法：

```css
选择器 {
    background-color: 颜色;
}
```

例如：

```css
.box {
    background-color: red;
}
```

对应 HTML：

```html
<div class="box">这个 div 有红色背景</div>
```

附件中的示例就是通过 `background-color: red` 为 `.box` 设置红色背景。

背景颜色可以使用前面已经学习过的多种颜色表示方式，例如：

```css
.box1 {
    background-color: red;
}

.box2 {
    background-color: rgb(255, 0, 0);
}

.box3 {
    background-color: #ff0000;
}
```

`background-color` 的默认值为 `transparent`，表示**背景透明**。也就是说，如果没有主动设置背景颜色，通常可以透过当前元素看到后方元素或父元素的背景。

------

#### `background-image`

`background-image` 用于为元素设置**背景图片**。

基本语法：

```css
.box {
    background-image: url("图片路径");
}
```

例如：

```css
.box {
    width: 600px;
    height: 600px;
    background-image: url("img/dogx.jpg");
}
```

其中，`url()` 用于指定背景图片资源的 URL。

附件中的示例同时展示了相对路径和以 `/` 开头的路径：

```css
background-image: url("img/dogx.jpg");
background-image: url("/img/dogx.jpg");
```

如果背景图片通过外部 `.css` 文件引用，相对路径通常应以**当前 CSS 文件的位置**为参照，这一点与前面学习的路径知识相同。

如果没有设置背景图片，`background-image` 默认值为：

```css
background-image: none;
```

表示当前元素没有背景图片。

> 注意：背景图片与 `<img>` 的用途不同。`<img>` 是 HTML 页面中的内容，而 `background-image` 属于 CSS 表现效果。用于表达页面内容本身的图片通常使用 `<img>`，装饰性的背景效果则更适合通过 CSS 设置。

------

#### `background-repeat`

当背景图片的尺寸小于元素的背景区域时，浏览器默认会重复显示图片，将剩余区域铺满。

`background-repeat` 用于控制这种**背景图片重复方式**。

常见取值如下：

| 值          | 作用                         |
| ----------- | ---------------------------- |
| `repeat`    | 水平、垂直方向都重复，默认值 |
| `repeat-x`  | 只在水平方向重复             |
| `repeat-y`  | 只在垂直方向重复             |
| `no-repeat` | 不重复                       |

例如：

```css
.box {
    width: 600px;
    height: 600px;

    background-image: url("img/dogx.jpg");
    background-repeat: no-repeat;
}
```

表示背景图片只显示一次，不再进行平铺。

附件中的代码也分别列出了 `no-repeat`、`repeat-x` 和 `repeat-y` 三种效果。

如果不设置：

```css
background-repeat: repeat;
```

浏览器默认会同时沿水平和垂直方向重复背景图片。

------

#### `background-position`

`background-position` 用于设置**背景图片在背景区域中的初始位置**，通常与 `background-image` 和 `background-repeat` 配合使用。

例如：

```css
.box {
    width: 600px;
    height: 600px;

    background-image: url("img/dogx.jpg");
    background-repeat: no-repeat;
    background-position: 200px 100px;
}
```

附件中的示例使用的就是这种写法。

当设置两个值时，可以先按下面的顺序理解：

```css
background-position: 水平方向 垂直方向;
```

因此：

```css
background-position: 200px 100px;
```

表示：

- 水平方向位置为 `200px`；
- 垂直方向位置为 `100px`。

在默认定位方式下，可以直观理解为图片相对于背景定位区域**向右移动 200px、向下移动 100px**。

> 易错点：原材料中的注释“左 200px，右 100px”不准确。第二个值控制的是**垂直方向**，不是右侧距离。

除了长度值，还可以使用关键字：

```text
left
center
right

top
center
bottom
```

例如：

```css
background-position: center center;
```

表示背景图片在水平和垂直方向都居中。

也可以简写为：

```css
background-position: center;
```

常见组合还有：

```css
background-position: left top;
background-position: right top;
background-position: left bottom;
background-position: right bottom;
background-position: center center;
```

通常第一个值描述水平方向，第二个值描述垂直方向。

也可以使用百分比等长度形式控制背景图片的位置。

------

#### `background-attachment`

`background-attachment` 用于控制**背景图片相对于滚动行为的显示方式**。

当前重点认识两个值：

| 值       | 作用                                           |
| -------- | ---------------------------------------------- |
| `scroll` | 背景随着元素所在页面的滚动而表现为普通滚动背景 |
| `fixed`  | 背景相对于视口固定                             |

例如：

```css
body {
    height: 2000px;
    background-image: url("img/dogx.jpg");
    background-attachment: fixed;
}
```

附件中通过增加 `body` 高度产生页面滚动条，再使用 `background-attachment: fixed` 演示背景固定效果。

当设置：

```css
background-attachment: fixed;
```

页面内容滚动时，背景图片会表现为相对于浏览器视口固定，因此会产生一种“页面内容在背景图片上方移动”的视觉效果。

默认情况下通常使用：

```css
background-attachment: scroll;
```

此时背景按照普通的滚动方式显示。

------

### 文本属性

CSS 提供了大量与文本显示有关的属性，可以控制文字的**颜色、字体、大小、粗细、对齐方式、装饰效果、字符间距和行高**等。

常见文本与字体属性包括：

| 属性              | 作用                 |
| ----------------- | -------------------- |
| `color`           | 设置文字颜色         |
| `font-family`     | 设置字体             |
| `font-size`       | 设置字体大小         |
| `font-style`      | 设置字体样式         |
| `font-weight`     | 设置字体粗细         |
| `text-align`      | 设置文本水平对齐方式 |
| `text-decoration` | 设置文本装饰线       |
| `letter-spacing`  | 设置字符间距         |
| `line-height`     | 设置行高             |

#### `color`

`color` 用于设置元素的**文字颜色**。

例如：

```css
.title {
    color: red;
}
```

颜色可以使用前面学习过的多种表示方式：

```css
.title1 {
    color: red;
}

.title2 {
    color: rgb(255, 0, 0);
}

.title3 {
    color: #ff0000;
}
```

`color` 设置的是文字的前景色，并且属于**可以继承的属性**。因此，如果父元素设置了 `color`，其子元素在没有自行设置文字颜色的情况下，通常会继承父元素的颜色。

------

#### `opacity`

`opacity` 用于设置元素整体的**不透明度**，取值范围通常为 `0`～`1`：

- `1`：完全不透明，默认值。
- `0`：完全透明。
- `0`～`1`：半透明。

例如：

```css
.box {
    opacity: 0.5;
}
```

表示整个 `.box` 以 `50%` 的不透明度显示。

如果设置：

```css
.box {
    opacity: 0;
}
```

元素会变得完全透明，看起来相当于“消失”，但**元素本身仍然存在，并继续占据原来的布局空间**。

因此：

```css
opacity: 0;
```

和真正从布局中移除元素并不是一回事。

> 注意：`opacity` 作用于**整个元素及其内容的最终显示效果**。例如给一个包含文字的 `<div>` 设置 `opacity: 0.5`，背景、文字以及内部子元素都会一起呈现半透明效果，而不是只控制字体透明度。

------

### 字体属性

字体相关属性主要用于控制文字使用什么字体、多大字号、是否加粗以及是否倾斜。

常见属性如下：

| 属性          | 作用         | 常见值                          |
| ------------- | ------------ | ------------------------------- |
| `font-family` | 设置字体系列 | `Arial`、`"微软雅黑"`、`"宋体"` |
| `font-size`   | 设置字体大小 | `18px`、`2em`                   |
| `font-style`  | 设置字体风格 | `normal`、`italic`、`oblique`   |
| `font-weight` | 设置字体粗细 | `normal`、`bold`、数字值        |

例如：

```css
.title {
    font-family: "宋体", "微软雅黑", Arial;
    font-size: 2em;
    font-weight: 900;
    font-style: italic;
}
```

#### `font-family`

`font-family` 用于设置元素采用的字体：

```css
.title {
    font-family: "微软雅黑";
}
```

还可以同时指定多个字体，并按照从左到右的顺序作为候选字体：

```css
.title {
    font-family: "宋体", "微软雅黑", Arial;
}
```

浏览器会优先尝试第一个字体，如果当前系统不存在该字体，再继续尝试后面的字体。

字体名称中如果包含空格，通常使用引号包裹，例如：

```css
font-family: "Microsoft YaHei", Arial;
```

------

#### `font-size`

`font-size` 用于设置字体大小：

```css
.title {
    font-size: 18px;
}
```

也可以使用相对单位：

```css
.title {
    font-size: 2em;
}
```

其中 `2em` 表示当前字体尺寸基准的两倍。

------

#### `font-weight`

`font-weight` 用于设置字体粗细。

常见写法：

```css
.title {
    font-weight: bold;
}
```

也可以使用数值：

```css
.title {
    font-weight: 700;
}
```

常见值可以简单理解为：

- `normal`：正常粗细，通常对应 `400`。
- `bold`：粗体，通常对应 `700`。
- 数字值：用于进一步控制字体粗细，例如 `400`、`500`、`700`、`900`。

具体能够显示多少种粗细，还取决于当前使用的字体是否提供相应字重。

------

#### `font-style`

`font-style` 用于控制字体是否使用倾斜样式。

常见值：

| 值        | 含义                   |
| --------- | ---------------------- |
| `normal`  | 正常字体               |
| `italic`  | 使用字体提供的斜体样式 |
| `oblique` | 使用倾斜样式           |

例如：

```css
.title {
    font-style: italic;
}
```

------

### `text-align`

`text-align` 用于控制元素内容的**水平对齐方式**。

常见值：

| 值        | 作用     |
| --------- | -------- |
| `left`    | 左对齐   |
| `right`   | 右对齐   |
| `center`  | 居中对齐 |
| `justify` | 两端对齐 |

例如：

```css
.left {
    text-align: left;
}

.center {
    text-align: center;
}

.right {
    text-align: right;
}
```

HTML：

```html
<p class="left">这段文本左对齐</p>
<p class="center">这段文本居中对齐</p>
<p class="right">这段文本右对齐</p>
```

需要注意，`text-align` 控制的是**元素内部行内内容的水平排列方式**，并不是把元素自身移动到左边、中间或右边。

例如：

```css
.box {
    width: 500px;
    text-align: center;
}
```

表示 `.box` 内部的文字居中，并不代表宽度为 `500px` 的 `.box` 自身在页面中居中。

#### `justify`

`justify` 表示**两端对齐**：

```css
.content {
    width: 500px;
    text-align: justify;
}
```

对于具有多行内容的文本，浏览器会调整行内内容的间距，使文本行尽量同时贴近容器左右两侧。

单行文本通常难以体现这种效果，因此 `justify` 的效果主要在多行文本中比较明显。

------

### `text-decoration`

`text-decoration` 用于设置文字的**装饰线**。

常见值：

| 值             | 作用         |
| -------------- | ------------ |
| `none`         | 不显示装饰线 |
| `underline`    | 下划线       |
| `overline`     | 上划线       |
| `line-through` | 删除线       |

例如：

```css
.none {
    text-decoration: none;
}

.underline {
    text-decoration: underline;
}

.overline {
    text-decoration: overline;
}

.line-through {
    text-decoration: line-through;
}
```

其中 `text-decoration: none` 很常见的一种用途是取消超链接默认的下划线：

```css
a {
    text-decoration: none;
}
```

需要注意，`none` 表示**不显示文本装饰线**，并不是“文本的默认样式”。例如 `<a>` 在浏览器默认样式中通常具有下划线，此时设置 `text-decoration: none` 实际是在覆盖默认装饰效果。

------

### `letter-spacing`

`letter-spacing` 用于控制**字符之间的额外间距**。

例如：

```css
.title {
    letter-spacing: 10px;
}
```

HTML：

```html
<p class="title">Hello World</p>
```

值越大，字符之间的距离通常越宽。

也可以使用负值缩小字符间距，例如：

```css
.title {
    letter-spacing: -1px;
}
```

因此，`letter-spacing` 更准确地说是设置**字符间距**，而不仅仅是中文语境中的“字与字之间的间距”。

------

### `line-height`

`line-height` 用于设置文本行的**行高**，也就是每一行文本所占据的垂直高度。

例如：

```css
.content {
    font-size: 16px;
    line-height: 24px;
}
```

表示每一行文本占据 `24px` 的行高。

`line-height` 可以使用多种值，例如：

```css
.content1 {
    line-height: 24px;
}

.content2 {
    line-height: 1.5;
}

.content3 {
    line-height: 150%;
}
```

其中，无单位数值会按照当前元素的字体大小进行计算。例如：

```css
font-size: 20px;
line-height: 1.5;
```

对应的行高为：

```
20px × 1.5 = 30px
```

#### 单行文本垂直居中

在一个**固定高度且只有一行文字**的元素中，可以让 `line-height` 与 `height` 相等，实现常见的单行文字垂直居中效果：

```css
.title {
    height: 80px;
    line-height: 80px;

    text-align: center;
    background-color: lightblue;
}
```

此时：

- `text-align: center` 控制**水平居中**。
- `line-height: 80px` 配合 `height: 80px`，使单行文本在视觉上**垂直居中**。

> 注意：这是一个针对**单行文本**的传统技巧。如果内容可能出现多行，`line-height` 与容器高度相等反而会导致显示异常。复杂的水平、垂直居中通常使用 Flexbox 等布局方式实现。

------

### `overflow`

`overflow` 用于规定：**当元素中的内容超出元素自身尺寸时，应如何处理溢出的部分。**

例如：

```css
.box {
    width: 200px;
    height: 100px;
}
```

如果其中的内容实际需要超过 `200px × 100px` 的空间，就会产生内容溢出。

常见属性值：

| 值        | 作用                                       |
| --------- | ------------------------------------------ |
| `visible` | 默认情况下允许溢出内容显示在元素框之外     |
| `hidden`  | 裁剪溢出部分，不显示超出的内容             |
| `scroll`  | 提供滚动机制以查看溢出内容                 |
| `auto`    | 浏览器根据是否发生溢出决定是否提供滚动机制 |

例如：

```css
.visible {
    overflow: visible;
}

.hidden {
    overflow: hidden;
}

.scroll {
    overflow: scroll;
}

.auto {
    overflow: auto;
}
```

其中：

#### `visible`

```css
overflow: visible;
```

溢出的内容仍然可以显示到元素边界之外。

#### `hidden`

```css
overflow: hidden;
```

超出元素范围的内容会被裁剪，通常无法直接看到。

#### `scroll`

```css
overflow: scroll;
```

使元素成为可滚动区域，通过滚动查看超出的内容。具体滚动条的显示形式会受到浏览器和操作系统影响。

#### `auto`

```css
overflow: auto;
```

通常只有发生溢出时才需要提供滚动机制，因此在很多场景下比固定使用 `scroll` 更灵活。

> 补充：`overflow` 并不是专门的“文本属性”。图片、子元素等其他内容超出容器范围时，同样会受到 `overflow` 控制。

------

### 文本溢出显示省略号

页面中经常需要限制一段文字只能显示一行，如果内容过长，则使用 `...` 表示后面还有未显示的内容。

例如：

```css
.title {
    width: 200px;

    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
}
```

HTML：

```html
<div class="title">
    这是一段很长的文本内容，超出的部分会使用省略号显示
</div>
```

实现**单行文本溢出显示省略号**时，通常需要同时理解三个属性：

```css
white-space: nowrap;
overflow: hidden;
text-overflow: ellipsis;
```

它们分别负责不同的工作。

#### `white-space: nowrap`

```css
white-space: nowrap;
```

表示文本不自动换到下一行，使过长的文字继续沿水平方向延伸。

#### `overflow: hidden`

```css
overflow: hidden;
```

将超出元素显示区域的内容裁剪掉。

#### `text-overflow: ellipsis`

```css
text-overflow: ellipsis;
```

使被裁剪的文本边缘通过省略号表示。

因此，可以将这一组合记为：

```css
.title {
    white-space: nowrap;      /* 不换行 */
    overflow: hidden;         /* 隐藏溢出 */
    text-overflow: ellipsis;  /* 省略号表示 */
}
```

同时还必须存在一个能够使文本真正产生溢出的宽度限制，例如：

```css
.title {
    width: 200px;
}
```

如果元素宽度可以无限随文本扩展，没有发生实际溢出，自然也不会出现省略号。

> 结论：文本样式可以从三个层面理解：`color` 和 `font-*` 决定文字本身如何显示；`text-align`、`letter-spacing`、`line-height` 等决定文字如何排版；`overflow`、`white-space` 和 `text-overflow` 则可以共同处理文本超出可用空间后的显示效果。

---

### 复合样式

CSS 中有些属性可以将多个相关的子属性合并到一条声明中书写，这种写法通常称为**简写属性（Shorthand Property）**，也可以理解为复合样式。

例如，分别设置边框可以写成：

```css
.box {
    border-width: 2px;
    border-style: solid;
    border-color: red;
}
```

也可以合并成：

```css
.box {
    border: 2px solid red;
}
```

使用简写属性可以减少重复代码，使样式更加紧凑。不过不同简写属性的值具有不同的语法和顺序要求，不能随意交换。

例如：

```css
.box {
    width: 200px;
    height: 100px;

    border: 2px solid red;
    font: italic bold 16px/1.5 Arial, sans-serif;
    margin: 10px 20px 10px 20px;
    padding: 15px 25px;
}
```

#### `border` 简写

`border` 可以同时设置边框的**宽度、样式和颜色**：

```css
border: 2px solid red;
```

可以理解为：

```css
border-width: 2px;
border-style: solid;
border-color: red;
```

其中，`solid` 表示实线边框。

------

#### `font` 简写

`font` 可以将多个字体属性合并书写，例如：

```css
font: italic bold 16px/1.5 Arial, sans-serif;
```

这里分别表示：

- `italic`：`font-style`
- `bold`：`font-weight`
- `16px`：`font-size`
- `1.5`：`line-height`
- `Arial, sans-serif`：`font-family`

其中：

```css
16px/1.5
```

表示：

```css
font-size: 16px;
line-height: 1.5;
```

`font` 简写具有一定的语法要求，特别是 **`font-size` 和 `font-family` 是核心组成部分**，不能像普通属性一样随意调整所有值的顺序。

------

#### `margin` 简写

`margin` 用于设置元素的外边距，可以分别设置：

```css
margin-top
margin-right
margin-bottom
margin-left
```

也可以使用简写形式。

##### 四个值

```css
margin: 10px 20px 30px 40px;
```

顺序为：

```
上 → 右 → 下 → 左
```

即：

```css
margin-top: 10px;
margin-right: 20px;
margin-bottom: 30px;
margin-left: 40px;
```

可以按照**顺时针方向**记忆：

```
上 → 右 → 下 → 左
```

##### 三个值

```css
margin: 10px 20px 30px;
```

表示：

- 上：`10px`
- 左右：`20px`
- 下：`30px`

##### 两个值

```css
margin: 10px 20px;
```

表示：

- 上下：`10px`
- 左右：`20px`

##### 一个值

```css
margin: 10px;
```

表示上、右、下、左四个方向全部为 `10px`。

可以归纳为：

| 值的数量 | 含义           |
| -------- | -------------- |
| 1 个     | 四个方向相同   |
| 2 个     | 上下、左右     |
| 3 个     | 上、左右、下   |
| 4 个     | 上、右、下、左 |

------

#### `padding` 简写

`padding` 用于设置元素内容与边框之间的**内边距**，同样支持 1～4 个值，其规则与 `margin` 完全一致。

例如：

```css
padding: 15px 25px;
```

表示：

- 上下内边距：`15px`
- 左右内边距：`25px`

而：

```css
padding: 10px 20px 30px 40px;
```

表示：

```
上 10px → 右 20px → 下 30px → 左 40px
```

> 结论：CSS 简写属性本质上是将多个相关属性合并成一条声明。`margin` 和 `padding` 的值数量不同，含义也不同；四个值时按照**上、右、下、左**的顺时针顺序理解。

------

### 列表属性

CSS 可以通过 `list-style-type` 设置列表项前面的**标记样式**。

例如：

```css
ul {
    list-style-type: square;
}
```

可以将无序列表默认的圆点改成方块。

#### 无序列表常见样式

常见值包括：

| 值       | 效果                               |
| -------- | ---------------------------------- |
| `disc`   | 实心圆点，通常是无序列表的默认样式 |
| `circle` | 空心圆点                           |
| `square` | 实心方块                           |
| `none`   | 不显示列表标记                     |

例如：

```css
ul.disc {
    list-style-type: disc;
}

ul.circle {
    list-style-type: circle;
}

ul.square {
    list-style-type: square;
}

ul.none {
    list-style-type: none;
}
```

HTML：

```html
<ul class="disc">
    <li>项目一</li>
    <li>项目二</li>
</ul>

<ul class="circle">
    <li>项目一</li>
    <li>项目二</li>
</ul>

<ul class="square">
    <li>项目一</li>
    <li>项目二</li>
</ul>

<ul class="none">
    <li>项目一</li>
    <li>项目二</li>
</ul>
```

其中：

```css
list-style-type: none;
```

经常用于取消列表默认的项目符号。

------

#### 有序列表常见样式

`list-style-type` 同样可以改变有序列表的编号形式。

常见值包括：

| 值            | 效果                       |
| ------------- | -------------------------- |
| `decimal`     | 十进制数字：1、2、3……      |
| `lower-roman` | 小写罗马数字：i、ii、iii…… |
| `upper-roman` | 大写罗马数字：I、II、III…… |
| `lower-alpha` | 小写英文字母：a、b、c……    |
| `upper-alpha` | 大写英文字母：A、B、C……    |

例如：

```css
ol.decimal {
    list-style-type: decimal;
}

ol.lower-roman {
    list-style-type: lower-roman;
}

ol.upper-roman {
    list-style-type: upper-roman;
}

ol.lower-alpha {
    list-style-type: lower-alpha;
}

ol.upper-alpha {
    list-style-type: upper-alpha;
}
```

HTML：

```html
<ol class="decimal">
    <li>项目一</li>
    <li>项目二</li>
</ol>

<ol class="lower-roman">
    <li>项目一</li>
    <li>项目二</li>
</ol>

<ol class="upper-alpha">
    <li>项目一</li>
    <li>项目二</li>
</ol>
```

需要注意，`list-style-type` 控制的是**列表标记的显示形式**，并不会改变 HTML 本身是 `<ul>` 还是 `<ol>`。

也就是说，HTML 仍然负责表达列表的语义：

- `<ul>`：无序列表。
- `<ol>`：有序列表。

CSS 只是决定这些列表标记最终以什么样式显示。

> 结论：列表的结构和语义由 HTML 决定，`list-style-type` 只负责修改列表项标记的视觉形式。

## 元素的分类

按照元素在普通文档流中的默认显示方式，可以将常见元素简单理解为**块级元素、内联元素和内联块级元素**。

这种分类主要用于理解元素如何排列、能否设置宽高以及盒模型属性如何表现。元素的显示方式还可以通过 CSS 的 `display` 属性进行改变。

| 类型         | 常见 `display` 值 | 是否独占一行 | 宽高设置                       | 默认宽度特点                     |
| ------------ | ----------------- | ------------ | ------------------------------ | -------------------------------- |
| 块级元素     | `block`           | 是           | 可以设置                       | `width: auto` 时通常占满可用宽度 |
| 内联元素     | `inline`          | 否           | `width`、`height` 通常不起作用 | 主要由内容决定                   |
| 内联块级元素 | `inline-block`    | 否           | 可以设置                       | 默认主要由内容决定               |

### 块级元素

块级元素在普通文档流中通常会**从新的一行开始显示**。

常见的块级元素包括：

`<body>`、`<div>`、`<p>`、`<h1>`～`<h6>`、`<ul>`、`<ol>`、`<li>`、`<pre>` 等。

块级元素通常具有以下特点：

1. 默认从新的一行开始，后面的普通块级元素也会继续换行排列。
2. 可以设置 `width` 和 `height`。
3. 可以设置上下左右四个方向的 `margin` 和 `padding`。
4. 当 `width` 为默认的 `auto` 时，块级元素通常会占据父容器中的可用宽度。
5. 块级元素可以包含其他内容，但具体允许包含哪些元素还要遵循 HTML 本身的内容模型规则。

例如：

```html
<div>第一个 div</div>
<div>第二个 div</div>
```

默认情况下，两个 `<div>` 会分别占据不同的行。

#### `display: block`

可以通过：

```css
display: block;
```

让元素按照块级盒子的方式参与布局。

例如，`<a>` 默认通常以内联方式显示：

```html
<a href="#">链接1</a>
<a href="#">链接2</a>
```

可以修改为：

```css
a {
    display: block;
    margin: 5px;
    padding: 10px;
    background-color: lightblue;
    border: 1px solid #333;
    text-decoration: none;
}
```

此时：

```html
<a href="#">链接1</a>
<a href="#">链接2</a>
<a href="#">链接3</a>
```

三个 `<a>` 会按照块级元素的方式分别换行，并且可以更直观地设置宽度、高度以及四个方向的盒模型属性。

> 注意：`display: block` 改变的是元素的 **CSS 显示方式**，并不会改变元素本身的 HTML 语义。`<a>` 仍然是超链接元素，只是按照块级盒子的方式参与布局。

------

### 内联元素

内联元素也称为**行内元素**，它们通常不会主动换行，而是和其他行内内容一起排列在同一行中。

常见的内联元素包括：

<a>、<span> 等。

内联元素通常具有以下特点：

1. 不会默认独占一行，可以与其他内联元素、文本或内联块元素排列在同一行。
2. 宽度主要由自身内容决定。
3. 普通 `width` 和 `height` 通常不能像块级元素那样直接控制其盒子尺寸。
4. 水平方向的 `margin`、`padding` 可以正常影响布局。
5. 垂直方向的 `padding` 可以产生视觉效果，但不会像块级盒子那样简单地把上下行整体撑开；垂直 `margin` 对普通非替换内联元素通常也不会产生和块级元素相同的布局效果。

例如：

```html
<span>Hello</span>
<span>World</span>
```

两个 `<span>` 默认会排列在同一行中。

如果设置：

```css
span {
    width: 300px;
    height: 100px;
}
```

对于普通 `display: inline` 的 `<span>`，这些宽高通常不会像块级元素那样直接决定其布局尺寸。

#### `display: inline`

通过：

```css
display: inline;
```

可以让元素按照普通内联元素的方式参与布局。

例如：

```css
div {
    display: inline;
    background-color: lightblue;
    margin: 5px;
    padding: 10px;
}
```

HTML：

```html
<div>div1</div>
<div>div2</div>
<div>div3</div>
普通文本
```

原本默认按照块级方式显示的 `<div>` 会改为行内排列，因此多个 `<div>` 可以和普通文本出现在同一行。

同样需要注意：

**`display: inline` 只改变显示方式，不会把 `<div>` 变成 `<span>`。**

------

### 内联块级元素

内联块级元素使用：

```css
display: inline-block;
```

它兼具一部分内联元素和块级元素的布局特点。

主要特点包括：

1. 不会默认独占一行，可以与其他行内内容排列在同一行。
2. 可以设置 `width` 和 `height`。
3. 可以设置上下左右四个方向的 `margin` 和 `padding`。
4. 未主动设置宽度时，其尺寸通常会根据内容计算，而不像普通块级元素那样默认扩展到整行可用宽度。

例如：

```css
.item {
    display: inline-block;
    width: 100px;
    height: 50px;
    margin: 5px;
    padding: 10px;
    background-color: lightblue;
}
```

HTML：

```html
<div class="item">div1</div>
<div class="item">div2</div>
<div class="item">div3</div>
```

三个 `<div>` 可以排列在同一行，同时又能够设置明确的宽度和高度。

可以将三者简单对比：

```text
block        → 会换行 + 可以设置宽高
inline       → 不换行 + 宽高通常由内容决定
inline-block → 不换行 + 可以设置宽高
```

> 补充：`<img>`、`<input>` 等元素在实际表现上具有可设置宽高、又可以参与行内排列等特点。理解这类元素时，重点掌握其实际盒子行为即可，不必仅依赖“HTML 标签天生属于哪一类”来判断。

------

### `display` 属性

`display` 用于控制元素生成什么类型的盒子，以及如何参与页面布局。

当前阶段常见值包括：

| 值             | 作用                       |
| -------------- | -------------------------- |
| `block`        | 按块级盒子显示             |
| `inline`       | 按内联盒子显示             |
| `inline-block` | 按内联块级盒子显示         |
| `none`         | 不生成盒子，元素不参与布局 |

例如：

```css
.block {
    display: block;
}

.inline {
    display: inline;
}

.inline-block {
    display: inline-block;
}

.hidden {
    display: none;
}
```

因此，所谓“块级元素”“内联元素”并不是完全不可改变的固定属性。CSS 可以通过 `display` 改变元素的**布局表现**。

------

### 元素的隐藏与显示

CSS 中常用 `visibility` 和 `display` 控制元素的显示与隐藏，但二者的行为不同。

#### `visibility`

`visibility` 常见值：

| 值        | 作用                             |
| --------- | -------------------------------- |
| `visible` | 元素可见，默认值                 |
| `hidden`  | 元素不可见，但保留原来的布局空间 |

例如：

```css
.box {
    visibility: hidden;
}
```

元素不会被看见，但是原本占据的位置仍然存在，因此周围元素不会自动填补这块空间。

可以理解为：

**元素还在那里，只是看不见。**

------

#### `display: none`

设置：

```css
.box {
    display: none;
}
```

会让元素不生成正常的布局盒子，因此它原本占据的空间也会消失，后面的元素会重新参与布局并填补空缺。

可以理解为：

**元素不参与当前页面布局。**

例如：

```html
<div class="box">盒子1</div>

<div class="box hidden-visibility">
    visibility: hidden
</div>

<div class="box">盒子2</div>

<div class="box hidden-display">
    display: none
</div>

<div class="box">盒子3</div>
```

CSS：

```css
.hidden-visibility {
    visibility: hidden;
}

.hidden-display {
    display: none;
}
```

两者的核心区别为：

| 方式                 | 是否可见 | 是否保留布局空间 |
| -------------------- | -------- | ---------------- |
| `visibility: hidden` | 否       | **是**           |
| `display: none`      | 否       | **否**           |

前面学习过的：

```css
opacity: 0;
```

也可以让元素完全透明。因此三个属性可以进一步对比：

| 写法                 | 是否可见     | 是否占据空间 | 元素是否仍参与正常布局 |
| -------------------- | ------------ | ------------ | ---------------------- |
| `opacity: 0`         | 否，完全透明 | 是           | 是                     |
| `visibility: hidden` | 否           | 是           | 是                     |
| `display: none`      | 否           | 否           | 否                     |

其中，`opacity: 0` 只是让元素完全透明；`visibility: hidden` 表示元素不可见但位置保留；`display: none` 则直接使元素不生成正常布局盒子。

> 结论：`display` 不仅可以在 `block`、`inline`、`inline-block` 之间改变元素的显示方式，还可以通过 `display: none` 将元素从布局中隐藏。判断元素类型时，应重点关注元素**当前的 `display` 计算值和实际布局行为**，而不能只根据 HTML 标签名称机械判断。

## CSS 布局

### 文档流

**文档流（Normal Flow）**是浏览器默认的页面元素排列方式。在没有使用浮动、定位等特殊布局方式时，HTML 元素会按照正常文档流进行排列。

基本规律包括：

- 块级元素通常从上到下依次排列。
- 行内元素通常从左到右依次排列，一行空间不足时会继续换行。
- 元素通常按照其在 HTML 中的出现顺序参与页面布局。

例如：

```html
<div>第一个 div</div>
<div>第二个 div</div>

<span>span1</span>
<span>span2</span>
```

默认情况下，两个 `<div>` 会上下排列，而两个 `<span>` 可以排列在同一行。

可以把普通文档流简单理解为：**页面中的元素按照默认规则依次“排队”，每个元素都在布局中占据自己的位置。**

------

### 脱离文档流

所谓**脱离文档流**，可以简单理解为：元素不再按照普通文档流原本的方式占据位置，其他元素在布局时不再按照原来的方式为它保留空间。

常见情况主要包括 `float`、`position: absolute` 和 `position: fixed`。

#### `float`

元素设置浮动后，可以向左或向右浮动：

```css
.box {
    float: left;
}
```

或者：

```css
.box {
    float: right;
}
```

浮动元素会脱离普通文档流，普通块级元素在布局时不会按照原来的方式为它保留位置。

但是 `float` 有一个比较特殊的地方：**周围的文字等行内内容仍然会避开浮动元素，并围绕浮动元素排列。**

因此，可以简单理解为：

- 普通块级布局会忽略浮动元素原本占据的位置。
- 文本和行内内容仍然会考虑浮动元素的位置。

这也是 `float` 最初经常用于实现“图片旁边环绕文字”效果的原因之一。

------

#### `position: absolute` 和 `position: fixed`

当元素使用：

```css
position: absolute;
```

或者：

```css
position: fixed;
```

时，元素会脱离普通文档流。

主要表现为：

- 不再占据原来的普通文档流空间。
- 后续元素可以移动到它原本应该占据的位置。
- 元素的位置由定位相关规则决定。

例如：

```css
.box {
    position: absolute;
    top: 100px;
    left: 100px;
}
```

此时 `.box` 不再按照普通块级元素的位置参与页面排列。

------

#### `position: relative`

`position: relative` 比较特殊，因为它**不会脱离文档流**。

例如：

```css
.box {
    position: relative;
    top: 20px;
    left: 30px;
}
```

元素虽然在视觉上发生了偏移，但它在普通文档流中的原始位置仍然会被保留。

可以理解为：

**元素先按照正常文档流占好自己的位置，再相对于自己的原位置进行视觉偏移。**

因此：

| 方式                 | 是否脱离普通文档流 | 原位置是否保留       |
| -------------------- | ------------------ | -------------------- |
| `float`              | 是                 | 不再按照普通方式占位 |
| `position: absolute` | 是                 | 否                   |
| `position: fixed`    | 是                 | 否                   |
| `position: relative` | 否                 | 是                   |

------

### `display: none` 与脱离文档流

`display: none` 会使元素不再生成正常的布局盒子：

```css
.box {
    display: none;
}
```

元素不会显示，也不会继续占据原来的页面空间。

从页面效果来看，它与“脱离文档流后不占原位置”都可能导致后面的元素向前补位，但两者的概念并不完全相同。

可以简单区分为：

- **脱离文档流**：元素仍然存在并可能继续显示，只是不再按照普通文档流方式占据原来的位置。
- **`display: none`**：元素直接不参与当前布局，也不会显示。

------

### float 浮动布局

`float` 可以让元素向父容器的左侧或右侧浮动。

基本语法：

```css
float: left;
```

或者：

```css
float: right;
```

#### float 布局基本使用

例如，可以通过左浮动实现一个简单的侧边栏布局：

```html
<div class="layout">
    <div class="sidebar">
        <h3>侧边栏</h3>
        <p>导航菜单</p>
        <p>分类列表</p>
    </div>

    <div class="main-content">
        <h2>主要内容区域</h2>
        <p>这里是主要内容。</p>
    </div>
</div>
```

CSS：

```css
.layout {
    width: 500px;
}

.sidebar {
    width: 120px;
    height: 200px;
    padding: 15px;
    background-color: #f5f5f5;

    float: left;
}

.main-content {
    height: 200px;
    padding: 15px;
    margin-left: 150px;
}
```

其中：

```css
.sidebar {
    float: left;
}
```

使侧边栏向左浮动。

而：

```css
.main-content {
    margin-left: 150px;
}
```

则给主要内容区域留出左侧空间，从而形成左右两栏的视觉效果。

在 Flexbox、Grid 等现代布局方式普及之前，`float` 曾经被大量用于网页的多栏布局。

------

### float 导致的高度塌陷

使用浮动时，一个非常典型的问题是**父元素高度塌陷**。

#### 什么是高度塌陷

假设父元素内部只有一个浮动子元素：

```html
<div class="parent">
    <div class="child">浮动子元素</div>
</div>
```

CSS：

```css
.parent {
    border: 3px solid red;
    padding: 10px;
}

.child {
    float: left;
    width: 100px;
    height: 100px;
    background-color: lightblue;
}
```

`.child` 设置了：

```css
float: left;
```

后，浮动元素不再按照普通文档流的方式撑开父元素。

如果父元素没有其他能够撑开高度的普通文档流内容，就可能出现：

**子元素明明有高度，但父元素的高度却无法按照子元素正常计算。**

这种现象通常称为**高度塌陷**。

------

### 高度塌陷带来的影响

例如：

```html
<div class="parent">
    <div class="child">浮动元素1</div>
    <div class="child">浮动元素2</div>
</div>

<div>下面的内容</div>
```

CSS：

```css
.parent {
    border: 3px solid red;
    margin: 20px;
}

.child {
    float: left;
    width: 100px;
    height: 100px;
    margin: 10px;
    background-color: lightblue;
}
```

两个 `.child` 都发生浮动后，父元素不能按照普通方式被它们撑开。

于是下面的内容可能向上移动，看起来像是进入了浮动元素所在区域。

因此，高度塌陷不仅影响父元素自身尺寸，还可能进一步影响后续元素的位置。

------

### 使用 `overflow: hidden` 处理高度塌陷

一种常见处理方式是在父元素上设置：

```css
overflow: hidden;
```

例如：

```css
.parent {
    border: 3px solid red;
    margin: 20px;
    overflow: hidden;
}

.child {
    float: left;
    width: 100px;
    height: 100px;
    margin: 10px;
    background-color: lightblue;
}
```

此时父元素能够重新包住浮动子元素，后面的普通元素也会回到父容器之后正常排列。

完整示例：

```html
<div class="parent">
    <div class="child">浮动元素1</div>
    <div class="child">浮动元素2</div>
</div>

<div>下面的内容正常显示</div>
.parent {
    border: 3px solid red;
    margin: 20px;
    overflow: hidden;
}

.child {
    float: left;
    width: 100px;
    height: 100px;
    margin: 10px;
    background-color: lightblue;
}
```

这里使用：

```css
overflow: hidden;
```

会使父元素形成新的 **BFC（Block Formatting Context，块级格式化上下文）**，从而能够包含内部的浮动元素，解决父元素不能被浮动子元素正常撑开的问题。

> 注意：`overflow: hidden` 本身的原始作用是处理内容溢出，这里只是利用它会创建特定布局环境的特性来处理浮动问题。因此，把它简单记成“清除浮动属性”并不完全准确。

------

### position 定位布局

`position` 属性用于设置元素的**定位方式**。配合 `top`、`right`、`bottom`、`left` 等属性，可以改变元素在页面中的位置。

当前主要学习以下四种定位方式：

| `position` 值 | 是否脱离文档流 | 定位特点                           |
| ------------- | -------------- | ---------------------------------- |
| `static`      | 否             | 默认定位方式，按照正常文档流排列   |
| `relative`    | 否             | 相对于元素原来的位置进行偏移       |
| `absolute`    | 是             | 相对于最近的已定位祖先元素进行定位 |
| `fixed`       | 是             | 通常相对于视口进行定位             |

------

#### `static` 静态定位

`static` 是元素默认的定位方式：

```css
.box {
    position: static;
}
```

元素会按照正常文档流进行排列，不会发生额外的位置偏移。

在 `position: static` 的情况下，下面这些定位偏移属性通常不会产生定位效果：

```css
top
right
bottom
left
```

因此：

```css
.box {
    position: static;
    top: 20px;
    left: 30px;
}
```

其中的 `top` 和 `left` 不会按照定位元素的方式改变 `.box` 的位置。

可以简单理解为：

**`static` = 按照普通文档流正常排列。**

------

#### `relative` 相对定位

设置：

```css
.box {
    position: relative;
}
```

表示元素使用**相对定位**。

相对定位有两个核心特点：

1. **不会脱离正常文档流。**
2. 使用 `top`、`right`、`bottom`、`left` 时，是相对于元素**原来的位置**进行偏移。

例如：

```css
.box {
    position: relative;
    top: 20px;
    left: 30px;
}
```

可以理解为：

- `top: 20px`：相对于原位置向下偏移 `20px`。
- `left: 30px`：相对于原位置向右偏移 `30px`。

虽然元素视觉位置发生了变化，但它在普通文档流中原本占据的位置仍然会被保留。

例如原本为：

```text
元素A
元素B
元素C
```

如果只有元素 B 使用相对定位向右、向下移动，元素 C **不会因此移动到 B 原来的位置**，因为 B 的原位置仍然存在于正常文档流中。

> 结论：相对定位可以理解为**“先正常占位，再相对于自己原来的位置移动”**。

相对定位还经常用于给后代的绝对定位元素提供定位参照：

```css
.container {
    position: relative;
}
```

这是一种非常常见的使用方式。

------

#### `absolute` 绝对定位

设置：

```css
.box {
    position: absolute;
}
```

表示元素使用**绝对定位**。

绝对定位的主要特点包括：

1. 元素脱离正常文档流。
2. 不再按照原来的方式占据布局空间。
3. 可以通过 `top`、`right`、`bottom`、`left` 设置位置。
4. 通常相对于最近的**已定位祖先元素**进行定位。

所谓**已定位元素**，基础阶段可以理解为：

```text
position 不是 static 的元素
```

例如：

```css
.container {
    position: relative;
}

.box {
    position: absolute;
    top: 0;
    right: 0;
}
```

HTML：

```html
<div class="container">
    <div class="box"></div>
</div>
```

因为 `.container` 设置了：

```css
position: relative;
```

所以它可以成为 `.box` 的定位参照。

此时：

```css
top: 0;
right: 0;
```

表示 `.box` 位于 `.container` 定位区域的右上方。

##### “最近的已定位祖先元素”是什么意思

这里需要特别注意：

**最近的祖先元素不等于直接父元素。**

例如：

```html
<div class="outer">
    <div class="middle">
        <div class="box"></div>
    </div>
</div>
```

如果：

```css
.outer {
    position: relative;
}

.middle {
    position: static;
}

.box {
    position: absolute;
}
```

`.box` 的直接父元素是 `.middle`，但 `.middle` 是 `position: static`，不能作为这里的定位参照。

浏览器会继续向上查找，最终找到：

```css
.outer {
    position: relative;
}
```

因此 `.box` 会以 `.outer` 作为定位参照。

可以理解为：

```text
当前绝对定位元素
       ↓
检查父元素
       ↓
如果 position: static，继续向上
       ↓
找到最近一个 position 非 static 的祖先元素
       ↓
作为定位参照
```

> 易错点：绝对定位寻找的是**最近的已定位祖先元素**，不一定是直接父元素，可能是父元素的父元素甚至更上层的祖先元素。

如果一直向上都没有找到合适的已定位祖先元素，则会根据页面的初始定位参考区域进行定位。基础阶段可以先将其理解为接近于页面初始显示区域的定位基准，不必简单死记成“永远相对于浏览器视口”。

------

#### `fixed` 固定定位

设置：

```css
.box {
    position: fixed;
}
```

表示元素使用**固定定位**。

固定定位的主要特点是：

1. 元素脱离正常文档流。
2. 不再占据原来的普通布局空间。
3. 通常相对于浏览器的**视口（Viewport）**进行定位。
4. 页面滚动时，元素通常仍保持在视口中的固定位置。

所谓**视口**，可以简单理解为：

**浏览器中当前实际用于显示网页内容的可视区域。**

例如：

```css
.header {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
}
```

表示 `.header` 固定在视口顶部。

页面向下滚动时，它仍然保持在顶部，因此固定定位常用于：

- 顶部导航栏。
- 返回顶部按钮。
- 悬浮工具栏。
- 固定操作按钮。

例如：

```css
.back-top {
    position: fixed;
    right: 30px;
    bottom: 30px;
}
```

可以让按钮固定在视口右下角附近。

------

### 定位方向属性

定位元素经常配合以下属性使用：

```css
top
right
bottom
left
```

它们分别控制元素与定位参照区域对应方向之间的位置关系。

例如：

```css
.box {
    position: absolute;
    top: 20px;
    left: 30px;
}
```

表示元素相对于定位参照区域：

- 顶部位置为 `20px`。
- 左侧位置为 `30px`。

又例如：

```css
.box {
    position: absolute;
    bottom: 20px;
    right: 30px;
}
```

表示元素靠近定位参照区域的右下方：

- 距底部 `20px`。
- 距右侧 `30px`。

------

### 相对定位与绝对定位配合

实际开发中非常常见的一种组合是：

```css
父元素 {
    position: relative;
}

子元素 {
    position: absolute;
}
```

例如：

```html
<div class="card">
    <span class="close">×</span>
    用户信息
</div>
```

CSS：

```css
.card {
    position: relative;
    width: 300px;
    height: 200px;
}

.close {
    position: absolute;
    top: 10px;
    right: 10px;
}
```

这样 `.close` 就可以稳定定位在 `.card` 的右上角。

为什么父元素通常使用：

```css
position: relative;
```

是因为相对定位具有两个合适的特点：

- 自己仍然保留正常文档流位置。
- 又能够成为绝对定位后代元素的定位参照。

因此可以把这种常见组合记为：

**父相子绝：父元素 `relative`，子元素 `absolute`。**

这不是 CSS 的强制规则，只是一种非常常见、方便理解的定位组合。

------

### position 定位案例

例如：

```html
<div class="container">
    <div class="box static">Static</div>
    <div class="box relative">Relative</div>
    <div class="box absolute">Absolute</div>
    <div class="box fixed">Fixed</div>
</div>
```

CSS：

```css
.container {
    position: relative;
    height: 300px;
    border: 1px solid #ccc;
}

.box {
    width: 100px;
    height: 100px;
    padding: 10px;
    color: white;
}

.static {
    position: static;
    background: red;
}

.relative {
    position: relative;
    top: 20px;
    left: 30px;
    background: blue;
}

.absolute {
    position: absolute;
    right: 30px;
    bottom: 20px;
    background: green;
}

.fixed {
    position: fixed;
    top: 20px;
    right: 30px;
    background: purple;
}
```

可以分别理解为：

- `.static`：按照正常文档流排列。
- `.relative`：仍占据原来的位置，但视觉上向下、向右偏移。
- `.absolute`：脱离文档流，并以 `.container` 作为定位参照。
- `.fixed`：脱离文档流，通常相对于视口固定。

------

### `z-index` 层叠顺序

当多个元素在页面中发生位置重叠时，需要决定**哪个元素显示在上面，哪个元素显示在下面**。`z-index` 用于控制元素之间的层叠顺序。

可以把普通页面理解为一个二维平面：

- x 轴：水平方向。
- y 轴：垂直方向。
- z 轴：垂直于屏幕的方向，可以理解为元素之间的“前后层级”。

在本节定位元素的使用场景中，`z-index` 的值越大，元素通常越靠上显示，也就是越靠近用户。

例如：

```css
.box1 {
    position: absolute;
    z-index: 1;
}

.box2 {
    position: absolute;
    z-index: 2;
}
```

当 `.box1` 和 `.box2` 发生重叠时，`.box2` 的 `z-index` 更大，因此会显示在 `.box1` 上方。

`z-index` 的默认值为：

```css
z-index: auto;
```

#### `z-index` 示例

HTML：

```html
<div class="container">
    <div class="box box1">Box 1</div>
    <div class="box box2">Box 2</div>
    <div class="box box3">Box 3</div>
</div>
```

CSS：

```css
.container {
    position: relative;
    height: 200px;
    background-color: aqua;
}

.box {
    position: absolute;
    width: 100px;
    height: 100px;
    color: white;
}

.box1 {
    background-color: red;
    z-index: 1;
    top: 20px;
    left: 20px;
}

.box2 {
    background-color: blue;
    z-index: 2;
    top: 50px;
    left: 50px;
}

.box3 {
    background-color: green;
    z-index: 3;
    top: 80px;
    left: 80px;
}
```

三个元素都使用绝对定位，因此可以通过 `top`、`left` 让它们发生重叠。

它们的层叠关系为：

```text
box3：z-index: 3    最上层
box2：z-index: 2
box1：z-index: 1    最下层
```

因此，当这些盒子的显示区域发生重叠时，`z-index` 较大的元素会覆盖较小的元素。

> 注意：`z-index` 不能简单理解为“整个页面所有元素统一比较一个数字”。实际页面还存在层叠上下文等更完整的规则。当前阶段先掌握定位元素发生重叠时，通过 `z-index` 控制前后顺序即可。

------

### Flex 弹性盒子布局

**Flex（Flexible Box，弹性盒子布局）**是一种用于排列和对齐元素的 CSS 布局方式。

过去网页的多栏布局经常借助 `float` 实现，但 `float` 本身最初并不是专门为整体页面布局设计的，而且可能带来高度塌陷、清除浮动等问题。

Flex 提供了更直接的排列和对齐能力，因此现代开发中大量布局场景会优先使用 Flex，而不是使用 `float` 完成元素排列。

#### 开启 Flex 布局

要使用 Flex 布局，需要在**父元素**上设置：

```css
.container {
    display: flex;
}
```

例如：

```html
<div class="container">
    <div class="item">项目1</div>
    <div class="item">项目2</div>
    <div class="item">项目3</div>
</div>
.container {
    display: flex;
}
```

此时：

- `.container` 称为 **Flex 容器**。
- `.item` 是 `.container` 的直接子元素，称为 **Flex 项目**。

默认情况下，三个 `.item` 会沿水平方向排列。

可以简单理解为：

```text
父元素：display: flex
        ↓
直接子元素进入 Flex 布局
        ↓
子元素按照 Flex 规则排列
```

> 易错点：设置 `display: flex` 的是**父容器**。真正按照 Flex 布局规则排列的是它的**直接子元素**。

------

### Flex 的主轴与交叉轴

理解 Flex 的对齐方式时，需要先认识两个方向：

- **主轴（Main Axis）**：Flex 项目主要排列的方向。
- **交叉轴（Cross Axis）**：与主轴垂直的方向。

在默认情况下：

```css
display: flex;
```

Flex 项目从左向右排列，因此可以先简单理解为：

```text
主轴：水平方向 → 左右
交叉轴：垂直方向 → 上下
```

因此，本阶段常见的两个属性：

```css
justify-content
align-items
```

可以先记为：

- `justify-content`：控制子元素在**主轴**方向的排列和对齐。
- `align-items`：控制子元素在**交叉轴**方向的对齐。

在默认水平排列情况下，可以直观理解为：

```text
justify-content → 左右方向
align-items     → 上下方向
```

------

### `justify-content`

`justify-content` 用于控制 Flex 项目在**主轴方向**上的排列方式。

例如：

```css
.container {
    display: flex;
    justify-content: center;
}
```

默认主轴为水平方向，因此：

```css
justify-content: center;
```

会让所有 Flex 项目整体在父容器中**水平居中**。

例如：

```html
<div class="container">
    <div class="ball">1</div>
    <div class="ball">2</div>
    <div class="ball">3</div>
</div>
.container {
    display: flex;
    justify-content: center;
}
```

三个 `.ball` 会作为一个整体在 `.container` 的水平方向居中排列。

------

### `align-items`

`align-items` 用于控制 Flex 项目在**交叉轴方向**上的对齐方式。

例如：

```css
.container {
    display: flex;
    align-items: center;
}
```

默认情况下交叉轴为垂直方向，所以：

```css
align-items: center;
```

会让 Flex 项目在父容器中**垂直居中**。

如果同时设置：

```css
.container {
    display: flex;
    justify-content: center;
    align-items: center;
}
```

那么直接子元素就会同时实现：

- 主轴居中。
- 交叉轴居中。

在默认方向下，也就是我们常说的：

**水平居中 + 垂直居中。**

------

### `flex: 1`

Flex 项目还可以通过 `flex` 属性控制自己如何占用父容器中的空间。

例如：

```css
.container {
    display: flex;
}

.item {
    flex: 1;
}
```

HTML：

```html
<div class="container">
    <div class="item">项目1</div>
    <div class="item">项目2</div>
    <div class="item">项目3</div>
</div>
```

三个 `.item` 都设置：

```css
flex: 1;
```

在这个简单场景中，可以先理解为：

**三个项目按照相同的比例分配可用空间。**

因此，三个元素通常会得到相同宽度。

例如父容器存在可分配空间时：

```text
父容器可用空间
┌──────────────────────────────┐
│ 项目1 │ 项目2 │ 项目3       │
│   1   │   1   │   1         │
└──────────────────────────────┘
```

由于三者的比例都是 `1`，所以会进行相对均等的空间分配。

> 补充：`flex` 实际上是一个复合属性，它包含更完整的弹性伸缩规则。当前阶段先掌握 `flex: 1` 常用于让多个 Flex 项目按相同比例分配空间即可。

------

### Flex 实现元素居中排列

例如要制作三个圆形元素：

```html
<div class="container">
    <div class="ball red">1</div>
    <div class="ball blue">2</div>
    <div class="ball purple">3</div>
</div>
```

首先让父容器采用 Flex 布局：

```css
.container {
    display: flex;
    justify-content: center;
}
```

此时 `.container` 是 Flex 容器，三个 `.ball` 是 Flex 项目。

`justify-content: center` 负责让**三个球整体水平居中**。

然后设置圆形：

```css
.ball {
    width: 100px;
    height: 100px;

    border: 2px solid #000;
    border-radius: 50%;

    margin-right: 30px;
}
```

其中：

```css
width: 100px;
height: 100px;
border-radius: 50%;
```

使元素成为圆形。

再分别设置背景颜色：

```css
.red {
    background-color: red;
}

.blue {
    background-color: blue;
}

.purple {
    background-color: purple;
}
```

------

### 嵌套 Flex 布局

这个案例中有一个非常重要的地方：

```css
.container {
    display: flex;
}

.ball {
    display: flex;
}
```

`.container` 和 `.ball` **都设置了 `display: flex`，但作用不同**。

#### `.container` 的 Flex

```css
.container {
    display: flex;
    justify-content: center;
}
```

这里控制的是：

```text
.container
├── .ball
├── .ball
└── .ball
```

也就是**三个球之间如何排列**。

三个 `.ball` 是 `.container` 的 Flex 项目。

#### `.ball` 的 Flex

每一个球内部还有文本，例如：

```html
<div class="ball red">1</div>
```

如果希望数字 `1` 在圆球内部水平、垂直居中，可以让 `.ball` 自己也成为一个 Flex 容器：

```css
.ball {
    display: flex;
    justify-content: center;
    align-items: center;
}
```

此时 `.ball` 控制的是它自己的内部内容：

```text
.ball
└── 文本 1
```

于是：

```css
justify-content: center;
```

让文字在球内水平方向居中；

```css
align-items: center;
```

让文字在球内垂直方向居中。

所以整个结构实际上存在**两层 Flex 布局**：

```text
.container  → Flex 容器
│
├── .ball   → Flex 项目，同时又是 Flex 容器
│   └── 1
│
├── .ball
│   └── 2
│
└── .ball
    └── 3
```

第一层解决：

**三个球怎么排。**

第二层解决：

**每个球里的数字怎么排。**

这是理解 Flex 布局非常重要的一点：**一个元素既可以是父级 Flex 容器中的 Flex 项目，也可以同时成为自己子内容的 Flex 容器。**

------

### 完整示例

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Flex 布局</title>

    <style>
        .container {
            display: flex;
            justify-content: center;
        }

        .ball {
            display: flex;
            justify-content: center;
            align-items: center;

            width: 100px;
            height: 100px;
            margin-right: 30px;

            border: 2px solid #000;
            border-radius: 50%;

            font-size: 50px;
            font-weight: bold;
            color: #fff;
        }

        .red {
            background-color: red;
        }

        .blue {
            background-color: blue;
        }

        .purple {
            background-color: purple;
        }
    </style>
</head>

<body>
    <div class="container">
        <div class="ball red">1</div>
        <div class="ball blue">2</div>
        <div class="ball purple">3</div>
    </div>
</body>
</html>
```

整个处理过程可以理解为：

1. `.container` 使用 `display: flex`，让三个 `.ball` 进入 Flex 布局。
2. `.container` 使用 `justify-content: center`，让三个球整体水平居中。
3. `.ball` 设置相同的宽高和 `border-radius: 50%`，形成圆形。
4. `.ball` 自己再设置 `display: flex`，成为新的 Flex 容器。
5. `.ball` 使用 `justify-content: center` 和 `align-items: center`，让圆球中的数字水平、垂直居中。

> 结论：`z-index` 负责处理元素重叠后的前后层级；Flex 则负责元素之间的排列和对齐。学习 Flex 时最重要的是先找到**谁是 Flex 容器、谁是 Flex 项目**，再判断主轴和交叉轴，最后使用 `justify-content`、`align-items` 等属性控制排列方式。
