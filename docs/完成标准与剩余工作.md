# 完成标准与剩余工作

2026-11-01。以下按已有需求收尾，不继续扩展账号、评论、云同步等已取消功能。

## 预计4批收尾

1. 操作验收：键盘、弹窗焦点、窄屏操作、搜索结果返回、阅读状态及折叠状态。
2. 内容回归：覆盖现有分类、长文和复杂语法；修复发现的缺失、错位、锚点和资源问题。没有实际问题时不为追求检查数量反复重构。
3. 发布候选：完整构建和内容、发布目录检查通过；用户对布局和主要阅读流程集中验收，处理阻塞问题；整理版本记录。
4. 正式切换：远端Linux构建、真实域名验证、保留原站和回退资料。部署及真实回退尚未执行，不能以本地检查替代。

若需求保持不变，预计4～6轮常规迭代进入发布候选；这是工作量判断，不是对远端服务或用户验收时间的保证。每轮应交付可核对结果，新增需求会改变估算。

## 首版完成标准

- 已确认的功能均有实现，所有已知阻塞阅读/搜索/数据保存的问题解决。
- 全部笔记自动检查通过，复杂内容有代表性目视回归记录。
- 构建、内容检查、发布目录检查通过；个人数据备份与恢复可用。
- 用户集中验收通过，使用和编写文档与实现一致。
- 正式域名能访问并通过主要流程核验，原站恢复资料完备。

真实设备、读屏器和所有浏览器不宣称已经全部通过。若发现首版不能接受的问题，应修复后再切换；非阻塞改进可进入后续版本清单。
