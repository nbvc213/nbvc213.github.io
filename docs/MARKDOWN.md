# 笔记 Markdown 编写规范

完整的命名、文件头、排序、显示规则和网站使用方法见 [README 使用与编写手册](../README.md)。本页保留常用语法速查。

笔记标题填写在 YAML 的 `title` 中，正文从 `##` 开始，不再重复写一级标题。自动编号由阅读设置控制，不要手工给各级标题加数字。标题文字决定默认章节标识，编号不会改变地址。

开启自动编号后，正文和目录统一显示“1    标题”“1.1    标题”，编号和标题之间保留清晰间距，不再显示短横线。

## 六种统一内容块

使用下面六个固定英文标记，大小写按示例填写。标记后可以加自定义标题。每行前都保留 `>`，不同内容块之间空一行。

| 含义 | 标记 | 默认行为 |
| --- | --- | --- |
| 注意 | `[!NOTE]` | 展示 |
| 补充 | `[!SUPPLEMENT]` | 可折叠，受全部补充开关控制 |
| 警告 | `[!WARNING]` | 展示 |
| 结论 | `[!CONCLUSION]` | 展示 |
| 练习 | `[!EXERCISE]` | 题目展示、答案折叠 |
| 示例 | `[!EXAMPLE]` | 可折叠，受全部示例开关控制 |

```markdown
> [!NOTE] 可选标题
>
> 注意内容，支持 **加粗**、列表和 `行内代码`。

> [!SUPPLEMENT]
>
> 补充内容。

> [!WARNING]
>
> 警告内容。

> [!CONCLUSION]
>
> 结论内容。

> [!EXAMPLE]
>
> 示例内容。
```

## 一道题一个引用块

`【答案】` 必须单独占一段：前后使用空引用行 `>` 分隔。其后所有内容属于答案与解析，可包含列表、表格、代码和公式。不要把两道题写进同一个练习引用块。

答案不要接在 `【答案】` 同一行，否则同一行的文字不会作为答案正文保留。复杂的多行公式优先作为正文独立段落，并检查实际显示效果。

```markdown
> [!EXERCISE] 单选题
>
> 哪个命令用于编译 Java？
>
> - A. java
> - B. javac
>
> 【答案】
>
> **B。** javac 是编译命令。
```

题目、说明和内容块标题不要使用 `##` 等文章章节标题，避免它们进入本文目录。推荐用粗体或内容块的可选标题。

## 常用正文语法

- 标题：`##` 至 `######`，保持连续层级。
- 强调：`**加粗**`、`*斜体*`、`~~删除~~`；标记内部不要留首尾空格。
- 行内代码用反引号；多行代码用围栏并标注 `java`、`sql`、`html` 等语言。代码中的 HTML 和 Markdown 仅展示，不执行。
- 无序列表用 `-`；有序列表用 `1.`；嵌套项缩进。
- 表格使用竖线与表头分隔行。
- 链接使用 `[说明](/read/文章ID/#章节标识)`；图片使用 `![说明](/media/文件名.png)`。
- 数学公式：`$...$` 行内、`$$...$$` 独立公式，也支持 `\(...\)` 与 `\[...\]`。
- 流程图使用语言为 `mermaid` 的代码围栏。
- 脚注：正文写 `[^名称]`，文末写 `[^名称]: 解释`。
- HTML 仅允许安全展示标签，例如 `kbd`、`sub`、`sup`、`details`、`summary`。不允许脚本、事件属性或任意嵌入网页。

完整可阅读示例见网站的“语法测试”文件夹。测试笔记不修改原有学习笔记。
