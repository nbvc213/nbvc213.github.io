# 项目结构说明

这个项目把 Markdown 笔记转换成静态网页，再由浏览器提供搜索、阅读设置和本机记录。Java 程序只在生成网站时运行，访问者无需安装 Java，也不需要常驻服务器。

## 平时维护笔记

| 位置 | 用途 |
| --- | --- |
| `content/` | 笔记原稿，按分类存放 Markdown 文件 |
| `config/site.yml` | 网站名称、分类名称和说明 |
| `public/media/` | 图片等公开资源 |
| `docs/MARKDOWN.md` | 笔记语法规范，包含注意、补充、警告、结论、练习和示例 |
| `content/examples/` | 三篇语法测试笔记 |

## 开发网站

| 位置 | 用途 |
| --- | --- |
| `src/main/java/` | Java 21 静态网站生成程序 |
| `src/main/resources/templates/page.html` | 网页结构模板 |
| `web/Widgets.vue` | 顶部工具、文章操作、本文目录和继续阅读 |
| `web/Collection.vue` | 笔记列表、书架及本机数据管理 |
| `web/GlobalUi.vue` | 搜索、阅读设置和图片预览 |
| `web/main.ts` | 页面交互、代码显示、公式图表、批注及关联返回 |
| `web/state.ts` | 阅读偏好与浏览器本地记录 |
| `web/style.css` | 笔记内容和基础组件样式 |
| `web/layout.css` | 新版页面布局、主题和手机适配 |
| `scripts/` | 构建、启动、导入与检查工具 |
| `.github/workflows/` | GitHub 自动构建和发布流程 |

## 自动生成的目录

`dist/` 是网站成品；`target/` 是 Java 构建结果；`node_modules/` 是前端依赖；`.tools/` 是本地构建工具。这些目录不用于编写笔记，不要直接修改生成网页，因为下次构建会覆盖。

## 常用操作

在项目目录打开终端：

```powershell
npm.cmd run build
npm.cmd run preview
```

构建完成后访问 http://127.0.0.1:4173/ 。预览服务需要保持运行。修改源文件后重新构建并刷新浏览器；需要自动构建时使用 `npm.cmd run dev`。
