> [!EXERCISE] 单选题
>
> 以下哪个命令用于编译 Java 源文件？
>
> - A. `java`
> - B. `javac`
> - C. `jar`
>
> 【答案】
>
> **B。** `javac` 负责将源文件编译为字节码。

> int a = 3;
> int b = 5;
> System.out.println(a + b);
> ```
>
> 输出为 `8`。一道题和答案放在同一个引用块中。
